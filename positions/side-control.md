# 사이드 컨트롤 (Side Control)

위가 옆에서 가슴을 붙여 누르는 자리 — 위가 크게 유리

이런 모양도 이 포지션이에요: 크로스페이스 사이드 — 왼팔로 상대 얼굴을 상대 왼쪽으로 돌려 누르는 기본형, 언더훅 사이드 — 왼팔을 상대 왼 겨드랑이 아래로 넣어 상체를 묶는다, 기프트 랩 — 상대 오른팔을 상대 목 앞으로 감아 내 손에 넘긴다, 숄더 오브 저스티스 — 어깨로 상대 턱을 눌러 고개를 못 돌리게 한다

## 아래에서

### 목표 (순서대로)

1. 목과 팔을 지키며 숨 쉴 공간을 만든다
2. 엉덩이를 빼서 무릎을 넣고 가드나 하프가드를 되찾는다
3. 안 되면 터틀이나 무릎으로 일어나 다시 시작한다

### 핵심

- 내 오른 팔꿈치 · 팔뚝은 상대 골반에, 왼 팔뚝은 상대 목에 프레임
- 팔은 몸에 붙인다 — 팔을 펴서 밀면 아메리카나 · 기무라를 당한다
- 엉덩이는 내 왼쪽으로 빼고 생긴 틈에 내 오른 무릎을 넣는다
- 옆으로 누워 상대를 본다 — 등이 바닥에 붙으면 아무것도 못 한다

### 상대가 ~하면

- 상대 무게가 가슴에 실려 있으면 → [사이드 이스케이프 (프레임 · 쉬림프)](../techniques/side-control-escape.md)
- 상대가 내 머리 쪽으로 무게를 옮기면 → [터틀로 돌기 (사이드)](../techniques/roll-to-turtle.md) 또는 [싯아웃 (사이드)](../techniques/sit-out-from-side-control.md)
- 상대가 마운트로 다리를 넘기려 하면 → [브릿지 앤 롤 (사이드)](../techniques/bridge-and-roll-from-side.md) 또는 [고스트 이스케이프](../techniques/ghost-escape.md)
- 상대가 팔을 잡아 고정하려 하면 → [팔 빼내기 (사이드 아래)](../techniques/arm-extraction.md)

### 흔한 실수

- 팔을 쭉 펴서 상대를 밀면 팔을 잡힌다 → 팔꿈치를 굽혀 팔뚝으로 프레임한다
- 브릿지만 하고 엉덩이를 안 빼면 제자리로 돌아온다 → 브릿지로 띄운 순간 엉덩이를 내 왼쪽으로 뺀다
- 상대에게 등을 보이며 돌면 백을 준다 → 무릎을 넣거나 터틀에서 바로 무릎 · 손으로 버틴다

### 드릴

- 프레임 → 브릿지 → 새우빼기 → 무릎 넣기를 파트너가 가볍게 누른 상태로 좌우 10번
- 혼자 새우빼기로 매트 끝까지 왕복

## 위에서

### 목표 (순서대로)

1. 상대가 무릎을 넣거나 몸을 돌리지 못하게 자리를 지킨다
2. 마운트나 니 온 밸리로 더 좋은 자리를 간다
3. 상대가 팔을 내놓으면 서브미션을 건다

### 핵심

- 양 무릎을 상대 오른쪽 옆구리에 붙이고 엉덩이는 낮게 둔다
- 내 왼팔로 크로스페이스 — 상대 얼굴을 상대 왼쪽으로 돌려 놓는다
- 내 오른팔로 상대 오른팔(가까운 팔)을 막고 상대 골반에 붙여 무릎이 못 들어오게 한다
- 무게는 손이 아니라 가슴과 엉덩이로 싣는다

### 상대가 ~하면

- 상대가 왼팔을 펴서 내 목이나 얼굴을 밀면 → [아메리카나 (사이드)](../techniques/americana-side.md) 또는 [기무라 (사이드)](../techniques/kimura-side.md)
- 상대가 무릎을 넣으려 하면 → [사이드 → 니 온 밸리](../techniques/side-to-knee-on-belly.md) 또는 [사이드에서 마운트 가기](../techniques/side-to-mount.md)
- 상대가 나를 향해 돌아 들어오면 → [남북](../techniques/north-south.md) 또는 [다스 초크](../techniques/darce-choke.md)
- 상대 왼팔이 상대 목 앞을 지나가면 → [암 트라이앵글 (헤드 앤 암)](../techniques/arm-triangle.md)
- 상대가 계속 버티기만 하면 → [사이드 컨트롤 유지](../techniques/side-control-maintain.md)

### 흔한 실수

- 엉덩이를 높이 들면 상대 무릎이 들어와 하프가드가 된다 → 엉덩이를 내리고 무릎을 옆구리에 붙인다
- 크로스페이스가 느슨하면 상대가 나를 향해 돌아 빠진다 → 왼팔로 얼굴을 계속 상대 왼쪽으로 밀어 둔다
- 서브미션만 쫓다 무게를 빼면 자리를 잃는다 → 자리를 먼저 지키고 팔이 나올 때만 건다

### 드릴

- 파트너가 절반 힘으로 빠져나오고 나는 1분 동안 사이드 컨트롤 유지만, 5라운드
- 사이드 → 니 온 밸리 → 마운트 → 사이드를 쉬지 않고 10바퀴

## 관련 개념

- [프레임](../concepts/frames.md) — 팔·다리 뼈를 버팀목처럼 세워 상대 무게를 막고 움직일 공간을 지키는 것
- [새우(힙 이스케이프)](../concepts/hip-escape.md) — 옆으로 누워 엉덩이를 상대에게서 빼내 다리를 다시 넣을 공간을 만드는 움직임
- [브릿지](../concepts/bridge.md) — 발과 어깨로 받쳐 엉덩이를 들어 올려 위 사람의 무게를 흔드는 움직임
- [언더훅](../concepts/underhook.md) — 내 팔을 상대 겨드랑이 밑으로 넣어 등을 감싸 몸통을 조종하는 그립
- [크로스페이스](../concepts/crossface.md) — 팔과 어깨로 상대 얼굴을 반대로 돌려 몸을 못 돌리게 묶는 위쪽 컨트롤
- [팔꿈치 · 무릎 붙이기](../concepts/elbow-knee.md) — 팔꿈치와 무릎을 붙여 몸통 옆 빈틈을 막아 패스와 팔 공격을 막는 것
- [거리 조절](../concepts/distance.md) — 다음에 할 동작에 맞게 상대와의 간격을 붙이거나 벌리는 것
- [압박(프레셔)](../concepts/pressure.md) — 몸무게를 정해진 곳에 실어 상대가 원하는 움직임을 못 하게 막는 힘
- [어깨 압박](../concepts/shoulder-pressure.md) — 어깨로 상대 턱·가슴에 무게를 실어 상체를 돌리지 못하게 묶는 압박
- [엉덩이 · 허리 압박](../concepts/hip-pressure.md) — 엉덩이를 낮추고 상대 골반에 붙여 새우·브릿지를 못 하게 막는 압박
- [머리 위치](../concepts/head-position.md) — 내 머리와 상대 머리를 어디 두느냐로 균형과 누르기가 달라진다
- [쐐기(웨지)](../concepts/wedges.md) — 무릎 · 정강이 · 팔꿈치를 틈에 끼워 공간을 지키고 압박 길을 막는 것
- [포지션 먼저, 서브미션은 나중](../concepts/position-before-submission.md) — 서브미션보다 먼저 확실한 자리와 누르기를 만든다
- [포지션 서열](../concepts/positional-hierarchy.md) — 어느 자리가 더 유리한지 순서를 알고 한 칸씩 올라가는 것
- [탈출의 기본 순서](../concepts/escape-basics.md) — 깔렸을 때 목 · 팔 지키기 → 프레임 → 엉덩이 빼기 → 가드 되찾기 순서
- [눌릴 때 버티기](../concepts/defense-under-pressure.md) — 위에서 체중으로 누를 때 숨 쉬며 버티고, 작게 틈을 모아 빠지는 법
- [패스의 3단계](../concepts/passing-phases.md) — 패스는 그립 풀기 → 다리 지나가기 → 눌러 고정하기 세 가지 일
- [전환 때 잃지 않기](../concepts/transition.md) — 자리를 옮기는 순간 잡은 걸 놓치지 않고, 막히면 돌아갈 길을 남기는 것
- [관절기 원리](../concepts/joint-locks.md) — 관절을 원래 굽는 방향과 반대로 밀거나 비틀어 탭을 받는 원리
- [팔 · 다리 떼어 내기](../concepts/limb-isolation.md) — 공격할 팔 · 다리를 상대 몸통과 다른 팔다리의 도움에서 떼어 놓는 것
- [화이트 벨트 길잡이](../concepts/beginner-roadmap.md) — 포지션 이름과 내 할 일부터 알고, 작은 기술 묶음 하나로 시작하기
- [포지션 스파링](../concepts/positional-sparring.md) — 정한 자리에서 시작해 각자 목표를 이루면 다시 시작하는 짧은 스파링
- [흘러가는 롤링(플로우 롤)](../concepts/flow-rolling.md) — 이기려 하지 않고 서로 움직임을 주고받으며 천천히 이어 가는 롤링
- [지면서 배우기](../concepts/investing-in-loss.md) — 진 장면 하나를 골라 그 바로 앞부터 다시 연습해 배우는 것
- [미리 막기](../concepts/prevention-over-cure.md) — 완전히 잡히고 나서 빠지기보다 잡히기 직전에 막는 게 훨씬 쉽다
- [힘 아끼기](../concepts/energy-conservation.md) — 쓸데없는 힘은 빼고, 자리를 좋게 하거나 급한 위험을 막는 데만 힘을 쓰는 것
- [동작을 작게 다듬기](../concepts/smaller-circles.md) — 기술 하나에서 필요 없는 동작을 빼며 작고 정확하게 다듬어 가는 연습법
- [목적 있는 방어](../concepts/defend-with-purpose.md) — 막기만 하지 말고, 막으면서 다음에 갈 작은 목표를 정해 두는 방어
- [시합 점수 (IBJJF)](../concepts/competition-scoring.md) — 테이크다운 · 스윕 · 니 온 밸리 2점, 가드 패스 3점, 마운트 · 백 4점 — 자세를 3초 지켜야 점수
