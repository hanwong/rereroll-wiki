# 니 온 밸리 (Knee on Belly)

위가 무릎으로 배를 누르며 움직이는 자리 — 위가 유리하지만 덜 안정

이런 모양도 이 포지션이에요: 니 온 밸리 기본 — 오른 무릎 배 위, 왼다리는 펴서 버팀, 리버스 니 온 밸리 — 상대 다리 쪽을 보고 무릎을 올린다

## 아래에서

### 목표 (순서대로)

1. 배 위 무릎을 밀어 숨을 쉬고 무게를 뺀다
2. 엉덩이를 빼서 무릎을 넣고 가드를 되찾는다
3. 팔을 내주지 않는다

### 핵심

- 양 팔뚝으로 상대 오른 무릎 · 골반에 프레임
- 엉덩이를 내 왼쪽으로 빼고 생긴 틈에 내 오른 무릎을 넣는다
- 팔을 쭉 펴서 상대 몸을 밀지 않는다 — 팔꿈치는 굽혀 붙인다
- 상대에게 등을 돌리지 않는다

### 상대가 ~하면

- 상대 무릎에 프레임이 들어가면 → [니 온 밸리 이스케이프](../techniques/knee-on-belly-escape.md)
- 상대 무게가 앞으로 쏠려 무릎이 무거우면 → [터틀로 돌기 (니 온 밸리 아래)](../techniques/turn-to-turtle-from-kob.md)
- 상대가 무릎을 내리고 사이드로 누르면 → [사이드 이스케이프 (프레임 · 쉬림프)](../techniques/side-control-escape.md)

### 흔한 실수

- 팔을 펴서 상대 가슴을 밀면 파 사이드 암바를 당한다 → 팔꿈치를 굽혀 무릎 쪽만 민다
- 상대에게 등을 보이며 내 왼쪽으로 엎드리면 백을 준다 → 상대 쪽을 보며 엉덩이를 뺀다
- 누운 채 버티기만 하면 계속 눌린다 → 바로 프레임과 엉덩이 빼기를 시작한다

### 드릴

- 파트너가 니 온 밸리로 가볍게 누르고 나는 프레임 → 새우빼기 → 무릎 넣기를 10번

## 위에서

### 목표 (순서대로)

1. 무릎 압박으로 상대가 반응하게 만든다
2. 상대가 밀면 서브미션, 돌면 마운트나 백으로 간다
3. 상대가 빠지면 바로 사이드로 내려가 자리를 지킨다

### 핵심

- 내 오른쪽 무릎은 상대 명치 · 아랫갈비에 — 가슴 위로 너무 올리지 않는다
- 내 왼손 상대 오른쪽 깃, 내 오른손 허리띠나 바지
- 내 왼다리는 넓게 펴서 버티고 발로 가볍게 움직일 준비
- 엉덩이는 들고 몸은 앞으로 — 뒤로 앉지 않는다

### 상대가 ~하면

- 상대가 왼팔로 내 무릎이나 다리를 밀면 → [파 사이드 암바 (니 온 밸리)](../techniques/far-side-armbar-from-kob.md)
- 상대가 가만히 버티면 → [베이스볼 배트 초크](../techniques/baseball-bat-choke.md) 또는 [크로스 칼라 초크 (니 온 밸리)](../techniques/cross-collar-choke-from-kob.md)
- 상대가 내 무릎을 피해 엉덩이를 빼면 → [니 온 밸리 → 마운트](../techniques/kob-to-mount.md) 또는 [니 온 밸리 → 사이드](../techniques/kob-to-side-control.md)
- 상대가 등을 돌려 엎드리려 하면 → [백 테이크 (니 온 밸리, 상대가 돌아설 때)](../techniques/kob-to-back-take.md)
- 상대가 내 쪽으로 돌아 들어오면 → [니 온 밸리 스위치 (반대쪽으로 옮기기)](../techniques/kob-switch-sides.md)

### 흔한 실수

- 무릎에 무게를 다 싣고 멈추면 균형을 잃고 스윕된다 → 발은 가볍게, 계속 조정한다
- 버티는 다리를 상대 몸에 붙이면 상대가 다리를 잡고 넘긴다 → 왼다리를 넓게 편다
- 그립 없이 무릎만 올리면 상대가 쉽게 돈다 → 깃과 허리띠를 잡고 올린다

### 드릴

- 사이드 → 니 온 밸리 → 상대 왼쪽 니 온 밸리 → 사이드를 쉬지 않고 10바퀴
- 파트너가 절반 힘으로 빠지고 나는 니 온 밸리 유지만 1분, 5라운드
