# 곁누르기 (Kesa Gatame)

위가 옆에 앉아 목과 팔을 감아 누르는 유도식 누르기 — 위가 유리

이런 모양도 이 포지션이에요: 곁누르기 (혼 케사) — 오른팔로 목 뒤를 감고 상대 오른팔을 왼 겨드랑이에 낀다, 변형 곁누르기 (쿠즈레 케사) — 목 대신 상대 왼 겨드랑이에 언더훅, 리버스 곁누르기 — 상대 발 쪽을 보고 앉아 상대 오른팔을 오른 겨드랑이에 낀다

## 아래에서

### 목표 (순서대로)

1. 끼인 오른팔과 목을 지킨다
2. 상대를 브릿지로 흔들어 등이나 가드를 찾는다
3. 안 되면 팔을 빼고 상대를 향해 돌아 무릎을 넣는다

### 핵심

- 끼인 오른팔은 팔꿈치를 굽혀 상대 허리 쪽으로 붙인다
- 내 왼손은 상대 허리띠나 등에 — 상대 무게를 당겨 흔든다
- 내 오른쪽으로 브릿지한 뒤 엉덩이는 왼쪽으로 뺀다
- 왼팔을 상대 얼굴에 펴서 밀지 않는다

### 상대가 ~하면

- 상대 무게가 내 가슴 위로 높이 올라오면 → [브릿지 이스케이프 (곁누르기)](../techniques/bridge-escape-from-kesa.md)
- 브릿지로 상대가 등을 짚으면 → [백 테이크 (곁누르기 아래)](../techniques/back-take-from-kesa.md)
- 상대가 내 머리 쪽으로 몸을 기울이면 → [다리로 머리 걸어 빼기 (곁누르기 아래)](../techniques/kesa-leg-hook-escape.md)
- 상대가 목 대신 언더훅으로 바꾸면 → [팔 빼고 가드 회복 (변형 곁누르기 아래)](../techniques/arm-recovery-to-guard-kesa.md)
- 위 방법이 막히면 → [곁누르기 이스케이프](../techniques/escape-kesa-gatame.md)

### 흔한 실수

- 왼팔로 상대 얼굴을 쭉 밀면 아메리카나 · 기무라를 당한다 → 왼손은 허리띠 · 등에 둔다
- 끼인 오른팔을 펴서 당기면 팔이 꺾인다 → 팔꿈치를 굽혀 몸 쪽으로 붙인다
- 브릿지 없이 엉덩이만 빼려 하면 안 빠진다 → 브릿지로 띄운 순간 엉덩이를 뺀다

### 드릴

- 파트너가 곁누르기로 가볍게 누르고, 나는 허리띠 잡고 브릿지 → 엉덩이 빼기를 10번

## 위에서

### 목표 (순서대로)

1. 상대 머리와 오른팔을 묶어 몸을 못 돌리게 누른다
2. 상대가 빼려는 팔을 서브미션으로 바꾼다
3. 버티기 힘들면 사이드나 마운트로 옮긴다

### 핵심

- 상대 오른팔을 내 왼 겨드랑이에 꽉 끼우고, 내 오른팔로 목 뒤를 감는다
- 내 오른다리는 앞, 왼다리는 뒤로 넓게 벌려 굴러가지 않게 받친다
- 엉덩이는 바닥에 낮게, 무게는 가슴 옆구리로 상대 가슴에
- 내 등이 상대 쪽으로 드러나니 상대 왼손이 등 뒤로 오는지 본다

### 상대가 ~하면

- 상대가 왼팔로 내 얼굴을 밀면 → [아메리카나 (곁누르기)](../techniques/americana-from-kesa.md) 또는 [기무라 (곁누르기)](../techniques/kimura-from-kesa.md)
- 상대가 끼인 오른팔을 펴서 빼려 하면 → [스트레이트 암락 (곁누르기)](../techniques/kesa-straight-armlock.md)
- 상대가 브릿지로 나를 넘기려 하면 → [곁누르기 → 사이드](../techniques/kesa-to-side-control.md)
- 상대가 목을 빼려 하면 → [변형 곁누르기](../techniques/kuzure-kesa-gatame.md)
- 상대 다리가 멀리 있고 엉덩이가 납작하면 → [곁누르기 → 마운트](../techniques/kesa-to-mount.md)

### 흔한 실수

- 상대 가슴 위에 높이 앉으면 브릿지에 넘어간다 → 엉덩이를 바닥으로 내린다
- 다리를 모으면 굴러간다 → 오른다리는 앞, 왼다리는 뒤로 넓게
- 서브미션 하려고 목을 놓으면 상대가 바로 돌아 들어온다 → 목 · 팔을 잡은 채로 건다

### 드릴

- 파트너가 브릿지 · 새우빼기로 빠지고 나는 곁누르기 유지만 1분, 5라운드
- 곁누르기 → 변형 곁누르기 → 리버스 곁누르기 → 사이드 흐르기 10바퀴
