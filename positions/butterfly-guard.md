# 버터플라이 가드 (Butterfly Guard)

앉아서 두 발 훅을 상대 허벅지 안에 넣는 가드 — 들어 올려 넘기기

이런 모양도 이 포지션이에요: 버터플라이 하프 — 한쪽은 하프로 감고 한 발만 훅, 싱글 버터플라이 — 한 발 훅, 다른 다리로 거리 조절, 버터플라이 → X 가드 — 상대를 들어 올린 뒤 X 가드로 들어간다

## 아래에서

### 목표 (순서대로)

1. 상체를 세우고 상대를 내 쪽으로 붙인다
2. 언더훅 · 소매로 상대를 기울여 훅으로 들어 넘긴다
3. 막히면 백 · X 가드로 이어 간다

### 핵심

- 내 오른팔 상대 왼팔 밑 언더훅, 내 왼손 상대 오른쪽 소매 · 손목
- 등은 세우고 머리는 상대 가슴 · 턱 밑에 붙인다
- 내 오른발 훅을 상대 왼쪽 허벅지 안에 걸어 둔다
- 눕는 것과 훅으로 드는 것을 한 번에 한다

### 상대가 ~하면

- 상대가 무게를 앞으로 실으면 → [버터플라이 스윕](../techniques/butterfly-sweep.md) 또는 [엘리베이터 스윕](../techniques/elevator-sweep.md)
- 상대 오른팔이 뻗어 나오면 → [암 드래그 → 백 (버터플라이)](../techniques/arm-drag-to-back-butterfly.md)
- 상대가 뒤로 버티며 서려 하면 → [버터플라이 → X 가드](../techniques/butterfly-guard-to-x-guard.md) · 다리를 빼며 일어서면 [애시 가라미 (스트레이트 애시)](../techniques/ashi-garami.md)
- 상대 머리가 내 앞에 내려오면 → [길로틴 (버터플라이)](../techniques/guillotine-from-butterfly.md) 또는 [길로틴 스윕 (버터플라이)](../techniques/butterfly-sweep-with-guillotine.md)
- 상대가 눌러 훅이 하나 빠지면 → [버터플라이 하프가드](../techniques/butterfly-half-guard.md)

### 흔한 실수

- 등을 대고 누우면 훅이 힘을 못 쓴다 → 앉아서 상체를 세운다
- 언더훅 없이 훅만 쓰면 상대가 무겁게 누른다 → 언더훅 · 소매를 먼저 잡는다
- 발목을 상대 허벅지 밖에 두면 쉽게 패스당한다 → 훅을 허벅지 안쪽에 깊게 건다

### 드릴

- 앉은 자세에서 훅으로 파트너 다리 들기 · 내리기 20회
- 버터플라이 스윕 좌우 번갈아 10회

## 위에서

### 목표 (순서대로)

1. 훅의 힘을 빼고 균형을 지킨다
2. 상대 언더훅 · 그립을 끊는다
3. 훅을 눌러 지나가거나 일어서서 패스한다

### 핵심

- 엉덩이를 낮추고 다리를 넓게 벌려 들리지 않는다
- 무게를 앞으로 싣지 않는다 — 앞으로 쏠리면 그대로 들려 넘어간다
- 상대 오른팔 언더훅을 막고 내 언더훅을 먼저 넣는다
- 무릎을 상대 몸 가운데로 모아 훅을 누른다

### 상대가 ~하면

- 상대가 두 훅을 넣고 바로 앉아 있으면 → [버터플라이 훅 컨트롤 패스](../techniques/pass-butterfly-hook-control.md)
- 상대가 뒤로 기대며 거리를 만들면 → [버터플라이 스매시 패스](../techniques/butterfly-smash.md) 또는 [롱 스텝 패스](../techniques/long-step-pass.md)
- 상대가 팔을 뻗어 거리를 두면 → [더블 언더 패스 (스택)](../techniques/double-under-pass.md) 또는 [오버 언더 패스](../techniques/over-under-pass.md)
- 상대가 버터플라이 하프로 바꾸면 → [니슬라이스 패스](../techniques/knee-slice-pass.md)

### 흔한 실수

- 앞으로 기대며 누르면 훅에 그대로 들린다 → 엉덩이를 뒤로 두고 상체를 세운다
- 훅을 바깥으로 벌려 떼려 하면 더 단단히 걸린다 → 무릎을 가운데로 모아 누른다
- 언더훅을 내주면 엘리베이터 · 백 테이크가 온다 → 팔을 겨드랑이에 붙여 막는다

### 드릴

- 파트너가 훅으로 들어 올릴 때 넓은 베이스로 버티기 1분
- 훅 눌러 스매시 패스 10회
