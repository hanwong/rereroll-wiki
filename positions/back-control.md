# 백 컨트롤 (Back Control)

상대 등 뒤에 붙어 훅과 시트벨트로 잡은 자세 — 위가 가장 유리

이런 모양도 이 포지션이에요: 시트벨트 — 내 오른팔은 상대 오른 어깨 위, 왼팔은 왼 겨드랑이 밑으로 두 손을 잡는다, 투 훅 — 두 발등을 상대 허벅지 안쪽에 걸어 엉덩이를 묶는다, 바디 트라이앵글 — 내 왼다리를 배 앞에 두르고 왼 발목을 오른 무릎 뒤에 잠근다, 훅 없는 시트벨트 — 다리가 걸리기 전, 상체만 붙잡은 상태

## 아래에서

### 목표 (순서대로)

1. 목부터 지킨다
2. 훅을 떼고 등을 바닥 쪽으로 내려온다
3. 돌아서 상대를 마주 보고 가드나 위로 간다

### 핵심

- 턱을 당기고 두 손으로 상대 오른 손목(조르는 팔)을 잡아 아래로 끌어내린다
- 조르는 팔 쪽인 내 오른쪽 어깨를 바닥에 붙이며 미끄러져 내려간다
- 상대 오른발 훅을 떼고 상대 오른다리를 넘어 내 왼쪽으로 돌아선다
- 엎드리지 말고 등을 상대 가슴 쪽, 바닥 쪽으로 기댄다

### 상대가 ~하면

- 상대가 시트벨트로 목을 노리면 → [핸드 파이팅 (백 아래)](../techniques/hand-fighting-from-back.md)
- 목을 지킨 뒤 상대 오른발 훅이 느슨하면 → [백 이스케이프](../techniques/back-escape.md) 또는 [숄더 워크 이스케이프](../techniques/shoulder-walk-escape.md)
- 상대 훅이 하나 빠지면 → [돌아서 마주 보기 (백 아래)](../techniques/turn-into-opponent.md)
- 상대가 바디 트라이앵글을 걸면 → [바디 트라이앵글 빠져나오기](../techniques/body-triangle-escape-to-side.md) 또는 [바디 트라이앵글 빠져나오기 (하프가드로)](../techniques/body-triangle-escape-to-half-guard.md)
- 상대가 다리 없이 시트벨트만 잡으면 → [시트벨트 빠져나오기](../techniques/escape-seat-belt-control.md)

### 흔한 실수

- 언더훅 쪽인 내 왼쪽으로 빠지면 상대가 다시 올라탄다 → 조르는 팔 쪽인 오른쪽 어깨로 내려간다
- 목을 비워 두고 손으로 훅부터 떼면 바로 초크가 들어온다 → 목을 지킨 다음 훅
- 앞으로 엎드리면 상대가 납작하게 눌러 버린다 → 등을 바닥 쪽으로 기댄다

### 드릴

- 상대는 시트벨트만 잡고 조르려 하고, 아래는 30초 손싸움 반복
- 혼자 누워 오른쪽 어깨로 바닥을 걸어 내려가는 숄더 워크 10회

## 위에서

### 목표 (순서대로)

1. 가슴을 등에 붙이고 훅과 시트벨트를 놓치지 않는다
2. 손싸움에서 이겨 목을 연다
3. 리어 네이키드 초크로 끝낸다

### 핵심

- 내 오른팔(조르는 팔)은 상대 오른 어깨 위, 왼팔은 왼 겨드랑이 밑, 두 손을 붙여 잡는다
- 가슴을 상대 등에 붙이고 내 머리는 상대 머리 오른쪽에 바짝 댄다
- 발등은 상대 허벅지 안쪽 깊이 걸고, 상대 배 앞에서 발목을 꼬지 않는다
- 눕는 방향은 언더훅 쪽인 내 왼쪽으로 함께 눕는다

### 상대가 ~하면

- 상대 턱이 들려 목이 열리면 → [리어 네이키드 초크](../techniques/rear-naked-choke.md)
- 상대가 두 손으로 내 조르는 팔을 막고 버티면 → [보우 앤 애로우 초크](../techniques/bow-and-arrow-choke.md) 또는 [암바 (백)](../techniques/armbar-from-back.md)
- 상대가 손으로 내 훅을 떼려 하면 → [바디 트라이앵글](../techniques/body-triangle.md)
- 상대가 목만 지키고 팔을 높이 들면 → [백 → 크루시픽스](../techniques/back-control-to-crucifix.md)
- 상대가 등을 바닥에 붙이며 돌아누우면 → [백 → 마운트 (상대가 등을 바닥에 붙일 때)](../techniques/back-to-mount-transition.md)

### 흔한 실수

- 상대 배 앞에서 발목을 꼬면 상대가 다리로 내 발목을 꺾는다 → 훅을 걸거나 바디 트라이앵글로 잠근다
- 뒤로 기대 가슴이 떨어지면 상대가 돌아선다 → 가슴과 엉덩이를 상대에게 붙인다
- 시트벨트를 일찍 풀고 목부터 노리면 상대 두 손에 막힌다 → 손싸움으로 팔을 내린 뒤 조른다

### 드릴

- 상대는 백 탈출만 시도, 위는 초크 없이 2분 동안 유지
- 시트벨트 → 손싸움 → 리어 네이키드 초크 세팅을 천천히 10회

## 관련 개념

- [각도 잡기](../concepts/angle.md) — 상대 정면을 피해 비스듬한 자리를 잡아 공격 길을 여는 것
- [그립](../concepts/grips.md) — 손으로 상대 몸이나 도복을 잡아 움직임과 거리를 조절하는 것
- [손싸움(그립 파이팅)](../concepts/grip-fighting.md) — 내 그립은 먼저 잡고 상대 그립은 못 잡게 하는 손의 싸움
- [훅](../concepts/hooks.md) — 팔이나 발을 갈고리처럼 걸어 상대를 따라가고 들어 올리는 연결
- [연결(커넥션)](../concepts/connection.md) — 그립 · 훅 · 몸 접촉으로 상대 움직임을 느끼고 조종하는 것
- [포지션 먼저, 서브미션은 나중](../concepts/position-before-submission.md) — 서브미션보다 먼저 확실한 자리와 누르기를 만든다
- [포지션 서열](../concepts/positional-hierarchy.md) — 어느 자리가 더 유리한지 순서를 알고 한 칸씩 올라가는 것
- [양자택일 만들기(포크 어택)](../concepts/dilemma.md) — 한 자리에서 두 공격을 함께 걸어 상대가 하나는 꼭 당하게 만드는 것
- [서브미션 방어 순서](../concepts/submission-defense.md) — 걸리기 전에 막고, 걸리면 상대가 잡은 조건을 하나씩 풀고, 늦으면 탭하는 순서
- [전환 때 잃지 않기](../concepts/transition.md) — 자리를 옮기는 순간 잡은 걸 놓치지 않고, 막히면 돌아갈 길을 남기는 것
- [조르기 두 종류(혈관 · 기도)](../concepts/chokes.md) — 목 옆 혈관을 누르는 조르기와 목 앞 숨길(기도)을 누르는 조르기의 차이
- [팔 · 다리 떼어 내기](../concepts/limb-isolation.md) — 공격할 팔 · 다리를 상대 몸통과 다른 팔다리의 도움에서 떼어 놓는 것
- [탭 · 안전](../concepts/tap-safety.md) — 위험하면 일찍 탭하고, 상대가 탭하면 바로 놓는 약속
- [화이트 벨트 길잡이](../concepts/beginner-roadmap.md) — 포지션 이름과 내 할 일부터 알고, 작은 기술 묶음 하나로 시작하기
- [포지션 스파링](../concepts/positional-sparring.md) — 정한 자리에서 시작해 각자 목표를 이루면 다시 시작하는 짧은 스파링
- [롤링 세기 고르기](../concepts/training-intensity.md) — 이번 판이 뭘 연습하는 판인지에 맞춰 속도와 버티는 정도를 정하는 것
- [지면서 배우기](../concepts/investing-in-loss.md) — 진 장면 하나를 골라 그 바로 앞부터 다시 연습해 배우는 것
- [돌아올 곳이 있는 공격](../concepts/attack-with-fallback.md) — 공격이 막혔을 때 돌아갈 자리까지 정해 두고 들어가는 것
- [미리 막기](../concepts/prevention-over-cure.md) — 완전히 잡히고 나서 빠지기보다 잡히기 직전에 막는 게 훨씬 쉽다
- [힘 아끼기](../concepts/energy-conservation.md) — 쓸데없는 힘은 빼고, 자리를 좋게 하거나 급한 위험을 막는 데만 힘을 쓰는 것
- [목적 있는 방어](../concepts/defend-with-purpose.md) — 막기만 하지 말고, 막으면서 다음에 갈 작은 목표를 정해 두는 방어
- [시합 점수 (IBJJF)](../concepts/competition-scoring.md) — 테이크다운 · 스윕 · 니 온 밸리 2점, 가드 패스 3점, 마운트 · 백 4점 — 자세를 3초 지켜야 점수
