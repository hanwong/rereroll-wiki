# X 가드 · 싱글 레그 X · 앵클락 (X-Guard, SLX & Ankle Lock)

아래가 서 있는 상대 다리 밑에서 양다리로 한 다리를 묶어 띄우는 가드

이런 모양도 이 포지션이에요: X 가드 — 상대 왼다리를 내 오른쪽 어깨에 안고, 내 왼발은 상대 오른쪽 오금, 오른발은 상대 오른쪽 허벅지, 싱글 레그 X — 상대 왼쪽 발목을 내 오른쪽 겨드랑이에 안고 내 오른발은 상대 왼쪽 골반, 리버스 X — 상대 오른다리를 내 왼쪽 어깨에 안고 내 오른다리로 상대 왼쪽 오금을 건다, 스트레이트 앵클락 — 싱글 레그 X에서 상대 왼발을 내 오른팔로 감아 내 오른쪽으로 눕는다

## 아래에서

### 목표 (순서대로)

1. 상대 한 다리를 묶어 무게를 받칠 다리를 없앤다
2. 다리를 펴고 당겨 상대를 띄워 스윕하고 일어선다
3. 상대가 다리를 빼면 싱글 레그 X로 바꿔 스윕이나 앵클락을 노린다

### 핵심

- 상대 왼다리를 내 오른팔로 꽉 안고 머리를 그 다리 가까이 둔다
- 내 왼발은 상대 오른쪽 오금 깊이 걸고, 내 오른발로 상대 허벅지를 밀어 X 모양을 유지한다
- 엉덩이를 상대 다리 밑으로 붙여 넣어 상대가 내 위로 무게를 싣게 한다
- 스윕 뒤에는 상대 다리를 안은 채 바로 일어서 위를 차지한다

### 상대가 ~하면

- 상대가 앞으로 몸을 숙여 무게를 실으면 → [X 가드 스윕](../techniques/x-guard-sweep.md)
- 상대가 뒤로 버티며 다리를 빼려 하면 → [토마호크 스윕](../techniques/tomahawk-sweep.md) 또는 [X 가드 → 일어나기](../techniques/x-guard-technical-stand-up.md)
- 상대가 묶인 다리를 뒤로 빼면 → [X 가드 → 싱글 레그 X](../techniques/x-guard-to-single-leg-x.md)
- 상대 왼발이 내 오른쪽 겨드랑이에 안긴 채 서 있으면 → [싱글 레그 X 스윕](../techniques/single-leg-x-sweep.md) 또는 [스트레이트 앵클락](../techniques/straight-ankle-lock.md) · 무릎을 안으로 돌려 버티면 [애시 가라미 (스트레이트 애시)](../techniques/ashi-garami.md)
- 상대가 등을 돌리며 빠지려 하면 → [X 가드 → 백 테이크](../techniques/x-guard-back-take.md)

### 흔한 실수

- 상대 다리를 느슨하게 안으면 상대가 다리를 빼고 눌러 버린다 → 머리와 팔을 다리에 붙여 꽉 안는다
- 오금 훅이 얕으면 다리를 펴도 상대가 뜨지 않는다 → 내 왼발을 오금 깊이 건다
- 스윕하고 누운 채 있으면 상대가 다시 가드를 만든다 → 넘어가는 순간 일어서서 위로 올라간다

### 드릴

- 파트너가 서 있을 때 앉은 자세에서 다리 밑으로 들어가 X 가드를 만드는 진입 10번
- X 가드에서 파트너가 무게를 앞·뒤로 옮길 때마다 맞는 스윕 방향으로 다리를 펴는 반응 연습

## 위에서

### 목표 (순서대로)

1. 묶인 다리를 지키며 넘어가지 않을 만큼 자세를 낮춘다
2. 상대 훅 두 개 중 하나를 먼저 떼어 X 모양을 무너뜨린다
3. 훅이 풀리면 다리를 누르고 패스해 사이드로 간다

### 핵심

- 똑바로 서지 말고 무릎을 굽혀 엉덩이를 낮추고 몸을 살짝 앞으로 둔다
- 풀린 오른발은 넓게 짚어 넘어지지 않을 바닥을 만든다
- 상대 소매·깃 그립을 떼서 내 상체를 끌고 다니지 못하게 한다
- 오금에 걸린 훅이 가장 위험하니 그 훅부터 떼어 낸다

### 상대가 ~하면

- 상대 훅이 깊고 나를 띄우기 시작하면 → [스매시 패스 (X 가드 상대)](../techniques/smash-pass-from-x-guard.md)
- 상대 훅이 얕거나 지쳐 느슨하면 → [무릎 눌러 X 가드 패스](../techniques/knee-pin-from-x-guard.md) 또는 [스텝 오버 (X 가드 상대)](../techniques/step-over-from-x-guard.md)
- 아직 서 있을 수 있고 거리가 있으면 → [X 가드 빠져나오기 (서서)](../techniques/standing-escape-from-x-guard.md)
- 상대가 싱글 레그 X로 바꾸면 → [싱글 레그 X 빠져나오기 (서서)](../techniques/standing-escape-from-slx.md) 또는 [백스텝 (싱글 레그 X 상대)](../techniques/backstep-from-single-leg-x.md)
- 상대가 내 왼발에 앵클락을 걸면 → [앵클락 빠져나오기](../techniques/ankle-lock-escape.md) · 힐훅 · 토홀드를 노리면 [하체 관절기 방어 (무릎 선 지키기 · 뒤꿈치 숨기기)](../techniques/heel-hook-defense-knee-line.md) · [토홀드 (앵클락 자세에서)](../techniques/toe-hold.md)

### 흔한 실수

- 다리를 좁게 붙이고 똑바로 서면 조금만 띄워도 넘어간다 → 무릎을 굽히고 자유로운 발을 넓게 짚는다
- 훅을 그대로 둔 채 넘어가려 하면 그 순간 스윕당한다 → 훅을 먼저 떼고 넘어간다
- 앵클락에 걸렸는데 다리를 당기기만 하면 발목이 더 잠긴다 → 발끝을 세우고 상대 다리를 막으며 무릎을 빼낸다

### 드릴

- X 가드에 걸린 채 시작해 위는 훅 떼기, 아래는 스윕만 하는 3분 부분 스파링
- 앵클락이 걸린 자세에서 천천히 발끝 세우고 무릎 빼기 동작만 5번 반복
