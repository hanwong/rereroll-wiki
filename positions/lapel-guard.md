# 라펠 가드 (Lapel Guard)

아래가 상대 라펠을 상대 다리에 감아 묶는 도복 가드, 위는 라펠부터 풀어야 한다

이런 모양도 이 포지션이에요: 라펠 가드 — 상대 오른쪽 라펠을 꺼내 상대 오른다리 오금 뒤로 돌려 내 왼손으로 잡는다, 웜 가드 — 돌린 라펠을 내 왼다리에 감고 왼발은 상대 오른쪽 골반, 라펠 끝은 내 오른손, 라펠 + 데라히바 — 라펠을 잡은 채 내 왼다리로 상대 오른다리에 데라히바 훅, 라펠 + 라쏘 · 스파이더 — 라펠 그립에 내 왼발로 상대 오른팔을 막아 묶는다

## 아래에서

### 목표 (순서대로)

1. 상대가 그립을 잡기 전에 라펠을 꺼내 상대 오른다리에 감아 둔다
2. 묶인 오른다리 쪽(내 왼쪽)으로 스윕하거나 백을 노린다
3. 패스 시도가 오면 데라히바·라쏘·스파이더로 갈아 끼워 가드를 유지한다

### 핵심

- 라펠은 상대 오른다리 오금 뒤로 깊게 돌려야 다리가 묶인다
- 내 왼손이 라펠 끝을 놓치지 않게 손목을 말아 짧게 잡는다
- 웜 가드에서는 내 왼발을 상대 오른쪽 골반에 대 거리를 지킨다
- 한쪽으로 비스듬히 누워 엉덩이를 계속 움직여 상대 체중이 실리지 않게 한다

### 상대가 ~하면

- 상대가 서서 오른다리에 체중을 실으면 → [라펠 엘리베이터 스윕](../techniques/lapel-elevator-sweep.md)
- 상대가 라펠을 떼려고 몸을 돌리면 → [라펠 스윕 → 백](../techniques/lapel-sweep-to-back.md)
- 상대가 무릎을 꿇어 자세를 낮추면 → [웜 가드 진입](../techniques/worm-guard-entry.md) 후 [웜 가드 스윕](../techniques/worm-guard-sweep.md)
- 상대가 다리를 빼며 패스를 시작하면 → [라펠 → 데라히바](../techniques/lapel-to-de-la-riva.md) 또는 [라펠 → 라쏘](../techniques/lapel-to-lasso.md)
- 상대가 상체를 숙여 들어오면 → [트라이앵글 (라펠)](../techniques/lapel-triangle-setup.md) 또는 [오모플라타 (라펠)](../techniques/lapel-omoplata-entry.md)

### 흔한 실수

- 라펠을 얕게 돌리면 상대가 다리만 빼도 풀린다 → 오금 뒤까지 깊게 돌린다
- 라펠을 감는 데만 집중하면 상대가 그 사이 무릎을 넘어온다 → 감는 동안 내 오른발로 상대 왼쪽 골반을 막는다
- 평평하게 누운 채 라펠만 당기면 힘만 들고 스윕이 안 된다 → 비스듬히 누워 각도를 만든 뒤 당긴다

### 드릴

- 파트너가 서 있을 때 라펠을 꺼내 오른다리 뒤로 돌려 잡는 동작만 10번 반복
- 라펠 가드에서 시작해 아래는 스윕, 위는 라펠 풀기만 하는 2분 부분 스파링

## 위에서

### 목표 (순서대로)

1. 라펠이 다리에 감기기 전에 막고, 감겼으면 패스보다 먼저 푼다
2. 푼 순간 바로 눌러서 다시 감지 못하게 한다
3. 상대 왼쪽으로 돌아 패스를 끝낸다

### 핵심

- 내 왼손으로 상대 오른쪽 손목을 눌러 라펠을 당기지 못하게 한다
- 라펠은 힘으로 뜯지 말고 다리를 빼거나 감긴 방향 반대로 풀어 낸다
- 거리를 만들 땐 한 발 물러서 상대 다리 힘이 닿지 않게 한다
- 한 자리에 오래 서 있지 말고 계속 각도를 바꿔 라펠을 다시 감지 못하게 한다

### 상대가 ~하면

- 상대가 라펠을 오른다리에 감기 시작하면 → [라펠 풀고 토레안도](../techniques/lapel-clear-to-toreando.md)
- 상대가 웜 가드를 완성하면 → [거리 만들어 리셋 (라펠 상대)](../techniques/distance-creation-to-reset.md) 또는 [웜 가드 상대 자세 지키기](../techniques/defend-worm-guard-posture.md)
- 상대 라펠 그립이 잡혀 있어도 무릎이 바닥에 닿아 있으면 → [니슬라이스 (라펠 잡힌 채)](../techniques/knee-slice-despite-lapel.md)
- 상대가 라펠을 쥔 채 다리가 바닥으로 내려오면 → [레그 드래그 (라펠 풀며)](../techniques/leg-drag-while-clearing-lapel.md)
- 상대가 라펠로 당기며 엉덩이를 들면 → [스택 패스 (라펠 상대)](../techniques/stack-pass-over-lapel.md)

### 흔한 실수

- 라펠을 감긴 채로 압박 패스를 하면 천이 막아서 붙지 못하고 스윕당한다 → 먼저 라펠을 풀고 들어간다
- 감긴 라펠을 손힘으로 뜯으면 손만 지친다 → 다리를 빼거나 감긴 방향 반대로 푼다
- 뒤로만 물러서면 위치가 다시 처음으로 돌아간다 → 푸는 동작과 패스 각도를 같이 만든다

### 드릴

- 파트너가 라펠을 꺼내려 할 때 손목을 눌러 막는 그립 싸움 30초 반복
- 웜 가드를 걸어 둔 채 시작해 라펠을 풀고 사이드까지 가는 동작 5번
