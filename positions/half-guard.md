# 하프가드 (Half Guard)

아래가 상대 오른다리 한쪽만 감은 자세, 언더훅과 크로스페이스 싸움이 승부를 가른다

이런 모양도 이 포지션이에요: 니 쉴드 — 내 왼쪽 무릎·정강이를 상대 배 앞에 가로로 세워 거리를 만든다, Z 가드 — 니 쉴드와 같은 그림으로 왼쪽 정강이를 높게 세워 상대 상체를 막는다, 언더훅 하프 — 내 왼팔로 상대 오른쪽 겨드랑이 밑을 파고 옆으로 일어나 앉는다, 쿼터 가드 — 상대 오른쪽 발목만 겨우 걸린, 패스 직전의 얕은 하프가드, 도그파이트 — 언더훅으로 무릎까지 올라와 상대와 옆으로 맞붙은 자세, 눌린 하프 — 등이 바닥에 붙고 상대 크로스페이스에 눌린 위험한 상태

## 아래에서

### 목표 (순서대로)

1. 평평하게 눌리지 않게 옆으로 누워 프레임을 세운다
2. 내 왼팔 언더훅을 먼저 차지해 옆으로 올라온다
3. 스윕하거나 백을 잡고, 안 되면 니 쉴드로 거리를 다시 만든다

### 핵심

- 내 오른쪽 어깨와 엉덩이를 바닥에 대고 몸을 상대 쪽(내 왼쪽)으로 세운다
- 내 왼팔은 상대 오른쪽 겨드랑이 밑으로 깊게 언더훅, 머리는 상대 가슴 밑에 붙인다
- 프레임은 내 오른쪽 팔뚝 상대 목, 왼쪽 팔뚝 상대 오른쪽 골반
- 엉덩이를 내 오른쪽으로 빼 공간을 만들고 내 왼쪽 무릎을 니 쉴드로 넣는다

### 상대가 ~하면

- 상대가 언더훅을 내주고 상체가 떠 있으면 → [하프가드 언더훅 잡기](../techniques/half-guard-underhook.md) 후 [올드 스쿨 스윕](../techniques/old-school-sweep.md)
- 상대가 언더훅에 위저로 막으며 버티면 → [도그파이트 스윕](../techniques/dogfight-sweep.md) 또는 [하프가드 백 테이크](../techniques/half-guard-back-take.md)
- 상대가 앞으로 눌러 들어오면 → [니 쉴드 하프가드](../techniques/knee-shield-half-guard.md) 후 [니 쉴드 스윕](../techniques/sweep-from-knee-shield.md)
- 상대 오른팔이 바닥을 짚고 팔꿈치가 벌어지면 → [기무라 (하프가드)](../techniques/kimura-half-guard.md)
- 상대 크로스페이스에 등이 눌리면 → [눌린 하프가드에서 회복](../techniques/flattened-half-guard.md) 또는 [눌린 하프 → 딥 하프](../techniques/deep-half-entry-from-flattened.md)

### 흔한 실수

- 등을 바닥에 대고 평평하게 누우면 크로스페이스에 눌려 패스당한다 → 바로 오른쪽 어깨로 돌아누워 옆으로 선다
- 언더훅을 상대에게 주면 내 위로 눌려 움직일 수 없다 → 내 왼팔을 먼저 넣어 겨드랑이를 차지한다
- 다리만 꽉 조이고 상체를 비우면 다리가 풀릴 때 바로 사이드가 된다 → 프레임과 언더훅을 다리보다 먼저 챙긴다

### 드릴

- 파트너가 크로스페이스를 시도할 때 오른쪽 어깨로 돌아누워 왼팔 언더훅을 넣는 동작 10번
- 하프가드에서 시작해 아래는 언더훅 차지, 위는 크로스페이스 차지만 하는 1분 싸움

## 위에서

### 목표 (순서대로)

1. 상체를 먼저 눌러 상대를 평평하게 만든다
2. 감긴 내 오른다리를 천천히 빼 하프를 풀어 낸다
3. 사이드나 마운트로 가서 자리를 굳힌다

### 핵심

- 내 오른팔 크로스페이스로 상대 얼굴을 상대 오른쪽으로 돌린다
- 상대 왼팔 언더훅을 막고 내 왼팔로 상대 오른팔 밑 언더훅을 차지한다
- 엉덩이를 낮추고 가슴으로 눌러 상대가 옆으로 돌아누울 공간을 없앤다
- 니 쉴드(상대 왼쪽 무릎)는 내 왼손으로 눌러 바닥으로 내린다

### 상대가 ~하면

- 상대가 평평하게 누워 있고 니 쉴드가 없으면 → [하프가드 패스 (크로스페이스 · 언더훅)](../techniques/half-guard-pass.md)
- 상대가 니 쉴드로 막고 있으면 → 스매시 패스 또는 [니슬라이스 패스](../techniques/knee-slice-pass.md) · 니 쉴드 다리를 쭉 펴 밀면 [니바 (하프가드 탑 · 스텝 오버)](../techniques/kneebar-half-guard-top.md) · 니 쉴드 발이 떠 있으면 [토홀드 (하프가드 탑 · 니 쉴드 상대)](../techniques/toe-hold-half-guard-top.md)
- 상대가 언더훅을 넣고 올라오면 → [하프 탑 위저 카운터](../techniques/half-guard-whizzer-counter.md) 또는 [바디락 패스](../techniques/body-lock-pass.md)
- 상대 다리가 내 오른쪽 발목까지 밀려 내려가면 → [하프가드 → 쿼터 가드 (탑)](../techniques/half-guard-to-quarter-guard.md) 후 [쿼터 가드 패스](../techniques/complete-pass-from-quarter.md)
- 상대가 프레임 없이 목이 비면 → [암 트라이앵글 (하프 탑)](../techniques/arm-triangle-from-half-top.md) 또는 [루프 초크 (하프 탑)](../techniques/loop-choke-from-half-top.md)

### 흔한 실수

- 크로스페이스 없이 다리부터 빼면 상대가 옆으로 올라와 스윕한다 → 상체를 먼저 누르고 다리를 뺀다
- 상대에게 언더훅을 내주면 도그파이트로 밀려 백까지 위험하다 → 겨드랑이를 붙이고 위저로 막는다
- 한 번에 다리를 확 빼려 하면 균형이 무너진다 → 조금씩 빼며 체중은 계속 상대 위에 둔다

### 드릴

- 하프 탑에서 크로스페이스와 언더훅을 잡고 30초 동안 상대가 옆으로 못 돌게 누르기
- 하프 탑에서 다리 빼기 → 사이드 안착까지 천천히 5번 반복

## 관련 개념

- [프레임](../concepts/frames.md) — 팔·다리 뼈를 버팀목처럼 세워 상대 무게를 막고 움직일 공간을 지키는 것
- [새우(힙 이스케이프)](../concepts/hip-escape.md) — 옆으로 누워 엉덩이를 상대에게서 빼내 다리를 다시 넣을 공간을 만드는 움직임
- [언더훅](../concepts/underhook.md) — 내 팔을 상대 겨드랑이 밑으로 넣어 등을 감싸 몸통을 조종하는 그립
- [크로스페이스](../concepts/crossface.md) — 팔과 어깨로 상대 얼굴을 반대로 돌려 몸을 못 돌리게 묶는 위쪽 컨트롤
- [위저(오버훅)](../concepts/whizzer.md) — 상대 언더훅 팔을 위에서 감아 눌러 언더훅의 힘을 빼는 방어 그립
- [인사이드 포지션](../concepts/inside-position.md) — 내 팔·무릎·발을 상대 팔다리 안쪽에 먼저 넣어 길목을 차지하는 것
- [팔꿈치 · 무릎 붙이기](../concepts/elbow-knee.md) — 팔꿈치와 무릎을 붙여 몸통 옆 빈틈을 막아 패스와 팔 공격을 막는 것
- [압박(프레셔)](../concepts/pressure.md) — 몸무게를 정해진 곳에 실어 상대가 원하는 움직임을 못 하게 막는 힘
- [어깨 압박](../concepts/shoulder-pressure.md) — 어깨로 상대 턱·가슴에 무게를 실어 상체를 돌리지 못하게 묶는 압박
- [엉덩이 · 허리 압박](../concepts/hip-pressure.md) — 엉덩이를 낮추고 상대 골반에 붙여 새우·브릿지를 못 하게 막는 압박
- [머리 위치](../concepts/head-position.md) — 내 머리와 상대 머리를 어디 두느냐로 균형과 누르기가 달라진다
- [훅](../concepts/hooks.md) — 팔이나 발을 갈고리처럼 걸어 상대를 따라가고 들어 올리는 연결
- [쐐기(웨지)](../concepts/wedges.md) — 무릎 · 정강이 · 팔꿈치를 틈에 끼워 공간을 지키고 압박 길을 막는 것
- [포지션 서열](../concepts/positional-hierarchy.md) — 어느 자리가 더 유리한지 순서를 알고 한 칸씩 올라가는 것
- [눌릴 때 버티기](../concepts/defense-under-pressure.md) — 위에서 체중으로 누를 때 숨 쉬며 버티고, 작게 틈을 모아 빠지는 법
- [가드 리텐션](../concepts/guard-retention.md) — 상대가 다리를 넘으려 할 때 팔꿈치 · 무릎 · 엉덩이로 가드를 지키는 기술
- [가드의 층](../concepts/layers-of-guard.md) — 상대가 내 몸통에 닿기 전 거쳐야 하는 막 — 발 · 정강이 · 무릎 · 팔
- [패스의 3단계](../concepts/passing-phases.md) — 패스는 그립 풀기 → 다리 지나가기 → 눌러 고정하기 세 가지 일
- [포지션 스파링](../concepts/positional-sparring.md) — 정한 자리에서 시작해 각자 목표를 이루면 다시 시작하는 짧은 스파링
- [흘러가는 롤링(플로우 롤)](../concepts/flow-rolling.md) — 이기려 하지 않고 서로 움직임을 주고받으며 천천히 이어 가는 롤링
- [롤링 세기 고르기](../concepts/training-intensity.md) — 이번 판이 뭘 연습하는 판인지에 맞춰 속도와 버티는 정도를 정하는 것
- [여러 상대와 하기](../concepts/partner-diversity.md) — 여러 사람과 해 봐야 내 기술이 어디서 상대 덕을 보고 있었는지 보인다
- [미리 막기](../concepts/prevention-over-cure.md) — 완전히 잡히고 나서 빠지기보다 잡히기 직전에 막는 게 훨씬 쉽다
- [동작을 작게 다듬기](../concepts/smaller-circles.md) — 기술 하나에서 필요 없는 동작을 빼며 작고 정확하게 다듬어 가는 연습법
- [잘하는 것 파기](../concepts/double-down.md) — 잘 되는 자리 하나를 골라 들어가는 길 · 막혔을 때 답까지 깊게 파는 것
- [목적 있는 방어](../concepts/defend-with-purpose.md) — 막기만 하지 말고, 막으면서 다음에 갈 작은 목표를 정해 두는 방어
