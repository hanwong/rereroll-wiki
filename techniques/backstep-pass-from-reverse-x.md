# 백스텝 패스 (리버스 X 상대) (Backstep Pass from Reverse X-Guard)

[X 가드 · 싱글 레그 X · 앵클락](../positions/x-guard.md) · 패스 · 위 → [사이드 컨트롤](../positions/side-control.md) / [하프가드](../positions/half-guard.md)

다른 이름: 리버스 X 백스텝

## 세팅 과정 (오른손잡이 기준)

1. 상대가 내 오른다리를 안고 리버스 X를 걸었을 때, 내 오른손으로 상대 깃이나 소매를 잡는다
2. 훅만 걸린 왼다리에 체중을 싣고 내 왼손으로 왼쪽 무릎 뒤 훅을 눌러 느슨하게 한다
3. 안긴 오른다리를 뒤로 크게 돌려 빼며 몸을 돌린다
4. 상대 옆에 엉덩이를 내리고 크로스페이스로 사이드를 잡는다

## 핵심 디테일

- 돌기 전에 내 오른손으로 상대 깃·소매를 잡아 상대가 따라 돌지 못하게 한다
- 체중을 훅만 걸린 왼다리에 완전히 실어 축으로 쓴다
- 안긴 오른다리를 크게 한 번에 돌려 뺀다 — 반쯤 돌다 멈추면 등이 보인다
- 착지하면 바로 엉덩이를 내리고 크로스페이스

## 흔한 실수

- 상체 그립 없이 돌면 → 상대가 따라 돌아 백을 잡는다 → 깃·소매부터
- 반쯤 돌다 멈추면 → 스윕이나 백을 내준다 → 끝까지 돈다
- 착지 뒤 서 있으면 → 상대가 무릎을 넣어 가드를 되찾는다 → 바로 가슴을 붙인다

## 막히면

- 상대가 싱글 레그 X로 바꾸면 → [백스텝 (싱글 레그 X 상대)](../techniques/backstep-from-single-leg-x.md)
- 상대가 다리를 하프가드로 감으면 → [하프가드 패스 (크로스페이스 · 언더훅)](../techniques/half-guard-pass.md)
- 상대가 따라 돌며 등을 노리면 → 상대 쪽으로 돌아 마주보며 엉덩이를 낮춘다

## 방어하는 쪽 (상대 입장)

- 상대가 내 깃·소매를 잡고 왼다리에 체중을 싣고 상대 왼손이 내 오른다리 훅을 누르면 백스텝 신호
- 돌기 전에 훅을 더 조이고 상대 소매를 당겨 리버스 X 가드 스윕
- 돌기 시작하면 상대 뒤로 따라 들어가 리버스 X → 백 테이크
- 이미 돌았으면 팔로 상대 골반에 프레임하고 무릎을 넣어 가드를 되찾는다
