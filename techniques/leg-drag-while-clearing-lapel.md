# 레그 드래그 (라펠 풀며) (Leg Drag While Clearing Lapel)

[라펠 가드](../positions/lapel-guard.md) · 패스 · 위 → [사이드 컨트롤](../positions/side-control.md)

다른 이름: 라펠 레그 드래그

## 세팅 과정 (오른손잡이 기준)

1. 상대가 오른손으로 내 라펠을 잡았을 때, 내 왼손으로 상대 오른쪽 손목이나 소매를 누른다
2. 내 오른손으로 상대 왼쪽 정강이 쪽 바지를 잡는다
3. 상대 왼다리를 내 왼쪽 엉덩이 옆으로 끌어오며 몸을 틀어 라펠을 풀어낸다
4. 내 가슴과 어깨를 상대 왼쪽 골반에 붙여 누르고 상대 왼쪽 사이드로 간다

## 핵심 디테일

- 라펠 쥔 상대 오른쪽 손목을 내 왼손으로 먼저 눌러 더 감지 못하게 한다
- 바지는 정강이 아래쪽을 잡아야 다리를 끌기 쉽다
- 다리를 끄는 몸 돌림으로 라펠이 같이 풀리게 — 풀기와 패스를 한 동작으로 한다
- 가슴과 어깨를 상대 왼쪽 골반에 붙여 하체를 눌러 둔다

## 흔한 실수

- 손목을 놔두면 상대가 라펠을 더 감아 따라온다 → 손목부터 누른다
- 다리만 끌고 몸이 떨어지면 상대가 돌아 무릎을 넣는다 → 골반에 붙인다
- 무릎 근처를 잡으면 다리를 끌기 어렵다 → 정강이 낮게 잡는다

## 막히면

- 상대가 등을 돌려 웅크리면 → [레그 드래그 → 백 테이크](../techniques/leg-drag-to-back-take.md)
- 상대가 돌아 다리를 감으면 → [하프가드](../positions/half-guard.md) 위에서 [패스](../positions/passing.md)를 이어간다
- 라펠이 안 풀려 끌 수 없으면 → [거리 만들어 리셋 (라펠 상대)](../techniques/distance-creation-to-reset.md)

## 방어하는 쪽 (상대 입장)

- 상대가 내 오른쪽 손목을 누르고 내 왼쪽 정강이 바지를 잡으면 레그 드래그 신호
- 왼쪽 무릎을 가슴 쪽으로 당겨 다리를 접고 바지 그립을 떼어 낸다
- 다리가 끌리면 상대 쪽으로 돌아누워 무릎을 다시 넣는다 → 레그 드래그 상대 프레임 · 쉬림프
- 이미 골반을 눌렸으면 → 레그 드래그 상대 하프 회복
