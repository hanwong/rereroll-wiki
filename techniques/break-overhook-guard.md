# 오버훅 가드 풀기 (Break Overhook Guard)

[클로즈드 가드](../positions/closed-guard.md) · 방어 · 위 → [클로즈드 가드](../positions/closed-guard.md)

다른 이름: 오버훅 가드 브레이크, Guard Pass from Diamond Guard, Overhook Strip from Diamond Guard

## 세팅 과정 (오른손잡이 기준)

1. 상대가 왼팔로 내 오른팔을 오버훅하면 오른쪽 팔꿈치를 몸에 붙이고 허리를 세운다
2. 내 왼손으로 상대 오른쪽 골반을 눌러 거리를 만든다
3. 내 오른쪽 팔꿈치를 아래로 돌려 오버훅을 빼낸다
4. 클로즈드 가드 안 자세로 돌아간다

## 핵심 디테일

- 무릎을 넓게 벌리고 엉덩이를 앞으로 밀어 자세부터 세운다
- 내 왼손으로 상대 오른쪽 골반을 눌러 상대 가슴과 내 어깨 사이 거리를 만든다
- 뒤로 잡아당기지 말고 오른쪽 팔꿈치를 아래로 원을 그리듯 돌려 뺀다
- 빠지자마자 오른손은 상대 깃·명치, 왼손은 상대 골반에 두고 자세를 다시 잡는다

## 흔한 실수

- 자세가 무너진 채 팔부터 빼면 스윕을 당한다 → 베이스와 자세를 먼저 만든다
- 팔을 일직선으로 당기면 오버훅이 더 조여진다 → 팔꿈치를 돌려 뺀다
- 팔이 빠진 뒤 손을 늦게 두면 다시 잡힌다 → 바로 클로즈드 가드 안 자세 되찾기

## 막히면

- 상대가 엉덩이를 빼 스윕을 노리면 → 무릎을 더 넓히고 무게를 상대 쪽으로 실어 누른다
- 상대 다리가 내 어깨 위로 올라오면 → 오른팔을 다리 안쪽으로 모으고 자세를 세워 트라이앵글을 막는다 · [트라이앵글 초크](../techniques/triangle-choke.md)
- 오버훅이 너무 깊으면 → [기무라 (오버훅 컨트롤 위에서)](../techniques/kimura-from-overhook-control.md)나 [오버훅 풀고 패스](../techniques/overhook-pass-to-side-control.md)

## 방어하는 쪽 (상대 입장)

- 상대가 허리를 세우고 왼손으로 내 오른쪽 골반을 누르면 오버훅을 빼려는 신호다
- 내 왼쪽 팔꿈치를 갈비에 붙여 더 조이고 발꿈치로 상대 허리를 당겨 다시 자세를 무너뜨린다
- 상대 팔이 빠지는 순간 다리를 올려 트라이앵글 (클램프 가드)나 오모플라타 (오버훅 가드)를 노린다
- 상대 무게가 뒤로 빠지면 → 오버훅 스윕
