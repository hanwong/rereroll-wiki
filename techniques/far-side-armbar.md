# 파 사이드 암바 (Far Side Armbar)

[사이드 컨트롤](../positions/side-control.md) · 서브미션 · 위

다른 이름: 먼 쪽 팔 암바

## 세팅 과정 (오른손잡이 기준)

1. 상대 오른쪽에서 사이드: 내 왼팔로 상대 왼쪽 팔꿈치를 당겨 내 왼쪽 겨드랑이에 가둔다
2. 내 왼다리(머리 쪽 다리)를 상대 머리 위로 넘긴다
3. 상대 왼쪽 어깨 옆에 앉으며 뒤로 누워 무릎을 모은다
4. 엉덩이를 들어 상대 왼팔을 편다

## 핵심 디테일

- 내 왼팔로 상대 왼쪽 팔꿈치를 당겨 내 왼쪽 겨드랑이에 꼭 가둔다
- 머리 쪽 다리인 내 왼다리를 상대 머리 위로 넘긴다
- 상대 왼쪽 어깨 옆에 바짝 앉으며 뒤로 눕고 무릎을 모은다
- 엉덩이를 천천히 들어 팔을 편다

## 흔한 실수

- 팔을 겨드랑이에 꽉 안 가두면 넘어가는 동안 빠진다 → 팔꿈치를 몸에 붙인다
- 어깨에서 멀리 앉으면 팔이 빠진다 → 바짝 붙여 앉는다
- 급하게 펴면 다친다 → 천천히 엉덩이를 든다

## 막히면

- 상대가 손을 맞잡으면 → 손을 하나씩 떼어 낸다
- 상대가 팔을 몸 쪽으로 당기면 → [기무라 (사이드)](../techniques/kimura-side.md)
- 상대가 내 쪽으로 돌면 → [사이드에서 마운트 가기](../techniques/side-to-mount.md)

## 방어하는 쪽 (상대 입장)

- 상대 왼팔이 내 왼쪽 팔꿈치를 당겨 겨드랑이에 가두면 파 사이드 암바 신호
- 상대 목을 왼팔을 쭉 펴서 밀지 않는다 — 팔꿈치를 굽혀 몸 가까이 둔다
- 상대 다리가 내 머리 위로 넘어오면 양손을 맞잡아 팔이 펴지지 않게 한다
- 팔이 펴지기 시작하면 바로 탭한다
