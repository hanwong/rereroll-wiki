# 터틀에서 훅 걷어내기 (Clear the Hook from Turtle)

[터틀 · 크루시픽스](../positions/turtle.md) · 탈출 · 아래 → [오픈 가드](../positions/open-guard.md)

다른 이름: 훅 빼기, 터틀 훅 방어, 훅 디펜스

## 세팅 과정 (오른손잡이 기준)

1. 상대가 내 등 뒤에서 내 왼쪽 허벅지 안에 훅을 넣으면 오른쪽 팔꿈치를 오른쪽 무릎에 붙여 두 번째 훅을 막는다
2. 내 왼손으로 훅 들어온 상대 왼발을 잡아 내 왼쪽 무릎 아래로 밀어 낸다
3. 훅이 빠지면 상대 몸에서 먼 내 오른쪽으로 엉덩이를 앉힌다
4. 다리를 상대 쪽으로 돌려 가드를 되찾는다

## 핵심 디테일

- 첫 훅이 들어오는 순간 오른쪽 팔꿈치를 오른쪽 무릎에 붙여 두 번째 훅 자리를 막는다
- 내 왼손으로 상대 왼발을 잡아 내 왼쪽 무릎 아래로 밀어 낸다
- 훅이 빠지면 바로 상대에게서 먼 내 오른쪽으로 앉는다
- 턱을 당겨 목을 지킨다

## 흔한 실수

- 훅을 걷느라 목이 열리면 초크를 당한다 → 턱을 당기고 팔꿈치를 몸에 붙인다
- 상대가 있는 내 왼쪽으로 앉으면 상대가 다시 등을 잡는다 → 상대에게서 먼 내 오른쪽으로 앉는다
- 훅만 걷고 멈추면 상대가 다시 넣는다 → 걷어내자마자 앉아 다리를 상대 쪽으로 돌린다

## 막히면

- 상대가 두 번째 훅까지 넣으면 → [백 이스케이프](../techniques/back-escape.md)
- 상대 무게에 눌려 앉지 못하면 → [그랜비 롤 (가드 회복)](../techniques/granby-roll.md)
- 상대가 시트벨트를 먼저 잡으면 → [핸드 파이팅 (백 아래)](../techniques/hand-fighting-from-back.md)

## 방어하는 쪽 (상대 입장)

- 상대가 왼손으로 내 왼발 훅을 밀어 내면 → 가슴을 등에 붙이고 시트벨트를 먼저 잡아 상대가 앉지 못하게 한다
- 상대가 오른쪽으로 앉으려 하면 → 무게를 상대 오른쪽으로 옮겨 따라가며 띠나 깃을 당긴다
- 훅이 빠졌으면 → 등에 계속 붙어 다시 훅을 넣거나 로데오 라이드 (터틀)로 잡는다
