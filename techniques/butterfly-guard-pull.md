# 버터플라이 가드 풀링 (Butterfly Guard Pull)

[클린치 · 가드 풀링](../positions/clinch.md) · 가드 풀링 · 서서 → [버터플라이 가드](../positions/butterfly-guard.md)

다른 이름: 버터플라이로 앉기

## 세팅 과정 (오른손잡이 기준)

1. 내 오른팔로 상대 왼쪽 겨드랑이 언더훅(또는 상대 왼쪽 깃)을 잡고 상대 가까이 붙는다
2. 엉덩이를 바닥에 앉히며 내 오른발은 상대 왼쪽 허벅지 안쪽, 왼발은 상대 오른쪽 허벅지 안쪽에 넣는다
3. 상체를 세운 채 상대 체중을 받는다
4. 바로 버터플라이 스윕으로 잇는다(내 왼쪽으로 기울며 오른발 훅으로 들어 넘김)

## 핵심 디테일

- 언더훅으로 상대에게 붙은 채 앉는다 — 붙어야 훅이 들어간다
- 엉덩이를 상대 발 앞 가까이 내리고 두 발을 상대 허벅지 안쪽에 넣는다
- 상체는 세워 상대 가슴에 붙인다 — 등이 바닥에 닿으면 훅이 약해진다
- 왼손으로 상대 오른팔을 잡아 상대가 손을 짚지 못하게 하고 바로 스윕으로 잇는다

## 흔한 실수

- 멀리서 앉으면 훅이 안 닿고 상대가 서서 패스한다 → 상대 발 바로 앞에 앉는다
- 뒤로 누우면 상대가 위에서 눌러 버린다 → 상체를 세워 붙는다
- 언더훅 없이 앉으면 상대가 크로스페이스와 언더훅을 먼저 잡는다 → 오른팔 언더훅 먼저

## 막히면

- 상대가 무릎을 꿇고 버티면 → [버터플라이 스윕](../techniques/butterfly-sweep.md)
- 상대가 일어서면 → [버터플라이 → X 가드](../techniques/butterfly-guard-to-x-guard.md)
- 상대가 내 다리를 눌러 납작하게 하면 → [버터플라이 하프가드](../techniques/butterfly-half-guard.md)로 다리를 감는다

## 방어하는 쪽 (상대 입장)

- 상대 오른팔이 내 왼쪽 겨드랑이로 들어오고 상대가 앉으며 두 발이 내 허벅지 안쪽에 걸리면 버터플라이 가드 풀링 신호
- 상대가 앉는 순간 서서 엉덩이를 뒤로 빼고 내 왼팔로 언더훅을 되찾는다
- 상대 무릎을 눌러 훅이 들어오지 못하게 한다
- 이미 훅이 걸렸으면 버터플라이 스매시 패스
