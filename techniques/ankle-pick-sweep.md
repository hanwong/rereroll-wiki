# 앵클 픽 스윕 (Ankle Pick Sweep)

[오픈 가드](../positions/open-guard.md) · 스윕 · 아래 → [패스](../positions/passing.md)

다른 이름: 앉아서 발목 잡기

## 세팅 과정 (오른손잡이 기준)

1. 앉은 가드에서 상대 왼발이 앞에 오면 내 오른손으로 그 뒤꿈치를 잡는다
2. 내 왼손은 뒤로 바닥을 짚는다
3. 엉덩이를 들어 일어나며 내 오른쪽 어깨로 상대 왼쪽 허벅지를 앞으로 민다
4. 뒤꿈치는 당기고 몸은 밀어 상대를 뒤로 넘긴다
5. 따라 올라가 헤드쿼터 자세를 잡는다

## 핵심 디테일

- 상대 왼발이 앞으로 나와 체중이 실렸을 때 내 오른손으로 뒤꿈치를 잡는다
- 뒤꿈치는 최대한 낮게 감싸 잡아 발이 빠지지 않게 한다
- 엉덩이를 들어 일어나며 오른쪽 어깨로 상대 왼 허벅지를 민다 → 뒤꿈치 당기기와 동시에
- 넘긴 뒤 바로 따라 올라가 헤드쿼터 자세로 패스를 시작한다

## 흔한 실수

- 종아리를 잡으면 발이 빠진다 → 뒤꿈치를 감싸 잡는다
- 엉덩이를 바닥에 둔 채 팔로만 당기면 안 넘어간다 → 엉덩이를 들고 어깨로 밀며 일어난다
- 왼손을 짚지 않고 일어나면 균형을 잃는다 → 내 왼손으로 뒤 바닥을 단단히 짚는다

## 막히면

- 상대가 왼다리를 뒤로 빼면 → [신 투 신 가드](../techniques/shin-to-shin-guard.md)로 붙어 다리를 다시 잡는다
- 상대가 오른발로 깡충 뛰며 버티면 → 뒤꿈치를 계속 당기며 [테크니컬 스탠드업 → 싱글 레그](../techniques/technical-stand-up-to-single-leg.md)로 끝낸다

## 방어하는 쪽 (상대 입장)

- 내 왼발이 앞에 있을 때 상대 오른손이 내 왼 뒤꿈치로 오면 앵클 픽 스윕 신호
- 앞발에 체중을 오래 두지 말고 왼발을 뒤로 빼 거리를 둔다
- 잡혔으면 무릎을 굽혀 상대 쪽으로 체중을 싣고 손으로 상대 머리·어깨를 눌러 일어나지 못하게 한다
- 넘어가면 바로 다리를 올려 가드를 만든다
