# 레그 훅 빠져나오기 (Escape Leg Hook)

[패스](../positions/passing.md) · 탈출 · 아래 → [하프가드](../positions/half-guard.md)

다른 이름: 레그 훅 이스케이프

## 세팅 과정 (오른손잡이 기준)

1. 상대가 내 오른다리를 걸어 누르고 내 오른쪽으로 넘어오려 할 때
2. 걸린 내 오른쪽 무릎을 세워 안쪽으로 돌려 훅을 푼다
3. 엉덩이를 내 왼쪽으로 빼며 내 오른다리를 빼낸다
4. 빼낸 내 오른다리로 상대 오른다리를 감아 하프가드를 잡는다
5. 내 왼팔로 상대 오른팔 언더훅을 노린다

## 핵심 디테일

- 걸린 내 오른쪽 무릎을 먼저 세운 뒤 안쪽으로 돌려야 훅이 풀린다
- 엉덩이를 내 왼쪽으로 크게 빼야 다리를 뺄 공간이 생긴다
- 빼낸 내 오른다리로 바로 상대 오른다리를 감아 다시 넘어오지 못하게 한다
- 하프가드가 되면 내 왼팔 언더훅을 바로 노린다

## 흔한 실수

- 다리를 펴서 힘으로 당기면 훅이 더 깊어진다 → 무릎을 접어 세운 다음 돌린다
- 엉덩이를 조금만 빼면 상대가 따라 눌러 온다 → 한 번에 크게 뺀다
- 다리만 빼고 감지 않으면 바로 사이드를 내준다 → 빼자마자 감는다

## 막히면

- 상대가 앞으로 강하게 눌러 엉덩이가 안 빠지면 → [레그 훅 상대 니 쉴드 회복](../techniques/shin-shield-recovery.md)
- 상대가 훅을 더 깊게 다시 걸면 → 엉덩이를 한 번 더 빼고 다시 무릎을 세운다
- 상대가 훅을 버리고 바로 사이드로 가면 → [사이드 이스케이프 (프레임 · 쉬림프)](../techniques/side-control-escape.md)

## 방어하는 쪽 (상대 입장)

- 상대가 걸린 오른쪽 무릎을 세워 안쪽으로 돌리면 훅을 풀려는 신호
- 내 왼발 훅을 더 깊게 걸고 체중을 낮춰 상대 무릎이 서지 못하게 한다
- 엉덩이가 빠지면 가슴을 붙여 따라가고 내 오른팔로 상대 왼팔 아래 언더훅을 먼저 잡는다
- 하프가드가 잡혔으면 하프가드 패스 (크로스페이스 · 언더훅)로 다시 간다
