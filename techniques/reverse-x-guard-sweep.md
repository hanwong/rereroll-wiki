# 리버스 X 가드 스윕 (Reverse X-Guard Sweep)

[X 가드 · 싱글 레그 X · 앵클락](../positions/x-guard.md) · 스윕 · 아래 → [마운트](../positions/mount.md)

다른 이름: 리버스 X 스윕

## 세팅 과정 (오른손잡이 기준)

1. 내 오른손으로 상대 왼쪽 소매나 손목을 잡아 당긴다
2. 상대 왼쪽 무릎 뒤에 건 오른다리를 펴며 엉덩이를 들어 상대 왼다리를 띄운다
3. 소매를 당긴 쪽인 상대 왼쪽으로 상대를 넘긴다
4. 놓지 않고 따라 올라가 마운트를 잡는다

## 핵심 디테일

- 소매 당기기와 다리 펴기를 동시에 해야 상대가 왼손을 못 짚는다
- 내 오른다리 훅을 상대 왼쪽 무릎 뒤 깊이 걸고 발끝을 당겨 둔다 — 지렛대 중심
- 똑바로 뒤가 아니라 상대 왼쪽으로 비스듬히 넘긴다
- 넘어가면 소매를 놓지 않고 따라 올라가 마운트

## 흔한 실수

- 엉덩이를 안 들고 다리만 펴면 → 상대 체중이 안 뜬다 → 엉덩이부터 띄운다
- 넘기는 중 소매를 놓으면 → 상대가 왼손을 짚고 버틴다 → 끝까지 잡는다
- 넘긴 뒤 늦게 따라가면 → 상대가 돌아 가드를 잡는다 → 바로 따라 올라간다

## 막히면

- 상대가 왼손을 짚으려 하면 → [엘리베이션 스윕 (리버스 X)](../techniques/elevation-sweep-to-mount.md)
- 상대가 넓게 서서 체중을 낮추면 → [싱글 레그 X 가드](../techniques/single-leg-x-guard.md)로 바꾼다
- 상대가 다리를 빼며 돌아가면 → [리버스 X → 백 테이크](../techniques/reverse-x-to-back-take.md)

## 방어하는 쪽 (상대 입장)

- 상대 오른손이 내 왼쪽 소매를 당기고 상대 엉덩이가 들리면 스윕 신호
- 왼쪽 소매 그립부터 끊고 왼다리를 넓게 디뎌 엉덩이를 낮춘다
- 뒤로 빼지 말고 엉덩이를 앞으로 보내 상대 가슴 쪽으로 눌러 훅을 무너뜨린다
- 이미 넘어가면 넘어가는 방향으로 몸을 돌려 상대 다리를 하프가드로 감는다
