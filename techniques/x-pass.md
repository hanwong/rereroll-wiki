# X 패스 (X Pass)

[패스](../positions/passing.md) · 패스 · 위 → [사이드 컨트롤](../positions/side-control.md)

다른 이름: 엑스 패스, 엑스패스, x pass

## 세팅 과정 (오른손잡이 기준)

1. 서서 내 왼손으로 상대 오른쪽 무릎, 오른손으로 상대 왼쪽 무릎 바지를 잡는다
2. 내 왼발을 상대 다리 사이로 내 오른쪽 대각선 깊숙이 내딛는다(X자 스텝)
3. 상대가 내 오른쪽을 막으면 내 왼쪽(상대 오른쪽)으로 빠르게 돌아 나간다
4. 다리를 바닥에 눌러 두고 가슴을 떨어뜨려 상대 오른쪽에서 사이드 컨트롤을 잡는다

## 핵심 디테일

- 양손으로 상대 무릎 바지를 잡아 다리 높이를 내가 정한다
- 내 왼발 X자 스텝은 깊고 빠르게 — 상대 엉덩이 옆까지 들어간다
- 상대가 한쪽을 막으면 그 힘을 이용해 반대 방향으로 빠르게 바꾼다
- 돌아 나간 뒤 다리를 바닥에 눌러 두고 가슴을 떨어뜨려야 끝난다

## 흔한 실수

- 스텝이 얕으면 상대 발이 내 골반에 다시 붙는다 → 상대 다리 사이로 깊게 내딛는다
- 방향을 바꿀 때 멈칫하면 상대가 따라온다 → 막히는 순간 바로 돈다
- 돌아 나가서 서 있기만 하면 상대가 무릎을 넣는다 → 바로 가슴을 붙인다

## 막히면

- 상대가 무릎을 세워 니 쉴드로 막으면 → [니슬라이스 패스](../techniques/knee-slice-pass.md)
- 상대가 다리를 높이 들어 따라오면 → [토레안도 패스](../techniques/toreando-pass.md)로 다리를 바닥에 누른다
- 상대가 내 다리 하나를 감으면 → [하프가드 패스 (크로스페이스 · 언더훅)](../techniques/half-guard-pass.md)

## 방어하는 쪽 (상대 입장)

- 상대가 양손으로 내 무릎 바지를 잡고 왼발을 내 다리 사이로 깊게 내딛으면 X 패스 신호
- 발을 상대 골반이나 무릎에 대 거리를 지키고 무릎 그립을 끊는다 (그립 끊기 (오픈 가드))
- 상대가 내 오른쪽으로 돌아 나가면 오른쪽 어깨로 돌아누워 엉덩이를 내 왼쪽으로 빼고 오른 무릎을 다시 넣는다
- 이미 사이드가 잡혔으면 사이드 이스케이프 (프레임 · 쉬림프)
