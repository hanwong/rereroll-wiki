# 스파이더 가드 (Spider Guard)

[스파이더 · 라쏘 · 소매 가드](../positions/spider-lasso.md) · 자세 · 컨트롤 · 아래 → [스파이더 · 라쏘 · 소매 가드](../positions/spider-lasso.md)

다른 이름: 스파이더, 스파이더가드, 칼라 슬리브 → 스파이더, 칼라슬리브 스파이더, 더블 슬리브 → 스파이더, 스파이더 진입

## 세팅 과정 (오른손잡이 기준)

1. 내 왼손으로 상대 오른쪽 소매를, 오른손으로 상대 왼쪽 소매를 잡고 팔이 펴지게 민다
2. 내 왼발바닥은 상대 오른쪽 이두에, 오른발바닥은 상대 왼쪽 이두에 댄다
3. 왼발로 밀 때 오른발은 당기는 식으로 번갈아 상대 균형을 흔든다
4. 상대가 무너지는 쪽으로 스윕이나 트라이앵글로 잇는다

## 핵심 디테일

- 소매 끝을 손바닥 쪽으로 말아 쥐고 상대 팔이 펴지게 민다
- 발바닥을 이두에 대고 무릎을 바깥으로 벌려 상대 팔을 펴 둔다
- 왼발로 밀 때 오른발은 당기는 식으로 번갈아 상대 균형을 흔든다

## 흔한 실수

- 발이 이두에서 미끄러지면 상대가 팔을 접어 그립을 끊는다 → 소매를 당기며 발로 이두를 계속 민다
- 두 다리를 쭉 편 채 버티기만 하면 상대가 다리를 넘어 패스한다 → 밀고 당기기를 섞어 상대를 계속 흔든다
- 소매 안으로 손가락을 넣어 잡으면 반칙이다 → 소매 끝을 바깥에서 말아 쥔다

## 막히면

- 상대가 뒤로 버티면 → [스파이더 스윕](../techniques/spider-sweep.md)
- 상대가 앞으로 기대면 → [트라이앵글 (스파이더)](../techniques/triangle-from-spider-guard.md)
- 상대가 팔을 접어 발을 떼려 하면 → [스파이더 → 라쏘](../techniques/spider-to-lasso.md)

## 방어하는 쪽 (상대 입장)

- 상대 두 손이 내 두 소매를 잡고 두 발이 내 이두에 오면 스파이더 신호
- 팔꿈치를 몸 쪽으로 붙이고 무릎을 낮춰 자세를 세운다
- 손목을 돌려 소매 그립을 끊거나 팔을 접어 발을 이두에서 떼어낸다
- 다 잡혔으면 스파이더 가드 패스나 스택 패스 (스파이더 상대)로 간다
