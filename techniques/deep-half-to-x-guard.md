# 딥 하프 → X 가드 (Deep Half to X-Guard)

[딥 하프가드](../positions/deep-half.md) · 전환 · 아래 → [X 가드 · 싱글 레그 X · 앵클락](../positions/x-guard.md)

다른 이름: 딥하프 X가드

## 세팅 과정 (오른손잡이 기준)

1. 상대가 일어서면 안은 상대 오른다리를 내 오른쪽 어깨 위로 올려 끌어안는다
2. 내 오른발을 상대 왼쪽 무릎 뒤에 건다
3. 내 왼발을 상대 왼쪽 골반 앞에 대어 두 발을 X로 엇갈린다
4. X 가드 — 다리를 펴서 상대 중심을 띄운다

## 핵심 디테일

- 상대가 일어서거나 체중을 뒤로 뺄 때 시작한다 — 앞으로 눌러 올 때는 하지 않는다
- 내 오른팔로 안은 상대 오른다리는 다리 훅이 다 걸릴 때까지 놓지 않는다
- 내 오른발은 상대 왼쪽 무릎 뒤까지 깊게 건다 — 엉덩이를 밀어 넣어 깊이를 만든다
- 훅이 다 걸리면 엉덩이를 상대 밑으로 넣고 몸을 상대 다리와 직각으로 둔다

## 흔한 실수

- 상대 오른다리를 먼저 놓으면 상대가 다리를 빼고 패스한다 → 발 훅이 걸릴 때까지 오른팔로 안고 있는다
- 오른발 훅이 얕으면 상대가 왼다리를 뒤로 빼 버린다 → 다리만 뻗지 말고 엉덩이째 밀어 넣어 무릎 뒤까지 건다
- X를 걸고 등을 바닥에 납작하게 두면 상대 중심이 안 뜬다 → 엉덩이를 들고 다리를 펴 상대를 띄운다

## 막히면

- 상대가 다시 앞으로 눌러 크로스페이스를 걸면 → 딥 하프로 돌아가 [딥 하프 스윕](../techniques/deep-half-sweep.md)이나 [웨이터 스윕](../techniques/waiter-sweep.md)을 노린다 · [딥 하프가드](../techniques/deep-half-guard.md)
- 상대가 왼다리를 빼 버리면 → 안고 있는 오른다리로 [싱글 레그 X 가드](../techniques/single-leg-x-guard.md)를 잡는다
- X 가드가 잡히면 → [X 가드 스윕](../techniques/x-guard-sweep.md)이나 [X 가드 → 일어나기](../techniques/x-guard-technical-stand-up.md)로 잇는다
- 안고 있는 상대 오른다리가 펴지며 빠지려 하면 → [애시 가라미 (스트레이트 애시)](../techniques/ashi-garami.md)

## 방어하는 쪽 (상대 입장)

- 상대가 안고 있는 내 오른다리를 자기 오른쪽 어깨 위로 끌어올리고 엉덩이를 내 밑으로 돌리면 X 가드로 바꾸려는 신호
- 일어서지 말고 낮게 앉아 체중을 앞으로 실어 크로스페이스로 상대 상체를 눌러 둔다
- 상대 오른발이 내 왼쪽 무릎 뒤로 들어오기 전에 왼다리를 뒤로 빼 거리를 둔다
- 이미 X가 걸렸으면 내 왼쪽 무릎을 바닥으로 꿇어 훅을 눌러 죽이고 패스 각도를 찾는다 (무릎 눌러 X 가드 패스)
