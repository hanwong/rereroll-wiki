# X 가드 → 싱글 레그 X (X-Guard to Single Leg X)

[X 가드 · 싱글 레그 X · 앵클락](../positions/x-guard.md) · 전환 · 아래 → [X 가드 · 싱글 레그 X · 앵클락](../positions/x-guard.md)

다른 이름: SLX 전환

## 세팅 과정 (오른손잡이 기준)

1. 내 오른쪽 어깨에 얹은 상대 왼다리를 내려 왼쪽 발목을 내 오른쪽 겨드랑이에 안는다
2. 내 오른발(바깥 다리)을 상대 왼쪽 골반에 걸고 내 왼다리(안쪽 다리)는 상대 왼쪽 허벅지 안쪽에 둔다
3. 상대 왼다리를 가슴 쪽으로 당긴다
4. 상대 왼다리에 싱글 레그 X가 완성된다

## 핵심 디테일

- 상대 왼쪽 발목을 내 오른쪽 겨드랑이에 꽉 안은 상태를 전환 내내 유지한다
- 바깥 다리인 내 오른발은 상대 왼쪽 골반, 안쪽 다리인 내 왼다리는 상대 왼쪽 허벅지 안쪽
- 훅을 한꺼번에 풀지 말고 하나씩 바꿔 늘 한 곳은 잡고 있는다
- 상대가 뒤로 체중을 옮기거나 다리를 빼려 할 때 바꾼다

## 흔한 실수

- 두 훅을 한꺼번에 풀면 상대가 다리를 뺀다 → 하나씩 바꾼다
- 발목을 느슨하게 안으면 빠진다 → 겨드랑이에 꽉 끼운다
- 오른발이 골반에서 떨어지면 상대가 다가와 누른다 → 계속 민다

- 상대 균형이 무너지면 → [싱글 레그 X 스윕](../techniques/single-leg-x-sweep.md)
- 상대가 다리를 빼려 뒤로 당기면 → [스트레이트 앵클락](../techniques/straight-ankle-lock.md)
- 상대가 발끝을 돌려 버티면 → [토홀드 (앵클락 자세에서)](../techniques/toe-hold.md)

## 방어하는 쪽 (상대 입장)

- 상대가 내 왼쪽 발목을 겨드랑이로 옮겨 안고 상대 오른발이 내 왼쪽 골반으로 오면 싱글 레그 X 신호
- 바뀌는 순간 왼다리를 뒤로 빼고 무릎을 안쪽으로 모아 훅을 떼어 낸다
- 이미 걸렸으면 → 싱글 레그 X 빠져나오기 (서서) · 백스텝 (싱글 레그 X 상대)
- 발목을 노려 오면 → 앵클락 빠져나오기
