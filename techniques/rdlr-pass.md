# 리버스 데라히바 패스 (RDLR Pass)

[데라히바 · 리버스 데라히바](../positions/de-la-riva.md) · 패스 · 위 → [사이드 컨트롤](../positions/side-control.md)

다른 이름: RDLR 패스

## 세팅 과정 (오른손잡이 기준)

1. 상대가 오른다리로 내 오른다리에 리버스 훅을 걸면 자세를 세우고 내 발목 잡은 상대 왼손을 떼어낸다
2. 내 오른쪽 골반에 댄 상대 왼발을 내 오른손으로 눌러 바닥으로 내린다
3. 훅 걸린 내 오른다리를 빼며 상대 양 무릎을 내 왼쪽으로 모아 누른다
4. 무릎을 누른 채 내 오른쪽으로 돌아 들어가 상대 왼쪽 사이드 컨트롤로 간다

## 핵심 디테일

- 자세를 세우고 내 오른쪽 발목을 잡은 상대 왼손부터 떼어낸다
- 골반에 댄 상대 왼발을 바닥으로 눌러 내려야 훅 걸린 오른다리를 뺄 공간이 생긴다
- 다리를 빼는 동안 상대 양 무릎을 내 왼쪽으로 모아 눌러 둔다
- 무릎을 누른 채 내 오른쪽으로 크게 돌아 사이드를 잡는다

## 흔한 실수

- 발목 그립을 두고 돌면 상대가 다리를 당겨 넘긴다 → 그립부터 뗀다
- 상체를 숙이고 다가가면 상대가 다리 사이로 굴러 백을 노린다 → 자세를 세우고 엉덩이를 낮춘다
- 무릎을 일찍 놓으면 상대가 다시 다리를 넣는다 → 사이드에 닿을 때까지 누른다

## 막히면

- 훅이 깊어 오른다리가 안 빠지면 → [백스텝 (RDLR 상대)](../techniques/rdlr-backstep-counter.md)
- 상대 무릎이 다시 세워지면 → [헤드쿼터 포지션](../techniques/headquarters-position.md)으로 무릎을 눌러 다시 시작한다

## 방어하는 쪽 (상대 입장)

- 상대가 내 왼손 발목 그립을 떼고 골반에 댄 내 왼발을 눌러 내리면 패스 신호
- 발목을 다시 잡고 왼발을 상대 골반에 다시 올려 거리를 지킨다
- 다리가 빠지려 하면 오른다리 훅을 더 깊게 감는다
- 무릎이 내 오른쪽으로 눌리고 상대가 내 왼쪽으로 돌면 왼쪽 어깨로 돌아누워 오른발로 밀고 왼쪽 무릎을 다시 넣는다
