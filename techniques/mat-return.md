# 맷 리턴 (뒤에서 끌어내리기) (Mat Return from Standing Back)

[클린치 · 가드 풀링](../positions/clinch.md) · 테이크다운 · 서서 → [백 컨트롤](../positions/back-control.md)

다른 이름: 맷리턴

## 세팅 과정 (오른손잡이 기준)

1. 뒤에서 양팔로 허리를 안아 내 오른손으로 왼 손목을 잡고 가슴을 상대 등에 붙인다
2. 내 오른발로 상대 오른발 발목을 뒤에서 걸거나 상대를 들어 올린다
3. 상대 오른쪽(내 오른쪽)으로 틀며 바닥으로 끌어내린다
4. 떨어지면 바로 양발 훅을 넣어 백 컨트롤

## 핵심 디테일

- 손깍지는 상대 배꼽 아래 골반 높이에서 잡는다
- 들 땐 무릎을 굽혀 내 골반을 상대 엉덩이 아래로 넣고 다리 힘으로 든다
- 들어 올린 뒤 옆으로 틀어 상대 다리 · 엉덩이부터 바닥에 내린다
- 떨어지는 순간 가슴을 등에 붙인 채 따라 내려가 훅을 넣는다

## 흔한 실수

- 허리를 숙여 들면 내 허리를 다친다 → 무릎을 굽혀 다리로 든다
- 상대를 머리부터 떨어뜨리면 위험하다 → 옆으로 틀어 다리부터 내린다
- 내려놓고 서 있으면 상대가 일어선다 → 바로 훅을 넣는다

## 막히면

- 상대가 다리를 내 다리에 감아 버티면 → 내 오른발로 상대 오른쪽 발목을 뒤에서 걸어 넘긴다
- 상대가 그립을 떼고 돌아서려 하면 → [스탠딩 백 → 앉으며 백 테이크](../techniques/takedown-to-grounded-back-control.md)
- 상대가 무릎을 꿇고 엎드리면 → [터틀에서 백 테이크](../techniques/turtle-back-take.md)

## 방어하는 쪽 (상대 입장)

- 상대 골반이 내 엉덩이 밑으로 들어오면 → 들어 올리려는 신호
- 무릎을 굽혀 낮추고 내 오른다리를 상대 오른다리 바깥에 감아 들리지 않게 한다
- 상대 오른발이 내 오른쪽 발목 뒤에 걸리면 그 발을 들어 빼며 체중을 앞으로 둔다
- 이미 내려갔으면 → 뒤에서 잡혔을 때 안전하게 내려가기처럼 팔꿈치를 무릎에 붙여 훅을 막는다
