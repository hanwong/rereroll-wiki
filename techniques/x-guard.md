# X 가드 (X-Guard)

[X 가드 · 싱글 레그 X · 앵클락](../positions/x-guard.md) · 자세 · 컨트롤 · 아래 → [X 가드 · 싱글 레그 X · 앵클락](../positions/x-guard.md)

다른 이름: 엑스 가드, X가드, 엑스가드

## 세팅 과정 (오른손잡이 기준)

1. 상대가 서면 상대 왼다리 아래로 들어가 그 다리를 내 오른쪽 어깨에 얹고 내 오른팔로 안는다
2. 내 왼발은 상대 오른쪽 무릎 뒤(오금)에 훅으로 건다
3. 내 오른발은 상대 오른쪽 허벅지 안쪽이나 골반에 대 두 다리가 X 모양이 되게 한다
4. 안은 상대 왼쪽 발목을 가슴으로 당기며 두 훅으로 상대 오른다리를 밀어 벌린다

## 핵심 디테일

- 상대가 서 있을 때 상대 왼다리 밑으로 들어가 내 오른쪽 어깨에 얹고 오른팔로 안는다
- 내 왼발은 상대 오른쪽 오금, 내 오른발은 상대 오른쪽 허벅지 안쪽·골반 — 두 다리가 X 모양
- 안은 왼쪽 발목을 가슴으로 당기고 두 훅으로 오른다리를 밀어 벌려야 균형이 깨진다
- 엉덩이를 상대 바로 밑에 두어야 상대가 체중을 싣지 못한다

## 흔한 실수

- 내 엉덩이가 멀리 떨어지면 상대가 다리를 뺀다 → 상대 밑으로 바짝 들어간다
- 왼다리를 느슨하게 안으면 상대가 빼서 거리를 둔다 → 오른팔로 꽉 안는다
- 훅이 얕으면 상대가 쉽게 떼어 낸다 → 오금·허벅지 깊이 건다

## 방어하는 쪽 (상대 입장)

- 상대가 내 왼다리 밑으로 들어와 오른쪽 어깨에 얹으면 X 가드 신호
- 들어오기 전에 무릎을 굽혀 엉덩이를 낮추고 상대 머리·어깨를 눌러 밀어낸다
- 걸렸으면 왼다리를 억지로 빼지 말고 → 무릎 눌러 X 가드 패스 · 스매시 패스 (X 가드 상대)
- 서서 빠질 수 있으면 → X 가드 빠져나오기 (서서)
