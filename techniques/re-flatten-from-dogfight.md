# 도그파이트 상대 다시 눕히기 (Re-flatten from Dogfight)

[하프가드](../positions/half-guard.md) · 자세 · 컨트롤 · 위 → [하프가드](../positions/half-guard.md)

다른 이름: 도그파이트 탑 디펜스

## 세팅 과정 (오른손잡이 기준)

1. 상대가 내 오른다리를 감고 왼팔 언더훅일 때 내 오른팔 위저로 상대 왼쪽 어깨를 눌러 둔다
2. 잡힌 내 오른다리를 뒤로 빼며 엉덩이를 낮춘다
3. 내 왼팔로 크로스페이스를 걸어 머리를 눌러 눕힌다
4. 하프 탑

## 핵심 디테일

- 내 오른팔 위저는 상대 왼쪽 팔꿈치 위까지 깊게 감고 내 옆구리에 붙인다
- 잡힌 내 오른다리를 뒤로 빼고 엉덩이를 낮춰 무게를 상대 등·어깨에 싣는다
- 내 왼다리는 넓게 디뎌 베이스를 만든다
- 왼팔 크로스페이스로 상대 턱을 밀어 얼굴을 돌려야 상체가 무너진다

## 흔한 실수

- 위저를 팔로만 잡으면 상대 언더훅이 더 깊어진다 → 팔꿈치를 옆구리에 붙이고 어깨로 누른다
- 상체를 세우고 버티면 상대가 다리를 안고 일어선다 → 엉덩이를 낮춘다
- 두 무릎을 붙이고 꿇어 있으면 앞으로 밀려 넘어간다 → 왼다리를 넓게 디딘다

## 막히면

- 상대가 앞으로 강하게 밀어 오면 → [스냅 다운 (도그파이트 탑)](../techniques/snap-down-from-dogfight.md)
- 상대 등이 바닥에 닿으면 → [크로스페이스 (도그파이트 탑)](../techniques/crossface-from-dogfight.md)로 [패스](../positions/passing.md)까지
- 상대가 계속 언더훅으로 버티면 → [하프 탑 위저 카운터](../techniques/half-guard-whizzer-counter.md)

## 방어하는 쪽 (상대 입장)

- 상대 오른팔 위저가 내 왼팔을 조이고 상대 왼팔이 내 얼굴 앞으로 오면 신호
- 머리를 상대 가슴에 붙여 크로스페이스 자리를 막고 왼팔 언더훅을 더 깊이 넣는다
- 눌리기 전에 오른팔로 상대 오른다리를 안고 앞으로 민다 → 도그파이트 전진 스윕
- 이미 눌렸으면 → 도그파이트 → 하프가드 복귀
