# Z 가드 (Z-Guard)

[하프가드](../positions/half-guard.md) · 자세 · 컨트롤 · 아래 → [하프가드](../positions/half-guard.md)

다른 이름: 제트 가드, Z가드, 지 가드, 높은 니 쉴드, 하이 니 쉴드

## 세팅 과정 (오른손잡이 기준)

1. 니 쉴드인 내 왼쪽 무릎을 상대 가슴이나 어깨 높이로 올린다
2. 아래쪽인 내 오른다리는 상대 오른다리를 감는다
3. 내 오른팔로 상대 머리를 밀어 프레임을 만든다
4. 내 왼손으로 상대 오른쪽 소매나 깃을 잡고 스윕 · 회복을 노린다

## 핵심 디테일

- 니 쉴드인 내 왼쪽 무릎을 상대 가슴·어깨 높이로 올려 상대가 가슴을 붙이지 못하게 한다
- 내 오른다리는 상대 오른다리를 감아 상대가 다리를 빼지 못하게 한다
- 내 오른팔로 상대 머리를 밀어 프레임 — 상대가 크로스페이스를 못 건다
- 내 왼손으로 상대 오른쪽 소매·깃을 잡아 상대 팔이 내 무릎을 치우지 못하게 한다

## 흔한 실수

- 무릎이 배 높이에만 있으면 → 상대가 눌러 접는다 → 가슴·어깨 높이로 올린다
- 머리 프레임이 없으면 → 상대가 무릎 위로 상체를 넘겨 누른다 → 오른팔로 머리를 민다
- 등을 대고 누우면 → 무릎이 힘을 못 받는다 → 오른쪽 어깨로 옆으로 눕는다

## 막히면

- 상대가 무릎을 치우면 → [Z 가드 → 하프가드 (언더훅)](../techniques/z-guard-to-half-guard.md)
- 상대가 오른손을 바닥에 짚으면 → [기무라 (니 쉴드)](../techniques/kimura-from-knee-shield.md)
- 상대가 물러나 거리가 생기면 → [니 쉴드 → 클로즈드 가드](../techniques/knee-shield-to-closed-guard.md)

## 방어하는 쪽 (상대 입장)

- 상대 왼쪽 무릎이 내 가슴 높이로 올라오고 상대 오른팔이 내 머리를 밀면 Z 가드
- 잡힌 내 오른쪽 소매부터 떼고 상대 왼쪽 무릎을 바닥 쪽으로 눌러 접는다 → 스매시 패스
- 무릎을 치우는 순간 상대 왼팔 언더훅이 들어오니 내 오른팔 위저로 막는다
