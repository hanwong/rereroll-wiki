# 니 쉴드 스윕 (Sweep from Knee Shield)

[하프가드](../positions/half-guard.md) · 스윕 · 아래 → [마운트](../positions/mount.md)

다른 이름: 니 쉴드 넘기기, Z 가드 스윕, 제트 가드 스윕

## 세팅 과정 (오른손잡이 기준)

1. 상대 오른다리를 감은 니 쉴드에서 내 오른손은 상대 왼쪽 깃, 왼손은 상대 오른쪽 소매를 잡는다
2. 니 쉴드인 내 왼다리를 풀어 왼발로 상대 왼쪽 허벅지 안쪽을 걸어 든다
3. 내 오른다리로 상대 오른쪽 발목을 걸어 당긴다
4. 상대를 상대 오른쪽으로 넘기고 마운트

## 핵심 디테일

- 깃·소매 그립을 먼저 단단히 잡아 상대가 손을 짚지 못하게 한다
- 왼발 훅으로 상대 왼쪽 허벅지를 드는 것과 내 오른다리로 상대 오른쪽 발목을 막는 것을 동시에
- 상대 오른쪽 소매를 잡아 두면 넘어가는 쪽(상대 오른쪽)에 짚을 손이 없다
- 상대가 앞으로 체중을 실을 때 하면 그 힘으로 넘어간다

## 흔한 실수

- 그립 없이 다리만 쓰면 → 상대가 손을 짚고 버틴다 → 소매부터 잡는다
- 반만 넘기고 멈추면 → 다시 깔린다 → 끝까지 넘긴다
- 상대 오른쪽 발목을 안 막으면 → 상대가 그 발을 디뎌 버틴다 → 오른다리로 걸어 당긴다

## 막히면

- 상대가 오른손을 바닥에 짚어 버티면 → [기무라 (니 쉴드)](../techniques/kimura-from-knee-shield.md)
- 상대가 무릎을 치우고 들어오면 → [Z 가드 → 하프가드 (언더훅)](../techniques/z-guard-to-half-guard.md)
- 상대가 무겁게 눌러 오면 → [니 쉴드 유지 (눌릴 때)](../techniques/knee-shield-retention.md)

## 방어하는 쪽 (상대 입장)

- 상대가 내 왼쪽 깃·오른쪽 소매를 잡고 상대 왼발이 내 왼쪽 허벅지 안쪽에 걸리면 스윕 신호
- 잡힌 오른쪽 소매부터 떼어 넘어가는 쪽(내 오른쪽)에 손을 짚을 수 있게 한다
- 엉덩이를 낮추고 체중을 상대 쪽으로 실어 들리지 않게 한다
- 이미 넘어가면 바로 상대 다리를 감아 하프가드로 막는다
