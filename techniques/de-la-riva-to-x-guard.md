# 데라히바 → X 가드 (De La Riva to X-Guard Transition)

[데라히바 · 리버스 데라히바](../positions/de-la-riva.md) · 전환 · 아래 → [X 가드 · 싱글 레그 X · 앵클락](../positions/x-guard.md)

다른 이름: DLR X가드

## 세팅 과정 (오른손잡이 기준)

1. 데라히바(내 왼다리 훅)에서 상대를 당겨 체중을 내 위로 싣게 한다
2. 엉덩이를 상대 밑으로 넣으며 상대 왼다리를 내 오른쪽 어깨에 얹고 오른팔로 안는다
3. 상대 왼쪽 골반에 댄 내 오른발을 떼어 상대 오른쪽 허벅지 앞에 댄다
4. 내 왼다리 훅은 상대 오른쪽 오금 뒤에 그대로 두어 X 모양을 만든다

## 핵심 디테일

- 상대가 앞으로 체중을 실을 때 엉덩이를 상대 밑으로 넣어야 쉽게 들어간다
- 상대 왼다리를 내 오른쪽 어깨에 얹고 오른팔로 꽉 안아 다리를 못 빼게 한다
- 오른발은 상대 오른쪽 허벅지 앞으로 옮기고 왼다리 훅은 오른쪽 오금 뒤에 두어 X를 만든다

## 흔한 실수

- 상대와 거리가 멀면 밑으로 못 들어간다 → 훅과 소매로 당겨 상대 무게를 내 위로 끌어온다
- 왼다리를 안지 않고 발만 바꾸면 상대가 다리를 빼고 패스한다 → 먼저 어깨에 얹고 안은 다음 발을 옮긴다
- 옮기는 중에 왼다리 훅이 풀리면 X가 안 만들어진다 → 훅은 오금 뒤에 그대로 둔다

## 막히면

- 상대가 뒤로 물러나 거리를 벌리면 → [데라히바 스윕](../techniques/de-la-riva-sweep.md)
- 상대가 무릎을 꿇어 낮게 버티면 → [베림볼로](../techniques/berimbolo-entry.md)
- X가 잡힌 뒤 상대가 버티면 → [X 가드 스윕](../techniques/x-guard-sweep.md)
- 상대가 앞다리를 들어 X 훅을 피하면 → [애시 가라미 (스트레이트 애시)](../techniques/ashi-garami.md)

## 방어하는 쪽 (상대 입장)

- 상대가 엉덩이를 내 밑으로 넣으며 내 왼다리를 끌어안으면 X 가드 신호
- 앞으로 체중을 싣지 말고 엉덩이를 뒤로 빼 자세를 낮춘다
- 안기려는 내 왼다리를 뒤로 빼 거리를 둔다
- 이미 X가 걸렸으면 무릎 눌러 X 가드 패스나 X 가드 빠져나오기 (서서)로 푼다
