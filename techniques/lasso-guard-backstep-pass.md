# 백스텝 패스 (라쏘 상대) (Lasso Guard Backstep Pass)

[스파이더 · 라쏘 · 소매 가드](../positions/spider-lasso.md) · 패스 · 위 → [사이드 컨트롤](../positions/side-control.md)

다른 이름: 라쏘 백스텝

## 세팅 과정 (오른손잡이 기준)

1. 상대 왼다리 라쏘가 내 오른팔에 걸리면 내 왼다리를 뒤로 돌리며 몸을 돌린다
2. 라쏘 걸린 내 오른쪽 팔꿈치를 당겨 느슨하게 만든다
3. 상대 왼다리를 내 손으로 눌러 두고 돌아 사이드로 간다
4. 사이드

## 핵심 디테일

- 돌기 전에 라쏘 걸린 내 오른쪽 팔꿈치를 옆구리에 붙여 팔을 짧게 만든다
- 내 왼손으로 내 오른쪽 소매를 잡은 상대 왼손 그립을 먼저 끊거나 느슨하게 한다
- 돌 때 무릎을 굽혀 엉덩이를 낮게 두고 체중을 상대 다리 쪽에 싣는다
- 라쏘가 풀리면 멈추지 말고 바로 가슴을 붙여 사이드를 굳힌다

## 흔한 실수

- 소매 그립이 단단한 채 돌면 라쏘가 더 조여 어깨가 끌려간다 → 그립부터 풀고 돈다
- 엉덩이를 들고 서서 돌면 등을 보이거나 넘어간다 → 낮게 돈다
- 돌다가 중간에 멈추면 상대가 다리를 다시 감는다 → 한 번에 끝까지 돈다

## 막히면

- 상대가 소매를 끝까지 놓지 않으면 → [스택 패스 (라쏘 상대)](../techniques/lasso-guard-stack-pass.md)
- 상대 왼팔이 깃이나 바닥으로 뻗어 나오면 → [기무라 (라쏘 위에서)](../techniques/kimura-from-lasso-guard.md)
- 상대가 다리를 내 등 쪽으로 넘겨 오모플라타로 바꾸면 → 자세를 세우고 [오모플라타 스택 방어](../techniques/stack-defense-from-omoplata.md)

## 방어하는 쪽 (상대 입장)

- 상대가 오른쪽 팔꿈치를 당기며 왼다리를 뒤로 빼 몸을 돌리기 시작하면 백스텝 신호
- 내 왼손 소매 그립을 내 엉덩이 쪽으로 당기고 내 왼다리 라쏘를 더 깊게 감아 팔을 못 빼게 한다
- 상대가 도는 중 균형이 흔들리면 → 라쏘 스윕
- 이미 라쏘가 풀렸으면 내 오른발로 상대 골반을 밀어 거리를 만들고 가드 리텐션 (다리 되돌리기)
