# 뒤에서 잡혔을 때 되치기 (Counter Throw from Rear Clinch)

[클린치 · 가드 풀링](../positions/clinch.md) · 테이크다운 · 서서 → [사이드 컨트롤](../positions/side-control.md) / [마운트](../positions/mount.md)

다른 이름: 리어 클린치 카운터

## 세팅 과정 (오른손잡이 기준)

1. 뒤에서 허리를 안기면 자세를 낮추고 내 두 손으로 내 배 앞의 상대 두 팔을 눌러 잡는다
2. 내 오른발을 뒤로 빼 상대 오른다리 바깥 뒤쪽에 걸어 넣는다
3. 상체를 내 오른쪽으로 틀며 상대를 내 오른다리 위로 뒤로 넘긴다
4. 상대가 넘어가면 그대로 상대 위로 올라간다

## 핵심 디테일

- 먼저 상대 두 팔을 내 배에 눌러 붙여 상대가 손을 빼 짚지 못하게 한다
- 무릎을 굽혀 내 골반이 상대 골반보다 낮아야 넘어간다
- 내 오른다리를 상대 오른다리 바깥 뒤쪽 깊이 넣어 걸림목을 만든다
- 상체를 내 오른쪽으로 틀며 체중을 뒤로 실어 함께 넘어간다

## 흔한 실수

- 선 채로 상체만 틀면 상대가 버틴다 → 낮추고 다리를 깊게 건다
- 상대 팔을 놓으면 상대가 짚고 버틴다 → 팔을 끝까지 눌러 잡는다
- 넘긴 뒤 내가 등을 대고 깔린다 → 넘어가며 몸을 돌려 위로 올라간다

## 막히면

- 상대가 오른다리를 빼 걸림목을 피하면 → [스탠딩 스위치](../techniques/standing-switch.md)
- 상대가 손을 풀고 물러나면 → [스탠딩 백에서 돌아서기](../techniques/grip-break-and-face.md)
- 상대가 같이 주저앉으면 → [뒤에서 잡혔을 때 안전하게 내려가기](../techniques/controlled-descent.md)

## 방어하는 쪽 (상대 입장)

- 상대 오른다리가 내 오른다리 바깥 뒤로 들어오면 → 되치기 신호
- 내 오른다리를 뒤로 빼고 엉덩이를 낮춰 걸림목을 피한다
- 손을 풀어 팔을 빼고 짚을 준비를 한다
- 넘어가면 팔을 펴서 짚지 말고 등을 둥글게 말아 떨어진 뒤 바로 가드를 만든다
