# 시클 스윕 (Sickle Sweep)

[오픈 가드](../positions/open-guard.md) · 스윕 · 아래 → [패스](../positions/passing.md)

다른 이름: 낫 스윕, 시클 스윕 (발 골반에서), 발 골반 시클

## 세팅 과정 (오른손잡이 기준)

1. 트라이포드와 같은 그립(내 오른손 상대 왼쪽 발목 · 왼손 상대 오른쪽 소매)에서 시작한다
2. 상대 왼쪽 골반에 댄 내 오른발은 그대로 밀고, 오금을 걸던 왼발을 바닥으로 내린다
3. 내린 왼발로 상대 오른쪽 발목 바깥을 낫처럼 걸어 안쪽으로 쓸면서 골반을 밀고 발목을 당긴다
4. 상대가 옆으로 넘어지면 왼쪽 발목을 놓지 않고 일어나 패스 자세로 간다

## 핵심 디테일

- 왼발 뒤꿈치·종아리로 상대 오른쪽 발목 바깥을 걸어 안쪽으로 쓸어 낸다
- 쓸기, 오른발로 골반 밀기, 왼쪽 발목 당기기를 동시에 한다
- 트라이포드 스윕이 막혔을 때 바로 바꿔 쓰는 짝 기술로 연습한다
- 상대가 넘어지면 왼쪽 발목을 쥔 채 바로 일어난다

## 흔한 실수

- 오른발이 골반에서 떨어지면 미는 힘이 없어 안 넘어간다 → 왼발만 바꾸고 오른발은 계속 민다
- 종아리 위쪽을 쓸면 상대가 버틴다 → 발목 높이로 낮게 쓴다
- 넘기고 누워 있으면 상대가 가드를 만든다 → 바로 일어나 패스 자세

## 막히면

- 상대가 오른다리를 넓게 빼고 버티면 → 다시 오금을 걸어 [트라이포드 스윕](../techniques/tripod-sweep.md)
- 상대가 앞으로 눌러 오면 → [발 골반 → 데라히바](../techniques/feet-on-hips-to-de-la-riva.md)로 바꿔 거리를 다시 잡는다

## 방어하는 쪽 (상대 입장)

- 상대가 내 왼쪽 발목을 잡은 채 왼발을 바닥으로 내려 내 오른쪽 발목 바깥에 대면 신호다
- 상대 오른손 그립부터 끊고 오른발을 뒤로 빼 거리를 둔다
- 왼쪽 무릎을 굽혀 엉덩이를 낮추고 오른발을 넓게 디뎌 쓸리지 않게 한다
- 넘어지면 손을 뒤로 짚지 말고 바로 앉아 다리로 상대를 막는다
