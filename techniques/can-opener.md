# 캔 오프너 (가드 열기) (Can Opener)

[클로즈드 가드](../positions/closed-guard.md) · 전환 · 위 → [패스](../positions/passing.md)

다른 이름: 캔오프너

## 세팅 과정 (오른손잡이 기준)

1. 클로즈드 가드 안에서 허리를 세우고 양손을 상대 뒤통수에 깍지 낀다
2. 팔꿈치를 모아 머리를 천천히 내 가슴 쪽으로 당긴다
3. 상대가 가드를 풀면 바로 손을 놓고 패스로 간다
4. 목 크랭크라 세게 당기지 않는다(대회·체육관 규칙 확인)

## 핵심 디테일

- 먼저 허리를 세우고 엉덩이를 뒤로 둬야 당길 힘이 생긴다
- 양손은 뒤통수 아래쪽에 깍지 끼고 두 팔꿈치를 모아 머리를 감싼다
- 목적은 탭이 아니라 상대가 다리를 풀게 만드는 것이다
- 가드가 풀리는 순간 손을 놓고 무릎을 다리 사이에 넣어 패스로 간다

## 흔한 실수

- 홱 잡아당기면 목을 다친다 → 아주 천천히 당기고 상대가 불편해하면 바로 놓는다
- 금지된 대회·체육관에서 쓰면 반칙이다 → 규칙을 먼저 확인하고 연습 상대와 미리 합의한다
- 머리를 당기느라 자세가 무너지면 트라이앵글·암바를 당한다 → 엉덩이를 뒤로 두고 팔꿈치를 모은다

## 막히면

- 상대가 가드를 안 풀면 → 손을 놓고 [가드 열기 (무릎 쐐기)](../techniques/closed-guard-break-knee.md)나 [스탠딩 가드 브레이크](../techniques/standing-guard-break.md)
- 상대가 내 팔을 잡아 트라이앵글을 노리면 → 손을 놓고 [클로즈드 가드 안 자세 되찾기](../techniques/posture-recovery.md)

## 방어하는 쪽 (상대 입장)

- 가드 안의 상대가 양손을 내 뒤통수에 깍지 끼면 신호다
- 평소 깃·소매 그립을 잡아 상대 손이 머리 뒤로 못 가게 한다
- 손이 들어오면 상대 상체를 내 가슴 쪽으로 끌어내려 당길 공간을 없애거나 깍지를 떼어 낸다
- 목이 눌리기 시작하면 버티지 말고 가드를 풀어 발로 상대 골반을 밀어 거리를 만든다
