# 테크니컬 마운트 (Technical Mount)

[마운트](../positions/mount.md) · 자세 · 컨트롤 · 위 → [마운트](../positions/mount.md)

다른 이름: 테크 마운트, 테크니컬 마운트 자세, 마운트 → 테크니컬 마운트, 테크니컬 마운트 전환

## 세팅 과정 (오른손잡이 기준)

1. 상대가 오른쪽으로 돌아누우면 내 오른 무릎을 상대 등 뒤에 붙인다
2. 내 왼발은 상대 머리 앞 옆에 세워 왼 무릎을 높인다
3. 가슴으로 상대 왼 어깨를 눌러 상대가 다시 눕지도 엎드리지도 못하게 한다
4. 여기서 암바 · 백 테이크 · 초크를 고른다

## 핵심 디테일

- 내 오른 무릎을 상대 등에 딱 붙여 상대가 다시 눕지 못하게 한다
- 왼발은 상대 머리 바로 앞에 세워 상대가 엎드리거나 일어나지 못하게 한다
- 가슴으로 위쪽 상대 왼 어깨를 눌러 둔다
- 위쪽 상대 왼팔이 가장 공격하기 좋다

## 흔한 실수

- 오른 무릎이 등에서 떨어지면 상대가 다시 등을 대 가드를 만든다 → 무릎을 등에 붙인다
- 왼발이 머리에서 멀면 상대가 앉아 일어난다 → 머리 바로 앞에 세운다
- 높이 앉아 쉬면 상대가 터틀로 굴러간다 → 가슴 무게를 계속 싣는다

## 막히면

- 상대가 왼팔을 붙여 숨기면 → [테크니컬 마운트 → 백](../techniques/technical-mount-to-back.md)
- 상대 왼팔이 뻗어 나오면 → [암바 (테크니컬 마운트)](../techniques/armbar-from-technical-mount.md)
- 상대가 다시 등을 대면 → [마운트](../positions/mount.md)로 돌아가 [마운트 유지](../techniques/mount-maintain.md)

## 방어하는 쪽 (상대 입장)

- 상대 오른 무릎이 내 등에 붙고 왼발이 내 머리 앞에 서면 → 테크니컬 마운트
- 위쪽인 내 왼팔은 팔꿈치를 몸에 붙이고 목을 지킨다
- 무릎이 등에서 떨어지는 순간 → 테크니컬 마운트 이스케이프
