# 크랩 라이드 빠져나오기 (Escape from Crab Ride)

[터틀 · 크루시픽스](../positions/turtle.md) · 탈출 · 아래 → [하프가드](../positions/half-guard.md)

다른 이름: 크랩 라이드 탈출, 크랩 라이드 이스케이프, Crab Ride Escape

## 세팅 과정 (오른손잡이 기준)

1. 엉덩이를 바닥 쪽으로 낮춰 상대가 띠로 끌어당기지 못하게 한다
2. 내 오른손으로 내 오른쪽 허벅지에 걸린 상대 오른발 훅을 내 오른쪽 무릎 바깥으로 밀어 뗀다
3. 훅이 빠진 내 오른쪽으로 몸을 돌려 상대를 마주 본다
4. 상대 오른다리를 내 두 다리 사이에 가두며 하프가드로 정리한다

## 핵심 디테일

- 엉덩이를 낮춰 상대 훅과 띠에 끌려가지 않게 한다
- 훅부터 먼저 뗀다 — 훅이 남아 있으면 돌아설 수 없다
- 훅이 빠진 내 오른쪽으로 돌아 상대를 마주 본다
- 턱을 당기고 팔꿈치를 붙여 초크를 막는다

## 흔한 실수

- 일어나려고 앞으로 나가면 상대가 띠를 당겨 앉힌다 → 엉덩이를 낮추고 훅부터 뗀다
- 훅이 남은 내 왼쪽으로 돌면 상대가 등에 그대로 붙는다 → 훅을 뗀 내 오른쪽으로 돈다
- 돌아선 뒤 다리를 안 감으면 상대가 바로 패스한다 → 상대 오른다리를 두 다리로 감는다

## 막히면

- 상대가 시트벨트를 먼저 잡으면 → [핸드 파이팅 (백 아래)](../techniques/hand-fighting-from-back.md)
- 상대가 훅을 다시 넣으면 → [터틀에서 훅 걷어내기](../techniques/clear-hook-from-turtle.md)
- 하프가드에서 납작하게 눌리면 → [하프가드에서 가드 회복](../techniques/half-guard-recovery.md)

## 방어하는 쪽 (상대 입장)

- 상대가 손으로 내 오른발 훅을 밀어 내면 → 띠를 당기며 가슴을 등에 붙여 상대 엉덩이를 내 쪽으로 끌어온다
- 상대가 오른쪽으로 돌기 시작하면 → 시트벨트를 잡아 상체를 묶는다
- 이미 마주 봤으면 → 하프가드 위에서 크로스페이스와 언더훅으로 눌러 패스를 시작한다
