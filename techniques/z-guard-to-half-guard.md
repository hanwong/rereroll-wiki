# Z 가드 → 하프가드 (언더훅) (Z-Guard to Half Guard)

[하프가드](../positions/half-guard.md) · 전환 · 아래 → [하프가드](../positions/half-guard.md)

다른 이름: 니 쉴드 풀어 언더훅

## 세팅 과정 (오른손잡이 기준)

1. 상대가 오른손으로 니 쉴드(내 왼쪽 무릎)를 밀어 치우면 그 팔을 따라 들어간다
2. 내 왼팔을 상대 오른쪽 겨드랑이 아래로 넣어 언더훅을 잡는다
3. 엉덩이를 상대 쪽으로 당겨 붙인다
4. 언더훅 스윕이나 백 테이크로 잇는다

## 핵심 디테일

- 상대가 오른손으로 무릎을 치우는 순간 그 팔을 따라 들어간다 — 기다리면 크로스페이스가 온다
- 내 왼팔은 상대 오른쪽 겨드랑이 깊이, 팔꿈치는 몸에 붙인다
- 무릎을 내릴 때 엉덩이를 상대 쪽으로 당겨 붙여 옆으로 선 자세를 지킨다
- 언더훅을 잡으면 바로 스윕이나 백으로 잇는다

## 흔한 실수

- 언더훅 없이 무릎부터 내리면 → 크로스페이스에 눌린다 → 팔을 먼저 넣는다
- 납작하게 누운 채 바꾸면 → 상대가 눌러 패스한다 → 옆으로 세운 채 바꾼다
- 잡고 멈추면 → 상대가 위저로 뺏는다 → 바로 다음 기술로

## 막히면

- 상대가 위저로 감으면 → [올드 스쿨 스윕](../techniques/old-school-sweep.md)
- 상대가 크로스페이스로 눌러 오면 → [눌린 하프 → 딥 하프](../techniques/deep-half-entry-from-flattened.md)
- 언더훅이 깊게 들어가면 → [도그파이트](../techniques/dogfight-position.md) 또는 [하프가드 백 테이크](../techniques/half-guard-back-take.md)

## 방어하는 쪽 (상대 입장)

- 내 오른손으로 상대 무릎을 치운 직후 상대 왼팔이 내 오른쪽 겨드랑이로 들어오면 언더훅 신호
- 무릎을 치운 오른팔을 그대로 상대 얼굴 쪽으로 가져가 크로스페이스로 눕힌다
- 이미 들어왔으면 내 오른팔로 위저를 감고 체중을 싣는다 → 하프 탑 위저 카운터
