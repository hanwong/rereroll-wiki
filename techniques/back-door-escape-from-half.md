# 백 도어 이스케이프 (하프) (Back Door Escape from Half Guard)

[하프가드](../positions/half-guard.md) · 백 테이크 · 아래 → [백 컨트롤](../positions/back-control.md) / [터틀 · 크루시픽스](../positions/turtle.md)

다른 이름: 백도어

## 세팅 과정 (오른손잡이 기준)

1. 상대 오른다리를 감은 하프에서 상대가 패스하며 체중이 앞으로 쏠리면 상대 오른다리 아래로 몸을 뺀다
2. 상대 오른쪽 엉덩이 뒤로 빠져나온다
3. 터틀이나 등 뒤로
4. 백 테이크

## 핵심 디테일

- 상대가 패스하려고 체중을 앞으로 실을 때가 기회 → 무게가 뒤에 있으면 안 된다
- 몸을 돌려 머리부터 상대 오른다리 밑으로 빠져나간다
- 나오면서 상대 오른쪽 엉덩이 뒤에 붙어 바로 허리를 잡는다

## 흔한 실수

- 상대 체중이 뒤에 있을 때 하면 빠질 공간이 없고 등만 보인다 → 앞으로 쏠릴 때 한다
- 빠져나와 멈추면 상대가 돌아앉아 마주 본다 → 바로 상대 허리·등에 붙는다
- 엎드릴 때 팔꿈치가 벌어지면 목·팔이 잡힌다 → 턱을 당기고 팔꿈치를 붙인다

## 막히면

- 상대가 엉덩이를 내려 공간을 막으면 → [눌린 하프 → 딥 하프](../techniques/deep-half-entry-from-flattened.md)
- 상대가 돌아앉아 마주 보면 → [하프가드 → 싱글 레그](../techniques/half-guard-to-single-leg.md)
- 상대가 내 등에 붙어 오면 → [터틀 → 가드 회복](../techniques/turtle-to-guard.md)

## 방어하는 쪽 (상대 입장)

- 패스 도중 상대가 몸을 돌려 머리가 내 오른다리 밑으로 들어가면 신호
- 체중을 다시 아래로 내려 엉덩이를 낮추고 상대 등을 가슴으로 누른다
- 상대가 엎드리면 등에 붙어 내가 먼저 뒤를 잡는다 → 터틀에서 백 테이크
- 이미 상대가 뒤로 나왔으면 돌아앉아 상대를 마주 보고 다리로 막는다
