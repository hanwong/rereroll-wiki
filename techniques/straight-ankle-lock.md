# 스트레이트 앵클락 (Straight Ankle Lock)

[X 가드 · 싱글 레그 X · 앵클락](../positions/x-guard.md) · 서브미션 · 아래

다른 이름: 앵클락, 발목 꺾기, 풋락, 스트레이트 풋락, 앵클락 (X 가드)

## 세팅 과정 (오른손잡이 기준)

1. 상대 왼쪽 발목을 내 오른쪽 겨드랑이에 끼우고 내 오른쪽 손목 날을 아킬레스 아래에 댄다
2. 내 두 다리로 상대 왼쪽 허벅지를 감아 무릎을 모은다
3. 오른쪽 손목을 가슴에 붙여 그립을 조이고 내 오른쪽으로 눕는다
4. 엉덩이를 천천히 밀고 가슴을 펴 상대가 탭할 시간을 준다

## 핵심 디테일

- 내 오른쪽 손목 뼈 날을 종아리가 아니라 아킬레스 힘줄에 정확히 댄다
- 상대 발을 겨드랑이 깊이 끼워 발이 돌아갈 틈을 없앤다
- 팔로 꺾지 말고 내 오른쪽으로 누워 엉덩이를 밀고 가슴을 펴는 힘으로 마무리한다
- 두 무릎을 모아 상대 왼쪽 허벅지를 계속 조여 상대가 무릎을 굽혀 빼거나 일어나지 못하게 한다

## 흔한 실수

- 손목이 종아리 위쪽에 걸리면 → 아프지 않다 → 손목을 아킬레스까지 내린다
- 팔로만 당기면 → 그립이 풀린다 → 눕고 엉덩이로 민다
- 확 꺾으면 → 파트너 발목이 다친다 → 천천히 조여 탭할 시간을 준다

## 막히면

- 상대가 일어서며 빠지려 하면 → [싱글 레그 X 스윕](../techniques/single-leg-x-sweep.md)
- 상대가 무릎을 빼 앞으로 넘어오면 → 발을 골반에 대 [싱글 레그 X 가드](../techniques/single-leg-x-guard.md)로 다시
- 상대가 발끝을 세워 버티면 → 손목을 아킬레스에 다시 붙이고 다리 조임부터 강하게
- 상대가 발끝을 돌려 발등이 드러나면 → [토홀드 (앵클락 자세에서)](../techniques/toe-hold.md) · 뒤꿈치가 드러나면 [아웃사이드 힐훅 (스트레이트 애시)](../techniques/outside-heel-hook.md)(노기 브라운 · 블랙만)

## 방어하는 쪽 (상대 입장)

- 상대 오른팔이 내 왼쪽 발목 뒤로 감기고 상대가 눕기 시작하면 앵클락 신호
- 상대가 눕기 전에 바로 앉아 상대 오른팔을 잡고 왼발 발끝을 세워 발목이 펴지지 않게 한다
- 왼쪽 무릎을 굽힌 채 내 오른발로 상대 엉덩이를 밀어 다리를 뺀다 → 앵클락 빠져나오기 · 무릎 빼기 (앵클락 상대)
- 이미 아프면 버티지 말고 바로 탭
