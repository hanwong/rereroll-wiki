# 도그파이트 → 하프가드 복귀 (Re-pull Half Guard from Dogfight)

[하프가드](../positions/half-guard.md) · 전환 · 아래 → [하프가드](../positions/half-guard.md)

다른 이름: 하프 다시 잡기

## 세팅 과정 (오른손잡이 기준)

1. 스윕이 막히면 내 오른팔로 상대 오른다리를 안은 채 엉덩이를 바닥에 앉힌다
2. 안은 상대 오른다리를 내 양 다리로 감는다
3. 내 오른쪽 어깨와 엉덩이를 바닥에 대고 몸을 상대 쪽으로 세운다
4. 내 왼팔 언더훅 하프가드

## 핵심 디테일

- 상대 위저가 깊어져 눌리기 전에 미리 앉는다 → 늦으면 납작하게 눌린다
- 앉을 때 등을 대지 말고 내 오른쪽 옆으로 앉아 상대를 보고 눕는다
- 두 다리로 감을 때까지 내 오른팔로 안은 상대 오른다리를 놓지 않는다
- 내 왼팔 언더훅은 끝까지 유지한다

## 흔한 실수

- 등을 바닥에 대고 털썩 누우면 바로 크로스페이스를 맞는다 → 오른쪽 어깨·엉덩이로 옆으로 앉는다
- 다리를 감기 전에 안은 다리를 놓으면 상대가 다리를 빼 패스한다 → 감은 뒤에 놓는다
- 언더훅까지 빼고 앉으면 상대 가슴이 붙어 온다 → 왼팔 언더훅을 그대로 둔다

## 막히면

- 상대가 크로스페이스로 눌러 납작해지면 → [눌린 하프가드에서 회복](../techniques/flattened-half-guard.md)
- 상대가 다리를 빼고 패스하려 하면 → [쿼터 가드 → 니 쉴드](../techniques/knee-shield-from-quarter.md)
- 상대가 일어서면 → [하프가드 → X 가드](../techniques/half-guard-to-x-guard.md)

## 방어하는 쪽 (상대 입장)

- 상대가 엉덩이를 바닥에 앉히며 내 오른다리를 다시 감으려 하면 신호
- 앉는 순간 내 왼팔 크로스페이스로 상대 머리를 눌러 납작하게 만든다 → 크로스페이스 (도그파이트 탑)
- 감기기 전에 오른다리를 뒤로 빼 낸다
- 이미 감겼으면 하프 탑 기본 자세로 크로스페이스와 언더훅부터 다시 잡는다
