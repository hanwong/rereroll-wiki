# 웜 가드 스윕 (Worm Guard Sweep)

[라펠 가드](../positions/lapel-guard.md) · 스윕 · 아래 → [사이드 컨트롤](../positions/side-control.md) / [마운트](../positions/mount.md)

다른 이름: 웜가드 스윕, 웜 가드 넘기기

## 세팅 과정 (오른손잡이 기준)

1. 웜 가드(상대 오른쪽 라펠을 상대 오른다리 뒤로 돌려 내 왼다리에 감음)에서 라펠 끝을 왼손으로 옮겨 당긴다
2. 감은 내 왼발로 상대 오른쪽 골반을 밀며 내 오른손으로 상대 왼쪽 발목이나 바지를 잡는다
3. 라펠을 당기며 상대 왼다리를 들어 묶인 오른다리 쪽(상대 오른쪽)으로 넘긴다
4. 라펠을 놓지 않고 따라 올라가 사이드나 마운트로 간다

## 핵심 디테일

- 라펠에 늘어짐이 없게 당겨 둔 상태에서 시작한다
- 내 오른손으로 상대 왼쪽 발목을 잡아 그 발로 디뎌 버티지 못하게 한다
- 감은 왼발로 상대 오른쪽 골반을 밀며 엉덩이를 비스듬히 틀어 상대 오른쪽으로 넘길 방향을 만든다
- 넘어가는 동안 라펠 긴장을 놓지 않고 따라 올라간다

## 흔한 실수

- 라펠이 느슨하면 상대가 오른발을 디뎌 버틴다 → 계속 당긴다
- 상대가 넓게 자리 잡고 있을 때 넘기면 안 된다 → 상대가 앞으로 오거나 움직일 때 넘긴다
- 넘긴 뒤 라펠부터 놓으면 상대가 돌아 나간다 → 자리를 잡을 때까지 쥔다

## 막히면

- 상대가 숙여 손을 짚으면 → [라펠 스윕 → 백](../techniques/lapel-sweep-to-back.md)
- 상대가 라펠을 벗기려 하면 → [라펠 엘리베이터 스윕](../techniques/lapel-elevator-sweep.md)
- 상대가 뒤로 물러나면 → [라펠 → 데라히바](../techniques/lapel-to-de-la-riva.md)

## 방어하는 쪽 (상대 입장)

- 상대 오른손이 내 왼쪽 발목을 잡고 라펠이 당겨지면 웜 가드 스윕 신호
- 왼발을 뒤로 빼 발목 그립을 떼고 엉덩이를 낮춰 체중을 뒤에 둔다
- 오른쪽으로 넘어가기 시작하면 내 오른손을 바닥에 짚어 버틴다
- 처음부터 막으려면 → 웜 가드 상대 자세 지키기
