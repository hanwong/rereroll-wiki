# 컴뱃 베이스 상대 가드 회복 (Guard Recovery vs Combat Base)

[패스](../positions/passing.md) · 방어 · 아래 → [오픈 가드](../positions/open-guard.md) / [클로즈드 가드](../positions/closed-guard.md)

다른 이름: 컴뱃 베이스 리가드

## 세팅 과정 (오른손잡이 기준)

1. 상대가 오른쪽 무릎을 세운 컴뱃 베이스로 들어왔을 때
2. 내 왼발 바닥으로 상대 오른쪽 무릎을 밀어 거리를 만든다
3. 엉덩이를 뒤로 빼며(쉬림프) 내 오른다리를 상대 허리 높이로 올린다
4. 내 오른발을 상대 왼쪽 골반이나 이두에 대어 거리를 지킨다
5. 양발로 거리를 잡았으면 오픈 가드나 클로즈드 가드로 돌아간다

## 핵심 디테일

- 상대가 무릎을 세운 순간 내 왼발 바닥을 상대 오른쪽 무릎에 대고 밀어 거리부터 만든다
- 발로 미는 것과 엉덩이를 뒤로 빼는 쉬림프를 같이 해 다리가 들어갈 자리를 만든다
- 내 오른발은 상대 왼쪽 골반이나 이두에 대 상대가 다시 다가오지 못하게 한다
- 두 발이 닿으면 손으로 깃·소매를 잡아 거리를 지킨다

## 흔한 실수

- 발로 밀기만 하고 엉덩이를 안 빼면 다리가 들어갈 공간이 없다 → 밀면서 같이 쉬림프한다
- 등을 바닥에 납작하게 두면 상대가 무릎을 넘긴다 → 옆으로 돌아누워 움직인다
- 상대가 무릎을 세운 뒤 한참 있다 움직이면 이미 니 슬라이드가 들어온다 → 세우는 순간 바로 민다

## 막히면

- 상대가 일어서서 헤드쿼터로 오면 → [헤드쿼터 상대 가드 회복](../techniques/re-guard-from-headquarters.md)
- 상대 오른발이 가까이 있으면 → [컴뱃 베이스 상대 스윕](../techniques/sweep-from-combat-base.md)
- 상대 무릎이 내 허벅지를 넘어오면 → 상대 오른발을 감아 [하프가드 (자세 · 프레임)](../techniques/half-guard-basics.md)

## 방어하는 쪽 (상대 입장)

- 상대 왼발이 내 오른쪽 무릎을 밀고 엉덩이가 뒤로 빠지면 가드 회복 신호
- 밀리기 전에 체중을 앞으로 실어 세운 오른쪽 무릎을 상대 오른쪽 허벅지 위로 넘긴다 (니 슬라이드 (컴뱃 베이스))
- 상대 오른발이 내 왼쪽 골반·이두에 닿으면 그 발을 쳐내거나 일어서서 헤드쿼터를 잡는다
