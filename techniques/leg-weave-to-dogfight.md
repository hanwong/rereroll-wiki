# 레그 위브 상대 도그파이트 (Leg Weave to Dogfight)

[패스](../positions/passing.md) · 탈출 · 아래 → [하프가드](../positions/half-guard.md)

다른 이름: 레그 위브에서 일어나기

## 세팅 과정 (오른손잡이 기준)

1. 상대가 내 오른다리를 엮었을 때 내 왼팔로 상대 오른팔 언더훅을 잡는다
2. 상대 어깨를 밀며 내 오른쪽 팔꿈치와 무릎으로 일어난다
3. 엮인 내 오른다리를 풀며 내 오른손으로 상대 오른다리를 안는다
4. 상대와 무릎을 맞댄 도그파이트 자세에서 스윕이나 백 테이크로 잇는다

## 핵심 디테일

- 내 왼팔 언더훅이 깊어야 일어날 수 있다 — 손이 상대 등까지 간다
- 오른쪽 팔꿈치 → 손 → 무릎 순서로 바닥을 짚으며 일어난다
- 머리는 상대 오른쪽 옆구리에 붙여 크로스페이스를 막는다
- 일어나면 내 오른손으로 상대 오른다리를 안아 다시 눌리지 않게 한다

## 흔한 실수

- 언더훅이 얕은데 일어나려 하면 다시 눌린다 → 언더훅부터 깊게
- 머리가 상대 가슴 앞에 있으면 크로스페이스를 당한다 → 머리를 상대 옆구리에 붙인다
- 엉덩이가 바닥에 남아 있으면 상대가 다시 눕힌다 → 무릎으로 올라와 엉덩이를 띄운다

## 막히면

- 상대가 내 왼팔을 위저로 감으면 → [하프가드 → 싱글 레그](../techniques/half-guard-to-single-leg.md)로 다리를 안고 올라온다
- 상대가 체중을 앞으로 실으면 → [도그파이트 전진 스윕](../techniques/forward-drive-sweep-from-dogfight.md)
- 상대가 다시 눌러 눕히면 → [도그파이트 → 하프가드 복귀](../techniques/re-pull-half-guard-from-dogfight.md)

## 방어하는 쪽 (상대 입장)

- 상대 왼팔이 내 오른쪽 겨드랑이 아래로 들어오면 도그파이트 신호
- 언더훅이 깊어지기 전에 내 왼팔로 크로스페이스를 걸고 내 오른팔로 상대 왼팔을 위저로 감는다
- 상대가 무릎으로 올라왔으면 크로스페이스 (도그파이트 탑)나 도그파이트 상대 다시 눕히기
- 머리가 낮으면 스냅 다운 (도그파이트 탑)으로 앞으로 끌어내린다
