# 라쏘 스윕 (Lasso Sweep)

[스파이더 · 라쏘 · 소매 가드](../positions/spider-lasso.md) · 스윕 · 아래 → [패스](../positions/passing.md)

다른 이름: 라쏘 가드 스윕, 라소 스윕, Russian Lasso Sweep

## 세팅 과정 (오른손잡이 기준)

1. 왼다리 라쏘(상대 오른팔)를 깊게 걸고 내 오른손으로 상대 왼쪽 발목이나 바지를 잡는다
2. 내 오른발을 상대 왼쪽 무릎 안쪽에 대고 민다
3. 왼다리로 상대 오른팔을 끌어당기며 오른손으로 발목을 당기고 오른발로 무릎을 밀어 넘긴다
4. 넘어가면 라쏘를 풀고 따라 올라간다

## 핵심 디테일

- 왼다리 라쏘가 깊어야 상대 오른팔과 상체를 끌어당길 수 있다
- 오른손으로 상대 왼쪽 발목을 잡아 상대가 그 발을 빼지 못하게 한다
- 라쏘로 팔 당기기 · 오른손 발목 당기기 · 오른발 무릎 밀기를 동시에 쓴다
- 넘어가면 라쏘를 풀고 바로 따라 올라간다

## 흔한 실수

- 라쏘가 얕으면 상대 상체가 따라오지 않는다 → 발을 겨드랑이까지 넣는다
- 발목을 잡지 않고 밀면 상대가 왼발을 빼 버틴다 → 발목을 먼저 잡는다
- 넘긴 뒤 라쏘를 풀지 않으면 위로 못 올라간다 → 넘어가는 순간 다리를 빼고 일어난다

## 막히면

- 상대가 앞으로 무게를 실어 버티면 → [오모플라타 (라쏘)](../techniques/omoplata-from-lasso.md)
- 상대가 자세를 세워 팔을 빼려 하면 → [트라이앵글 (라쏘)](../techniques/triangle-from-lasso.md)

## 방어하는 쪽 (상대 입장)

- 상대 오른손이 내 왼쪽 발목을 잡고 상대 오른발이 내 왼쪽 무릎 안쪽에 오면 스윕 신호
- 내 왼발을 뒤로 빼 발목 그립을 풀고 체중을 낮춘다
- 라쏘 걸린 내 오른팔을 몸 쪽으로 당겨 라쏘를 느슨하게 한다
- 넘어지면 바로 다리를 세워 가드를 만든다
