# 신 투 신 → 싱글 레그 X (Shin-to-Shin to Single Leg X)

[오픈 가드](../positions/open-guard.md) · 전환 · 아래 → [X 가드 · 싱글 레그 X · 앵클락](../positions/x-guard.md)

다른 이름: SLX 진입, 싱글 레그 X 진입, 신투신 SLX

## 세팅 과정 (오른손잡이 기준)

1. 신 투 신에서 내 오른손으로 상대 왼쪽 발목을 잡은 채 뒤로 누우며 그 다리를 내 쪽으로 당긴다
2. 내 오른다리를 상대 왼쪽 허벅지 위로 넘겨 발을 상대 왼쪽 골반에 걸고 무릎은 바깥으로 조인다
3. 내 왼다리를 상대 두 다리 사이로 넣어 왼발을 상대 오른쪽 골반에 댄다
4. 잡은 왼쪽 발목을 가슴에 안아 싱글 레그 X를 완성한다

## 핵심 디테일

- 오른손 발목 그립을 놓지 않고 뒤로 누우며 상대 왼다리를 내 쪽으로 끌어온다
- 엉덩이를 상대 왼발 가까이 붙여야 다리가 깊게 감긴다
- 오른 무릎은 바깥으로 조여 상대 왼다리를 묶고 왼발은 상대 오른쪽 골반을 밀어 거리를 막는다
- 상대 왼 발목을 가슴에 꼭 안는다

## 흔한 실수

- 정강이를 너무 일찍 떼면 상대가 다리를 뺀다 → 오른다리가 감길 때까지 붙여 둔다
- 엉덩이가 멀면 감은 다리가 얕다 → 엉덩이를 상대 발밑까지 끌어 붙인다
- 발목을 안지 않으면 다리가 빠진다 → 발목을 겨드랑이·가슴에 끼운다

## 막히면

- 상대가 왼다리를 뒤로 빼면 → 따라 앉아 [신 투 신 가드](../techniques/shin-to-shin-guard.md)로 다시 붙는다
- 상대가 앞으로 눌러 오면 → [오픈 가드 → 딥 하프](../techniques/open-guard-to-deep-half.md)
- 싱글 레그 X가 잡히면 → [싱글 레그 X 스윕](../techniques/single-leg-x-sweep.md)
- 상대가 무릎을 안으로 돌려 버티면 → [애시 가라미 (스트레이트 애시)](../techniques/ashi-garami.md)

## 방어하는 쪽 (상대 입장)

- 상대가 내 왼 발목을 잡은 채 뒤로 누우며 다리를 끌면 싱글 레그 X 진입 신호
- 왼다리를 뒤로 빼고 엉덩이를 낮춰 상대가 밑으로 못 들어오게 한다
- 이미 감겼으면 낮게 균형을 잡고 싱글 레그 X 빠져나오기 (서서)나 백스텝 (싱글 레그 X 상대)로 빠진다
