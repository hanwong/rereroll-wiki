# 테크니컬 스탠드업 (Technical Stand-Up)

[오픈 가드](../positions/open-guard.md) · 전환 · 아래 → [스탠딩 · 테이크다운](../positions/standing.md)

다른 이름: 테크니컬 겟업, 기본 일어서기, 테크니컬 스탠드 업, 겟업

## 세팅 과정 (오른손잡이 기준)

1. 앉은 자세에서 내 왼손은 뒤 바닥을 짚고 오른손은 앞을 막는다(프레임)
2. 오른발을 세우고 엉덩이를 들어 올린다
3. 오른발과 왼손 사이로 왼다리를 빼서 뒤로 보낸다
4. 무릎을 펴고 일어서며 오른손은 계속 상대를 막는다

## 핵심 디테일

- 왼손은 엉덩이보다 조금 뒤에 짚고 왼손과 오른발로 몸을 받쳐 엉덩이를 높이 든다
- 엉덩이를 충분히 들어야 왼다리가 바닥에 걸리지 않고 뒤로 빠진다
- 일어나는 내내 눈과 오른손은 상대를 향해 거리를 지킨다
- 왼다리는 멀리 뒤로 보내 상대와 거리를 벌린 채 선다

## 흔한 실수

- 상대를 안 보고 일어나면 들어오는 상대에게 다시 깔린다 → 끝까지 상대를 보며 오른손으로 막는다
- 엉덩이를 덜 들고 다리를 빼면 다리가 끌려 넘어진다 → 엉덩이부터 높이 든다
- 다리를 바로 밑에 내리면 상대와 가까워 다리를 잡힌다 → 왼다리를 멀리 뒤로 빼서 선다

## 막히면

- 상대가 밀고 들어오면 → 오른발로 상대 골반을 밀어 [시팅 가드 기본 자세](../techniques/seated-guard-basics.md)로 돌아간다
- 상대가 몸을 숙여 다리를 내밀면 → [테크니컬 스탠드업 → 싱글 레그](../techniques/technical-stand-up-to-single-leg.md)
- 일어서기 전에 다리를 넘어오려 하면 → [가드 리텐션 (다리 되돌리기)](../techniques/open-guard-retention.md)

## 방어하는 쪽 (상대 입장)

- 상대가 왼손을 뒤에 짚고 오른발을 세워 엉덩이를 들면 일어서려는 신호다
- 엉덩이가 뜨는 순간 가슴을 낮춰 밀고 들어가 상대를 다시 뒤로 눕힌다
- 상대 오른발이 버티고 있으면 그 무릎·발목을 치우고 바로 패스로 간다 (토레안도 패스 · 레그 드래그)
- 이미 일어섰으면 → 그립 파이팅 (기본 그립)으로 다시 시작한다
