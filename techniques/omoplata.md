# 오모플라타 (Omoplata)

[클로즈드 가드](../positions/closed-guard.md) · 서브미션 · 아래

다른 이름: 오모플라따

## 세팅 과정 (오른손잡이 기준)

1. 내 왼손으로 상대 오른팔 삼두를 잡고 내 오른손으로 머리를 당겨 자세를 무너뜨린다
2. 내 오른발로 상대 왼쪽 골반을 밀며 몸을 돌리고, 왼다리를 상대 오른쪽 어깨 위로 넘긴다
3. 왼다리를 바깥으로 돌려 상대를 바닥에 엎드리게 만들고 내 오른팔로 상대 허리를 잡는다
4. 상대 오른손을 내 왼쪽 허벅지 쪽에 붙인 채 상체를 앞으로 천천히 숙여 어깨를 꺾는다

## 핵심 디테일

- 오른발로 상대 왼쪽 골반을 밀어 몸을 크게 돌려야 왼다리가 어깨 위로 넘어간다
- 왼다리는 상대 오른쪽 어깨 위에 오금까지 깊게 걸어 바닥으로 누른다
- 상대가 엎드리면 바로 내 오른팔로 허리를 감아 앞으로 구르지 못하게 한다
- 앉아 올라와 상대 오른손을 내 왼쪽 허벅지 옆에 붙인 채 천천히 숙인다

## 흔한 실수

- 허리를 안 감으면 상대가 앞으로 굴러 빠진다 → 엎드리자마자 감는다
- 다리가 어깨에 얕게 걸리면 상대가 자세를 세운다 → 오금까지 깊게 건다
- 누운 채 꺾으려 하면 각도가 안 나온다 → 앉아 올라와 상체를 숙인다

## 막히면

- 상대가 엎드려 버티면 → [오모플라타 스윕](../techniques/omoplata-sweep.md)
- 상대가 무릎을 세워 일어나려 하면 → [오모플라타 → 백](../techniques/omoplata-to-back.md)
- 상대가 자세를 세우고 쌓아 누르면 → [트라이앵글 초크](../techniques/triangle-choke.md)

## 방어하는 쪽 (상대 입장)

- 상대 왼다리가 내 오른쪽 어깨 위로 넘어오면 → 오모플라타 신호
- 엎드리기 전에 내 오른팔을 빼며 자세를 세우거나 상대 쪽으로 쌓아 누른다 → 오모플라타 스택 방어
- 엎드렸으면 허리가 감기기 전에 → 오모플라타 앞구르기 탈출
- 늦으면 탭한다
