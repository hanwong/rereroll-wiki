# X 가드 스윕 (X-Guard Sweep)

[X 가드 · 싱글 레그 X · 앵클락](../positions/x-guard.md) · 스윕 · 아래 → [패스](../positions/passing.md)

다른 이름: X가드 넘기기, X가드 스윕

## 세팅 과정 (오른손잡이 기준)

1. 안은 상대 왼다리를 가슴 쪽으로 당기고 두 훅으로 상대 오른다리를 밀어 다리를 벌린다
2. 상대가 뒤로 앉거나 손을 짚어도 안은 상대 왼쪽 발목을 놓지 않는다
3. 상대 왼다리를 든 채 일어나 밀어 눕힌다
4. 상대 왼다리를 놓지 않고 패스 자세로 간다

## 핵심 디테일

- 왼쪽 발목은 가슴으로 당기고 오른다리는 두 훅으로 밀어 다리를 크게 벌린다
- 상대가 뒤로 앉거나 손을 짚어도 안은 왼쪽 발목은 끝까지 놓지 않는다
- 상대가 넘어지면 바로 일어나 다리를 든 채 패스 자세를 잡는다

## 흔한 실수

- 발목을 놓으면 상대가 다시 일어나 거리를 둔다 → 끝까지 안는다
- 훅만 밀고 발목을 안 당기면 다리가 안 벌어진다 → 당기기와 밀기를 동시에
- 넘기고 누워 있으면 상대가 가드를 되찾는다 → 바로 일어난다

## 막히면

- 상대가 넓게 버티면 → [토마호크 스윕](../techniques/tomahawk-sweep.md)
- 상대가 다리를 빼려 뒤로 물러나면 → [X 가드 → 싱글 레그 X](../techniques/x-guard-to-single-leg-x.md)
- 상대 균형만 흔들리고 안 넘어가면 → [X 가드 → 일어나기](../techniques/x-guard-technical-stand-up.md)

## 방어하는 쪽 (상대 입장)

- 상대가 내 왼쪽 발목을 당기며 훅으로 오른다리를 밀어 벌리면 스윕 신호
- 엉덩이를 낮추고 체중을 상대 쪽으로 실어 무릎으로 눌러 균형을 지킨다
- 뒤로 앉게 되면 왼다리를 빼고 무릎을 세워 바로 가드를 만든다
