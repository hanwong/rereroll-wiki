# 사이드 → 곁누르기 (Side Control to Kesa Gatame)

[사이드 컨트롤](../positions/side-control.md) · 전환 · 위 → [곁누르기](../positions/kesa-gatame.md)

다른 이름: 사이드 → 케사가타메, 케사 전환, 케사가타메, 스카프 홀드

## 세팅 과정 (오른손잡이 기준)

1. 상대 오른쪽에서 사이드: 상대 오른팔을 내 왼쪽 겨드랑이에 끼운다
2. 엉덩이를 돌려 상대 머리 쪽을 보고 앉으며 내 오른팔로 상대 목 뒤를 감는다
3. 내 오른다리는 앞으로, 왼다리는 뒤로 벌려 베이스를 잡는다
4. 내 오른쪽 가슴으로 상대 가슴을 눌러 곁누르기를 만든다

## 핵심 디테일

- 상대 오른팔을 내 왼쪽 겨드랑이에 꽉 끼워 공간을 없앤다
- 엉덩이를 돌리는 동안 가슴을 상대에게서 떼지 않는다
- 엉덩이는 바닥에 낮게 앉고 오른다리 앞 · 왼다리 뒤로 넓게 벌려 베이스를 만든다
- 내 오른팔로 목 뒤를 깊게 감아 상대 머리를 내 옆구리 쪽으로 당긴다

## 흔한 실수

- 돌 때 가슴을 들면 상대가 팔을 빼고 프레임을 넣는다 → 가슴을 붙인 채 엉덩이만 돌린다
- 엉덩이를 들고 무릎으로 버티면 브릿지에 넘어간다 → 엉덩이를 바닥에 붙여 앉는다
- 상대 오른팔을 느슨하게 끼우면 상대가 팔을 빼고 내 등 쪽으로 돈다 → 겨드랑이를 조여 둔다

## 막히면

- 상대가 브릿지로 나를 넘기려 하면 → 다리를 더 넓게 벌리고 엉덩이를 낮춰 [곁누르기 (스카프 홀드)](../techniques/kesa-gatame.md)를 지킨다
- 상대가 나를 향해 돌아 등을 노리면 → [곁누르기 → 마운트](../techniques/kesa-to-mount.md) · [곁누르기 → 사이드](../techniques/kesa-to-side-control.md)
- 상대 오른팔이 빠지면 → [사이드 컨트롤 유지](../techniques/side-control-maintain.md)로 돌아가 다시 누른다

## 방어하는 쪽 (상대 입장)

- 상대가 내 오른팔을 자기 왼쪽 겨드랑이로 끌어안고 엉덩이를 내 머리 쪽으로 돌리기 시작하면 신호다
- 내 오른 팔꿈치를 옆구리에 붙이고 팔을 빼서 끼이지 않게 한다
- 상대가 도는 순간 엉덩이를 내 왼쪽으로 빼며 오른 무릎을 넣는다
- 이미 곁누르기가 잡혔으면 곁누르기 이스케이프 · 백 테이크 (곁누르기 아래)로 간다
