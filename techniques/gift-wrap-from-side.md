# 기프트 랩 (사이드) (Gift Wrap from Side Control)

[사이드 컨트롤](../positions/side-control.md) · 자세 · 컨트롤 · 위 → [사이드 컨트롤](../positions/side-control.md)

다른 이름: 사이드 기프트랩

## 세팅 과정 (오른손잡이 기준)

1. 상대 오른쪽에서 사이드: 내 오른손으로 상대 왼팔을 당겨 상대 얼굴을 가로지르게 둔다
2. 내 왼팔을 상대 머리 뒤로 넣어 상대 왼쪽 손목을 잡는다
3. 내 오른손으로 상대 왼쪽 팔꿈치를 눌러 팔이 빠지지 않게 한다
4. 테크니컬 마운트나 백으로 잇는다

## 핵심 디테일

- 내 오른손으로 상대 왼팔을 당길 때 팔꿈치가 얼굴 앞을 넘을 만큼 깊게 가로지르게 한다
- 머리 뒤로 넣은 내 왼손이 상대 왼쪽 손목을 잡으면 상대 팔이 자기 목 앞에 묶인다
- 내 오른손으로 상대 왼 팔꿈치를 눌러 팔이 빠지지 않게 하고 가슴 압박을 유지한다
- 상대는 오른팔로만 막아야 하니 잡히자마자 다음 공격으로 잇는다

## 흔한 실수

- 팔이 얕게 넘어온 채 손목을 잡으면 상대가 팔꿈치를 당겨 빠진다 → 팔꿈치가 얼굴을 넘을 만큼 깊게 당긴다
- 그립만 잡고 가슴을 띄우면 상대가 브릿지로 돌아 나간다 → 가슴으로 계속 누른다
- 왼손이 손가락 끝으로만 걸면 쉽게 풀린다 → 손목을 깊게 감아 잡는다

## 막히면

- 상대가 왼 팔꿈치를 당겨 빼려 하면 → [기프트 랩 유지](../techniques/gift-wrap-maintenance.md)
- 상대가 옆으로 돌아누우면 → [기프트 랩 → 테크니컬 마운트](../techniques/gift-wrap-to-technical-mount.md) · [테크니컬 마운트 → 백](../techniques/technical-mount-to-back.md)
- 상대 오른팔이 뜨면 → [기프트 랩 → 자유 팔 암바](../techniques/armbar-on-free-arm.md) · 갇힌 왼팔은 [기무라 (기프트 랩)](../techniques/kimura-from-gift-wrap.md)

## 방어하는 쪽 (상대 입장)

- 상대 오른손이 내 왼팔을 내 얼굴 앞으로 당기면 신호다
- 내 왼 팔꿈치를 옆구리에 붙여 팔이 얼굴 앞을 넘지 않게 한다
- 이미 손목을 잡혔으면 기프트 랩 빠져나오기: 왼 팔꿈치를 가슴 쪽으로 당기며 엉덩이를 내 왼쪽으로 빼 무릎을 넣는다
- 오른팔을 뻗어 상대를 밀지 않는다 — 자유 팔 암바가 온다
