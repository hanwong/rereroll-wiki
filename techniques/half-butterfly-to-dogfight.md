# 버터플라이 하프 → 도그파이트 (Half Butterfly to Dogfight)

[버터플라이 가드](../positions/butterfly-guard.md) · 전환 · 아래 → [하프가드](../positions/half-guard.md)

다른 이름: 도그파이트 진입

## 세팅 과정 (오른손잡이 기준)

1. 상대 오른다리를 하프로 잡고 내 왼팔로 상대 오른팔 밑 언더훅, 오른발 훅으로 상대를 띄운다
2. 언더훅을 유지한 채 상체를 세우며 무릎으로 일어난다
3. 내 오른손으로 상대 오른다리를 안고 네발 자세(도그파이트)를 만든다
4. 스윕이나 백 테이크로 잇는다

## 핵심 디테일

- 왼팔 언더훅을 먼저 깊이 잡는다
- 오른발 훅으로 상대를 띄워 가벼워진 순간 일어난다
- 위로 곧게가 아니라 상대 쪽 앞으로 비스듬히 밀며 무릎으로 올라온다
- 올라오면 오른손으로 상대 오른다리를 안아 네발 자세를 굳힌다

## 흔한 실수

- 언더훅 없이 일어나면 상대가 눌러 다시 눕힌다 → 언더훅부터 잡는다
- 위로 곧게 일어나면 상대가 크로스페이스로 누른다 → 상대 쪽으로 밀며 올라온다
- 일어나며 하프가드 다리를 풀면 상대가 다리를 빼 돈다 → 다리를 계속 조인다

## 막히면

- 상대가 위저로 언더훅을 막으면 → [하프가드](../positions/half-guard.md)로 돌아가 [니 쉴드 하프가드](../techniques/knee-shield-half-guard.md)
- 상대가 엉덩이를 빼며 다리를 빼려 하면 → [하프가드 → 싱글 레그](../techniques/half-guard-to-single-leg.md)
- 도그파이트가 잡히면 → [도그파이트 스윕](../techniques/dogfight-sweep.md)이나 [하프가드 백 테이크](../techniques/half-guard-back-take.md)

## 방어하는 쪽 (상대 입장)

- 상대 왼팔 언더훅이 깊고 상대가 무릎으로 일어나려 하면 도그파이트 신호
- 오른팔 위저로 언더훅을 눌러 막고 왼팔 크로스페이스로 다시 눕힌다
- 이미 올라왔으면 도그파이트 상대 다시 눕히기나 크로스페이스 (도그파이트 탑)
