# 남북 → 사이드 (North-South to Side Control)

[남북 (노스사우스)](../positions/north-south.md) · 전환 · 위 → [사이드 컨트롤](../positions/side-control.md)

다른 이름: 남북에서 사이드로, 노스사우스 → 사이드

## 세팅 과정 (오른손잡이 기준)

1. 남북에서 가슴으로 상대 가슴을 누른 채 상대 오른쪽 옆으로 다리를 걸어 돈다
2. 내 왼팔을 상대 목 아래로 옮겨 크로스페이스를 잡고, 오른팔은 상대 오른쪽 골반 옆을 막는다
3. 양 무릎을 상대 오른쪽 옆구리에 붙이고 엉덩이를 낮춘다
4. 상대 오른쪽에서 사이드 컨트롤로 끝난다

## 핵심 디테일

- 가슴 압박을 유지한 채 상대 오른쪽으로 작은 걸음으로 돈다
- 내 왼팔은 상대 목 아래로 옮겨 크로스페이스로 얼굴을 상대 왼쪽으로 돌린다
- 내 오른팔로 상대 오른쪽 골반 옆을 막아 무릎이 못 들어오게 한다
- 양 무릎을 상대 오른쪽 옆구리에 붙이고 엉덩이를 낮춘다

## 흔한 실수

- 돌 때 가슴을 들면 상대가 돌아 무릎을 넣는다 → 가슴을 붙인 채 걷는다
- 골반을 막지 않으면 상대가 새우빼기로 하프가드를 감는다 → 오른팔로 골반을 먼저 막는다
- 무릎을 띄워 두면 공간이 생긴다 → 무릎을 상대 옆구리에 붙인다

## 막히면

- 상대가 브릿지로 공간을 만들면 → 엉덩이를 낮춰 받아 내고 [사이드 컨트롤 유지](../techniques/side-control-maintain.md)
- 상대가 내 다리를 감으려 하면 → [하프가드 패스 (크로스페이스 · 언더훅)](../techniques/half-guard-pass.md)
- 자리가 잡히면 → [사이드 → 니 온 밸리](../techniques/side-to-knee-on-belly.md) · [사이드에서 마운트 가기](../techniques/side-to-mount.md)

## 방어하는 쪽 (상대 입장)

- 상대가 내 머리 쪽에서 내 오른쪽으로 걸어 돌기 시작하면 신호다
- 상대가 도는 순간 오른 무릎을 상대와 나 사이로 넣어 하프가드로 감는다
- 크로스페이스가 들어오기 전에 왼 팔뚝을 상대 목 앞에 대 고개가 안 돌아가게 막는다
- 이미 사이드면 사이드 이스케이프 (프레임 · 쉬림프)로 간다
