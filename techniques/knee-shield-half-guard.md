# 니 쉴드 하프가드 (Knee Shield Half Guard)

[하프가드](../positions/half-guard.md) · 자세 · 컨트롤 · 아래 → [하프가드](../positions/half-guard.md)

다른 이름: 제트 가드, Z 가드, Z가드, 니실드, 니쉴드

## 세팅 과정 (오른손잡이 기준)

1. 하프가드에서 위쪽인 내 왼쪽 무릎을 상대 배나 골반 앞에 가로로 세운다(낮은 니 쉴드)
2. 아래쪽인 내 오른다리는 상대 오른다리를 계속 감아 둔다
3. 내 오른손은 상대 왼쪽 깃을 잡아 팔을 펴고, 왼손은 상대 오른쪽 소매를 잡아 거리를 지킨다
4. 상대가 오른손으로 내 무릎을 밀어 치우면 내 왼팔을 상대 오른쪽 겨드랑이 아래로 넣어 언더훅

## 핵심 디테일

- 내 왼쪽 정강이를 상대 배·골반 앞에 비스듬히 대 상대 체중이 내 가슴으로 오지 못하게 한다
- 내 오른손 깃 그립은 팔을 펴 상체 거리를 지키고, 왼손은 상대 오른쪽 소매를 묶는다
- 내 오른다리는 계속 상대 오른다리를 감아 상대가 다리를 빼지 못하게 한다
- 상대가 오른손으로 무릎을 치우는 순간이 왼팔 언더훅 타이밍

## 흔한 실수

- 무릎만 세우고 손 그립이 없으면 → 상대가 상체로 눌러 무릎을 접는다 → 깃·소매로 거리를 지킨다
- 니 쉴드가 낮아 바닥으로 눌리면 → 스매시 패스를 당한다 → 엉덩이를 빼 무릎 각도를 세운다
- 등이 평평하면 → 무릎에 힘이 안 실린다 → 오른쪽 어깨로 옆으로 눕는다

## 막히면

- 상대가 오른손을 바닥에 짚으면 → [기무라 (니 쉴드)](../techniques/kimura-from-knee-shield.md)
- 상대가 무겁게 눌러 오면 → [니 쉴드 유지 (눌릴 때)](../techniques/knee-shield-retention.md)

## 방어하는 쪽 (상대 입장)

- 상대 왼쪽 무릎이 내 배 앞에 서고 상대가 내 깃·소매를 잡으면 거리를 두는 니 쉴드
- 잡힌 내 오른쪽 소매부터 떼고 상대 왼쪽 무릎을 바닥 쪽으로 눌러 접는다 → 스매시 패스
- 무릎을 치우는 순간 상대 왼팔이 내 오른쪽 겨드랑이로 들어오니 내 오른팔 위저를 준비한다
