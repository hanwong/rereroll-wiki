# 리버스 곁누르기 이스케이프 (Escape Ushiro Kesa Gatame)

[곁누르기](../positions/kesa-gatame.md) · 탈출 · 아래 → [하프가드](../positions/half-guard.md)

다른 이름: 리버스 스카프 홀드 탈출, 우시로 케사 이스케이프, Reverse Kesa Escape, Bridge from Ushiro Kesa Gatame

## 세팅 과정 (오른손잡이 기준)

1. 갇힌 내 오른팔은 손을 배 쪽으로 당겨 팔꿈치를 오른쪽 옆구리에 붙인다
2. 자유로운 내 왼손으로 상대 허리를 밀어 버틴다
3. 발로 바닥을 밀어 엉덩이를 내 왼쪽으로 빼며(새우빼기) 공간을 만든다
4. 생긴 공간으로 내 오른쪽 무릎을 상대와 내 몸 사이에 넣는다
5. 두 다리로 상대 왼다리를 감아 하프가드로 정리한다

## 핵심 디테일

- 갇힌 오른팔은 팔꿈치를 옆구리에 붙여 팔이 펴지지 않게 한다
- 왼손으로 상대 허리를 밀어 버티는 틈을 먼저 만든다
- 새우빼기는 엉덩이를 내 왼쪽으로 크게 뺀다
- 생긴 틈에 바로 오른 무릎부터 넣는다

## 흔한 실수

- 갇힌 팔을 펴서 빼려 하면 팔이 꺾일 수 있다 → 팔꿈치를 몸에 붙인다
- 바로 누운 채 버둥대면 안 빠진다 → 옆으로 누워 새우빼기한다
- 무릎만 넣고 멈추면 상대가 다시 누른다 → 두 다리로 다리를 감아 하프가드를 끝낸다

## 막히면

- 상대가 사이드로 돌아오면 → [사이드 이스케이프 (프레임 · 쉬림프)](../techniques/side-control-escape.md)
- 상대가 머리 쪽으로 돌아 남북이 되면 → [남북 이스케이프](../techniques/north-south-escape.md)

## 방어하는 쪽 (상대 입장)

- 상대가 갇힌 오른 팔꿈치를 옆구리에 붙이고 왼손으로 내 허리를 밀면 → 탈출 신호
- 엉덩이를 상대 옆구리에 다시 붙이고 왼손으로 상대 왼쪽 바지를 당겨 둔다
- 상대 무릎이 들어오면 → 리버스 곁누르기 → 사이드로 바꿔 가슴을 붙인다
