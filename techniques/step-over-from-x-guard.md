# 스텝 오버 (X 가드 상대) (Step Over from X-Guard)

[X 가드 · 싱글 레그 X · 앵클락](../positions/x-guard.md) · 패스 · 위 → [사이드 컨트롤](../positions/side-control.md)

다른 이름: X가드 스텝오버

## 세팅 과정 (오른손잡이 기준)

1. 상대가 내 왼다리를 안고 내 오른다리에 X 훅을 걸었을 때, 내 왼쪽 발목을 잡은 상대 손을 먼저 떼어낸다
2. 내 오른손으로 상대 왼쪽 골반이나 무릎을 바닥에 누른다
3. 훅만 걸린 내 오른다리를 크게 돌려 상대 몸 위로 넘긴다
4. 안긴 왼다리를 빼고 크로스페이스로 사이드를 굳힌다

## 핵심 디테일

- 내 왼쪽 발목을 잡은 상대 손부터 떼야 넘는 동안 다시 잡히지 않는다
- 내 오른손으로 상대 왼쪽 골반·무릎을 바닥에 눌러 상대가 각도를 못 만들게 한다
- 오른다리를 넘길 때 엉덩이를 앞·아래로 보내며 크게 한 번에 돌린다
- 착지하면 바로 가슴을 붙이고 크로스페이스로 사이드를 굳힌다

## 흔한 실수

- 훅이 깊게 걸린 채 넘으면 → 왼다리 하나로 선 순간 스윕 당한다 → 먼저 눌러 훅을 얕게 만든다
- 오른다리를 허공에 띄운 채 머뭇거리면 → 상대가 그 다리를 잡아 하프가드로 감는다 → 결심하면 빠르게 넘긴다
- 뒤로 기대며 넘으면 → 균형을 잃는다 → 엉덩이를 앞으로 보낸다

## 막히면

- 상대가 훅을 다시 깊게 넣으면 → [무릎 눌러 X 가드 패스](../techniques/knee-pin-from-x-guard.md)
- 상대가 싱글 레그 X로 바꾸면 → [백스텝 (싱글 레그 X 상대)](../techniques/backstep-from-single-leg-x.md)
- 넘기던 다리를 상대가 하프가드로 감으면 → [하프가드 패스 (크로스페이스 · 언더훅)](../techniques/half-guard-pass.md)

## 방어하는 쪽 (상대 입장)

- 상대가 내 발목 그립을 떼고 상대 오른손으로 내 왼쪽 골반·무릎을 누르면 넘어가려는 신호
- 상대 오른다리가 뜨는 순간은 왼다리 하나로 선 때 → 안은 왼다리를 끌어당기며 X 가드 스윕
- 넘어오는 상대 오른다리를 두 손으로 막아 가드 안으로 돌려보낸다
- 이미 넘어왔으면 상대 쪽으로 돌아 무릎을 넣거나 다리를 감아 하프가드로 막는다
