# 테크니컬 스탠드업 → 싱글 레그 (Technical Stand-Up to Single Leg)

[오픈 가드](../positions/open-guard.md) · 스윕 · 아래 → [패스](../positions/passing.md)

다른 이름: 일어나며 싱글렉, 싱글 레그 테이크다운

## 세팅 과정 (오른손잡이 기준)

1. 앉은 가드에서 내 오른손으로 상대 왼쪽 발목을 잡고 왼손으로 바닥을 짚어 테크니컬 스탠드업으로 일어난다
2. 일어나며 상대 왼다리를 내 양팔로 안고 내 양 무릎을 모아 가둔다
3. 머리를 상대 왼쪽 옆구리에 붙이고 등을 편다
4. 상대 왼다리를 들어 올리며 상대를 넘긴다

## 핵심 디테일

- 내 왼손과 오른발로 바닥을 디딘 채 왼다리를 뒤로 빼며 일어나야 균형이 잡힌다
- 일어나는 동안 오른손 발목 그립을 놓지 않는다
- 상대 왼다리를 양팔로 안고 내 양 무릎을 모아 가둔다
- 머리는 상대 왼쪽 옆구리에 붙이고 등을 펴 상대 체중에 깔리지 않게 한다

## 흔한 실수

- 손·발을 짚지 않고 바로 일어서면 상대가 밀어 다시 앉힌다 → 테크니컬 스탠드업 순서대로 일어난다
- 머리를 숙이면 상대가 길로틴·프론트 헤드락을 잡는다 → 머리를 세우고 상대 옆구리에 붙인다
- 다리를 팔로만 안으면 빠진다 → 무릎으로도 가둔다

## 막히면

- 상대가 위에서 체중으로 눌러 오면 → 다시 앉아 [싱글 레그 X 가드](../techniques/single-leg-x-guard.md)로 다리를 감는다
- 상대가 오른발로 깡충 뛰며 버티면 → 다리를 높이 든 채 뒤로 물러나 균형을 무너뜨린다
- 상대가 내 목을 감아 오면 → [길로틴 방어](../techniques/guillotine-defense.md)부터 한다

## 방어하는 쪽 (상대 입장)

- 앉은 상대가 왼손으로 뒤 바닥을 짚고 오른손으로 내 왼 발목을 잡으면 일어나 싱글 레그로 오는 신호
- 일어나는 순간 손으로 상대 머리·어깨를 눌러 다시 앉힌다
- 다리를 안겼으면 엉덩이를 뒤로 빼고 체중을 상대 등에 실어 스프롤 (테이크다운 방어)로 막는다
