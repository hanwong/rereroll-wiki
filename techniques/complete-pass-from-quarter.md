# 쿼터 가드 패스 (Complete Pass from Quarter)

[하프가드](../positions/half-guard.md) · 패스 · 위 → [사이드 컨트롤](../positions/side-control.md)

다른 이름: 쿼터 패스

## 세팅 과정 (오른손잡이 기준)

1. 내 오른쪽 발목이 걸리면 내 오른팔 크로스페이스로 상대 얼굴을 상대 오른쪽으로 돌린다
2. 걸린 오른쪽 발목을 내 왼발로 밀어 빼낸다
3. 체중을 상대 가슴에 싣는다
4. 사이드

## 핵심 디테일

- 다리를 빼는 동안 내 오른팔 크로스페이스를 절대 놓지 않는다
- 다리를 빼기 직전에 가슴 무게를 더 실어 상대를 눌러 둔다
- 내 왼발바닥으로 걸린 내 오른쪽 발목을 밀어내듯 뺀다
- 빠지자마자 엉덩이를 낮춰 사이드에 바로 자리 잡는다

## 흔한 실수

- 다리 빼느라 크로스페이스를 풀면 상대가 돌아누워 무릎을 넣는다 → 끝까지 유지
- 엉덩이를 들고 다리를 빼면 공간이 생긴다 → 엉덩이를 낮춘 채 뺀다
- 빠진 뒤 멈추면 상대가 다시 하프를 감는다 → 바로 가슴을 붙여 고정한다

## 막히면

- 상대가 발목을 꽉 꼬아 안 빠지면 → [쿼터 가드 → 마운트](../techniques/knee-through-from-quarter.md)
- 상대가 오른손을 짚어 프레임하면 → [기무라 (쿼터 가드 탑)](../techniques/kimura-from-quarter-guard.md)
- 상대가 다시 무릎까지 감으면 → [하프가드 → 쿼터 가드 (탑)](../techniques/half-guard-to-quarter-guard.md)

## 방어하는 쪽 (상대 입장)

- 상대 오른팔 크로스페이스가 내 얼굴을 내 오른쪽으로 돌리고 상대 왼발이 내 발을 밀면 신호
- 발목 걸이를 꽉 꼬아 두고 오른팔뚝 목 프레임으로 공간을 만든다
- 엉덩이를 내 오른쪽으로 빼며 왼쪽 무릎을 넣는다 → 쿼터 가드 → 니 쉴드
- 이미 다리가 빠졌으면 → 사이드 이스케이프 (프레임 · 쉬림프)
