# 스탠딩 백에서 돌아서기 (Grip Break and Face (Standing Back))

[클린치 · 가드 풀링](../positions/clinch.md) · 탈출 · 서서 → [클린치 · 가드 풀링](../positions/clinch.md)

다른 이름: 백 그립 끊기

## 세팅 과정 (오른손잡이 기준)

1. 상대가 뒤에서 허리를 안으면 자세를 낮추고 양손으로 상대 손을 잡는다
2. 상대 오른손 손가락이나 손목을 떼어 그립을 끊는다
3. 끊는 순간 내 오른쪽으로 엉덩이를 돌려 상대와 마주 본다
4. 클린치나 거리로 돌아간다

## 핵심 디테일

- 먼저 자세를 낮춰 상대가 나를 들어 올리지 못하게 한다
- 손깍지 전체가 아니라 상대 오른손 손가락 · 손목 하나를 내 두 손으로 잡아 뗀다
- 그립이 풀리는 순간 멈추지 말고 내 오른쪽으로 엉덩이를 돌려 마주 본다
- 돌아서면서 바로 언더훅이나 내 그립을 잡는다

## 흔한 실수

- 허리를 펴고 그립만 떼려 하면 들려서 던져진다 → 자세부터 낮춘다
- 그립을 뗀 뒤 머뭇거리면 상대가 다시 잡는다 → 떼는 순간 돈다
- 내 왼쪽으로 돌면 아직 잡혀 있는 상대 왼팔에 다시 감긴다 → 뗀 손 쪽인 내 오른쪽으로 돈다

## 막히면

- 상대가 손깍지를 낮게 잡아 안 풀리면 → [스탠딩 스위치](../techniques/standing-switch.md)
- 상대가 들어 올리려 하면 → [뒤에서 잡혔을 때 되치기](../techniques/counter-throw-from-rear-clinch.md)
- 상대가 목을 감아 오면 → [뒤에서 잡혔을 때 안전하게 내려가기](../techniques/controlled-descent.md)

## 방어하는 쪽 (상대 입장)

- 상대가 두 손으로 내 오른손 손가락을 떼려 하면 → 돌아서려는 신호
- 손깍지 대신 내 오른손으로 내 왼쪽 손목을 잡고 상대 배꼽 아래로 낮춘다
- 상대가 오른쪽으로 돌면 가슴을 등에 붙인 채 따라 돈다
- 돌기 전에 → 맷 리턴 (뒤에서 끌어내리기)으로 먼저 바닥에 내린다
