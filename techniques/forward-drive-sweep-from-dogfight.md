# 도그파이트 전진 스윕 (Forward Drive Sweep from Dogfight)

[하프가드](../positions/half-guard.md) · 스윕 · 아래 → [마운트](../positions/mount.md) / [사이드 컨트롤](../positions/side-control.md)

다른 이름: 밀어 넘기기

## 세팅 과정 (오른손잡이 기준)

1. 내 오른팔로 상대 오른다리를 안은 채 왼쪽 어깨를 상대 오른쪽 골반에 붙인다
2. 양발로 바닥을 밀며 상대 쪽으로 돌진한다
3. 오른다리를 안겨 딛지 못한 상대가 뒤로 넘어진다
4. 마운트나 사이드

## 핵심 디테일

- 내 오른팔은 상대 오른쪽 무릎 뒤를 꽉 안아 상대가 오른발을 못 딛게 한다
- 무릎이 아니라 발끝으로 서서 다리 힘으로 민다 → 팔로 밀지 않는다
- 밀어 넣는 방향은 상대 오른쪽 뒤 대각선(다리를 안긴 쪽)이다
- 상대가 위저에 신경 쓰거나 체중이 뒤로 갈 때 한 번에 끝까지 민다

## 흔한 실수

- 무릎 꿇은 채로 밀면 힘이 안 실린다 → 발끝을 세우고 일어나며 민다
- 정면 뒤로 밀면 상대가 왼다리를 뒤로 디뎌 버틴다 → 오른쪽 뒤 대각선으로 민다
- 넘어진 순간 안은 다리를 놓으면 상대가 다시 가드를 만든다 → 다리를 넘어 가슴을 붙일 때까지 안고 있는다

## 막히면

- 상대가 왼다리를 뒤로 넓게 디뎌 버티면 → [도그파이트 스윕](../techniques/dogfight-sweep.md)
- 상대가 위저로 내 어깨를 눌러 오면 → [도그파이트 → 하프가드 복귀](../techniques/re-pull-half-guard-from-dogfight.md)
- 상대가 상체를 숙여 무게를 실으면 → [하프가드 → 싱글 레그](../techniques/half-guard-to-single-leg.md)

## 방어하는 쪽 (상대 입장)

- 상대 오른팔이 내 오른쪽 무릎을 안고 상대 왼쪽 어깨가 내 오른쪽 골반에 붙으면 전진 신호
- 내 오른다리를 뒤로 빼 스프롤하고 엉덩이를 낮춘다
- 내 오른팔 위저로 상대 왼팔을 감아 상대 왼쪽 어깨를 바닥으로 누른다
- 이미 뒤로 넘어가면 등이 닿기 전에 다리로 상대 허리를 감아 가드로 받는다
