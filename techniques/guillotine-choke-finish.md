# 길로틴 마무리 (Guillotine Choke Finish)

[프론트 헤드락 · 길로틴](../positions/front-headlock.md) · 서브미션 · 위

다른 이름: 길로틴 피니시, 길로틴 초크

## 세팅 과정 (오른손잡이 기준)

1. 오른팔로 목을 감고 왼손으로 오른손목을 잡은 그립에서 오른쪽 팔꿈치를 몸에 붙인다
2. 뒤로 눕지 말고 목을 감은 오른팔 쪽(내 오른쪽)으로 몸을 튼다
3. 두 다리로 상대 허리를 감는다
4. 가슴을 펴고 오른쪽 팔꿈치를 당기며 체중으로 조인다
5. 천천히 조이고 탭하면 바로 푼다

## 핵심 디테일

- 손목 날이 상대 목 앞을 가로지르게 깊게 넣은 상태를 먼저 확인한다
- 오른쪽 팔꿈치를 옆구리에 붙여 팔과 몸 사이 공간을 없앤다
- 뒤로 평평하게 눕지 말고 내 오른쪽으로 몸을 틀어 각도를 만든다
- 두 다리로 상대 허리를 감아 상대가 자세를 세우지 못하게 한다

## 흔한 실수

- 팔힘으로만 짜면 금방 지친다 → 가슴을 펴고 팔꿈치를 당겨 몸 전체로 조인다
- 똑바로 누워 당기면 상대가 목을 뺀다 → 오른쪽으로 몸을 틀어 각을 만든다
- 홱 당기면 목을 다친다 → 천천히 조이고 탭하면 바로 푼다

## 막히면

- 상대가 왼팔을 내 오른쪽 어깨 너머로 넘겨 돌아가려 하면 → 다리로 허리를 더 조이고 [하이 엘보 길로틴](../techniques/high-elbow-guillotine.md)
- 상대 왼팔이 그립 안에 같이 들어오면 → [암 인 길로틴](../techniques/arm-in-guillotine.md)
- 상대가 자세를 세워 버티면 → [힙 범프 스윕](../techniques/hip-bump-sweep.md)

## 방어하는 쪽 (상대 입장)

- 상대 오른팔이 목을 감고 다리로 내 허리를 감으려 하면 → 턱을 당기고 두 손으로 상대 오른쪽 손목을 당겨 숨 쉴 공간을 만든다
- 상대 다리가 잠기기 전에 → 내 왼팔을 상대 오른쪽 어깨 너머로 넘기고 내 왼쪽(상대 오른쪽)으로 돌아 나간다
- 이미 조여 오면 → 늦었으면 바로 탭한다
