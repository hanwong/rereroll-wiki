# 싱글 레그 X 가드 (Single Leg X Guard)

[X 가드 · 싱글 레그 X · 앵클락](../positions/x-guard.md) · 자세 · 컨트롤 · 아래 → [X 가드 · 싱글 레그 X · 앵클락](../positions/x-guard.md)

다른 이름: SLX, 싱글렉 X, 싱글렉스, 싱글 레그 엑스

## 세팅 과정 (오른손잡이 기준)

1. 상대 왼쪽 발목을 내 오른쪽 겨드랑이에 안고 상대 왼다리를 내 두 다리 사이에 둔다
2. 내 오른발(바깥 다리)을 상대 왼쪽 골반에 건다(중앙선을 넘지 않는다)
3. 내 왼다리(안쪽 다리)는 상대 왼쪽 허벅지 안쪽에서 뒤로 감는다
4. 왼쪽 발목을 가슴으로 당기며 상대 왼쪽 무릎을 상대 왼쪽 바깥으로 돌린다

## 핵심 디테일

- 상대 왼쪽 발목을 내 오른쪽 겨드랑이에 깊이 끼워 가슴으로 당긴다
- 내 오른발은 상대 왼쪽 골반에 — 배 가운데를 넘어가면 상대가 쉽게 넘어온다
- 내 왼다리는 상대 왼쪽 허벅지 안쪽에서 깊이 감아 상대가 다리를 뒤로 못 빼게 한다
- 엉덩이를 바닥에 붙이고 정면으로 있지 말고 잡은 다리 쪽으로 몸을 비스듬히 튼다

## 흔한 실수

- 발목 대신 무릎·허벅지를 잡으면 → 상대가 다리를 쉽게 뺀다 → 발목 쪽을 안는다
- 내 오른발을 배·가슴 높이에 대면 → 상대가 눌러 넘어온다 → 골반 높이에 둔다
- 상대와 정면으로 누워 있으면 → 균형을 못 뺏는다 → 잡은 다리 쪽으로 몸을 튼다

## 막히면

- 상대가 넓게 서서 버티면 → [싱글 레그 X 스윕](../techniques/single-leg-x-sweep.md)
- 상대가 오른발을 가까이 두고 버티면 → [힐 그랩 스윕](../techniques/heel-grab-sweep.md)
- 상대가 앞으로 무겁게 눌러 오면 → [싱글 레그 X → X 가드](../techniques/slx-to-x-guard.md)
- 상대가 무릎을 안으로 돌려 버티면 → [애시 가라미 (스트레이트 애시)](../techniques/ashi-garami.md)

## 방어하는 쪽 (상대 입장)

- 상대가 내 왼쪽 발목을 잡고 엉덩이를 붙여 오면 싱글 레그 X 진입 신호
- 상대 왼다리가 내 왼쪽 허벅지 안쪽을 감기 전에 왼다리를 뒤로 빼 거리를 둔다
- 이미 걸렸으면 엉덩이를 낮추고 왼쪽 무릎을 안쪽으로 유지한 채 내 왼쪽 골반의 상대 오른발부터 떼어낸다
- 그다음 싱글 레그 X 빠져나오기 (서서) 나 백스텝 (싱글 레그 X 상대)
