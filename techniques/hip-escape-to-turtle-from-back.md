# 백 → 터틀로 빠지기 (Hip Escape to Turtle from Back)

[백 컨트롤](../positions/back-control.md) · 탈출 · 아래 → [터틀 · 크루시픽스](../positions/turtle.md)

다른 이름: 백에서 터틀

## 세팅 과정 (오른손잡이 기준)

1. 상대가 오른팔로 내 오른쪽 어깨 위를 감은 기준 — 그 팔을 양손으로 막으며 엉덩이를 바닥 쪽으로 빼 훅을 느슨하게 한다
2. 내 오른쪽으로 몸을 엎어 양 무릎과 양 팔꿈치를 바닥에 댄다(터틀)
3. 팔꿈치를 무릎에 붙이고 턱을 당겨 목 공간을 막는다
4. 내 오른발을 세워 베이스를 잡고 일어서거나 가드로 돌아온다

## 핵심 디테일

- 두 손은 끝까지 상대 오른팔을 잡아 목을 지킨다
- 엉덩이를 바닥 쪽으로 빼서 훅이 허벅지에서 미끄러지게 한다
- 엎드릴 때 팔꿈치를 무릎에 붙이고 턱을 당겨 목 틈을 없앤다
- 엎드린 뒤 머무르지 말고 오른발을 세워 일어서거나 가드로 간다

## 흔한 실수

- 엎드리며 팔을 바닥에 뻗으면 크루시픽스에 걸린다 → 팔꿈치를 무릎에 붙인다
- 엎드릴 때 무릎이 벌어지면 상대가 훅을 다시 넣는다 → 무릎을 붙여 엎드린다
- 터틀에서 가만히 있으면 상대가 다시 백을 잡는다 → 바로 다음 탈출로 이어 간다

## 막히면

- 상대가 시트벨트를 놓지 않고 따라오면 → [시트벨트 빠져나오기](../techniques/escape-seat-belt-control.md)
- 터틀에서 상대가 내 왼쪽에 붙으면 → [터틀 → 가드 회복](../techniques/turtle-to-guard.md) 또는 [그랜비 롤 (가드 회복)](../techniques/granby-roll.md)
- 상대가 훅을 다시 넣으면 → [터틀에서 훅 걷어내기](../techniques/clear-hook-from-turtle.md)

## 방어하는 쪽 (상대 입장)

- 상대가 엉덩이를 바닥으로 빼며 오른쪽으로 엎드리려 하면 터틀로 빠지는 신호
- 훅을 더 깊게 넣고 시트벨트를 당겨 상대를 다시 옆으로 눕힌다
- 엎드렸으면 시트벨트를 유지한 채 터틀에서 백 테이크로 훅을 다시 넣는다
- 상대 팔이 바닥으로 나오면 → 크루시픽스 (터틀)
