# 백 이스케이프 (Back Escape)

[백 컨트롤](../positions/back-control.md) · 탈출 · 아래 → [클로즈드 가드](../positions/closed-guard.md) / [사이드 컨트롤](../positions/side-control.md)

다른 이름: 백 빠져나오기, 핸드 파이팅, 백 탈출, 힙 이스케이프 (백 아래), 백 힙 이스케이프

## 세팅 과정 (오른손잡이 기준)

1. 상대가 오른팔로 내 오른쪽 어깨 위를 감은 기준 — 턱을 당기고 양손으로 상대 오른팔을 잡아 막는다(핸드 파이팅)
2. 상대 언더훅 반대쪽인 내 오른쪽으로 오른쪽 어깨를 바닥에 붙이며 눕는다
3. 엉덩이를 바닥 쪽으로 밀어 상대 오른발 훅을 빼낸다
4. 상대 오른다리를 넘어 엉덩이를 바닥에 붙이고 내 왼쪽으로 돌아서 가드나 사이드 탑으로 간다

## 핵심 디테일

- 손 싸움이 먼저다: 턱을 당기고 양손으로 상대 오른팔을 잡아 목을 지킨다
- 조르는 팔 쪽인 내 오른쪽 어깨를 바닥에 붙인다 — 언더훅 쪽(내 왼쪽)으로 가면 더 깊이 잡힌다
- 엉덩이를 바닥으로 밀어 상대 오른발 훅부터 뺀다
- 상대 오른다리를 넘어 엉덩이를 바닥에 붙인 뒤 내 왼쪽으로 돌아 마주 본다

## 흔한 실수

- 손을 놓고 다리부터 빼려 하면 초크를 당한다 → 목을 지킨 채 움직인다
- 언더훅 쪽으로 누우면 상대가 위로 올라탄다 → 오른쪽 어깨를 바닥에 붙인다
- 훅을 뺀 뒤 바로 돌지 않으면 상대가 다시 훅을 넣는다 → 다리를 넘자마자 돈다

## 막히면

- 상대가 바디 트라이앵글을 걸면 → [바디 트라이앵글 빠져나오기](../techniques/body-triangle-escape-to-side.md)
- 상대가 훅을 다시 넣으면 → [숄더 워크 이스케이프](../techniques/shoulder-walk-escape.md)
- 상대가 마운트로 올라타면 → [마운트 이스케이프 (엘보)](../techniques/mount-escape-elbow.md)

## 방어하는 쪽 (상대 입장)

- 상대가 오른쪽 어깨를 바닥에 붙이며 아래로 미끄러지면 탈출 신호
- 언더훅 쪽인 내 왼쪽으로 눕는 자세를 지키고 오른발 훅을 깊게 다시 넣는다
- 훅이 빠지면 → 바디 트라이앵글
- 상대가 등을 바닥에 대면 → 백 → 마운트 (상대가 등을 바닥에 붙일 때)
