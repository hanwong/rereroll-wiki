# 스파이더 스윕 (Spider Sweep)

[스파이더 · 라쏘 · 소매 가드](../positions/spider-lasso.md) · 스윕 · 아래 → [패스](../positions/passing.md)

다른 이름: 스파이더 가드 스윕, 더블 슬리브 스윕, 양 소매 스윕

## 세팅 과정 (오른손잡이 기준)

1. 스파이더 가드에서 내 오른발을 상대 왼쪽 이두에서 떼어 상대 왼쪽 무릎 안쪽을 건다
2. 내 왼발은 상대 오른쪽 이두를 계속 밀어 상대 오른팔을 뻗게 한다
3. 건 오른발로 상대 왼쪽 무릎을 당기고 두 소매는 내 머리 쪽으로 당겨 넘긴다
4. 소매를 놓지 않고 일어나 패스 자세로 간다

## 핵심 디테일

- 왼발은 상대 오른쪽 이두를 계속 밀어 그 팔을 펴 둬서 상대가 짚지 못하게 한다
- 오른발로 상대 왼쪽 무릎을 걸어 당겨 상대 다리 베이스를 빼낸다
- 두 소매를 내 머리 쪽으로 당기는 힘과 무릎 당기기를 동시에 써야 넘어간다
- 넘어가는 동안 소매를 놓지 않고 그 힘으로 일어난다

## 흔한 실수

- 소매를 놓으면 상대가 손을 짚어 버틴다 → 넘어갈 때까지 소매를 당긴다
- 무릎 건 발로 당기지 않으면 상대가 발을 내디뎌 버틴다 → 오른발로 무릎을 확실히 당긴다
- 넘긴 뒤 누워 있으면 상대가 다시 가드를 잡는다 → 소매를 잡은 채 바로 일어난다

## 막히면

- 상대가 무릎을 꿇어 낮게 버티면 → [트라이앵글 (스파이더)](../techniques/triangle-from-spider-guard.md)
- 상대가 팔을 빼려 하면 → [스파이더 → 라쏘](../techniques/spider-to-lasso.md)

## 방어하는 쪽 (상대 입장)

- 상대 오른발이 내 왼쪽 이두에서 떨어져 내 왼쪽 무릎에 걸리면 스윕 신호
- 체중을 낮추고 내 왼다리를 뒤로 빼 훅을 푼다
- 소매 그립을 끊어 상대가 당길 힘을 없앤다
- 넘어지면 바로 다리를 세워 가드를 만든다
