# 3/4 마운트 (3-4 Mount)

[마운트](../positions/mount.md) · 자세 · 컨트롤 · 위 → [마운트](../positions/mount.md)

다른 이름: 쓰리쿼터 마운트, 쓰리 쿼터 마운트, 3/4 마운트

## 세팅 과정 (오른손잡이 기준)

1. 상대가 내 왼다리를 하프가드처럼 감아도 내 오른쪽 무릎은 바닥에 붙이고 엉덩이를 낮춰 버틴다
2. 내 왼팔로 크로스페이스해 상대 얼굴을 상대 왼쪽(내 오른쪽)으로 돌린다
3. 내 오른발로 상대 발목을 밀어 내리거나 내 왼쪽 무릎을 세워 왼다리를 빼낸다
4. 빼낸 왼다리를 바닥에 내려 풀 마운트를 완성한다

## 핵심 디테일

- 왼다리가 감겨도 오른 무릎은 바닥에 붙이고 엉덩이를 낮춰 상대가 돌아눕지 못하게 한다
- 내 왼팔 크로스페이스로 상대 얼굴을 상대 왼쪽으로 돌려 등을 바닥에 붙인다
- 상대가 눌린 뒤에 오른발로 상대 발목을 밀어 내리거나 왼 무릎을 세워 다리를 뺀다

## 흔한 실수

- 엉덩이를 들고 다리부터 빼려 하면 상대가 하프가드를 굳힌다 → 상체부터 눌러 놓는다
- 크로스페이스가 없으면 상대가 언더훅을 잡고 돌아 나온다 → 왼팔로 얼굴부터 돌린다
- 다리만 힘으로 당기면 안 빠진다 → 발로 상대 발목을 밀어 걸림을 푼다

## 막히면

- 상대가 언더훅을 잡으면 → [하프 탑 위저 카운터](../techniques/half-guard-whizzer-counter.md)
- 상대가 니 쉴드를 세우면 → [스매시 패스](../techniques/smash-pass.md)
- 다리가 끝까지 안 빠지면 → [하프 탑 기본 자세](../techniques/half-guard-top-control.md)

## 방어하는 쪽 (상대 입장)

- 상대가 오른발로 내 발목을 밀거나 왼 무릎을 세우면 다리를 빼려는 신호
- 발목을 꼬아 상대 왼다리를 더 깊게 감고 내 오른팔로 상대 왼팔 아래 언더훅을 노린다
- 크로스페이스가 깊어지기 전에 옆으로 돌아 엉덩이를 빼고 무릎을 넣는다 → 3/4 마운트 이스케이프
