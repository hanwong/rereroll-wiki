# 니 쉴드 유지 (눌릴 때) (Knee Shield Retention)

[하프가드](../positions/half-guard.md) · 자세 · 컨트롤 · 아래 → [하프가드](../positions/half-guard.md)

다른 이름: 니 쉴드 리텐션, Knee Shield Retention, 무릎 방패 지키기

## 세팅 과정 (오른손잡이 기준)

1. 위 사람이 내 왼쪽 정강이(니 쉴드)를 눌러 오면 내 왼손으로 상대 오른쪽 무릎이나 골반을 민다
2. 내 오른손은 상대 깃이나 왼쪽 어깨를 밀어 머리가 가까이 오지 못하게 한다
3. 엉덩이를 내 오른쪽(상대에게서 먼 쪽)으로 빼서 정강이와 상대 몸 사이에 공간을 만든다
4. 왼쪽 정강이를 상대 골반이나 배에 다시 걸어 니 쉴드로 돌아온다

## 핵심 디테일

- 정강이만으로 버티지 말고 내 왼손 · 오른손 프레임을 먼저 댄다
- 내 오른손은 상대 깃·왼쪽 어깨를 밀어 상대 머리가 가까이 못 오게 한다
- 엉덩이를 내 오른쪽으로 빼서 정강이를 다시 세울 공간을 만든다
- 정강이는 상대 골반·배에 비스듬히 걸어 뼈로 받친다

## 흔한 실수

- 정강이만으로 버티면 체중에 접혀 버린다 → 손 프레임과 엉덩이 빼기를 같이
- 등을 바닥에 대면 무릎을 다시 못 세운다 → 오른쪽으로 돌아눕는다
- 상대 머리가 가까이 오게 두면 크로스페이스를 맞는다 → 오른손으로 밀어 둔다

## 막히면

- 상대가 팔을 무릎 위로 넘겨 엮으면 → [레그 위브 상대 하프 회복](../techniques/leg-weave-escape-to-half-guard.md)
- 무릎이 완전히 눌려 발목만 남으면 → [쿼터 가드 → 니 쉴드](../techniques/knee-shield-from-quarter.md)
- 공간이 생기면 → [니 쉴드 스윕](../techniques/sweep-from-knee-shield.md)

## 방어하는 쪽 (상대 입장)

- 상대 왼손이 내 오른쪽 무릎·골반을, 상대 오른손이 내 깃·왼쪽 어깨를 밀며 엉덩이를 빼면 신호
- 손 프레임을 안쪽으로 걷어 내고 엉덩이를 낮춰 따라 붙는다
- 정강이 위에 체중을 실어 무릎을 바닥 쪽으로 접는다
- 니 쉴드가 다시 섰으면 → 레그 위브 패스 · 바디락 패스
