# 도그파이트 (Dogfight Position)

[하프가드](../positions/half-guard.md) · 자세 · 컨트롤 · 아래 → [하프가드](../positions/half-guard.md)

다른 이름: 도그 파이트

## 세팅 과정 (오른손잡이 기준)

1. 상대 오른다리를 감고 내 왼팔로 언더훅, 무릎으로 일어나 내 오른팔로 상대 오른다리를 안는다
2. 상대도 오른팔 위저로 버티면 둘 다 네발 자세(도그파이트)
3. 머리를 상대 오른쪽 옆구리에 붙인다
4. 상대 반응에 따라 스윕 · 백 테이크 · 재하프

## 핵심 디테일

- 언더훅 싸움이 전부 — 내 왼팔 언더훅을 깊게 유지한다
- 무릎으로 올라올 때 가슴은 상대 쪽 — 등을 보이면 안 된다
- 무릎을 세울 때까지 상대 오른다리 감기를 풀지 않는다
- 머리를 상대 오른쪽 옆구리에 붙여 크로스페이스·목 조르기를 막는다

## 흔한 실수

- 상대가 크로스페이스로 단단히 누를 때 올라오면 → 다시 눌린다 → 상대 체중이 뒤로 갈 때 올라온다
- 머리가 떨어져 있으면 → 상대가 목을 감는다 → 옆구리에 붙인다
- 팔꿈치를 몸에서 멀리 짚으면 → 받침이 약하다 → 어깨 아래에 짚는다

## 막히면

- 상대가 위저로 버티면 → [도그파이트 스윕](../techniques/dogfight-sweep.md)
- 상대가 넓게 버티면 → [도그파이트 전진 스윕](../techniques/forward-drive-sweep-from-dogfight.md)
- 상대가 크로스페이스로 눌러 오면 → [도그파이트 → 하프가드 복귀](../techniques/re-pull-half-guard-from-dogfight.md)

## 방어하는 쪽 (상대 입장)

- 상대 왼팔이 내 오른쪽 겨드랑이에 깊이 들어오고 무릎으로 올라오려 하면 도그파이트 신호
- 올라오기 전에 내 왼팔 크로스페이스로 다시 눕힌다 → 도그파이트 상대 다시 눕히기
- 이미 올라왔으면 내 오른팔 위저를 깊게 감고 엉덩이를 뒤로 뺀다 → 크로스페이스 (도그파이트 탑) · 스냅 다운 (도그파이트 탑)
