# 무릎 눌러 X 가드 패스 (Knee Pin from X-Guard)

[X 가드 · 싱글 레그 X · 앵클락](../positions/x-guard.md) · 패스 · 위 → [하프가드](../positions/half-guard.md)

다른 이름: X가드 니핀

## 세팅 과정 (오른손잡이 기준)

1. 상대가 내 왼다리를 안고 내 오른다리에 X 훅을 걸었을 때, 내 왼손으로 상대 깃이나 머리를 잡아 상체를 고정한다
2. 내 오른손으로 내 오른쪽 무릎 뒤에 걸린 상대 왼다리 무릎을 바닥으로 누른다
3. 엉덩이를 낮추며 체중을 실어 상대 왼쪽 무릎을 바닥에 붙인다
4. 안긴 왼다리를 빼 하프가드 위로 자리 잡고 니슬라이스로 잇는다

## 핵심 디테일

- 무릎을 누르기 전에 내 왼손으로 상대 깃·머리를 잡아 상체부터 고정한다
- 팔 힘이 아니라 엉덩이를 낮추며 체중으로 상대 왼쪽 무릎을 바닥에 붙인다
- 내 오른쪽 팔꿈치를 몸에 붙여 상대 무릎이 다시 오금으로 들어올 틈을 막는다
- 안긴 왼다리는 확 뽑지 말고 엉덩이를 조금씩 움직여 빼낸다

## 흔한 실수

- 상체 그립 없이 무릎만 누르면 → 상대가 당기거나 들어 올려 스윕한다 → 왼손 깃·머리 그립부터
- 선 채 팔로만 누르면 → 힘이 안 실리고 훅이 다시 들어온다 → 엉덩이를 낮춰 체중을 싣는다
- 다리를 뺀 뒤 멈추면 → 상대가 니 쉴드로 다시 막는다 → 하프 위에서 바로 니슬라이스로 잇는다

## 막히면

- 상대가 무릎을 다시 내 오른쪽 오금에 넣으면 → [스매시 패스 (X 가드 상대)](../techniques/smash-pass-from-x-guard.md)
- 상대가 싱글 레그 X로 바꾸면 → [백스텝 (싱글 레그 X 상대)](../techniques/backstep-from-single-leg-x.md)
- 하프가드에서 니 쉴드가 서면 → [스매시 패스](../techniques/smash-pass.md)

## 방어하는 쪽 (상대 입장)

- 상대 오른손이 내 왼쪽 무릎(오금에 건 훅)으로 내려오고 상대 왼손이 내 깃·머리를 잡으면 무릎 누르기 신호
- 눌리기 전에 내 왼쪽 무릎을 상대 오른쪽 오금에 다시 깊이 넣고 엉덩이를 띄운다
- 상대가 앞으로 체중을 싣는 순간 X 가드 스윕
- 무릎이 바닥에 붙었으면 X 가드 → 싱글 레그 X 로 갈아탄다
