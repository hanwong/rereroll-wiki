# 볼로 스윕 (Bolo Sweep)

[데라히바 · 리버스 데라히바](../positions/de-la-riva.md) · 스윕 · 아래 → [패스](../positions/passing.md) / [백 컨트롤](../positions/back-control.md)

다른 이름: 볼로

## 세팅 과정 (오른손잡이 기준)

1. 데라히바(내 왼다리 훅)에서 내 오른손으로 상대 허리띠를 잡고 당겨 상대를 앉힌다
2. 턱을 당기고 어깨로 구르며 상대 밑으로 들어간다
3. 훅이 걸리지 않은 상대 왼다리를 내 오른팔로 잡아 끌어당긴다
4. 회전을 이어 상대를 옆으로 넘기고 위나 백으로 간다

## 핵심 디테일

- 허리띠 그립으로 상대를 당겨 앉혀야 밑으로 굴러 들어갈 공간이 생긴다
- 구를 때 턱을 당기고 어깨로 굴러 목을 보호한다
- 내 오른팔로 상대 왼다리를 끌어안아야 상대가 그 다리로 버티지 못한다
- 왼다리 훅은 회전 내내 상대 오른다리에 감아 둔다

## 흔한 실수

- 상대가 높게 서 있을 때 구르면 그대로 눌린다 → 먼저 당겨 무너뜨린다
- 상대 왼다리를 잡지 않고 구르기만 하면 상대가 버티고 돌아서 패스한다 → 오른팔로 왼다리를 꼭 안는다
- 넘긴 뒤 바로 일어나지 않으면 상대가 다시 가드를 잡는다 → 회전이 끝나면 바로 위로 올라간다

## 막히면

- 상대가 넘어가지 않고 등을 보이면 → [베림볼로](../techniques/berimbolo-entry.md)
- 상대가 앉지 않고 서서 버티면 → [데라히바 스윕](../techniques/de-la-riva-sweep.md)

## 방어하는 쪽 (상대 입장)

- 상대 오른손이 내 허리띠를 당기고 상대가 내 다리 밑으로 굴러 들어오면 신호
- 허리띠 그립을 끊고 엉덩이를 낮춰 서서 앉혀지지 않게 버틴다
- 상대 오른팔이 내 왼다리를 잡으면 왼다리를 뒤로 빼 거리를 둔다
- 넘어가면 등을 보이지 말고 돌아앉아 마주 보며 가드를 만든다
