# 남북 초크 (North-South Choke)

[남북 (노스사우스)](../positions/north-south.md) · 서브미션 · 위

다른 이름: 노스사우스 초크, 남북 조르기, NS 초크

## 세팅 과정 (오른손잡이 기준)

1. 남북에서 상대 오른팔을 상대 머리 위쪽으로 밀어 치워 목 앞을 비운다
2. 내 왼팔을 상대 목 아래로 깊게 넣어 감고 내 오른손과 손바닥끼리 맞잡는다
3. 내 왼쪽 겨드랑이와 가슴 옆을 상대 턱 아래 목 앞에 붙인다
4. 엉덩이를 바닥으로 낮추고 체중을 내 왼쪽 가슴에 실어 천천히 조인다 — 탭하면 바로 푼다

## 핵심 디테일

- 상대 오른팔을 머리 위쪽으로 치워 목 앞을 비워야 조일 수 있다
- 내 왼팔을 목 아래로 깊게 넣어 겨드랑이와 가슴 옆이 상대 목 앞에 오게 한다
- 엉덩이를 바닥으로 낮추고 체중을 왼쪽 가슴에 실어 조인다 — 팔로 짜지 않는다
- 천천히 조이고 탭하면 바로 푼다

## 흔한 실수

- 팔을 얕게 넣으면 턱만 눌리고 안 조여진다 → 겨드랑이가 목에 닿을 만큼 깊게 넣는다
- 엉덩이를 들면 체중이 목에 안 실린다 → 엉덩이를 바닥 쪽으로 낮춘다
- 상대 오른팔이 목 앞에 남아 있으면 막힌다 → 팔을 머리 위로 먼저 치운다

## 막히면

- 상대가 턱을 당기고 팔로 막으면 → [남북 기무라](../techniques/north-south-to-kimura.md) · [아메리카나 (남북)](../techniques/americana-from-north-south.md)
- 상대가 나를 향해 돌며 무릎을 넣으려 하면 → [남북 → 사이드](../techniques/north-south-to-side-control.md)로 다시 누른다
- 상대가 엎드리려 하면 → [백 테이크 (남북, 상대가 엎드릴 때)](../techniques/north-south-to-back-take.md)

## 방어하는 쪽 (상대 입장)

- 상대가 내 오른팔을 머리 위로 치우고 목 아래로 팔을 깊게 넣으면 신호다
- 오른팔을 다시 목 앞으로 끌어와 턱과 팔로 목을 막는다
- 양손으로 상대 골반을 밀어 공간을 만들고 내 오른쪽으로 돌아 남북 이스케이프로 간다
- 조여 오면 버티지 말고 일찍 탭한다
