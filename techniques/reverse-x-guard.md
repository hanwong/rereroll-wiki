# 리버스 X 가드 (Reverse X-Guard)

[X 가드 · 싱글 레그 X · 앵클락](../positions/x-guard.md) · 자세 · 컨트롤 · 아래 → [X 가드 · 싱글 레그 X · 앵클락](../positions/x-guard.md)

다른 이름: 리버스 엑스

## 세팅 과정 (오른손잡이 기준)

1. 상대 오른다리 아래로 들어가 그 다리를 내 왼쪽 어깨에 얹고 왼팔로 안되, 몸은 반대로 향한다
2. 내 오른다리로 상대 왼쪽 무릎 뒤를 건다
3. 내 왼발로 상대 왼쪽 허벅지를 민다
4. 안은 상대 오른쪽 발목을 당겨 균형을 뺏는다

## 핵심 디테일

- 상대가 서 있을 때 들어간다 — 위에서 눌릴 땐 안 된다
- 상대 오른다리를 내 왼쪽 어깨에 얹고 왼팔로 꽉 안아 다리를 못 빼게 한다
- 내 오른다리 훅은 상대 왼쪽 무릎 뒤에 깊게, 내 왼발은 상대 왼쪽 허벅지를 밀어 가위처럼 쓴다
- 어깨는 바닥에 붙이고 엉덩이만 돌려 각도를 만든다

## 흔한 실수

- 훅이 얕아 무릎 뒤에 안 걸리면 → 상대가 다리를 쉽게 뺀다 → 오금까지 깊게 건다
- 상대가 체중을 실어 누를 때 들어가면 → 그대로 깔린다 → 상대가 서 있을 때
- 어깨가 들리면 → 버틸 지지점이 없다 → 어깨를 바닥에 붙인다

## 막히면

- 상대가 왼손을 짚으려 하면 → [엘리베이션 스윕 (리버스 X)](../techniques/elevation-sweep-to-mount.md)
- 상대가 넓게 서서 버티면 → [리버스 X 가드 스윕](../techniques/reverse-x-guard-sweep.md)
- 상대가 다리를 빼며 돌아서면 → [리버스 X → 백 테이크](../techniques/reverse-x-to-back-take.md)

## 방어하는 쪽 (상대 입장)

- 상대가 내 오른다리 밑으로 파고들며 엉덩이를 돌리면 리버스 X 진입 신호
- 들어오기 전에 앞으로 체중을 실어 상대 어깨·엉덩이를 눌러 버린다
- 내 왼다리를 비스듬히 뒤로 빼 훅이 걸릴 목표를 없애고 발목 그립을 뗀다
- 이미 걸렸으면 엉덩이를 낮추고 백스텝 패스 (리버스 X 상대)
