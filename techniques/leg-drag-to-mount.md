# 레그 드래그 → 마운트 (Leg Drag to Mount)

[패스](../positions/passing.md) · 전환 · 위 → [마운트](../positions/mount.md)

다른 이름: 레그 드래그 마운트

## 세팅 과정 (오른손잡이 기준)

1. 내 왼팔 크로스페이스로 상대 상체를 눌러 둔다
2. 내 오른손으로 상대 오른팔을 눌러 걸리지 않게 한다
3. 내 오른쪽 무릎을 상대 배 위로 가로질러 상대 왼쪽 바닥까지 미끄러뜨린다
4. 무릎이 상대 왼쪽 바닥에 닿고 내 왼발이 상대 오른쪽에 남으면 엉덩이를 낮춰 마운트를 잡는다

## 핵심 디테일

- 내 왼팔 크로스페이스로 상대 상체를 눌러 상대가 돌아눕지 못하게 한다
- 내 오른손으로 상대 오른팔을 눌러 무릎이 지나갈 때 걸리지 않게 한다
- 오른쪽 무릎은 상대 배에 붙여 낮게 미끄러뜨린다 — 높이 들면 상대가 무릎을 넣는다
- 무릎이 상대 왼쪽 바닥에 닿으면 엉덩이를 낮춰 마운트를 굳힌다

## 흔한 실수

- 무릎을 높이 들고 넘기면 상대가 다리를 넣어 하프가드를 잡는다 → 배에 붙여 낮게 넘긴다
- 크로스페이스를 풀고 넘어가면 상대가 몸을 돌려 막는다 → 끝까지 눌러 둔다
- 마운트에서 엉덩이를 높게 두면 상대가 브릿지로 넘긴다 → 엉덩이를 낮춰 붙인다

## 막히면

- 상대 왼쪽 무릎이 세워져 막으면 → [레그 드래그 → 사이드](../techniques/leg-drag-pass-to-side-control.md)
- 상대가 내 다리를 감아 하프가드를 잡으면 → [하프가드 패스 (크로스페이스 · 언더훅)](../techniques/half-guard-pass.md)
- 상대가 등을 돌리면 → [레그 드래그 → 백 테이크](../techniques/leg-drag-to-back-take.md)

## 방어하는 쪽 (상대 입장)

- 상대 왼팔이 내 목 밑으로 크로스페이스를 걸고 상대 오른쪽 무릎이 내 배 위로 넘어오면 마운트로 가는 신호
- 무릎이 넘어오기 전에 내 왼쪽 무릎을 세우고 왼손으로 상대 무릎을 밀어 길을 막는다
- 이미 마운트가 잡혔으면 마운트 이스케이프 (엘보)로 하프가드를 되찾는다
