# 웨이터 스윕 (Waiter Sweep)

[딥 하프가드](../positions/deep-half.md) · 스윕 · 아래 → [하프가드](../positions/half-guard.md) / [사이드 컨트롤](../positions/side-control.md)

다른 이름: 웨이터

## 세팅 과정 (오른손잡이 기준)

1. 딥 하프에서 내 오른팔로 감은 상대 오른다리를 계속 안는다
2. 내 왼손을 상대 왼쪽 무릎 아래에 쟁반처럼 받친다
3. 양 다리로 상대 오른다리를 밀어 펴며 받친 왼다리를 내 머리 위로 들어 올린다
4. 상대가 상대 왼쪽으로 넘어가면 따라 일어나 위를 잡는다

## 핵심 디테일

- 내 오른팔로 안은 상대 오른다리는 끝까지 놓지 않는다
- 내 왼손은 손바닥이 위로 가게 상대 왼쪽 무릎 아래에 쟁반처럼 받친다
- 두 다리로 상대 오른다리를 밀어 펴는 것과 왼다리 들어 올리기를 동시에 한다
- 상대가 넘어가면 바로 따라 일어나 위를 잡는다

## 흔한 실수

- 왼다리를 들기 전에 안은 오른다리를 놓으면 상대가 다시 딛는다 → 계속 안는다
- 팔힘만으로 들면 안 올라간다 → 다리를 펴는 힘과 같이 든다
- 넘긴 뒤 누워 있으면 상대가 다시 가드를 만든다 → 바로 따라 올라간다

## 막히면

- 상대가 왼다리를 뒤로 빼 들 수 없으면 → [딥 하프 스윕](../techniques/deep-half-sweep.md)
- 상대가 뒤로 기대 버티면 → [호머 심슨 스윕](../techniques/homer-simpson-sweep.md)
- 상대가 백스텝으로 돌면 → [딥 하프 → 백 테이크](../techniques/deep-half-to-back.md)

## 방어하는 쪽 (상대 입장)

- 상대 왼손이 내 왼쪽 무릎 아래로 들어와 받치면 신호
- 왼다리를 뒤로 빼 넓게 디디고 무게를 낮춘다
- 오른팔 위저로 상대 상체를 눌러 상대가 밑에서 못 들게 한다
- 넘어가면 다리로 상대를 감아 하프·가드로 받는다
