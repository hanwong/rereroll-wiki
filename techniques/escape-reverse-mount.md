# 리버스 마운트 이스케이프 (하프가드로) (Escape Reverse Mount)

[마운트](../positions/mount.md) · 탈출 · 아래 → [하프가드](../positions/half-guard.md)

다른 이름: 리버스 마운트 탈출, Escape Reverse Mount

## 세팅 과정 (오른손잡이 기준)

1. 두 팔꿈치를 몸에 붙이고 양손으로 상대 허리 뒤를 받친다
2. 브릿지로 상대를 내 다리 쪽으로 밀어낸다
3. 엉덩이를 내 왼쪽으로 빼며(새우빼기) 내 오른쪽 무릎을 상대 다리 사이로 넣는다
4. 상대 오른다리를 내 두 다리로 감는다
5. 하프가드

## 핵심 디테일

- 팔꿈치를 몸에 붙인 채 손으로 상대 허리 뒤를 받친다 — 팔을 쭉 뻗지 않는다
- 브릿지로 상대를 내 다리 쪽으로 밀어 엉덩이 아래 틈을 만든다
- 새우빼기로 엉덩이를 내 왼쪽으로 빼고 오른 무릎을 상대 다리 사이로 넣는다
- 바로 상대 오른다리를 두 다리로 감아 하프가드를 잡는다

## 흔한 실수

- 팔을 뻗어 밀면 암바를 당한다 → 팔꿈치를 붙인 채 받친다
- 브릿지 없이 새우빼기만 하면 상대 무게에 막힌다 → 브릿지로 먼저 띄운다
- 무릎만 넣고 다리를 안 감으면 상대가 다시 올라탄다 → 바로 상대 오른다리를 감는다

## 막히면

- 상대 무게가 다리 쪽으로 쏠리면 → [리버스 마운트 브릿지 → 터틀](../techniques/bridge-from-reverse-mount.md)
- 상대가 마운트로 돌아오면 → [마운트 이스케이프 (엘보)](../techniques/mount-escape-elbow.md)
- 상대가 사이드로 내려가면 → [사이드 이스케이프 (프레임 · 쉬림프)](../techniques/side-control-escape.md)

## 방어하는 쪽 (상대 입장)

- 상대가 손으로 내 허리를 받치고 브릿지하면 탈출 신호
- 체중을 상대 배에 싣고 다리를 넓혀 받쳐 무릎이 들어올 틈을 막는다
- 상대가 팔을 뻗으면 → 리버스 마운트 → 암바
- 무릎이 들어오기 시작하면 → 리버스 마운트 → 사이드
