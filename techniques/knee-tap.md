# 니 탭 (Knee Tap)

[스탠딩 · 테이크다운](../positions/standing.md) · 테이크다운 · 서서 → [사이드 컨트롤](../positions/side-control.md)

다른 이름: 니탭, 니 픽

## 세팅 과정 (오른손잡이 기준)

1. 내 오른팔로 상대 왼쪽 언더훅(또는 상대 왼쪽 깃)을 잡고 밀어 상대 오른다리에 체중을 싣게 한다
2. 내 왼손을 내려 상대 오른쪽 무릎 바깥쪽을 잡는다(탭)
3. 오른팔 언더훅으로 밀며 왼손으로 무릎을 당겨 상대를 상대 오른쪽 무릎 위로 넘어뜨린다
4. 넘어가면 바로 사이드로

## 핵심 디테일

- 오른팔(언더훅이나 깃)로 상대를 밀어 체중을 상대 오른다리에 싣는다
- 상대가 오른발을 앞으로 딛는 순간 레벨을 낮추며 왼손으로 상대 오른 무릎 바깥을 막는다
- 왼손은 무릎을 막고 오른팔은 사선으로 밀어 상대가 무릎 위로 넘어지게 한다
- 머리는 상대 가슴 가까이 두고 몸을 멀리 떨어뜨리지 않는다

## 흔한 실수

- 체중을 싣지 않고 무릎만 치면 상대가 다리를 빼고 선다 → 오른팔로 먼저 기울인다
- 허리를 숙여 손만 뻗으면 앞으로 고꾸라지거나 목을 잡힌다 → 무릎을 굽혀 낮춘다
- 정면으로만 밀면 상대가 뒷발로 버틴다 → 무릎 바깥 방향으로 사선 밀기

## 막히면

- 상대가 오른다리를 빼고 버티면 → 그 다리를 잡아 [싱글 레그 테이크다운](../techniques/single-leg-takedown.md)
- 상대가 뒤로 버텨 체중이 왼발로 가면 → [안다리후리기](../techniques/o-uchi-gari.md)
- 상대가 내 언더훅을 끊으면 → 다시 [언더훅 퍼멀링](../techniques/underhook-pummeling.md)으로 손을 넣는다

## 방어하는 쪽 (상대 입장)

- 상대 오른팔이 내 왼쪽 겨드랑이(언더훅)나 깃을 잡고 나를 내 오른쪽으로 밀며 상대 왼손이 내 오른 무릎으로 내려오면 니 탭 신호
- 오른발을 뒤로 빼 무릎을 피하고 체중을 두 발 가운데로 되돌린다
- 내 왼팔로 상대 오른팔을 위에서 감아(위저) 언더훅의 힘을 끊는다
- 이미 넘어가면 낙법하고 상대 쪽으로 몸을 돌려 하프가드나 가드를 잡는다
