# 딥 하프 스윕 (Deep Half Sweep)

[딥 하프가드](../positions/deep-half.md) · 스윕 · 아래 → [사이드 컨트롤](../positions/side-control.md)

다른 이름: 딥하프 넘기기

## 세팅 과정 (오른손잡이 기준)

1. 딥 하프에서 내 오른팔로 상대 오른쪽 허벅지를 안고 왼손으로 상대 왼쪽 발목을 잡는다
2. 엉덩이를 상대 아래로 더 넣는다
3. 상대 오른다리를 들어 올리며 돌아 상대 왼쪽으로 넘긴다
4. 위로 올라온다

## 핵심 디테일

- 내 왼손으로 상대 왼쪽 발목을 잡아 상대가 그 발로 버티지 못하게 한다
- 엉덩이를 상대 무게중심 밑으로 더 넣은 뒤 시작한다
- 팔로 들지 말고 다리를 펴는 힘으로 상대 오른다리를 들어 올린다
- 넘어가는 순간 따라 일어나 위를 잡는다

## 흔한 실수

- 왼쪽 발목을 안 잡으면 상대가 왼발로 디뎌 버틴다 → 발목부터 잡는다
- 얕은 자리에서 들면 상대가 무게로 눌러 버린다 → 엉덩이를 더 밑으로
- 넘긴 뒤 누워 있으면 상대가 다시 가드를 만든다 → 바로 따라 올라간다

## 막히면

- 상대가 뒤로 기대 버티면 → [호머 심슨 스윕](../techniques/homer-simpson-sweep.md)
- 상대가 일어서면 → [딥 하프 → X 가드](../techniques/deep-half-to-x-guard.md)

## 방어하는 쪽 (상대 입장)

- 상대 왼손이 내 왼쪽 발목을 잡고 상대 엉덩이가 내 밑으로 더 들어오면 신호
- 왼발을 뒤로 빼 발목 그립을 떼고 체중을 상대 상체 쪽으로 낮춘다
- 오른팔 위저로 상대 상체를 눌러 상대가 못 들게 한다
- 넘어가면 다리로 상대를 감아 가드로 받는다
