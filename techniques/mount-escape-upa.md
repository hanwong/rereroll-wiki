# 마운트 이스케이프 (업파) (Mount Escape (Upa / Trap and Roll))

[마운트](../positions/mount.md) · 탈출 · 아래 → [클로즈드 가드](../positions/closed-guard.md)

다른 이름: 업파, 브릿지 앤 롤, 트랩 앤 롤, 업파 이스케이프, 브릿지 앤 롤 (마운트), 업파 변형

## 세팅 과정 (오른손잡이 기준)

1. 상대 오른팔을 내 양손으로 감싸 가슴에 붙이고 내 왼발로 상대 오른발 바깥을 걸어 묶는다(트랩)
2. 양발을 엉덩이 가까이 당겨 세운다
3. 내 왼쪽 어깨 너머로 높게 브릿지하며 몸을 왼쪽으로 돌린다
4. 굴러 넘겨 상대 클로즈드 가드 안에서 자세를 세운다

## 핵심 디테일

- 상대 오른팔과 오른발을 함께 묶어야 상대가 그쪽으로 짚지 못한다
- 양발을 엉덩이 가까이 세워 높게 브릿지한다
- 곧장 위가 아니라 내 왼쪽 어깨 너머 대각선으로 민다
- 상대 무게가 앞으로 쏠렸을 때 하면 쉽다

## 흔한 실수

- 팔만 묶고 발을 안 묶으면 상대가 다리로 버틴다 → 내 왼발로 상대 오른발 바깥을 건다
- 곧장 위로 브릿지하면 상대가 떴다가 다시 앉는다 → 왼쪽 어깨 너머로 민다
- 상대가 높이 앉아 있을 때 하면 무게가 없어 안 넘어간다 → 무게가 앞으로 올 때 한다

## 막히면

- 상대가 다리를 넓게 벌려 버티면 → [마운트 이스케이프 (엘보)](../techniques/mount-escape-elbow.md)
- 상대가 팔을 빼 바닥을 짚으면 → 그 틈에 엉덩이를 빼 엘보 이스케이프로 간다 · [마운트 이스케이프 (엘보)](../techniques/mount-escape-elbow.md)

## 방어하는 쪽 (상대 입장)

- 상대가 양손으로 내 오른팔을 감싸고 상대 왼발이 내 오른발 바깥에 걸리면 → 업파 신호
- 오른팔을 빼 바닥을 넓게 짚고 오른다리를 벌려 버틴다
- 엉덩이를 낮추고 무게를 뒤로 빼 브릿지 힘을 줄인다
- 이미 굴려졌으면 → 클로즈드 가드 안 자세 되찾기
