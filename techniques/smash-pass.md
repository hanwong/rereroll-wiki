# 스매시 패스 (Smash Pass)

[하프가드](../positions/half-guard.md) · 패스 · 위 → [사이드 컨트롤](../positions/side-control.md)

다른 이름: 스매쉬 패스, 하프 스매시, 니 쉴드 패스, 니실드 패스, 무릎 방패 패스, Z가드 패스, Pass Pocket Half, Pocket Half Pass, Smash Pocket Half

## 세팅 과정 (오른손잡이 기준)

1. 상대가 내 오른다리를 하프가드로 감고 오른쪽 무릎으로 니 쉴드를 댔을 때
2. 내 왼손으로 상대 오른쪽 무릎을 상대 왼쪽 바닥으로 눌러 내린다
3. 상대 양 무릎이 상대 왼쪽으로 겹치게 내 엉덩이 체중으로 눌러 골반을 비튼다
4. 내 오른쪽 팔꿈치를 바닥에 가깝게 두고 머리로 상대 가슴을 누른다
5. 감긴 내 오른다리를 빼며 상대 오른쪽으로 돌아 사이드 컨트롤로

## 핵심 디테일

- 내 왼손으로 상대 오른쪽 무릎을 상대 왼쪽 바닥으로 넘겨 두 무릎을 겹치게 한다
- 엉덩이 체중으로 눌러 상대 골반을 비틀어 두면 상대가 무릎을 다시 못 세운다
- 내 오른쪽 팔꿈치를 바닥 가까이 두고 머리로 상대 가슴을 눌러 상대가 몸을 세우지 못하게 한다
- 한 번에 넘으려 하지 말고 무릎 접기 → 압박 → 다리 빼기 순서로

## 흔한 실수

- 니 쉴드를 안 접고 가슴으로 밀면 → 무릎에 막힌다 → 무릎부터 넘긴다
- 엉덩이가 들리면 → 상대가 무릎을 다시 세운다 → 낮게 누른다
- 다리를 확 뽑으면 → 상대가 하프가드를 다시 감는다 → 압박을 유지하며 천천히 뺀다

## 막히면

- 상대가 언더훅으로 올라오면 → [하프 탑 위저 카운터](../techniques/half-guard-whizzer-counter.md)
- 상대가 머리를 내 아래로 넣어 딥 하프로 가면 → [위저 (딥 하프 상대)](../techniques/whizzer-from-deep-half.md)
- 니 쉴드가 너무 단단하면 → [하프가드 패스 (크로스페이스 · 언더훅)](../techniques/half-guard-pass.md)
- 상대 니 쉴드 발이 내 골반 옆에 떠 있으면 → [토홀드 (하프가드 탑 · 니 쉴드 상대)](../techniques/toe-hold-half-guard-top.md)

## 방어하는 쪽 (상대 입장)

- 상대 왼손이 내 오른쪽 무릎(니 쉴드)을 내 왼쪽 바닥으로 누르면 스매시 신호
- 무릎이 넘어가기 전에 엉덩이를 빼 각도를 다시 만들고 무릎을 세운다 → 니 쉴드 유지 (눌릴 때)
- 무릎이 겹쳐졌으면 언더훅으로 몸을 세우거나 머리를 상대 아래로 넣어 눌린 하프 → 딥 하프
- 다리가 빠지려 하면 상대 다리를 감아 쿼터 가드로 버티고 → 쿼터 가드 → 니 쉴드
