# 신 투 신 가드 패스 (Pass Shin-to-Shin Guard)

[오픈 가드](../positions/open-guard.md) · 패스 · 위 → [사이드 컨트롤](../positions/side-control.md)

다른 이름: 신투신 패스, 니 스루 (신 투 신 상대), 신투신 니스루

## 세팅 과정 (오른손잡이 기준)

1. 상대가 정강이를 내 오른쪽 정강이에 대고 내 오른쪽 발목을 잡았을 때
2. 대인 내 오른다리를 뒤로 빼거나 바깥으로 돌린다
3. 내 오른손으로 내 발목을 잡은 상대 왼손 그립을 끊는다
4. 내 오른쪽 무릎을 상대 두 다리 사이로 넣어 상대 오른쪽 허벅지 위에 올린다
5. 무릎을 올린 채 니슬라이스로 상대 오른쪽으로 패스한다

## 핵심 디테일

- 오른다리를 뒤로 빼거나 바깥으로 돌려 정강이 연결부터 떼어 낸다
- 내 오른손으로 내 오른 발목을 잡은 상대 왼손 그립을 끊는다
- 오른 무릎을 상대 두 다리 사이로 넣어 상대 오른 허벅지 위에 올린다
- 무릎을 올린 채 니슬라이스로 상대 오른쪽에 가슴을 붙여 끝낸다

## 흔한 실수

- 정강이를 정면으로 밀고 들어가면 상대가 밑으로 들어와 싱글 레그 X를 잡는다 → 다리를 빼거나 돌려 연결부터 끊는다
- 발목 그립을 남겨 두면 상대가 다시 붙는다 → 그립부터 끊는다
- 크게 급하게 움직이면 균형을 잃는다 → 무릎을 굽힌 낮은 자세로 움직인다

## 막히면

- 상대가 밑으로 들어와 다리를 감으면 → [싱글 레그 X 빠져나오기 (서서)](../techniques/standing-escape-from-slx.md)나 [백스텝 (싱글 레그 X 상대)](../techniques/backstep-from-single-leg-x.md)
- 상대가 니 쉴드로 막으면 → [하프가드](../positions/half-guard.md)로 받아 [하프가드 패스 (크로스페이스 · 언더훅)](../techniques/half-guard-pass.md)
- 상대가 엉덩이를 빼 거리를 다시 만들면 → 따라가 [토레안도 패스](../techniques/toreando-pass.md)

## 방어하는 쪽 (상대 입장)

- 상대가 오른다리를 빼거나 돌리며 오른손으로 내 왼손 발목 그립을 끊으려 하면 패스 신호
- 발목 그립을 다시 잡고 엉덩이를 상대 다리 쪽으로 붙여 싱글 레그 X 가드로 먼저 들어간다
- 상대 오른 무릎이 내 오른 허벅지를 넘어오면 무릎을 세워 니 쉴드 하프가드로 받는다
