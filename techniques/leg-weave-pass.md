# 레그 위브 패스 (Leg Weave Pass)

[하프가드](../positions/half-guard.md) · 패스 · 위 → [사이드 컨트롤](../positions/side-control.md)

다른 이름: 레그 레이스, 다리 엮기

## 세팅 과정 (오른손잡이 기준)

1. 내 오른다리가 감기고 상대가 왼쪽 무릎 니 쉴드를 대면 내 오른팔을 상대 왼다리 위로 넘겨 오른다리 밑으로 넣어 바닥을 짚는다(엮기)
2. 머리와 어깨를 낮춰 상대 무릎 두 개를 한데 모은다
3. 스프롤로 엉덩이를 낮추며 감긴 오른다리를 뺀다
4. 엮은 상대 다리를 돌아 사이드 컨트롤로 간다

## 핵심 디테일

- 내 오른팔을 상대 왼다리 위로 넘겨 오른다리 밑까지 깊게 넣고 바닥을 짚는다
- 오른쪽 어깨로 상대 왼쪽 허벅지를 눌러 두 무릎을 한데 모은다
- 머리와 엉덩이를 낮게 두고 스프롤하듯 오른다리를 뺀다
- 다리가 빠지면 엮은 다리를 돌아 가슴을 붙여 사이드로

## 흔한 실수

- 팔을 얕게 넣으면 니 쉴드가 다시 선다 → 어깨까지 깊게 넣는다
- 엉덩이를 들고 다리를 빼면 상대가 다시 감는다 → 엉덩이를 낮춘 채 뺀다
- 상체가 높으면 상대가 다리를 빼 가드를 만든다 → 머리를 낮게 둔다

## 막히면

- 상대가 내 쪽으로 돌아 무릎으로 올라오면 → [크로스페이스 (도그파이트 탑)](../techniques/crossface-from-dogfight.md)
- 상대가 다리를 꽉 감아 안 빠지면 → [하프가드 → 쿼터 가드 (탑)](../techniques/half-guard-to-quarter-guard.md)
- 상대가 니 쉴드를 풀고 붙어 오면 → [바디락 패스](../techniques/body-lock-pass.md)

## 방어하는 쪽 (상대 입장)

- 상대 오른팔이 내 왼다리 위로 넘어와 내 오른다리 밑으로 들어오면 신호
- 왼쪽 무릎을 접어 내리지 말고 내 왼손으로 상대 오른쪽 팔꿈치를 밀어낸다
- 무릎이 모이면 엉덩이를 빼 다리를 다시 감는다 → 레그 위브 상대 하프 회복
- 눌려 있으면 상대 쪽으로 돌아 무릎으로 올라온다 → 레그 위브 상대 도그파이트
