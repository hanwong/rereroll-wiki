# 엘리베이터 스윕 (Elevator Sweep)

[버터플라이 가드](../positions/butterfly-guard.md) · 스윕 · 아래 → [마운트](../positions/mount.md) / [사이드 컨트롤](../positions/side-control.md)

다른 이름: 엘레베이터 스윕, 엘리베이터

## 세팅 과정 (오른손잡이 기준)

1. 상대가 무릎 서서 들어올 때 내 오른발을 상대 왼쪽 허벅지 안쪽에 훅으로 넣는다
2. 내 왼손으로 상대 오른쪽 소매나 손목을 잡아 상대가 오른손을 짚지 못하게 한다
3. 상대를 당기면서 내 오른발 훅으로 상대 왼다리를 위로 들어 올린다
4. 상대를 내 왼쪽으로 넘기고 따라 올라온다

## 핵심 디테일

- 상대가 무릎 서서 들어오는 순간 오른발 훅을 상대 왼 허벅지 안쪽 깊이 넣는다
- 왼손으로 상대 오른쪽 소매·손목을 잡아 상대 오른손이 바닥을 못 짚게 한다
- 당기는 힘과 오른발 훅으로 드는 힘을 한 번에 쓴다
- 상체를 세워 앉은 자세에서 시작한다

## 흔한 실수

- 등을 대고 누운 채 하면 훅에 힘이 안 실린다 → 상체를 세워 앉는다
- 팔로만 당기거나 다리로만 들면 안 넘어간다 → 당김과 들기를 동시에 한다
- 훅이 무릎 근처에 얕게 걸리면 미끄러진다 → 허벅지 안쪽 깊이 건다

## 막히면

- 상대가 오른손을 짚어 버티면 → [암 드래그 → 백 (버터플라이)](../techniques/arm-drag-to-back-butterfly.md)
- 상대가 엉덩이를 뒤로 빼면 → [신 투 신 가드](../techniques/shin-to-shin-guard.md)로 다리를 잡는다
- 상대가 일어서면 → [버터플라이 → X 가드](../techniques/butterfly-guard-to-x-guard.md)

## 방어하는 쪽 (상대 입장)

- 상대 오른발 훅이 내 왼 허벅지 안쪽 깊이 들어오고 내 오른쪽 소매가 잡히면 스윕 신호
- 소매 그립을 끊고 무릎을 넓게 벌려 엉덩이를 낮춘다
- 왼다리가 들리면 오른손·오른다리를 넓게 짚어 버틴다
