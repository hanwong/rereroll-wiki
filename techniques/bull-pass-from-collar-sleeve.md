# 불 패스 (칼라 슬리브 상대) (Bull Pass vs Collar Sleeve)

[스파이더 · 라쏘 · 소매 가드](../positions/spider-lasso.md) · 패스 · 위 → [사이드 컨트롤](../positions/side-control.md)

다른 이름: 칼라슬리브 토레안도, 토레안도 (더블 슬리브 상대), 소매 토레안도

## 세팅 과정 (오른손잡이 기준)

1. 상대가 내 왼쪽 깃·오른쪽 소매를 잡으면 엉덩이를 뒤로 빼고 가슴을 세워 끌리지 않게 한다
2. 두 손으로 내 왼쪽 깃(또는 오른쪽 소매)을 잡은 상대 손을 끊는다
3. 상대 양 무릎 바지를 잡고 두 다리를 내 왼쪽으로 밀어 넘긴다
4. 내 오른쪽으로 크게 돌아 가슴을 눌러 상대 왼쪽 사이드로 간다

## 핵심 디테일

- 엉덩이를 뒤로 빼고 가슴을 세워 깃 그립에 끌려가지 않는다
- 두 손으로 깃 잡은 상대 손을 끊은 뒤 바로 양 무릎 바지를 잡는다
- 상대 두 다리를 내 왼쪽으로 밀어 넘기는 순간 내 오른쪽으로 크게 돌아간다
- 돌아 들어가면 가슴으로 눌러 다리가 다시 못 들어오게 한다

## 흔한 실수

- 그립을 그대로 두고 돌면 상대가 당겨 스윕한다 → 깃·소매 그립부터 끊는다
- 다리를 밀기만 하고 돌지 않으면 상대 다리가 다시 돌아온다 → 밀면서 동시에 크게 돈다
- 무릎을 일찍 놓으면 상대가 가드를 다시 만든다 → 사이드에 붙을 때까지 누른다

## 막히면

- 상대가 왼다리로 내 오른다리에 데라히바를 걸면 → [토레안도 (데라히바 상대)](../techniques/toreando-pass-from-de-la-riva.md)
- 상대 발이 이두에 붙어 그립이 안 끊기면 → [스택 패스 (스파이더 상대)](../techniques/stack-pass-from-spider.md)

## 방어하는 쪽 (상대 입장)

- 상대가 엉덩이를 빼고 내 깃·소매 그립을 끊으며 내 두 무릎을 잡으면 패스 신호
- 무릎이 잡히기 전에 그립을 다시 잡고 발을 상대 골반·이두에 다시 댄다
- 다리가 내 오른쪽으로 밀리면 왼쪽 어깨로 돌아누워 엉덩이를 내 오른쪽으로 빼고 왼쪽 무릎을 다시 넣는다
- 이미 붙었으면 팔뚝으로 상대 골반과 목에 프레임을 세운다
