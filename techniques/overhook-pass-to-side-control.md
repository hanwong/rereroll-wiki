# 오버훅 풀고 패스 (Overhook Pass to Side Control)

[클로즈드 가드](../positions/closed-guard.md) · 패스 · 위 → [사이드 컨트롤](../positions/side-control.md)

다른 이름: 오버훅 패스

## 세팅 과정 (오른손잡이 기준)

1. 상대가 왼팔로 내 오른팔을 오버훅하면 내 오른쪽 팔꿈치를 몸 쪽으로 당겨 빼낸다
2. 빠지면 바로 내 두 손으로 상대 양 무릎을 눌러 가드를 연다
3. 내 오른쪽 무릎을 상대 오른쪽 허벅지 위로 미끄러뜨려(니슬라이스) 다리를 지난다
4. 상대 오른쪽에서 사이드 컨트롤

## 핵심 디테일

- 팔을 뺄 때 오른쪽 팔꿈치를 내 옆구리로 붙이며 원을 그리듯 아래로 돌려 뺀다
- 팔이 빠지면 쉬지 말고 바로 두 손으로 상대 양 무릎을 눌러 가드를 연다
- 니슬라이스 때 엉덩이를 낮추고 오른쪽 정강이로 상대 오른쪽 허벅지를 무겁게 누른다
- 지나가면서 내 왼팔 크로스페이스로 상대 얼굴을 상대 왼쪽으로 돌린다

## 흔한 실수

- 팔을 뒤로 일직선으로 잡아당기면 안 빠진다 → 팔꿈치를 몸에 붙여 원을 그리며 뺀다
- 팔이 빠진 뒤 머뭇거리면 상대가 다시 오버훅을 잡거나 가드를 잠근다 → 빠지자마자 무릎을 연다
- 머리를 높이 들고 지나가면 상대가 프레임을 넣는다 → 머리와 엉덩이를 낮게 붙인다

## 막히면

- 상대가 니 쉴드로 막으면 → [스매시 패스](../techniques/smash-pass.md)
- 상대가 내 오른다리를 감아 하프가드를 만들면 → [하프 탑 기본 자세](../techniques/half-guard-top-control.md) 후 [하프가드 패스 (크로스페이스 · 언더훅)](../techniques/half-guard-pass.md)
- 오버훅이 안 빠지면 → [기무라 (오버훅 컨트롤 위에서)](../techniques/kimura-from-overhook-control.md)

## 방어하는 쪽 (상대 입장)

- 상대가 오른쪽 팔꿈치를 몸에 붙여 빼내고 두 손으로 내 무릎을 누르면 패스 신호다
- 팔이 빠지는 순간 다시 가드를 잠그거나 발로 상대 골반을 막는다
- 상대 오른 무릎이 내 오른쪽 허벅지 위로 오면 내 왼쪽 무릎을 세워 니 쉴드를 만들고 왼팔로 상대 오른쪽 겨드랑이 언더훅을 잡는다
- 이미 지나갔으면 팔뚝으로 상대 목·골반에 프레임을 대고 엉덩이를 내 왼쪽으로 빼 무릎을 다시 넣는다
