# 거리 만들어 리셋 (라펠 상대) (Distance Creation to Reset)

[라펠 가드](../positions/lapel-guard.md) · 방어 · 위 → [오픈 가드](../positions/open-guard.md)

다른 이름: 라펠 리셋

## 세팅 과정 (오른손잡이 기준)

1. 상대가 오른손으로 내 라펠을 잡았을 때, 내 왼손으로 상대 오른쪽 손목(소매)을 먼저 잡아 더 감지 못하게 한다
2. 엉덩이를 뒤로 빼고 등을 세워 자세를 지킨다
3. 내 오른손으로 감긴 라펠을 한 겹씩 풀어 몸에서 빼낸다
4. 한 걸음 뒤로 물러나 바로 양손으로 바지나 무릎 그립을 다시 잡고 패스를 시작한다

## 핵심 디테일

- 내 왼손으로 상대 오른쪽 손목을 먼저 잡아야 라펠을 더 못 감는다
- 엉덩이를 뒤로 빼고 등을 세워 당기는 힘을 몸 전체로 버틴다
- 라펠은 한 겹씩 풀어 벗긴다 — 확 잡아 뜯지 않는다
- 물러난 뒤 바로 바지나 무릎 그립을 잡아 패스를 다시 시작한다

## 흔한 실수

- 손목을 놔둔 채 풀면 상대가 다시 감는다 → 손목부터 잡는다
- 숙인 채 풀면 스윕 당한다 → 등을 세운다
- 물러나서 가만히 서 있으면 상대가 다시 라펠을 잡는다 → 바로 그립을 잡고 움직인다

## 막히면

- 라펠이 다리에 감겨 물러나기 어려우면 → [웜 가드 상대 자세 지키기](../techniques/defend-worm-guard-posture.md)
- 물러날 공간이 없으면 → [스택 패스 (라펠 상대)](../techniques/stack-pass-over-lapel.md)
- 라펠이 풀리면 → [토레안도 패스](../techniques/toreando-pass.md)

## 방어하는 쪽 (상대 입장)

- 상대 왼손이 라펠 쥔 내 오른쪽 손목을 잡고 엉덩이를 빼면 라펠을 풀려는 신호
- 손목을 돌려 그립을 빼고 라펠을 더 당겨 상대 자세를 숙이게 한다
- 상대가 한 겹씩 풀기 시작하면 소매·발목 그립으로 바꿔 → 라펠 → 스파이더 · 라펠 → 데라히바
