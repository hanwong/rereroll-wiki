# 아메리카나 (곁누르기) (Americana from Kesa Gatame)

[곁누르기](../positions/kesa-gatame.md) · 서브미션 · 위

다른 이름: 아메리카나 (케사가타메), 케사 키락, 케사 아메리카나, 다리 아메리카나

## 세팅 과정 (오른손잡이 기준)

1. 상대가 왼손(먼 쪽 손)으로 내 얼굴을 밀면 내 왼손으로 그 손목을 잡는다
2. 상대 왼 손목을 상대 머리 쪽 바닥으로 눌러 팔꿈치를 90도로 접는다
3. 목 감은 내 오른팔은 유지하고 상대 왼 손목을 바닥에 붙여 둔다
4. 손목은 그대로 두고 상대 왼 팔꿈치를 들어 올려 어깨를 꺾는다

## 핵심 디테일

- 상대가 왼팔을 뻗어 내 얼굴을 밀 때가 기회
- 상대 오른팔은 내 왼 겨드랑이에 끼운 채로 둔다
- 상대 왼 손목을 머리 쪽 바닥에 붙이고 팔꿈치를 90도로 접는다
- 손목은 바닥에 두고 팔꿈치만 천천히 들어 올린다

## 흔한 실수

- 상대 팔이 쭉 펴진 채로 꺾으면 걸리지 않는다 → 먼저 팔꿈치를 접는다
- 손목이 바닥에서 뜨면 상대가 팔을 빼낸다 → 손목을 바닥에 눌러 둔다
- 손목을 잡느라 끼운 오른팔을 놓치면 상대가 돌아 들어온다 → 겨드랑이를 계속 조인다

## 막히면

- 상대가 왼팔을 거둬 숨기면 → [곁누르기 → 마운트](../techniques/kesa-to-mount.md)
- 상대가 오른팔을 빼려 하면 → [기무라 (곁누르기)](../techniques/kimura-from-kesa.md)

## 방어하는 쪽 (상대 입장)

- 내 왼손으로 상대 얼굴을 밀다가 상대 왼손이 내 왼 손목을 잡으면 → 아메리카나 신호
- 바로 왼팔을 거둬 팔꿈치를 몸에 붙인다
- 얼굴을 밀 때는 손바닥보다 팔뚝을 턱·목에 대 프레임을 만든다
- 손목이 바닥에 붙고 팔꿈치가 들리면 → 일찍 탭한다
