# 다스 방어 (Defend Darce)

[프론트 헤드락 · 길로틴](../positions/front-headlock.md) · 방어 · 아래 → [하프가드](../positions/half-guard.md) / [오픈 가드](../positions/open-guard.md)

다른 이름: 다스 디펜스, 다스 탈출

## 세팅 과정 (오른손잡이 기준)

1. 상대 다스에 내 왼팔이 갇히면 턱을 당기고 왼쪽 팔꿈치를 내 몸에 붙인다
2. 자유로운 내 오른팔로 상대 골반이나 허벅지를 밀어 프레임을 세운다
3. 엉덩이를 상대에게서 멀리 빼며 공간을 만든다
4. 허리를 세우며 머리와 갇힌 왼팔을 뽑아낸다
5. 내 오른쪽 무릎을 상대 몸 앞에 넣어 하프 가드나 오픈 가드를 잡는다

## 핵심 디테일

- 턱을 당기고 갇힌 왼쪽 팔꿈치를 몸에 붙인다
- 오른팔로 상대 골반이나 허벅지를 밀어 프레임 — 목이 아니라 몸을 민다
- 프레임으로 버틴 채 엉덩이를 멀리 빼 공간을 키운다
- 공간이 생기면 바로 오른쪽 무릎을 상대 몸 앞에 넣는다

## 흔한 실수

- 목을 쭉 빼며 뒤로 당기면 더 조여진다 → 턱을 붙인 채 엉덩이로 공간을 만든다
- 프레임만 하고 엉덩이를 안 빼면 상대 무게에 눌린다 → 프레임과 엉덩이 빼기를 같이 한다
- 공간이 생겨도 무릎을 안 넣으면 상대가 다시 붙는다 → 바로 무릎을 넣어 가드를 만든다

## 막히면

- 상대가 가슴을 더 실어 누르면 → [백 도어 이스케이프 (다스)](../techniques/back-door-escape-darce.md)
- 상대가 아나콘다로 바꾸면 → [아나콘다 방어](../techniques/frame-and-posture-from-anaconda.md)
- 하프가드에서 납작하게 눌리면 → [하프가드에서 가드 회복](../techniques/half-guard-recovery.md)

## 방어하는 쪽 (상대 입장)

- 상대 오른팔이 내 골반을 밀며 엉덩이를 빼면 → 가슴을 상대 왼쪽 어깨에 더 싣고 따라 걸어간다
- 상대 무릎이 들어오기 전에 → 엉덩이를 낮춰 그 공간을 막는다
- 머리가 빠지고 있으면 → 그립을 풀고 사이드 컨트롤을 잡는다
