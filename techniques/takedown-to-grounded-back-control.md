# 스탠딩 백 → 앉으며 백 테이크 (Standing Back to Grounded Back Control)

[클린치 · 가드 풀링](../positions/clinch.md) · 테이크다운 · 서서 → [백 컨트롤](../positions/back-control.md)

다른 이름: 앉으며 훅 넣기, 시트벨트 앉히기, Sit-Down Back Take

## 세팅 과정 (오른손잡이 기준)

1. 뒤에서 내 오른팔은 상대 오른쪽 어깨 위, 왼팔은 왼쪽 겨드랑이 밑으로 시트벨트를 꽉 잡는다
2. 내 왼발로 상대 왼쪽 무릎 뒤를 눌러 무릎을 꺾는다
3. 상대를 뒤로 끌어당기며 언더훅 쪽인 내 왼쪽 엉덩이부터 비스듬히 바닥에 내린다
4. 앉는 순간 위쪽 오른발, 아래쪽 왼발 순서로 상대 허벅지 안쪽에 훅을 넣는다
5. 백 컨트롤로 끝난다

## 핵심 디테일

- 시트벨트를 꽉 잡고 가슴을 등에 붙인 상태에서만 앉는다
- 내 왼발로 상대 왼쪽 무릎 뒤를 눌러 상대가 주저앉게 만든다
- 등으로 똑바로 눕지 말고 내 왼쪽 엉덩이로 비스듬히 앉는다
- 엉덩이가 닿는 순간 위쪽 오른발부터 훅을 넣는다

## 흔한 실수

- 똑바로 뒤로 누우면 상대 체중에 깔리고 상대가 돌아선다 → 왼쪽 엉덩이로 옆으로 앉는다
- 시트벨트 없이 앉으면 상대가 앞으로 빠져나간다 → 그립을 먼저 잡는다
- 훅을 늦게 넣으면 상대가 돌아앉는다 → 앉는 순간 넣는다

## 막히면

- 상대가 다리를 버텨 안 앉으면 → [맷 리턴 (뒤에서 끌어내리기)](../techniques/mat-return.md)
- 앉았는데 훅이 안 들어가면 → [시트벨트 컨트롤 (훅 없이)](../techniques/seat-belt-control.md)
- 상대가 내 오른팔을 잡고 돌아앉으려 하면 → [시트벨트 → 풀 백 컨트롤](../techniques/seat-belt-to-full-back.md)

## 방어하는 쪽 (상대 입장)

- 상대 왼발이 내 왼쪽 무릎 뒤를 누르면 → 앉히려는 신호
- 내 오른쪽 어깨 위로 온 상대 오른팔(조르는 팔)을 두 손으로 잡아 목부터 지킨다
- 같이 앉을 때 엉덩이를 상대 다리 사이에서 빼 훅이 들어올 자리를 없앤다
- 훅이 들어왔으면 → 핸드 파이팅 (백 아래) → 백 이스케이프
