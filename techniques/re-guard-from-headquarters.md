# 헤드쿼터 상대 가드 회복 (Re-Guard from Headquarters)

[패스](../positions/passing.md) · 방어 · 아래 → [오픈 가드](../positions/open-guard.md)

다른 이름: HQ 리가드

## 세팅 과정 (오른손잡이 기준)

1. 상대가 내 오른다리를 허벅지 사이에 끼운 헤드쿼터일 때
2. 끼인 내 오른쪽 무릎을 세워 정강이로 상대 골반을 민다
3. 엉덩이를 뒤로 빼며(쉬림프) 내 오른다리를 빼낸다
4. 빼낸 내 오른발을 상대 왼쪽 골반이나 허벅지에 대어 거리를 만든다
5. 내 왼발도 상대 오른쪽 골반에 대어 오픈 가드로 돌아간다

## 핵심 디테일

- 끼인 오른쪽 무릎을 세워 정강이를 상대 골반 앞에 대고 민다 — 다리를 당기기만 하면 안 빠진다
- 정강이로 미는 것과 엉덩이를 뒤로 빼는 쉬림프를 동시에 한다
- 빼낸 오른발을 바로 상대 왼쪽 골반이나 허벅지에 대 거리를 지킨다
- 내 왼발도 상대 오른쪽 골반에 대 두 발로 거리를 잡는다

## 흔한 실수

- 등을 바닥에 납작하게 두고 다리만 당기면 안 빠진다 → 옆으로 돌아누워 쉬림프한다
- 다리를 빼고 발을 늦게 대면 상대가 바로 패스한다 → 빠지는 순간 발을 골반에 댄다
- 손이 놀고 있으면 상대가 다시 붙어 온다 → 깃·소매를 잡아 손으로도 거리를 둔다

## 막히면

- 상대 체중이 앞다리에 실려 다리가 안 빠지면 → [헤드쿼터 상대 신 투 신](../techniques/shin-to-shin-from-headquarters.md)
- 상대가 계속 눌러 오면 → [헤드쿼터 상대 인버트 → 데라히바](../techniques/inversion-from-headquarters.md)
- 상대가 일어서서 버티면 → [헤드쿼터 상대 스윕](../techniques/sweep-from-headquarters.md)

## 방어하는 쪽 (상대 입장)

- 상대가 끼인 오른쪽 무릎을 세워 정강이로 내 골반을 밀고 엉덩이를 빼면 가드 회복 신호
- 허벅지를 더 조이고 체중을 끼운 다리에 실어 무릎이 세워지지 않게 한다
- 다리가 빠지기 시작하면 바로 니컷 (헤드쿼터)이나 레그 드래그 (헤드쿼터)로 넘어간다
- 발이 이미 내 골반에 닿았으면 발을 쳐내고 다시 헤드쿼터를 잡는다
