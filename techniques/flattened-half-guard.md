# 눌린 하프가드에서 회복 (Flattened Half Guard Recovery)

[하프가드](../positions/half-guard.md) · 탈출 · 아래 → [하프가드](../positions/half-guard.md)

다른 이름: 플랫 하프, 눌렸을 때

## 세팅 과정 (오른손잡이 기준)

1. 상대 오른다리를 감은 채 상대가 오른팔 크로스페이스로 누르면 내 오른쪽 팔뚝을 상대 목 밑에 세워 받친다
2. 브릿지로 상대를 띄운다
3. 그 순간 엉덩이를 내 오른쪽으로 빼며 내 오른쪽 어깨와 엉덩이를 바닥에 대 공간을 만든다
4. 내 왼팔을 상대 오른쪽 겨드랑이 밑으로 밀어 넣어 언더훅을 되찾는다

## 핵심 디테일

- 언더훅을 넣기 전에 먼저 내 오른쪽 팔뚝 프레임과 엉덩이 빼기로 공간부터 만든다
- 브릿지로 띄운 그 순간에 엉덩이를 내 오른쪽으로 뺀다
- 내 왼팔 언더훅은 손이 상대 등·날개뼈까지 가도록 깊게 넣는다
- 그동안 두 다리로 감은 상대 오른다리를 끝까지 놓지 않는다

## 흔한 실수

- 공간 없이 왼팔부터 밀어 넣으면 상대가 어깨로 눌러 막는다 → 프레임과 엉덩이 빼기 먼저
- 등을 바닥에 댄 채로 있으면 계속 눌린다 → 오른쪽 어깨·엉덩이로 돌아눕는다
- 언더훅을 얕게 넣으면 상대가 위저로 바로 눌러 끈다 → 등까지 깊게 넣는다

## 막히면

- 상대가 겨드랑이를 닫아 언더훅이 안 들어가면 → [눌린 하프 → 딥 하프](../techniques/deep-half-entry-from-flattened.md)
- 상대가 감긴 다리를 빼려 하면 → [쿼터 가드 → 니 쉴드](../techniques/knee-shield-from-quarter.md)
- 상대가 오른손을 바닥에 짚어 버티면 → [기무라 (하프가드)](../techniques/kimura-half-guard.md)

## 방어하는 쪽 (상대 입장)

- 상대 오른쪽 팔뚝이 내 목 밑을 받치고 브릿지를 준비하면 신호
- 내 오른팔 크로스페이스를 더 깊게 넣고 오른쪽 겨드랑이를 닫는다
- 엉덩이를 낮게 두고 상대가 빠지는 쪽으로 가슴을 따라 붙인다
- 언더훅을 이미 잡혔으면 → 하프 탑 위저 카운터
