# 트라이포드 스윕 (Tripod Sweep)

[오픈 가드](../positions/open-guard.md) · 스윕 · 아래 → [패스](../positions/passing.md)

다른 이름: 삼각대 스윕, 트리포드 스윕, 트라이포드 스윕 (발 골반에서), 발 골반 트라이포드

## 세팅 과정 (오른손잡이 기준)

1. 앉은 가드에서 내 오른손으로 상대 왼쪽 발목(뒤꿈치)을 잡고 왼손으로 상대 오른쪽 소매를 잡는다
2. 내 오른발을 상대 왼쪽 골반에 대고 민다
3. 내 왼발로 상대 오른다리 오금을 걸어 당긴다
4. 골반을 밀고 발목과 오금을 당겨 뒤로 눕힌 뒤, 왼쪽 발목을 놓지 않고 바로 일어나 패스 자세로 간다

## 핵심 디테일

- 상대 왼쪽 발목(뒤꿈치)을 단단히 잡아야 상대가 그 발을 뒤로 빼 버티지 못한다
- 오른발로 상대 왼쪽 골반을 미는 힘과 왼발로 상대 오른쪽 오금을 당기는 힘을 동시에 쓴다
- 소매를 당겨 상대 무게를 앞으로 끌어낸 순간에 쓴다
- 상대가 넘어지는 동안 발목을 놓지 말고 바로 일어나 위를 잡는다

## 흔한 실수

- 상대 무게가 뒤에 있을 때 밀면 한 걸음 물러나 버틴다 → 소매를 당겨 무게를 앞으로 끌어낸 뒤 민다
- 밀기와 당기기를 따로 하면 힘이 나뉜다 → 한 동작으로 동시에 한다
- 넘긴 뒤 누워 있으면 상대가 일어나거나 가드를 만든다 → 발목을 쥔 채 바로 일어난다

## 막히면

- 상대가 오른다리를 빼고 버티면 → [시클 스윕](../techniques/sickle-sweep.md)
- 상대가 뒤로 물러나 거리를 두면 → [테크니컬 스탠드업](../techniques/technical-stand-up.md)이나 [발 잡아 넘기기 (시팅 가드)](../techniques/foot-grab-sweep.md)

## 방어하는 쪽 (상대 입장)

- 상대가 내 왼쪽 발목을 잡고 오른발로 내 왼쪽 골반을, 왼발로 내 오른쪽 오금을 걸면 신호다
- 상대 오른손 그립부터 끊고 잡힌 왼다리를 빼 거리를 둔다
- 소매에 끌려 무게가 앞으로 쏠리지 않게 엉덩이를 낮추고 두 발을 넓게 둔다
- 넘어지면 손을 뒤로 짚지 말고 바로 앉아 다리로 상대를 막는다
