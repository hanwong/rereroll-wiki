# 페이퍼 커터 초크 (Paper Cutter Choke)

[곁누르기](../positions/kesa-gatame.md) · 서브미션 · 위

다른 이름: 종이칼 초크, 페이퍼커터, 페이퍼 커터

## 세팅 과정 (오른손잡이 기준)

1. 언더훅으로 넣은 내 오른손으로 상대 목 뒤쪽 깃을 네 손가락을 넣어 깊게 잡는다
2. 내 왼손으로 상대 오른쪽 깃을 잡고 왼 팔뚝을 상대 목 앞에 가로로 댄다
3. 오른손으로 뒤 깃을 당겨 상대 머리를 들며 내 왼 팔꿈치를 바닥으로 떨어뜨린다
4. 가슴을 낮춰 체중을 실어 조인다

## 핵심 디테일

- 뒤 깃은 네 손가락을 목 뒤 깊숙이 넣어 잡는다
- 왼 팔뚝 손목뼈 쪽을 상대 목 앞에 가로로 댄다
- 오른손으로 머리를 들고 왼 팔꿈치를 바닥으로 떨어뜨리는 두 힘을 같이 쓴다
- 팔 힘보다 가슴을 낮춰 체중으로 조인다

## 흔한 실수

- 뒤 깃을 어깨 위에서 얕게 잡으면 조임이 없다 → 목 뒤 깊숙이 잡는다
- 팔뚝을 목과 나란히 대면 안 조인다 → 목을 가로지르게 댄다
- 그립을 바꾸며 엉덩이 압박을 빼면 상대가 새우빼기로 빠진다 → 엉덩이를 붙여 둔다

## 막히면

- 상대가 내 쪽으로 돌아 가슴을 밀면 → [곁누르기 → 마운트](../techniques/kesa-to-mount.md)
- 상대가 오른팔로 내 왼팔을 밀어 막으면 → [아메리카나 (변형 곁누르기)](../techniques/americana-from-kuzure-kesa.md)
- 상대가 엎드려 돌면 → [터틀에서 백 테이크](../techniques/turtle-back-take.md)

## 방어하는 쪽 (상대 입장)

- 상대 오른손이 내 목 뒤 깃을 깊게 잡으면 → 초크 신호
- 턱을 당기고 손으로 그 깃 그립을 떼어 낸다
- 상대 왼 팔뚝이 목 앞으로 오면 → 내 오른손으로 상대 왼 팔꿈치를 밀어 올려 떨어지지 못하게 한다
- 이미 조여 오면 → 일찍 탭한다
