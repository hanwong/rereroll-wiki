# 가드 풀링 당했을 때 패스 시작 (Guard Pass from Standing Guard)

[클린치 · 가드 풀링](../positions/clinch.md) · 패스 · 위 → [패스](../positions/passing.md)

다른 이름: 가드 풀링 대처

## 세팅 과정 (오른손잡이 기준)

1. 상대가 앉으면 바로 허리를 세우고 내 깃 · 소매를 잡은 상대 그립을 뗀다
2. 양손으로 상대 양 무릎이나 바지를 잡아 다리를 컨트롤한다
3. 내 두 발을 상대 다리 사이에서 빼 상대 다리 바깥으로 옮긴다
4. 토레안도나 니슬라이스로 패스 시작

## 핵심 디테일

- 상대가 앉는 순간 허리를 세워 상체가 끌려 내려가지 않게 한다
- 내 왼쪽 깃을 잡은 상대 오른손 그립부터 끊는다
- 무릎 · 바지를 잡을 땐 팔을 펴서 상대 발이 내 몸에 닿지 않게 거리를 둔다
- 두 발은 상대 다리 사이에서 빼 상대 다리 바깥에 둔다

## 흔한 실수

- 그립을 그대로 두고 패스하면 끌려가 스윕 당한다 → 깃 그립부터 뗀다
- 발이 상대 다리 사이에 남으면 훅이 걸린다 → 발을 다리 바깥으로 뺀다
- 같이 무릎을 꿇고 앉으면 상대가 클로즈드 가드로 감는다 → 서서 거리를 두고 시작한다

## 막히면

- 상대가 다리를 감아 클로즈드 가드를 잡으면 → [스탠딩 가드 브레이크](../techniques/standing-guard-break.md)
- 상대 발이 내 골반을 밀어 거리를 두면 → [발 골반 가드 패스](../techniques/pass-feet-on-hips-guard.md)
- 상대 다리가 벌어져 있으면 → [토레안도 패스](../techniques/toreando-pass.md)

## 방어하는 쪽 (상대 입장)

- 상대가 허리를 세우고 내 깃 그립을 끊으려 하면 → 패스 시작 신호
- 그립이 끊기기 전에 내 오른발을 상대 왼쪽 골반에 대 거리를 만든다
- 상대가 내 양 무릎을 잡으면 발을 골반 · 팔로 옮겨 다리를 다시 세운다
- 다리가 옆으로 밀렸으면 → 쉬림프 (힙 이스케이프)로 무릎을 다시 넣는다
