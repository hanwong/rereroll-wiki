# 니 슬라이드 (컴뱃 베이스) (Knee Slide from Combat Base)

[패스](../positions/passing.md) · 패스 · 위 → [사이드 컨트롤](../positions/side-control.md)

다른 이름: 컴뱃 베이스 니슬라이스

## 세팅 과정 (오른손잡이 기준)

1. 세운 내 오른쪽 무릎을 상대 오른쪽 허벅지 안쪽 위로 올려 정강이를 걸친다
2. 내 오른손으로 상대 왼쪽 깃을 잡거나 오른팔로 상대 왼팔 언더훅을 잡아 상체를 누른다
3. 내 오른쪽 정강이를 상대 오른쪽 허벅지 너머 바닥까지 미끄러뜨려 다리를 빼낸다
4. 골반을 돌려 가슴을 붙이고 상대 오른쪽에서 사이드 컨트롤을 잡는다

## 핵심 디테일

- 세운 오른쪽 무릎을 상대 오른쪽 허벅지 안쪽 위로 넘겨 정강이를 낮게 걸친다
- 오른손 깃이나 오른팔 언더훅으로 상대 왼쪽 어깨를 바닥에 붙여 상대가 일어나지 못하게 한다
- 내 왼발은 뒤에 넓게 짚어 미는 힘과 받침을 만든다
- 정강이가 바닥에 닿아 오른발까지 빠진 뒤에 골반을 돌려 가슴을 붙인다

## 흔한 실수

- 정강이를 높이 들어 넘기면 상대가 무릎을 다시 넣는다 → 허벅지 위를 미끄러지듯 낮게 민다
- 상체를 안 누르고 무릎만 넘기면 상대가 언더훅을 잡고 일어난다 → 왼쪽 어깨를 먼저 바닥에 붙인다
- 발이 빠지기 전에 골반을 돌리면 하프가드에 걸린다 → 발끝까지 뺀 뒤 돈다

## 막히면

- 상대가 니 쉴드로 막으면 → [롱 스텝 패스](../techniques/long-step-pass.md)
- 상대가 내 오른발을 감아 하프가드를 잡으면 → [하프가드 패스 (크로스페이스 · 언더훅)](../techniques/half-guard-pass.md)
- 상대가 발로 내 무릎을 밀어 거리를 두면 → [컴뱃 베이스 → 헤드쿼터](../techniques/combat-base-to-headquarters.md)

## 방어하는 쪽 (상대 입장)

- 상대가 세운 오른쪽 무릎을 내 오른쪽 허벅지 위로 넘기고 상대 오른팔이 내 왼팔 밑을 파고들면 니 슬라이드 신호
- 무릎이 넘어오기 전에 내 왼발로 상대 오른쪽 무릎을 밀어 거리를 만든다
- 넘어오면 내 오른팔로 상대 왼쪽 겨드랑이 밑 언더훅을 잡고 옆으로 돌아누워 버틴다
- 거의 빠졌으면 상대 오른발을 내 두 다리로 감아 하프가드로 붙잡는다
