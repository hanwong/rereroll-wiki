# 허리후리기 (Harai Goshi)

[스탠딩 · 테이크다운](../positions/standing.md) · 테이크다운 · 서서 → [사이드 컨트롤](../positions/side-control.md)

다른 이름: 하라이고시

## 세팅 과정 (오른손잡이 기준)

1. 내 오른손은 상대 왼쪽 깃, 왼손은 상대 오른쪽 소매를 잡고 앞으로 당긴다
2. 내 왼쪽으로 몸을 돌려 들어가며 내 오른쪽 엉덩이를 상대 앞에 붙인다
3. 내 오른다리로 상대 오른쪽 허벅지 바깥쪽을 쓸어 올린다
4. 상체를 숙이고 왼손으로 소매를 당기며 넘긴다

## 핵심 디테일

- 왼손 소매를 내 왼쪽 앞으로 당겨 상대를 상대 오른 발끝 쪽으로 기울인다
- 내 오른쪽 엉덩이가 상대 배 앞에 붙어 있어야 다리가 힘을 쓴다
- 오른다리는 쭉 펴서 상대 오른 허벅지 바깥을 뒤로 쓸어 올린다
- 디딤발인 왼발 무릎을 굽혔다 펴며 상체를 숙여 돌린다

## 흔한 실수

- 엉덩이가 덜 들어가면 다리만 휘두르다 실패한다 → 엉덩이를 상대 앞에 깊게 붙인다
- 상체를 세우면 상대가 뒤로 버틴다 → 숙이며 돌린다
- 오른손 깃 그립이 느슨하면 상대가 떨어져 나간다 → 깃을 끌어 가슴을 붙인다

## 막히면

- 상대가 허리를 뒤로 빼면 → [안다리후리기](../techniques/o-uchi-gari.md)
- 상대가 다리를 피해 앞으로 빠지면 → [몸떨어뜨리기](../techniques/tai-otoshi.md)
- 상대가 뒤로 버텨 체중이 오른발 뒤꿈치로 가면 → [밭다리후리기](../techniques/o-soto-gari.md)

## 방어하는 쪽 (상대 입장)

- 상대가 내 오른쪽 소매를 당기며 돌아 들어와 상대 오른쪽 엉덩이가 내 배 앞에 붙으면 허리후리기 신호
- 엉덩이를 뒤로 빼고 무릎을 굽혀 낮게 버틴다
- 내 왼손으로 상대 허리를 밀어 공간을 만들고 상대 오른다리가 내 오른 허벅지에 닿기 전에 몸을 뺀다
- 이미 쓸려 넘어가면 낙법하고 바로 상대 쪽으로 몸을 돌려 가드를 만든다
