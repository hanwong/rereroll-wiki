# 토레안도 패스 (Toreando Pass)

[패스](../positions/passing.md) · 패스 · 위 → [사이드 컨트롤](../positions/side-control.md)

다른 이름: 불 패스, 토레아도, 투우사 패스, 불파이터 패스, 토리안도, toreando, bullfighter pass, 불파이터 패스 (시팅 가드 상대), 앉은 가드 토레안도, 불파이터

## 세팅 과정 (오른손잡이 기준)

1. 내 왼손은 상대 오른쪽 무릎 뒤(바지 끝), 오른손은 상대 왼쪽 무릎 뒤(바지 끝)를 잡는다
2. 상대 두 무릎을 내 오른쪽 바닥으로 눌러 '죽이고' 그쪽으로 다리를 밀어 넘긴다
3. 발을 내 왼쪽으로 옮겨 상대 오른쪽 옆으로 돌아 들어간다
4. 어깨를 상대 가슴에 떨어뜨리고 머리를 컨트롤해 사이드 컨트롤로

## 핵심 디테일

- 두 손은 무릎 뒤 바지를 꽉 잡고 팔꿈치를 몸 쪽에 붙여 상대 발이 내 골반·이두에 닿지 못하게 한다
- 다리를 내 오른쪽으로 미는 것과 내 발을 내 왼쪽으로 옮기는 것을 한 동작으로 한다
- 앞으로 걸어 들어가지 말고 옆으로 크게 돌아 각도를 만든다
- 엉덩이가 상대 골반을 지나 가슴이 붙을 때까지 무릎 그립을 놓지 않는다

## 흔한 실수

- 앞으로 곧장 들어가면 상대 다리가 다시 앞으로 온다 → 옆으로 크게 돈다
- 엉덩이가 지나기 전에 손을 놓으면 상대가 다리를 다시 넣는다 → 가슴이 붙을 때까지 쥐고 있는다
- 허리를 굽히고 서면 상대가 깃을 당겨 무너뜨린다 → 허리를 펴고 무릎을 굽혀 낮게 선다

## 막히면

- 상대가 따라 돌며 다리를 다시 넣으면 → [레그 드래그](../techniques/leg-drag.md)
- 상대가 발로 내 골반·이두를 밀어 거리를 두면 → 발을 쳐내고 다시 그립을 잡는다 ([발 골반 가드 패스](../techniques/pass-feet-on-hips-guard.md))
- 상대가 무릎을 세워 버티면 → [니슬라이스 패스](../techniques/knee-slice-pass.md)

## 방어하는 쪽 (상대 입장)

- 상대가 양손으로 내 두 무릎 바지를 잡고 다리를 모아 내 왼쪽으로 누르면 토레안도 신호
- 그립이 잡히자마자 손을 끊고 발을 상대 골반·이두에 다시 댄다
- 상대가 내 오른쪽으로 돌면 엉덩이를 같이 돌려 무릎과 발이 계속 상대를 향하게 한다
- 다리가 이미 넘어갔으면 내 오른 팔꿈치로 상대 골반을 막고 오른 무릎을 다시 넣는다
