# 니 쉴드 → 클로즈드 가드 (Knee Shield to Closed Guard)

[하프가드](../positions/half-guard.md) · 전환 · 아래 → [클로즈드 가드](../positions/closed-guard.md)

다른 이름: 니 쉴드 리가드

## 세팅 과정 (오른손잡이 기준)

1. 니 쉴드(내 왼쪽 무릎)로 상대를 밀어 거리를 만들고 엉덩이를 내 오른쪽으로 뺀다
2. 감았던 내 오른다리를 빼내 상대 왼쪽 허리 위로 넘긴다
3. 니 쉴드였던 왼다리도 상대 오른쪽 허리 뒤로 넘겨 두 발을 잠근다
4. 클로즈드 가드에서 상대 자세를 무너뜨린다

## 핵심 디테일

- 다리를 빼는 순간까지 니 쉴드로 거리를 지킨다 — 먼저 풀면 눌린다
- 엉덩이를 내 오른쪽 비스듬히 빼 감았던 오른다리가 빠질 길을 만든다
- 깃·소매 그립 하나는 끝까지 잡아 상대가 자세를 못 바꾸게 한다
- 다리가 빠지면 바로 두 발을 잠근다 — 틈이 있으면 상대가 패스한다

## 흔한 실수

- 거리가 없는데 다리를 빼면 → 상대가 따라와 눌린다 → 니 쉴드로 먼저 민다
- 뒤로 똑바로 쉬림프하면 → 다리가 안 빠진다 → 비스듬히 뺀다
- 다리를 빼고 발 잠금이 늦으면 → 상대가 일어나 패스한다 → 빼기와 잠그기를 한 동작으로

- 상대가 일어서면 → [하프가드 → X 가드](../techniques/half-guard-to-x-guard.md)
- 상대가 무릎을 치우면 → [Z 가드 → 하프가드 (언더훅)](../techniques/z-guard-to-half-guard.md)

## 방어하는 쪽 (상대 입장)

- 상대가 니 쉴드로 밀며 엉덩이를 빼고 감은 다리를 빼기 시작하면 클로즈드 가드로 가려는 신호
- 그때 앞으로 체중을 실어 거리를 없애고 크로스페이스로 붙는다
- 다리가 반쯤 빠졌으면 각도를 틀어 상대 두 발이 잠기지 못하게 한다
- 이미 잠겼으면 클로즈드 가드 안에서 자세를 세우고 연다
