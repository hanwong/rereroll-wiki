# 컴뱃 베이스 (Combat Base)

[패스](../positions/passing.md) · 자세 · 컨트롤 · 위 → [패스](../positions/passing.md)

다른 이름: 콤뱃 베이스, 한 무릎 세우기, 콤뱃베이스, combat base

## 세팅 과정 (오른손잡이 기준)

1. 상대 오픈 가드 앞에서 내 왼쪽 무릎은 바닥, 오른쪽 무릎은 세운다
2. 세운 내 오른쪽 무릎을 상대 두 다리 사이에 둔다
3. 허리를 펴고 내 왼손은 상대 오른쪽 무릎, 오른손은 상대 왼쪽 깃을 잡아 거리를 잡는다
4. 상대 반응을 보고 니슬라이스나 헤드쿼터로 잇는다

## 핵심 디테일

- 허리를 펴고 머리를 세워 상대가 깃을 당겨도 무너지지 않게 한다
- 세운 오른쪽 무릎이 상대 두 다리 사이에서 쐐기가 되어 상대가 붙지 못하게 한다
- 내 왼손으로 상대 오른쪽 무릎을 눌러 두고 오른손 깃 그립으로 거리를 잡는다
- 오래 머물지 말고 상대 반응을 보고 바로 다음 패스로 잇는다

## 흔한 실수

- 허리를 굽히면 상대가 당겨 클로즈드 가드를 잡거나 스윕한다 → 허리를 펴고 머리를 든다
- 세운 오른발을 그대로 두면 상대가 발목을 잡고 무릎을 밀어 뒤로 넘긴다 → 머물지 말고 바로 움직인다
- 손이 비어 있으면 상대가 발을 골반·이두에 대 거리를 만든다 → 무릎과 깃 그립을 계속 쥐고 있는다

## 막히면

- 상대가 발로 내 무릎을 밀어 거리를 만들면 → [컴뱃 베이스 → 헤드쿼터](../techniques/combat-base-to-headquarters.md)
- 상대가 다리를 넓게 열고 있으면 → [니 슬라이드 (컴뱃 베이스)](../techniques/knee-slide-from-combat-base.md)
- 상대가 다리를 붙여 버티면 → [프레셔 패스](../techniques/pressure-pass.md)

## 방어하는 쪽 (상대 입장)

- 상대가 오른쪽 무릎을 세워 내 다리 사이에 두고 왼손으로 내 오른쪽 무릎을 누르면 컴뱃 베이스
- 바로 내 왼발로 상대 오른쪽 무릎을 밀어 거리를 두고 오른발은 상대 왼쪽 골반이나 이두에 댄다 (컴뱃 베이스 상대 가드 회복)
- 세운 상대 오른쪽 발목이 가까우면 내 왼손으로 잡고 무릎을 밀어 뒤로 앉힌다 (컴뱃 베이스 상대 스윕)
