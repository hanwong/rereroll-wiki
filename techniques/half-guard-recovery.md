# 하프가드에서 가드 회복 (Half Guard to Full Guard Recovery)

[하프가드](../positions/half-guard.md) · 전환 · 아래 → [클로즈드 가드](../positions/closed-guard.md) / [버터플라이 가드](../positions/butterfly-guard.md)

다른 이름: 가드 리커버리, 풀 가드 복귀

## 세팅 과정 (오른손잡이 기준)

1. 내 오른쪽 팔뚝은 상대 목, 왼쪽 팔뚝은 상대 오른쪽 골반에 대어 프레임을 만든다
2. 브릿지 → 엉덩이를 내 오른쪽으로 빼기(쉬림프)를 한 번이 아니라 두 번 한다
3. 위쪽인 내 왼쪽 무릎을 상대 배 앞으로 가져온다
4. 감던 오른다리를 빼 상대 왼쪽 허리 위로 넘기고 왼다리도 상대 오른쪽 허리를 감아 클로즈드 가드나 버터플라이

## 핵심 디테일

- 움직이기 전에 프레임 먼저: 오른쪽 팔뚝 상대 목, 왼쪽 팔뚝 상대 오른쪽 골반
- 브릿지로 띄우고 엉덩이를 내 오른쪽으로 — 한 번으로 모자라면 두 번
- 위쪽인 내 왼쪽 무릎을 상대 배 앞으로 넣어 다시 눌리지 않게 막는다
- 상대가 자세를 바꾸거나 움직일 때 시도한다 — 무겁게 누를 때 억지로 하지 않는다

## 흔한 실수

- 프레임 없이 쉬림프만 하면 → 상대가 따라와 다시 눌린다 → 팔뚝 프레임 먼저
- 상대에게서 등을 돌려 빠지면 → 백을 내준다 → 상대 쪽을 보고 움직인다
- 쉬림프 한 번으로 무릎이 안 들어갔는데 멈추면 → 다시 납작해진다 → 한 번 더

## 막히면

- 상대가 크로스페이스로 눌러 오면 → [눌린 하프가드에서 회복](../techniques/flattened-half-guard.md)
- 무릎만 들어가면 → [니 쉴드 하프가드](../techniques/knee-shield-half-guard.md)
- 상대가 일어서면 → [하프가드 → X 가드](../techniques/half-guard-to-x-guard.md)

## 방어하는 쪽 (상대 입장)

- 상대가 팔뚝으로 내 목·오른쪽 골반을 받치고 브릿지·쉬림프를 하면 가드를 되찾으려는 신호
- 상대 프레임 팔을 걷어내고 크로스페이스·언더훅으로 다시 납작하게 누른다
- 상대가 엉덩이를 빼면 따라가 가슴을 붙여 공간을 지운다
- 무릎이 이미 들어왔으면 → 스매시 패스로 무릎을 접는다
