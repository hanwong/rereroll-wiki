# 바디락 패스 (Body Lock Pass)

[하프가드](../positions/half-guard.md) · 패스 · 위 → [사이드 컨트롤](../positions/side-control.md)

다른 이름: 보디락 패스

## 세팅 과정 (오른손잡이 기준)

1. 내 오른다리가 감긴 하프 탑에서 양팔로 상대 허리를 감아 오른손으로 내 왼쪽 손목을 잡는다
2. 가슴을 붙이고 엉덩이를 낮춘다
3. 상대 두 무릎을 상대 왼쪽으로 몰아 깔아뭉갠다
4. 오른다리를 빼며 상대 오른쪽 사이드

## 핵심 디테일

- 팔은 가슴이 아니라 허리·골반 높이에서 감아 오른손으로 내 왼쪽 손목을 잡는다
- 가슴을 붙이고 엉덩이를 낮춰 상대가 돌아누울 틈을 없앤다
- 상대 두 무릎을 상대 왼쪽으로 몰아 바닥에 눌러 둔다
- 무릎이 눌린 뒤에 감긴 오른다리를 뺀다

## 흔한 실수

- 팔을 높게 감으면 상대가 엉덩이를 빼 돌아눕는다 → 허리 높이에서 감는다
- 가슴이 떨어지면 상대가 니 쉴드를 다시 넣는다 → 가슴을 붙인다
- 무릎을 누르기 전에 다리부터 빼면 다시 감긴다 → 무릎 먼저 눕힌다

## 막히면

- 상대가 언더훅을 잡고 올라오면 → [하프 탑 위저 카운터](../techniques/half-guard-whizzer-counter.md)
- 상대가 니 쉴드를 세우면 → [레그 위브 패스](../techniques/leg-weave-pass.md)
- 다리가 꽉 감겨 안 빠지면 → [하프가드 → 쿼터 가드 (탑)](../techniques/half-guard-to-quarter-guard.md)

## 방어하는 쪽 (상대 입장)

- 상대 두 팔이 내 허리를 감아 손을 맞잡고 가슴을 붙여 오면 신호
- 감기기 전에 왼쪽 무릎 니 쉴드와 팔뚝 프레임으로 거리를 만든다
- 왼팔 언더훅을 먼저 잡아 상대 가슴이 붙지 못하게 한다
- 무릎이 눌렸으면 다리 감기를 꽉 유지하고 → 하프가드에서 가드 회복
