# 스파이더 → 라쏘 (Spider to Lasso Guard)

[스파이더 · 라쏘 · 소매 가드](../positions/spider-lasso.md) · 전환 · 아래 → [스파이더 · 라쏘 · 소매 가드](../positions/spider-lasso.md)

다른 이름: 스파이더 라쏘 전환, 더블 슬리브 → 라쏘, 라쏘 진입

## 세팅 과정 (오른손잡이 기준)

1. 내 왼발을 상대 오른쪽 이두에서 떼어 상대 오른팔 바깥에서 안으로 감는다
2. 왼발을 상대 오른쪽 겨드랑이까지 깊게 넣는다
3. 내 오른발은 상대 왼쪽 이두에 남긴다
4. 라쏘 가드

## 핵심 디테일

- 내 왼손 소매 그립을 놓지 않고 당겨 상대 오른팔이 빠지지 않게 한다
- 왼다리는 상대 팔꿈치에 걸리지 않게 바깥에서 둥글게 돌려 넣는다
- 정강이가 상대 삼두를 가로질러 겨드랑이까지 깊게 들어가야 힘이 걸린다
- 감는 동안 내 오른발은 상대 왼쪽 이두를 계속 밀어 거리를 지킨다

## 흔한 실수

- 다리를 반쯤 넣고 멈추면 상대가 팔을 빼거나 그립을 끊는다 → 한 번에 깊게 넣는다
- 소매를 놓고 감으면 상대가 팔을 당겨 뺀다 → 소매를 계속 당긴다
- 라쏘가 팔꿈치 아래로 얕게 걸리면 힘이 안 걸린다 → 겨드랑이까지 넣는다

## 막히면

- 라쏘가 걸리면 → [라쏘 스윕](../techniques/lasso-sweep.md) · [오모플라타 (라쏘)](../techniques/omoplata-from-lasso.md)
- 상대가 오른팔을 몸에 붙여 감기를 막으면 → 스파이더로 돌아가 [스파이더 스윕](../techniques/spider-sweep.md) · [스파이더 가드](../techniques/spider-guard.md)
- 상대가 소매 그립을 끊으면 → [스파이더에서 가드 회복](../techniques/guard-recovery-from-spider.md)

## 방어하는 쪽 (상대 입장)

- 상대 왼발이 내 오른쪽 이두에서 떨어져 내 오른팔 바깥으로 돌아오면 라쏘 신호
- 내 오른쪽 팔꿈치를 옆구리에 붙이고 손목을 돌려 소매 그립을 먼저 끊는다
- 이미 감겼으면 오른팔을 펴지 말고 몸에 붙인 채 → 백스텝 패스 (라쏘 상대) · 스택 패스 (라쏘 상대)
