# 더블 언더 상대 버터플라이 훅 회복 (Butterfly Hook Recovery)

[패스](../positions/passing.md) · 방어 · 아래 → [버터플라이 가드](../positions/butterfly-guard.md)

다른 이름: 훅 되찾기

## 세팅 과정 (오른손잡이 기준)

1. 내 오른쪽 팔뚝으로 상대 왼쪽 어깨나 목에 프레임을 만든다
2. 엉덩이를 뒤로 빼며 내 오른쪽 무릎을 가슴 쪽으로 당긴다
3. 내 오른발등을 상대 왼쪽 허벅지 안쪽에 걸어 훅을 넣는다
4. 같은 방법으로 내 왼발도 상대 오른쪽 허벅지 안쪽에 훅으로 넣는다
5. 상체를 세워 버터플라이 가드를 잡는다

## 핵심 디테일

- 오른쪽 팔뚝 프레임을 상대 왼쪽 어깨·목에 대 상대 체중이 내 쪽으로 오지 못하게 한다
- 엉덩이를 뒤로 빼야 무릎이 가슴 쪽으로 들어갈 자리가 생긴다
- 오른발등을 상대 왼쪽 허벅지 안쪽에 걸고, 이어서 왼발등도 상대 오른쪽 허벅지 안쪽에 건다
- 두 훅이 들어가면 상체를 세워 앉는다 — 누워 있으면 다시 눌린다

## 흔한 실수

- 팔을 쭉 펴서 밀면 힘이 빠지고 팔을 잡힌다 → 팔꿈치를 굽힌 팔뚝으로 받친다
- 엉덩이를 안 빼고 무릎만 당기면 들어갈 자리가 없다 → 쉬림프로 공간부터 만든다
- 훅을 넣고 누워 있으면 상대가 다시 눌러 패스한다 → 바로 상체를 세운다

## 막히면

- 한쪽 훅만 들어가면 → [버터플라이 하프가드](../techniques/butterfly-half-guard.md)
- 상대가 앞으로 깊게 눌러 오면 → [더블 언더 상대 스윕](../techniques/sweep-from-double-unders.md)
- 훅이 들어가고 상대가 앞으로 기울면 → [버터플라이 스윕](../techniques/butterfly-sweep.md)

## 방어하는 쪽 (상대 입장)

- 상대 오른쪽 팔뚝이 내 왼쪽 어깨·목을 밀고 상대 무릎이 가슴 쪽으로 접혀 들어오면 훅 회복 신호
- 체중을 앞으로 실어 상대 엉덩이를 바닥에 붙이고 손을 맞잡아 다리 사이 공간을 없앤다
- 훅이 이미 들어왔으면 상대가 앉기 전에 머리와 가슴으로 눌러 눕히고 버터플라이 스매시 패스로 간다
