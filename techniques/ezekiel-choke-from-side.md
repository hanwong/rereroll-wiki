# 에제키엘 (사이드) (Ezekiel Choke from Side Control)

[사이드 컨트롤](../positions/side-control.md) · 서브미션 · 위

다른 이름: 사이드 에제키엘

## 세팅 과정 (오른손잡이 기준)

1. 상대 오른쪽에서 사이드: 내 왼팔을 상대 머리 아래로 넣는다
2. 내 왼손으로 내 오른팔 소매 안쪽을 잡는다
3. 내 오른손 손날을 상대 목 앞에 밀어 넣는다
4. 가슴을 낮추며 양팔을 조여 마무리한다

## 핵심 디테일

- 내 왼팔을 상대 머리 아래로 깊게 넣는다
- 내 왼손으로 내 오른팔 소매 안쪽을 잡아 고정한다
- 내 오른손 손날은 상대 목 앞에 옆에서 밀어 넣는다
- 가슴을 낮추며 양팔을 모아 천천히 조인다

## 흔한 실수

- 손날을 정면에서 넣으면 턱에 막힌다 → 목 옆에서 비스듬히 넣는다
- 소매 그립이 얕으면 풀린다 → 소매 안쪽을 깊게 잡는다
- 그립을 만드는 동안 체중을 띄우면 상대가 빠진다 → 가슴을 계속 붙인다

## 막히면

- 상대가 턱을 당겨 막으면 → [사이드 컨트롤 유지](../techniques/side-control-maintain.md)로 돌아가 다른 기회를 본다
- 상대가 양손으로 손날을 밀면 → 비어 있는 팔을 노려 [기무라 (사이드)](../techniques/kimura-side.md)
- 상대가 엉덩이를 빼면 → 엉덩이를 낮추고 [사이드에서 마운트 가기](../techniques/side-to-mount.md)

## 방어하는 쪽 (상대 입장)

- 상대 왼팔이 내 머리 아래로 들어오고 상대 오른손이 내 목 앞으로 오면 에제키엘 신호
- 턱을 당겨 손날이 목 앞에 들어오지 못하게 한다
- 양손으로 상대 오른손 손날을 밀어 목에서 떼어 낸다
- 조여 오면 버티지 말고 탭한다
