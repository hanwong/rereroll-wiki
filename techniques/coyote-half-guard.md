# 코요테 하프가드 (Coyote Half Guard)

[하프가드](../positions/half-guard.md) · 스윕 · 아래 → [사이드 컨트롤](../positions/side-control.md) / [하프가드](../positions/half-guard.md)

다른 이름: 코요테 하프, 다리 언더훅 하프

## 세팅 과정 (오른손잡이 기준)

1. 상대 오른다리를 감은 하프에서 내 오른쪽 어깨와 엉덩이를 바닥에 대고 내 오른팔을 상대 오른다리 바깥으로 넣어 허벅지를 안는다
2. 내 왼손으로 상대 왼쪽 발목이나 바지 무릎을 잡는다
3. 안은 오른다리를 들어 올리며 상대 왼쪽 발목을 당겨 중심을 뺏는다
4. 상대가 뒤로 넘어지면 올라와 사이드나 하프 탑으로 간다

## 핵심 디테일

- 오른쪽 어깨·엉덩이를 대고 옆으로 누운 자세에서 시작한다
- 내 오른팔로 상대 오른쪽 허벅지를 높게 끌어안는다
- 내 왼손으로 상대 왼쪽 발목·바지 무릎을 잡아 상대가 뒤로 못 딛게 한다
- 다리 들기와 발목 당기기를 한 번에 해 상대를 뒤로 넘긴다

## 흔한 실수

- 등을 대고 하면 다리를 들 힘이 안 나온다 → 옆으로 누운 채 한다
- 왼쪽 발목을 안 잡으면 상대가 뒤로 디뎌 버틴다 → 발목부터 잡는다
- 넘어진 뒤 안은 다리를 놓으면 상대가 다시 가드를 만든다 → 올라갈 때까지 안는다

## 막히면

- 상대가 크로스페이스로 눌러 오면 → [눌린 하프가드에서 회복](../techniques/flattened-half-guard.md)
- 상대가 체중을 앞으로 실으면 → [딥 하프가드](../techniques/deep-half-guard.md)
- 상대가 일어서면 → [하프가드 → X 가드](../techniques/half-guard-to-x-guard.md)

## 방어하는 쪽 (상대 입장)

- 상대 오른팔이 내 오른쪽 허벅지를 안고 상대 왼손이 내 왼쪽 발목을 잡으면 신호
- 왼발을 뒤로 빼 발목 그립을 떼고 체중을 상대 상체 쪽으로 낮춘다
- 크로스페이스로 상대를 바닥에 눌러 옆으로 못 눕게 한다
- 이미 넘어가면 다리로 상대 허리를 감아 가드로 받는다
