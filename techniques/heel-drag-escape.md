# 힐 드래그 이스케이프 (Heel Drag Escape)

[마운트](../positions/mount.md) · 탈출 · 아래 → [하프가드](../positions/half-guard.md)

다른 이름: 뒤꿈치 끌기 탈출, 힐 드래그, 뒤꿈치 끌기

## 세팅 과정 (오른손잡이 기준)

1. 몸을 내 오른쪽으로 돌려 오른 팔꿈치로 상대 왼 골반에 프레임을 만들고 엉덩이를 왼쪽으로 살짝 뺀다
2. 내 왼발 뒤꿈치로 상대 왼 발목을 걸어 내 양다리 사이로 끌어온다
3. 상대 왼다리 위로 내 왼 무릎을 넘겨 양다리로 감는다(하프가드)
4. 내 오른팔로 상대 왼 겨드랑이 언더훅을 잡거나 니 쉴드를 세워 하프가드를 지킨다

## 핵심 디테일

- 먼저 오른쪽으로 돌아누워 오른 팔꿈치 프레임으로 상대 왼 골반을 막는다
- 내 왼 뒤꿈치로 상대 왼 발목을 걸어 내 다리 사이로 끌어온다
- 상대 왼다리 위로 왼 무릎을 넘기자마자 두 다리로 감는다
- 하프가드가 되면 바로 언더훅이나 니 쉴드로 지킨다

## 흔한 실수

- 바로 누운 채 발목을 걸면 다리가 안 끌려온다 → 돌아누워 엉덩이를 조금 뺀다
- 발목을 끌고 멈추면 상대가 다리를 다시 빼 마운트로 돌아간다 → 바로 감는다
- 하프가드만 만들고 납작하게 누우면 크로스페이스를 당한다 → 언더훅·니 쉴드로 옆으로 선다

## 막히면

- 상대가 왼발을 높이 붙여 안 끌려오면 → [마운트 이스케이프 (엘보)](../techniques/mount-escape-elbow.md)
- 상대 무게가 앞으로 쏠리면 → [마운트 이스케이프 (업파)](../techniques/mount-escape-upa.md)

## 방어하는 쪽 (상대 입장)

- 상대가 오른 팔꿈치로 내 왼 골반을 밀고 상대 왼 뒤꿈치가 내 왼 발목을 걸면 → 힐 드래그 신호
- 왼발을 상대 엉덩이 쪽으로 붙이거나 그레이프바인으로 감아 다리를 지킨다
- 이미 하프가드가 되면 → 하프 탑 기본 자세로 크로스페이스를 잡는다
