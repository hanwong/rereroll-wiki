# 점핑 가드 (Jumping Guard)

[클린치 · 가드 풀링](../positions/clinch.md) · 가드 풀링 · 서서 → [클로즈드 가드](../positions/closed-guard.md)

다른 이름: 가드 점프

## 세팅 과정 (오른손잡이 기준)

1. 내 오른손은 상대 왼쪽 깃, 왼손은 상대 오른쪽 소매를 잡고 상대 가까이 선다(상대가 받아 줄 수 있을 때만, 화이트 벨트 시합에선 금지)
2. 내 오른발을 상대 왼쪽 골반에 먼저 대고 뛰어 올라 양 다리를 상대 허리 뒤에서 감는다
3. 오른손 깃 그립으로 상대 상체를 당겨 무너뜨린다(상대가 버티고 서 있으면 함께 넘어질 수 있어 주의)
4. 바닥에 닿으면 클로즈드 가드로

## 핵심 디테일

- 깃 그립으로 상대 상체를 끌어당겨 가슴을 붙인 채 뛴다
- 내 오른발을 상대 왼쪽 골반에 먼저 대 발판으로 쓰고 다리는 허리 위 높게 감는다
- 뛰자마자 발목을 잠가 매달린 상태를 만든다
- 상대가 받아 주기로 한 연습에서만 쓰고 화이트 벨트 시합에선 쓰지 않는다

## 흔한 실수

- 다리를 엉덩이 아래로 낮게 감으면 미끄러져 떨어진다 → 허리 위를 감는다
- 상대가 다리를 편 채 버티는데 매달리면 상대 무릎이 다치거나 같이 넘어진다 → 준비 안 된 상대에겐 뛰지 않는다
- 깃을 놓고 뛰면 등부터 떨어진다 → 깃 그립을 끝까지 유지한다

## 막히면

- 상대가 받지 않고 물러나면 → [앉아서 가드 잡기 (시팅 가드)](../techniques/sitting-guard-pull.md)
- 착지 후 상대가 일어서 버티면 → [상대가 섰을 때 클로즈드 가드 유지](../techniques/closed-guard-vs-standing.md)
- 상대가 바로 자세를 세우면 → [클로즈드 가드 (자세 · 포스처 깨기)](../techniques/closed-guard-basics.md)로 다시 당긴다

## 방어하는 쪽 (상대 입장)

- 상대가 내 왼쪽 깃 · 오른쪽 소매를 잡고 바짝 붙으면 → 뛰어오를 수 있는 신호
- 다리를 쭉 펴서 버티지 말고 무릎을 살짝 굽혀 받는다(무릎 부상 위험)
- 넘어갈 것 같으면 무릎을 꿇으며 천천히 내려앉는다
- 이미 감겼으면 → 클로즈드 가드 안 자세 되찾기
