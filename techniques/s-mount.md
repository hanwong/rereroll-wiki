# S 마운트 (S-Mount)

[마운트](../positions/mount.md) · 자세 · 컨트롤 · 위 → [마운트](../positions/mount.md)

다른 이름: 에스 마운트, 에스마운트

## 세팅 과정 (오른손잡이 기준)

1. 하이 마운트에서 내 왼 무릎을 상대 머리 오른쪽으로 올려 왼발을 바닥에 딛는다
2. 내 오른다리는 무릎을 접어 오른발을 상대 왼 겨드랑이 아래에 넣어 S 모양을 만든다
3. 엉덩이를 상대 가슴 위에 앉힌다
4. 여기서 상대 오른팔 암바나 마운티드 트라이앵글을 노린다

## 핵심 디테일

- 상대 오른팔을 먼저 고립시킨다: 팔꿈치를 머리 쪽으로 밀어 올려 겨드랑이를 연다
- 내 왼 무릎을 상대 머리 오른쪽에 바짝 붙여 오른팔이 내려오지 못하게 한다
- 접은 오른발을 상대 왼 겨드랑이 아래에 끼워 상대가 왼쪽으로 돌아눕지 못하게 막는다
- 엉덩이는 상대 가슴 위에 무겁게 앉히고 상체는 살짝 앞으로 둔다

## 흔한 실수

- 팔 고립 없이 S 모양부터 만들면 팔이 빠진다 → 팔꿈치를 먼저 밀어 올린다
- 엉덩이가 배 쪽으로 내려가면 브릿지에 흔들린다 → 가슴 위에 높게 앉는다
- 상체를 너무 세우면 뒤로 굴러간다 → 손을 상대 머리 옆 바닥에 짚어 균형을 잡는다

## 막히면

- 상대 오른팔이 펴지면 → [암바 (S 마운트)](../techniques/armbar-from-s-mount.md)
- 상대가 두 손을 맞잡아 오른팔을 지키면 → [S 마운트 → 마운티드 트라이앵글](../techniques/s-mount-to-mounted-triangle.md)
- 상대가 왼쪽으로 돌아 무릎을 넣으려 하면 → 체중을 낮춰 [마운트 유지](../techniques/mount-maintain.md)

## 방어하는 쪽 (상대 입장)

- 상대 왼 무릎이 내 머리 오른쪽으로 올라오고 상대 오른발이 내 왼 겨드랑이 밑으로 들어오면 S 마운트 신호
- 양 팔꿈치를 몸에 붙이고 오른손으로 내 왼쪽 깃을 잡아 오른팔을 지킨다
- 상대가 무릎을 올리느라 무게가 뜬 순간 브릿지해 균형을 흔든다
- 이미 잡혔으면 상대 접힌 다리 쪽(내 왼쪽)으로 돌아 무릎을 넣는다 → S 마운트 이스케이프
