# 안뒤축후리기 (Kouchi Gari)

[스탠딩 · 테이크다운](../positions/standing.md) · 테이크다운 · 서서 → [패스](../positions/passing.md)

다른 이름: 코우치가리, 안발목 후리기, 코우치, 안뒤축

## 세팅 과정 (오른손잡이 기준)

1. 상대를 상대 오른쪽 뒤로 밀어 상대 오른발 뒤꿈치에 체중을 싣게 한다
2. 내 오른발 발바닥으로 상대 오른발 뒤꿈치 안쪽을 쓸어 낸다
3. 상체는 상대 오른쪽 뒤로 밀어 균형을 깬다
4. 넘어가면 상대 다리 사이로 들어가 패스

## 핵심 디테일

- 상대를 상대 오른쪽 뒤로 밀어 체중을 상대 오른발 뒤꿈치에 먼저 싣는다
- 내 오른발 발바닥으로 상대 오른발 뒤꿈치 안쪽을 상대 발끝 방향으로 쓸어 낸다
- 발은 바닥을 스치듯 낮게, 작고 빠르게 쓴다
- 쓸면서 상체는 계속 밀어 상대가 다시 딛지 못하게 한다

## 흔한 실수

- 다리를 높이 들어 차면 걸리지 않는다 → 바닥을 스치듯 낮게 쓴다
- 체중이 실리지 않은 발을 쓸면 발만 들리고 버틴다 → 먼저 밀어 뒤꿈치에 체중을 싣는다
- 쓸고 나서 멈추면 상대가 다시 딛는다 → 상체를 끝까지 민다

## 막히면

- 상대가 오른발을 빼 체중이 왼발로 가면 → [안다리후리기](../techniques/o-uchi-gari.md)
- 상대가 앞으로 밀며 버티면 → 그 힘을 받아 [업어치기](../techniques/seoi-nage.md)
- 상대가 뒤로 물러나며 다리가 벌어지면 → [더블 레그 테이크다운](../techniques/double-leg-takedown.md)

## 방어하는 쪽 (상대 입장)

- 상대가 나를 내 오른쪽 뒤로 밀고 상대 오른발이 내 오른발 뒤꿈치 안쪽으로 낮게 들어오면 안뒤축후리기 신호
- 뒤꿈치에 체중을 두지 말고 무릎을 굽혀 체중을 앞쪽으로 둔다
- 발이 쓸리는 순간 오른발을 살짝 들어 피하고 다시 넓게 딛는다
- 이미 넘어가면 낙법하고 다리 사이로 들어오는 상대를 클로즈드 가드로 감는다
