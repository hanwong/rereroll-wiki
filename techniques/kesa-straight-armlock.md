# 스트레이트 암락 (곁누르기) (Straight Armlock from Kesa Gatame)

[곁누르기](../positions/kesa-gatame.md) · 서브미션 · 위

다른 이름: 곁누르기 암락, 케사 암락, 곁누르기 팔 꺾기, Kesa Gatame Arm Crush from Kesa Gatame

## 세팅 과정 (오른손잡이 기준)

1. 내 왼 겨드랑이에 끼운 상대 오른팔의 손목을 왼손으로 잡고 팔꿈치 안쪽이 위를 보게 돌린다
2. 앞으로 뻗은 내 오른다리의 무릎을 세워 오른 허벅지를 상대 오른 팔꿈치 아래에 받친다
3. 목 감은 내 오른팔과 가슴으로 상대 오른 어깨를 눌러 움직이지 못하게 한다
4. 상대 오른 손목을 바닥 쪽으로 눌러 내 오른 허벅지 위에서 팔꿈치를 편다

## 핵심 디테일

- 상대 팔꿈치 안쪽이 위를 보게 돌려야 팔꿈치가 꺾인다
- 내 오른 허벅지는 상대 팔꿈치 바로 위(팔꿈치 관절)에 받친다
- 목 감은 팔과 가슴으로 상대 어깨를 눌러 몸을 못 돌리게 한다
- 손목을 천천히 눌러 내린다

## 흔한 실수

- 허벅지가 팔뚝이나 위팔 밑에 있으면 안 걸린다 → 팔꿈치 바로 밑에 받친다
- 팔꿈치 안쪽이 옆을 보면 팔이 굽어 빠진다 → 손목을 돌려 방향을 맞춘다
- 세게 눌러 내리면 다친다 → 천천히 누르고 탭을 기다린다

## 막히면

- 상대가 팔을 굽혀 버티면 → [기무라 (곁누르기)](../techniques/kimura-from-kesa.md)
- 상대가 몸을 돌려 팔을 빼려 하면 → 겨드랑이를 다시 조여 [곁누르기](../positions/kesa-gatame.md)로 돌아간다

## 방어하는 쪽 (상대 입장)

- 상대가 내 오른 손목을 돌리고 상대 오른 허벅지가 내 팔꿈치 밑으로 오면 → 암락 신호
- 팔꿈치를 굽히고 손을 배 쪽으로 당겨 팔이 펴지지 않게 한다
- 팔이 이미 허벅지 위에서 펴지면 → 일찍 탭한다
