# 라쏘 가드 패스 (Lasso Guard Pass)

[스파이더 · 라쏘 · 소매 가드](../positions/spider-lasso.md) · 패스 · 위 → [사이드 컨트롤](../positions/side-control.md)

다른 이름: 라쏘 패스, Pass Russian Leg Lasso, Pass Inverted Lasso Guard

## 세팅 과정 (오른손잡이 기준)

1. 일어서서 자세를 세우고 내 왼손으로 내 오른쪽 소매를 잡은 상대 왼손을 떼어낸다
2. 내 오른쪽 팔꿈치를 몸 쪽 아래로 당겨 라쏘 건 상대 왼다리에서 빼낸다
3. 빠진 내 오른손으로 상대 왼다리를 바닥에 눌러 둔다
4. 니슬라이스나 스택으로 패스한다

## 핵심 디테일

- 일어서서 자세를 세워야 라쏘 다리가 당기는 힘이 약해진다
- 내 왼손으로 내 오른쪽 소매를 잡은 상대 왼손부터 떼어낸다
- 오른쪽 팔꿈치를 몸 쪽 아래로 당겨 라쏘 다리 밖으로 빼낸다
- 빠진 오른손으로 상대 왼다리를 바닥에 눌러 두고 바로 패스로 잇는다

## 흔한 실수

- 소매 그립을 두고 팔만 빼려 하면 안 빠진다 → 그립부터 끊는다
- 팔을 위로 들어 빼려 하면 라쏘가 더 깊어진다 → 팔꿈치를 아래로 몸에 붙여 뺀다
- 무릎을 꿇은 채 하면 상대가 오모플라타·스윕을 쉽게 건다 → 일어서서 한다

## 막히면

- 팔이 안 빠지면 → [백스텝 패스 (라쏘 상대)](../techniques/lasso-guard-backstep-pass.md)
- 상대가 다리를 다시 감아 오면 → [스택 패스 (라쏘 상대)](../techniques/lasso-guard-stack-pass.md)

## 방어하는 쪽 (상대 입장)

- 상대가 일어서서 내 왼손 소매 그립을 떼어내면 라쏘를 풀려는 신호
- 소매를 다시 잡고 왼다리 라쏘를 더 깊게 넣어 팔이 못 빠지게 한다
- 팔이 빠지기 직전이면 오모플라타 (라쏘)나 라쏘 스윕으로 먼저 공격한다
- 팔이 빠지면 오른발로 상대 골반을 밀어 거리를 만들고 스파이더 가드로 다시 잡는다
