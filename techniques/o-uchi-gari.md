# 안다리후리기 (O Uchi Gari)

[스탠딩 · 테이크다운](../positions/standing.md) · 테이크다운 · 서서 → [패스](../positions/passing.md)

다른 이름: 오우치가리, 인사이드 트립, 오우치, 안다리

## 세팅 과정 (오른손잡이 기준)

1. 내 오른손은 상대 왼쪽 깃, 왼손은 상대 오른쪽 소매를 잡고 뒤로 밀어 상대 왼발에 체중을 싣게 한다
2. 상대 다리 사이로 내 오른다리를 넣어 상대 왼쪽 종아리 안쪽을 건다
3. 건 오른다리를 상대 왼쪽 바깥으로 둥글게 후리며 상체는 상대 왼쪽 뒤로 민다
4. 넘어가면 상대 다리 사이로 들어가 패스 자세를 잡는다

## 핵심 디테일

- 그립으로 상대를 상대 왼쪽 뒤로 밀어 체중을 상대 왼발 뒤꿈치에 싣는다
- 내 오른 종아리로 상대 왼 종아리 안쪽을 걸고 바깥으로 둥글게 쓸어 낸다
- 다리만 쓰지 말고 가슴을 붙여 상체로 같이 민다
- 디딤발인 왼발을 상대 가까이 두어 내가 한 발로 흔들리지 않게 한다

## 흔한 실수

- 다리만 걸고 상체로 밀지 않으면 상대가 다리를 빼고 선다 → 가슴을 붙여 다리와 상체를 함께 쓴다
- 멀리서 다리를 넣으면 내가 한 발로 서 되치기 당한다 → 왼발을 먼저 상대 가까이 딛는다
- 넘긴 뒤 다리 사이에 그대로 있으면 가드에 갇힌다 → 바로 무릎을 세우고 패스 자세를 잡는다

## 막히면

- 상대가 왼발을 빼며 체중이 오른발로 옮기면 → [안뒤축후리기](../techniques/kouchi-gari.md)
- 상대가 허리를 뒤로 빼며 버티면 → 몸을 낮춰 [더블 레그 테이크다운](../techniques/double-leg-takedown.md)
- 넘어가며 상대가 다리로 허리를 감으면 → [가드 풀링 당했을 때 패스 시작](../techniques/guard-pull-defense.md)

## 방어하는 쪽 (상대 입장)

- 상대가 나를 뒤로 밀고 상대 오른다리가 내 다리 사이로 들어와 내 왼 종아리 안쪽에 닿으면 안다리 신호
- 걸리기 전에 내 왼다리를 뒤로 빼고 무릎을 굽혀 체중을 앞으로 둔다
- 걸렸으면 왼다리를 들어 상대 다리를 넘겨 피하고 두 발을 다시 넓게 딛는다
- 이미 넘어가면 낙법하고 다리로 상대 허리를 감아 클로즈드 가드를 잡는다
