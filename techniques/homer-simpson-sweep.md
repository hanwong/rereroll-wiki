# 호머 심슨 스윕 (Homer Simpson Sweep)

[딥 하프가드](../positions/deep-half.md) · 스윕 · 아래 → [마운트](../positions/mount.md)

다른 이름: 호머심슨

## 세팅 과정 (오른손잡이 기준)

1. 딥 하프에서 내 오른팔로 상대 오른다리를 안은 채 머리를 바닥에 댄다
2. 무릎으로 일어서며 상대 오른다리를 밀어 올린다
3. 상대가 등으로 넘어진다
4. 마운트

## 핵심 디테일

- 내 오른팔로 상대 오른다리를 꽉 안은 채 무릎으로 일어선다
- 머리는 바닥에 대 받침으로만 쓰고 목에 체중을 싣지 않는다
- 무릎으로 일어서며 상대 오른다리를 높이 밀어 올려 상대를 등으로 넘긴다
- 넘어가면 바로 엉덩이를 따라 올려 마운트로

## 흔한 실수

- 목으로 체중을 받치면 다친다 → 머리는 대기만 하고 무릎·다리로 일어선다
- 다리를 낮게 들면 상대가 버틴다 → 높이 밀어 올린다
- 넘긴 뒤 머뭇거리면 상대가 다리를 감아 가드를 만든다 → 바로 올라탄다

## 막히면

- 상대가 체중을 앞으로 실어 누르면 → [웨이터 스윕](../techniques/waiter-sweep.md)
- 상대가 왼다리를 넓게 디뎌 버티면 → [딥 하프 스윕](../techniques/deep-half-sweep.md)
- 상대가 백스텝으로 돌면 → [딥 하프 → 백 테이크](../techniques/deep-half-to-back.md)

## 방어하는 쪽 (상대 입장)

- 상대가 내 오른다리를 안은 채 무릎으로 일어서며 다리를 들면 신호
- 왼다리를 넓게 디디고 체중을 앞으로 실어 상대 등을 누른다
- 오른팔 위저로 상대 상체를 눌러 상대가 못 일어서게 한다
- 넘어가면 다리로 상대 허리를 감아 가드로 받는다
