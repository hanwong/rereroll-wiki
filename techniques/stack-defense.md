# 스택 당했을 때 방어 (가드) (Stack Defense in Closed Guard)

[클로즈드 가드](../positions/closed-guard.md) · 방어 · 아래 → [클로즈드 가드](../positions/closed-guard.md) / [오픈 가드](../positions/open-guard.md)

다른 이름: 스택 디펜스

## 세팅 과정 (오른손잡이 기준)

1. 상대가 내 다리를 머리 쪽으로 누르면 양발을 상대 양쪽 골반에 대어 밀어낸다
2. 턱을 당기고 목이 꺾이지 않게 한다
3. 엉덩이를 내 오른쪽으로 빼고 몸을 왼쪽 옆으로 세워 압력을 피한다
4. 가드를 다시 잠그거나 오픈 가드로

## 핵심 디테일

- 무게가 머리 쪽으로 오기 전에 두 발로 상대 골반을 밀어 거리를 만든다
- 턱을 당기고 목 대신 어깨로 체중을 받는다
- 엉덩이를 내 오른쪽으로 빼고 몸을 옆으로 세워 무게를 비켜낸다
- 공간이 생기면 다리를 다시 잠그거나 발을 골반에 둬 오픈 가드로 간다

## 흔한 실수

- 다리를 잠근 채 버티면 목이 꺾인다 → 발을 풀어 골반을 민다
- 등을 바닥에 똑바로 대고 있으면 무게를 다 받는다 → 옆으로 돌아눕는다
- 팔을 쭉 펴서 밀면 팔이 잡힌다 → 발과 엉덩이로 피한다

## 막히면

- 상대가 다리를 안고 돌아 패스하려 하면 → [쉬림프 (힙 이스케이프)](../techniques/shrimp-hip-escape.md)로 무릎을 다시 넣는다
- 상대 오른팔이 내 다리 사이에 남아 있으면 → [트라이앵글 초크](../techniques/triangle-choke.md)
- 거리가 생기면 → [발 골반 가드 (피트 온 힙스)](../techniques/feet-on-hips-guard.md)

## 방어하는 쪽 (상대 입장)

- 상대가 두 발로 내 골반을 밀며 엉덩이를 옆으로 빼면 → 스택에서 빠지려는 신호
- 상대 엉덩이를 내 허벅지에 붙여 공간을 주지 않고 체중을 상대 어깨 쪽에 계속 싣는다
- 발이 골반에 닿으면 그 발목을 잡아 옆으로 치운다
- 다리가 다시 열리면 → 더블 언더 패스 (스택)
