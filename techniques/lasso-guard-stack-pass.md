# 스택 패스 (라쏘 상대) (Lasso Guard Stack Pass)

[스파이더 · 라쏘 · 소매 가드](../positions/spider-lasso.md) · 패스 · 위 → [사이드 컨트롤](../positions/side-control.md)

다른 이름: 라쏘 스택, Stack from Inverted Lasso

## 세팅 과정 (오른손잡이 기준)

1. 라쏘 건 상대 왼다리를 내 오른쪽 어깨로 들어 올린다
2. 상대 엉덩이를 내 허벅지 위로 올린다(스택)
3. 라쏘가 느슨해지면 내 오른팔을 빼낸다
4. 돌아 사이드

## 핵심 디테일

- 손으로 밀지 말고 다리로 걸어 들어가 엉덩이 힘으로 상대를 접는다
- 상대 엉덩이가 내 허벅지 위로 올라올 때까지 가슴을 상대 다리에 붙여 공간을 안 준다
- 라쏘 걸린 내 오른팔은 억지로 뜯지 말고 접혀서 느슨해질 때 뺀다
- 내 왼손으로 상대 오른쪽 무릎·바지를 눌러 그 발이 골반을 다시 밀지 못하게 한다

## 흔한 실수

- 엉덩이를 높이 들고 누르면 상대가 다리로 띄워 스윕한다 → 엉덩이를 낮추고 앞으로 민다
- 라쏘가 조인 상태에서 팔부터 당기면 힘만 빠진다 → 먼저 접고 나서 뺀다
- 상대 머리 쪽으로 크게 뛰어 돌면 상대가 다리를 다시 넣는다 → 작은 걸음으로 누르며 돈다

## 막히면

- 상대가 엉덩이를 옆으로 빼 스택이 안 걸리면 → [백스텝 패스 (라쏘 상대)](../techniques/lasso-guard-backstep-pass.md)
- 상대가 라쏘를 풀고 다리를 내 목 쪽으로 올리면 → 머리를 빼고 자세를 세운다 · 잠기면 [트라이앵글 스택 탈출](../techniques/stack-escape-from-triangle.md)
- 상대 왼팔이 뻗어 나오면 → [기무라 (라쏘 위에서)](../techniques/kimura-from-lasso-guard.md)

## 방어하는 쪽 (상대 입장)

- 상대가 라쏘 건 내 왼다리를 자기 오른쪽 어깨로 들어 올리며 걸어오면 스택 신호
- 내 오른발로 상대 왼쪽 골반을 밀어 거리를 지키고 엉덩이를 바닥에 붙여 둔다
- 접히기 시작하면 엉덩이를 옆으로 빼 각도를 다시 만든다
- 이미 접혔으면 라쏘를 버리고 무릎을 가슴 쪽으로 당겨 상대 가슴 앞에 넣는다
