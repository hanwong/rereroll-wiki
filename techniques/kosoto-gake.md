# 밭뒤축걸기 (Kosoto Gake)

[스탠딩 · 테이크다운](../positions/standing.md) · 테이크다운 · 서서 → [사이드 컨트롤](../positions/side-control.md) / [하프가드](../positions/half-guard.md)

다른 이름: 코소토가케, 바깥 걸기

## 세팅 과정 (오른손잡이 기준)

1. 상대를 상대 오른쪽 뒤로 밀어 체중을 상대 오른발 뒤에 싣는다
2. 내 왼다리로 상대 오른다리 바깥에서 종아리 뒤를 걸어 감는다
3. 건 채 상체를 밀며 체중으로 넘긴다
4. 넘어가면 사이드나 하프 탑

## 핵심 디테일

- 내 왼다리로 상대 오른 종아리 뒤를 감아 상대 오른발이 뒤로 빠지지 못하게 고정한다
- 가슴을 붙이고 체중을 상대 오른쪽 뒤로 실어 민다
- 다리를 걸어 둔 채 내 몸 전체가 앞으로 따라가며 넘긴다
- 넘어질 때 무릎으로 착지해 상대 다리 사이에 떨어지지 않게 한다

## 흔한 실수

- 걸기만 하고 밀지 않으면 상대가 버틴다 → 가슴으로 체중을 싣는다
- 거리가 멀면 내 다리가 펴져 내가 먼저 흔들린다 → 몸을 붙인 뒤 건다
- 같이 떨어지며 다리 사이로 들어가면 가드에 갇힌다 → 상대 옆으로 무릎을 내려 바로 패스

## 막히면

- 상대가 걸린 오른발을 빼려고 체중을 왼발로 옮기면 → [안다리후리기](../techniques/o-uchi-gari.md)
- 상대가 정면으로 버티면 → 허리를 감아 [바디락 테이크다운](../techniques/body-lock-takedown.md)
- 넘어가며 상대가 내 다리를 감으면 → [하프가드 패스 (크로스페이스 · 언더훅)](../techniques/half-guard-pass.md)

## 방어하는 쪽 (상대 입장)

- 상대가 나를 내 오른쪽 뒤로 밀고 상대 왼다리가 내 오른 종아리 뒤를 감으면 밭뒤축걸기 신호
- 체중을 앞으로 옮기고 무릎을 굽혀 버틴다
- 걸린 오른다리를 앞으로 빼며 상대 가슴을 밀어 공간을 만든다
- 이미 넘어가면 낙법하고 상대 다리를 감아 하프가드를 잡는다
