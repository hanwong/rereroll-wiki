# 스매시 패스 (X 가드 상대) (Smash Pass from X-Guard)

[X 가드 · 싱글 레그 X · 앵클락](../positions/x-guard.md) · 패스 · 위 → [사이드 컨트롤](../positions/side-control.md)

다른 이름: X가드 스매시

## 세팅 과정 (오른손잡이 기준)

1. 상대가 내 왼다리를 안고 내 오른다리에 X 훅을 걸었을 때, 체중을 상대 위로 떨어뜨려 훅을 뭉갠다
2. 상대 두 무릎을 내 오른쪽으로 모아 누른다
3. 상대 어깨에 얹힌 내 왼다리를 빼낸다
4. 상대 무릎 반대쪽인 내 왼쪽으로 돌아 사이드를 잡는다

## 핵심 디테일

- 서서 버티지 말고 엉덩이·가슴을 낮춰 상대 훅보다 아래로 체중을 떨어뜨린다
- 상대 두 무릎을 내 오른쪽으로 모아 바닥에 눌러 골반을 비튼다
- 압박은 한 번에 터뜨리지 말고 조금씩 더해 틈을 주지 않는다
- 왼다리를 빼는 동안에도 무릎 누르기와 가슴 압박을 놓지 않는다

## 흔한 실수

- 상체를 세운 채 누르면 → 상대가 들어 올려 스윕한다 → 가슴을 낮춘다
- 무릎만 모으고 상체를 놓으면 → 상대가 팔로 밀어내 가드를 되찾는다 → 머리·어깨로 상대 가슴을 누른다
- 왼다리를 빼다 압박을 풀면 → 상대 무릎이 다시 선다 → 다리를 다 뺄 때까지 누른다

## 막히면

- 상대가 싱글 레그 X로 바꾸면 → [백스텝 (싱글 레그 X 상대)](../techniques/backstep-from-single-leg-x.md)
- 상대가 훅을 풀고 버터플라이로 돌아가면 → [버터플라이 스매시 패스](../techniques/butterfly-smash.md)
- 상대가 팔로 내 어깨를 밀면 → 그 팔을 안쪽으로 걷어내고 크로스페이스부터 다시 · [사이드 컨트롤 유지](../techniques/side-control-maintain.md)

## 방어하는 쪽 (상대 입장)

- 상대가 엉덩이를 낮추고 가슴을 앞으로 기울이면 체중으로 뭉개려는 신호
- 상대가 낮아지기 전에 훅을 깊게 유지하며 X 가드 스윕
- 눌리기 시작하면 팔뚝으로 상대 어깨에 프레임을 대고 엉덩이를 빼 각도를 다시 만든다
- 훅이 무너지면 X 가드 → 싱글 레그 X 나 버터플라이 가드로 갈아탄다
