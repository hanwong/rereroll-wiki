# 버터플라이 훅 컨트롤 패스 (Pass Butterfly Hook Control)

[버터플라이 가드](../positions/butterfly-guard.md) · 패스 · 위 → [사이드 컨트롤](../positions/side-control.md)

다른 이름: 훅 잡혀도 패스, 니슬라이스 (버터플라이 하프), 하프 버터플라이 니슬라이스, 버터플라이 패스, 버터플라이 가드 패스, 버터플라이 훅 패스, 훅 죽이기 패스

## 세팅 과정 (오른손잡이 기준)

1. 내 오른손으로 상대 왼발 훅을 바닥에 누른다
2. 내 왼쪽 엉덩이를 뒤로 빼 상대 오른발 훅에 들리지 않게 한다
3. 내 오른쪽 무릎을 상대 왼쪽 허벅지 위로 올린다
4. 니슬라이스로 상대 왼쪽 사이드로 간다

## 핵심 디테일

- 훅은 하나씩 처리한다 → 내 오른손으로 상대 왼발 훅부터 바닥에 누른다
- 내 왼쪽 엉덩이를 뒤로 빼 상대 오른발 훅에 체중이 실리지 않게 한다
- 내 왼팔은 상대 상체(목·깃)를 잡아 상대가 앉지 못하게 한다
- 오른 무릎을 상대 왼 허벅지 위로 올려 니슬라이스로 상대 왼쪽에 가슴을 붙인다

## 흔한 실수

- 훅이 살아 있는데 앞으로 밀고 들어가면 들려 넘어간다 → 훅부터 누른다
- 두 훅을 한꺼번에 처리하려 하면 둘 다 놓친다 → 상대 왼발 훅부터 처리한다
- 양손을 다 다리에 쓰면 상대가 상체를 세워 훅을 다시 넣는다 → 왼팔은 상체에 둔다

## 막히면

- 상대가 훅으로 들어 올리면 → 다리를 넓게 벌리고 엉덩이를 낮춰 버틴 뒤 다시 시작한다
- 상대가 쉬림프로 훅을 다시 넣으면 → 따라가 다시 눌러 [버터플라이 스매시 패스](../techniques/butterfly-smash.md)
- 상대가 하프가드로 다리를 잡으면 → [하프가드 패스 (크로스페이스 · 언더훅)](../techniques/half-guard-pass.md)

## 방어하는 쪽 (상대 입장)

- 상대 오른손이 내 왼발 훅을 누르고 상대 엉덩이가 뒤로 빠지면 패스 신호
- 눌린 왼 무릎을 가슴 쪽으로 당겨 훅을 다시 넣고 언더훅을 잡는다
- 상대 오른 무릎이 내 왼 허벅지를 넘어오면 무릎을 세워 니 쉴드 하프가드로 받는다
