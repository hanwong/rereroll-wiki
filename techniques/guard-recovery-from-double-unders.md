# 더블 언더 상대 가드 회복 (Guard Recovery from Double Unders)

[패스](../positions/passing.md) · 방어 · 아래 → [오픈 가드](../positions/open-guard.md) / [클로즈드 가드](../positions/closed-guard.md)

다른 이름: 더블언더 리가드

## 세팅 과정 (오른손잡이 기준)

1. 상대가 더블 언더로 내 양 다리를 안으면 양손으로 상대 어깨나 이두를 밀어 스택을 막는다
2. 엉덩이를 내 왼쪽으로 빼서 내 오른다리를 상대 왼팔에서 빼낸다
3. 빼낸 내 오른발을 상대 왼쪽 골반에 대어 거리를 만든다
4. 내 왼다리도 상대 오른팔에서 빼내 오픈 가드로 돌아간다

## 핵심 디테일

- 상대가 들어 올리기 전에 양손으로 상대 어깨·이두를 밀어 스택을 막는다
- 엉덩이를 내 왼쪽으로 빼 내 오른다리부터 상대 왼팔에서 빼낸다 — 두 다리를 한꺼번에 빼지 않는다
- 빼낸 오른발을 바로 상대 왼쪽 골반에 대 거리를 지킨다
- 그다음 왼다리도 상대 오른팔에서 빼 두 발로 오픈 가드를 만든다

## 흔한 실수

- 두 다리를 한꺼번에 빼려 하면 둘 다 안 빠진다 → 오른다리부터 하나씩 뺀다
- 엉덩이가 들린 뒤에 밀면 늦는다 → 상대 팔이 들어오는 순간 프레임을 댄다
- 다리를 빼고 그대로 두면 상대가 다시 팔을 넣는다 → 바로 발을 골반에 댄다

## 막히면

- 다리가 안 빠지면 → [더블 언더 상대 버터플라이 훅 회복](../techniques/butterfly-hook-recovery.md)
- 상대가 앞으로 깊게 체중을 실어 스택하면 → [더블 언더 상대 스윕](../techniques/sweep-from-double-unders.md)
- 상대가 다리를 던져 옆으로 돌면 → [쉬림프 (힙 이스케이프)](../techniques/shrimp-hip-escape.md)

## 방어하는 쪽 (상대 입장)

- 상대가 양손으로 내 어깨를 밀고 엉덩이를 빼며 오른다리를 내 왼팔에서 빼려 하면 가드 회복 신호
- 손을 더 깊게 맞잡고 가슴을 낮춰 상대 엉덩이를 내 허벅지 위에 붙여 둔다
- 한 다리가 빠지면 남은 다리를 안은 채 오버 언더 패스로 바꾼다
