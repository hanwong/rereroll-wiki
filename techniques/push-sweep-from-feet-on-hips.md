# 푸시 스윕 (Push Sweep from Feet on Hips)

[오픈 가드](../positions/open-guard.md) · 스윕 · 아래 → [패스](../positions/passing.md)

다른 이름: 밀어 넘기기

## 세팅 과정 (오른손잡이 기준)

1. 발 골반 가드에서 내 오른손은 상대 왼쪽 소매, 왼손은 오른쪽 소매를 잡고 당긴다
2. 상대가 뒤로 버티는 순간 양 소매는 계속 당긴 채 양 발로 상대 양 골반을 강하게 민다
3. 상대가 엉덩이부터 주저앉으면 바로 상대 오른쪽 소매를 놓고 내 왼손을 짚고 일어난다
4. 상대 양 발목이나 양 무릎을 잡고 패스 자세로 간다

## 핵심 디테일

- 먼저 소매를 당겨 상대가 뒤로 버티게 만든 뒤 그 힘에 맞춰 민다
- 양손은 끝까지 당기고 양발은 골반뼈를 세게 밀어 상대가 발을 뒤로 못 디디게 한다
- 상대가 주저앉는 순간 오른쪽 소매를 놓지 말고 왼손을 짚어 바로 일어난다
- 일어나면 상대 양 발목이나 무릎을 잡아 다시 가드를 못 만들게 한다

## 흔한 실수

- 상대가 단단히 버틸 때 그냥 밀면 내 몸만 밀려난다 → 당겼다가 상대가 뒤로 버티는 순간 민다
- 미는 순간 소매를 놓으면 상대가 한 걸음 물러나 균형을 잡는다 → 주저앉을 때까지 당긴다
- 넘기고 누워 있으면 상대가 다시 들어온다 → 바로 일어나 패스 자세

## 막히면

- 상대가 뒤로 한 걸음 물러나 버티면 → 상대가 앞에 낸 다리로 [발 골반 → 데라히바](../techniques/feet-on-hips-to-de-la-riva.md)
- 상대가 내 발목을 잡아 떼면 → 다리를 접어 [그립 끊기 (오픈 가드)](../techniques/grip-break.md)
- 상대가 앞으로 밀고 들어오면 → [벌룬 스윕](../techniques/balloon-sweep.md)

## 방어하는 쪽 (상대 입장)

- 상대가 양 소매를 세게 당긴 뒤 갑자기 두 발로 내 골반을 밀면 푸시 스윕 신호다
- 당길 때 뒤로 크게 버티지 말고 오른발을 뒤로 빼 넓게 서서 받는다
- 소매 그립부터 끊고 상대 발목을 잡아 발을 골반에서 떼어 낸다
- 주저앉으면 손을 뒤로 짚지 말고 바로 다리로 상대를 막는다
