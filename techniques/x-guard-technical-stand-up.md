# X 가드 → 일어나기 (X-Guard Technical Stand Up)

[X 가드 · 싱글 레그 X · 앵클락](../positions/x-guard.md) · 스윕 · 아래 → [패스](../positions/passing.md)

다른 이름: X가드 스탠드업

## 세팅 과정 (오른손잡이 기준)

1. 상대 왼다리를 내 오른팔로 안은 채 내 왼손으로 바닥을 짚는다
2. 오른발로 바닥을 딛고 엉덩이를 들어 왼다리를 뒤로 빼서 일어난다
3. 상대 왼다리를 든 채 서서 밀어 눕힌다
4. 상대 왼다리를 놓지 않고 패스 자세로 간다

## 핵심 디테일

- 오른팔로 상대 왼다리를 안은 채 왼손을 엉덩이 가까이 바닥에 짚는다
- 팔로 끌어올리지 말고 오른발과 엉덩이 힘으로 몸을 밀어 올린다
- 일어날 때 왼다리를 뒤로 빼 넓게 서야 균형이 잡힌다
- 서자마자 멈추지 말고 든 다리로 상대를 밀어 눕힌다

## 흔한 실수

- 왼손을 멀리 짚으면 일어나는 힘이 약하다 → 엉덩이 가까이 짚는다
- 다리를 놓고 일어나면 그냥 서서 맞서는 자세로 돌아간다 → 다리를 계속 안는다
- 머리를 숙이고 일어나면 상대가 눌러 다시 앉힌다 → 머리를 들고 가슴을 앞으로

## 막히면

- 상대가 내 머리·어깨를 눌러 못 일어나면 → [X 가드 스윕](../techniques/x-guard-sweep.md) · [토마호크 스윕](../techniques/tomahawk-sweep.md)
- 상대가 다리를 빼려 하면 → [X 가드 → 싱글 레그 X](../techniques/x-guard-to-single-leg-x.md)

## 방어하는 쪽 (상대 입장)

- 상대가 내 왼다리를 안은 채 손을 바닥에 짚고 엉덩이를 들면 일어나려는 신호
- 상대 머리나 어깨를 눌러 다시 앉히고 왼쪽 무릎을 굽혀 체중을 싣는다
- 이미 일어섰으면 오른발로 깡충 뛰며 균형을 잡고 왼다리를 빼낸다
