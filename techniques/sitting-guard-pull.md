# 앉아서 가드 잡기 (시팅 가드) (Sitting Guard Pull)

[클린치 · 가드 풀링](../positions/clinch.md) · 가드 풀링 · 서서 → [오픈 가드](../positions/open-guard.md)

다른 이름: 시팅 가드, 앉은 가드

## 세팅 과정 (오른손잡이 기준)

1. 내 오른손은 상대 왼쪽 깃, 왼손은 상대 오른쪽 소매를 잡고 엉덩이를 바닥에 앉힌다
2. 내 오른발로 상대 왼쪽 무릎이나 골반을 막는다
3. 상체를 세워 상대가 들어오지 못하게 한다
4. 소매를 놓은 내 왼손으로 상대 오른쪽 발목 뒤를 잡아 스윕이나 싱글 레그로 잇는다

## 핵심 디테일

- 앉기 전에 내 오른손 깃 · 왼손 소매를 먼저 잡고 앉는다
- 앉자마자 내 오른발로 상대 왼쪽 무릎 · 골반을 막아 거리를 지킨다
- 상체를 세워 앉고 등이 바닥에 닿지 않게 한다
- 상대 오른발이 가까이 있으면 내 왼손으로 그 발목 뒤를 바로 잡는다

## 흔한 실수

- 그립 없이 앉으면 상대가 바로 돌아 패스한다 → 깃 · 소매를 먼저 잡는다
- 등을 대고 누우면 상대가 위에서 누른다 → 상체를 세워 앉는다
- 발이 골반에 안 닿으면 상대가 밀고 들어온다 → 오른발을 상대 왼쪽 골반 · 무릎에 바로 댄다

## 막히면

- 상대가 오른발을 앞에 두고 서 있으면 → [발 잡아 넘기기 (시팅 가드)](../techniques/foot-grab-sweep.md)
- 상대가 다리를 돌아 패스하려 하면 → [가드 리텐션 (다리 되돌리기)](../techniques/open-guard-retention.md)
- 상대가 뒤로 물러나 거리를 두면 → [테크니컬 스탠드업 → 싱글 레그](../techniques/technical-stand-up-to-single-leg.md)

## 방어하는 쪽 (상대 입장)

- 상대가 내 왼쪽 깃 · 오른쪽 소매를 잡고 앉으면 → 바로 허리를 세우고 깃을 잡은 상대 오른손부터 끊는다
- 상대 오른발이 내 왼쪽 무릎 · 골반을 막으면 그 발을 걷어내며 다리 바깥으로 돌아간다
- 상대 왼손이 내 오른쪽 발목을 잡으면 오른발을 뒤로 빼고 체중을 앞에 실어 넘어가지 않는다
