# 가드 열기 순서 (Guard Opening Sequence)

[클로즈드 가드](../positions/closed-guard.md) · 전환 · 위 → [패스](../positions/passing.md)

다른 이름: 가드 오프닝

## 세팅 과정 (오른손잡이 기준)

1. 자세 세우기 → 무릎 쐐기 → 손으로 무릎 누르기 순으로 간다
2. 안 열리면 서서 열기로 바꾼다
3. 열리는 순간 무릎을 상대 다리 사이로 넣어 다시 닫지 못하게 한다
4. 바로 패스로 잇는다

## 핵심 디테일

- 자세가 무너진 상태에선 열기를 시작하지 않는다 — 자세부터 세운다
- 무릎 쐐기는 내 오른쪽 무릎을 상대 엉덩이 밑에 넣고 내 왼손으로 상대 오른쪽 무릎을 눌러 연다
- 팔 힘으로 다리를 벌리지 말고 엉덩이를 뒤로 빼는 힘으로 연다
- 열리는 순간 무릎을 상대 다리 사이에 넣어 다시 못 잠그게 하고 바로 패스로 잇는다

## 흔한 실수

- 숙인 채 다리부터 벌리면 상대가 깃을 당겨 공격한다 → 손을 상대 골반에 두고 허리를 세운다
- 서서 열 때 발이 상대 엉덩이 가까이 있으면 스윕을 당한다 → 발을 엉덩이 바깥 조금 뒤에 두고 무릎을 굽힌다
- 열고 나서 멈추면 상대가 오픈 가드를 만든다 → 열기와 패스를 한 동작으로 잇는다

## 막히면

- 무릎 쐐기로 안 열리면 → [스탠딩 가드 브레이크](../techniques/standing-guard-break.md)
- 상대가 자세를 무너뜨리면 → [클로즈드 가드 안 자세 되찾기](../techniques/posture-recovery.md) 후 다시 시작
- 열렸는데 상대가 발을 골반에 대면 → [발 골반 가드 패스](../techniques/pass-feet-on-hips-guard.md)

## 방어하는 쪽 (상대 입장)

- 상대가 허리를 세우고 손을 내 골반·무릎으로 옮기면 가드를 열려는 신호다
- 깃과 발꿈치로 상대를 당겨 자세를 다시 무너뜨린다
- 상대가 엉덩이를 뒤로 빼 무릎을 세우면 힙 범프 스윕, 일어서면 상대가 섰을 때 클로즈드 가드 유지
- 결국 열리면 바로 발로 골반을 막아 오픈 가드로 바꾼다
