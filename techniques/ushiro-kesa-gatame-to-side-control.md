# 리버스 곁누르기 → 사이드 (Ushiro Kesa Gatame to Side Control)

[곁누르기](../positions/kesa-gatame.md) · 전환 · 위 → [사이드 컨트롤](../positions/side-control.md)

다른 이름: 리버스 스카프 홀드 → 사이드, Reverse Kesa to Side Control, 우시로 케사 → 사이드

## 세팅 과정 (오른손잡이 기준)

1. 상대 오른쪽에서 리버스 곁누르기로 상대 오른팔을 내 오른쪽 겨드랑이에 끼운 채 유지한다
2. 엉덩이를 바닥에 끌며 몸을 내 왼쪽으로 돌려 상대 머리 쪽을 바라본다
3. 오른쪽 무릎은 상대 엉덩이 옆, 왼쪽 무릎은 상대 오른쪽 겨드랑이 옆에 붙인다
4. 가슴을 붙이고 내 왼팔로 크로스페이스를 잡는다 → 사이드 컨트롤

## 핵심 디테일

- 돌아오는 동안 상대 오른팔은 끼운 채로 둔다
- 엉덩이를 바닥에 끌듯 낮게 돌아 가슴을 떼지 않는다
- 무릎을 상대 엉덩이 옆과 겨드랑이 옆에 붙여 틈을 막은 뒤 크로스페이스를 잡는다

## 흔한 실수

- 엉덩이를 들고 돌면 상대가 무릎을 넣는다 → 바닥에 끌며 돈다
- 크로스페이스 전에 끼운 팔을 놓으면 상대가 프레임을 만든다 → 팔은 마지막에 놓는다
- 무릎을 벌린 채 자리 잡으면 → 상대가 새우빼기로 빠진다 → 무릎을 몸에 붙인다

## 막히면

- 상대가 엉덩이를 빼 무릎을 넣으려 하면 → 무릎으로 골반을 막고 리버스 [곁누르기](../positions/kesa-gatame.md)로 다시 누른다
- 상대가 엎드려 돌면 → [터틀에서 백 테이크](../techniques/turtle-back-take.md)
- 상대가 가까운 팔을 뻗어 밀면 → [사이드 → 니 온 밸리](../techniques/side-to-knee-on-belly.md)

## 방어하는 쪽 (상대 입장)

- 리버스 곁누르기 상태에서 상대가 엉덩이를 끌며 내 머리 쪽을 보려 하면 → 사이드로 바꾸는 신호
- 돌아오는 순간 생긴 틈으로 엉덩이를 내 왼쪽으로 빼고 오른 무릎을 넣는다
- 이미 사이드가 되면 → 사이드 이스케이프 (프레임 · 쉬림프)
