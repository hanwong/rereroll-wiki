# 쿼터 가드 스윕 (Sweep from Quarter Guard)

[하프가드](../positions/half-guard.md) · 스윕 · 아래 → [사이드 컨트롤](../positions/side-control.md)

다른 이름: 쿼터 스윕

## 세팅 과정 (오른손잡이 기준)

1. 상대 오른쪽 발목을 건 쿼터 가드에서 내 왼팔로 언더훅을 잡고 오른쪽 어깨와 엉덩이를 바닥에 대 몸을 세운다
2. 내 오른손으로 걸린 상대 오른쪽 발목을 당겨 중심을 뺏는다
3. 상대 오른쪽 옆구리로 밀며 올라온다
4. 사이드

## 핵심 디테일

- 내 왼팔 언더훅을 깊게 잡은 뒤에 시작한다
- 오른쪽 어깨·엉덩이를 대고 상대 쪽으로 몸을 세워 올라온다
- 내 오른손으로 상대 오른쪽 발목을 내 쪽으로 당겨 상대가 오른발을 못 딛게 한다
- 상대 오른쪽 옆구리 쪽으로 밀며 따라 올라간다

## 흔한 실수

- 언더훅 없이 발목만 당기면 상대가 체중으로 눌러 버린다 → 언더훅 먼저
- 등을 댄 채 당기면 힘이 안 들어간다 → 옆으로 세워 올라온다
- 넘긴 뒤 발목을 놓으면 상대가 앉아 다시 가드를 만든다 → 위로 올라갈 때까지 잡는다

## 막히면

- 상대가 위저로 언더훅을 누르면 → [쿼터 가드 → 니 쉴드](../techniques/knee-shield-from-quarter.md)
- 상대가 크로스페이스로 눌러 오면 → [쿼터 가드 → 풀 가드](../techniques/recover-full-guard-from-quarter.md)
- 상대가 일어서면 → [하프가드 → 싱글 레그](../techniques/half-guard-to-single-leg.md)

## 방어하는 쪽 (상대 입장)

- 상대 왼팔 언더훅이 내 오른쪽 겨드랑이에 들어오고 상대 오른손이 내 오른쪽 발목을 잡으면 신호
- 내 오른팔 위저로 상대 왼팔을 감고 엉덩이를 뒤로 뺀다
- 내 왼다리를 넓게 디뎌 베이스를 만든다
- 이미 넘어가면 다리로 상대 허리를 감아 가드로 받는다
