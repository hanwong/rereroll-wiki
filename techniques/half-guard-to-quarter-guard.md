# 하프가드 → 쿼터 가드 (탑) (Half Guard to Quarter Guard)

[하프가드](../positions/half-guard.md) · 전환 · 위 → [하프가드](../positions/half-guard.md)

다른 이름: 쿼터 가드 만들기, Half to Quarter, 다리 반쯤 빼기

## 세팅 과정 (오른손잡이 기준)

1. 상대가 내 오른다리를 감은 하프가드 위에서 내 오른팔 크로스페이스, 왼팔 언더훅으로 상대를 눕힌다
2. 걸리지 않은 내 왼발이나 손으로 상대 위쪽 무릎을 바닥 쪽으로 누른다
3. 걸린 내 오른쪽 무릎을 앞으로 빼서 오른발목만 걸린 상태로 만든다
4. 가슴 압박을 유지한 채 쿼터 가드에서 마지막 오른발목을 뺄 준비를 한다

## 핵심 디테일

- 크로스페이스와 언더훅으로 먼저 상대를 눕혀 둔다
- 걸리지 않은 왼발이나 손으로 상대 위쪽 무릎을 바닥에 눌러 니 쉴드를 막는다
- 걸린 오른쪽 무릎은 뒤로 당기지 말고 앞으로 빼 낸다
- 발목만 남으면 가슴 압박을 유지한 채 마지막 발을 뺄 준비를 한다

## 흔한 실수

- 무릎을 뒤로 당겨 빼면 엉덩이가 떠 공간이 생긴다 → 앞으로 뺀다
- 크로스페이스를 풀면 상대가 돌아누워 무릎을 넣는다 → 끝까지 유지
- 위쪽 무릎을 안 누르면 니 쉴드가 다시 선다 → 먼저 누른다

## 막히면

- 상대가 발목을 꽉 꼬아 버티면 → [쿼터 가드 → 마운트](../techniques/knee-through-from-quarter.md)
- 상대가 오른손을 바닥에 짚으면 → [기무라 (쿼터 가드 탑)](../techniques/kimura-from-quarter-guard.md)
- 상대가 니 쉴드를 다시 세우면 → [레그 위브 패스](../techniques/leg-weave-pass.md)

## 방어하는 쪽 (상대 입장)

- 상대 무릎이 앞으로 빠지며 내 다리 꼬임이 발목까지 내려가면 신호
- 다리를 상대 무릎 위쪽으로 다시 끌어올려 꼰다
- 왼쪽 무릎을 상대 배 앞에 세워 니 쉴드로 막는다
- 쿼터가 됐으면 → 쿼터 가드 → 니 쉴드 · 쿼터 가드 → 풀 가드
