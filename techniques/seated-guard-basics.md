# 시팅 가드 기본 자세 (Seated Guard Basics)

[오픈 가드](../positions/open-guard.md) · 자세 · 컨트롤 · 아래 → [오픈 가드](../positions/open-guard.md)

다른 이름: 시팅 가드, 앉은 가드, 시티드 가드

## 세팅 과정 (오른손잡이 기준)

1. 앉아서 내 왼손은 뒤 바닥을 짚고 오른쪽 무릎을 세워 상체를 상대 쪽으로 기울인다
2. 내 오른손으로 상대 왼쪽 깃이나 소매를 먼저 잡고, 세운 오른발 발바닥은 상대 왼쪽 골반이나 무릎 앞에 둔다
3. 상대가 옆으로 돌면 엉덩이를 돌려 항상 상대와 정면을 유지한다
4. 상대가 서면 발목을 잡아 스윕을, 무릎 서면 버터플라이나 신 투 신으로 바꾼다

## 핵심 디테일

- 내 왼손은 뒤 바닥을 짚고 오른 무릎을 세워 상체를 상대 쪽으로 기울인다
- 내 오른손으로 상대 왼쪽 깃·소매를 먼저 잡아 거리를 정한다
- 세운 오른 발바닥을 상대 왼쪽 골반·무릎 앞에 두어 상대가 다가오는 걸 막는다
- 짚은 왼손을 축으로 엉덩이를 돌려 항상 상대와 정면을 유지한다

## 흔한 실수

- 뒤로 기대 누우면 상대가 다리를 넘어 들어온다 → 상체를 앞으로 세운다
- 그립 없이 앉아 있으면 상대가 먼저 다리를 잡는다 → 오른손 그립부터 잡는다
- 상대가 옆으로 도는데 엉덩이가 그대로면 옆이 뚫린다 → 엉덩이를 따라 돌린다

## 막히면

- 상대가 서서 버티면 → [앵클 픽 스윕](../techniques/ankle-pick-sweep.md)이나 [발 잡아 넘기기 (시팅 가드)](../techniques/foot-grab-sweep.md)
- 상대가 무릎 서서 다가오면 → [버터플라이 가드](../techniques/butterfly-guard.md)나 [신 투 신 가드](../techniques/shin-to-shin-guard.md)
- 상대가 옆으로 돌아 패스하려 하면 → [가드 리텐션 (다리 되돌리기)](../techniques/open-guard-retention.md)

## 방어하는 쪽 (상대 입장)

- 상대가 앉아서 오른손으로 내 왼쪽 깃·소매를 잡고 오른발을 내 왼쪽 골반에 대면 시팅 가드
- 내 왼쪽 깃·소매 그립부터 끊고 발목을 잡히지 않게 발을 뒤에 둔다
- 상대 발을 손으로 걷어 상대 왼쪽으로 몰고 토레안도 패스로 상대 오른쪽으로 돈다
