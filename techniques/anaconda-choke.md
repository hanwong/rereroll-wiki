# 아나콘다 초크 (Anaconda Choke)

[프론트 헤드락 · 길로틴](../positions/front-headlock.md) · 서브미션 · 위

다른 이름: 아나콘다, 아나콘다초크, 게이터 롤

## 세팅 과정 (오른손잡이 기준)

1. 프론트 헤드락에서 내 오른팔을 상대 목 아래로 넣어 상대 오른쪽 겨드랑이 아래로 뺀다
2. 뺀 오른손으로 내 왼팔 이두를 잡고 내 왼손은 상대 등에 올린다(8자 그립)
3. 갇힌 상대 왼팔 쪽(내 오른쪽)으로 오른쪽 어깨를 대고 구르며(게이터 롤) 상대를 넘긴다
4. 무릎으로 상대 쪽으로 걸어 들어가며 가슴을 조인다
5. 천천히 조이고 탭하면 바로 푼다

## 핵심 디테일

- 오른팔이 상대 목 아래로 들어가 상대 오른쪽 겨드랑이까지 깊게 빠져야 조인다
- 오른손이 왼팔 이두를 잡는 그립을 꽉 잠근 뒤에 구른다
- 구를 때 가슴을 갇힌 상대 왼쪽 어깨에 붙인 채 같이 돈다
- 구른 뒤 무릎으로 상대 쪽에 걸어 들어가며 가슴으로 조인다

## 흔한 실수

- 그립이 헐거운데 구르면 상대가 팔을 빼고 위로 온다 → 그립과 가슴 압박부터 확실히 한다
- 구르다 가슴이 떨어지면 조임이 풀린다 → 어깨에 가슴을 붙인 채 구른다
- 팔힘으로만 짜면 안 조인다 → 오른쪽 팔꿈치를 내 엉덩이 쪽으로 당기고 가슴을 부풀린다

## 막히면

- 상대가 갇힌 왼팔을 빼내면 → [길로틴 세팅](../techniques/guillotine-setup.md)
- 상대가 손으로 짚어 구르기를 막으면 → [아나콘다 안 되면 사이드](../techniques/anaconda-to-side-control.md)
- 구른 뒤에도 안 조이면 → [다스 ↔ 아나콘다 전환](../techniques/darce-to-anaconda-switch.md)으로 그립을 다시 잡는다

## 방어하는 쪽 (상대 입장)

- 상대 오른팔이 내 목 아래로 들어와 겨드랑이로 빠지면 → 턱을 당기고 왼쪽 팔꿈치를 몸에 붙인다
- 그립이 잠기기 전에 → 갇히는 왼팔을 빼내거나 오른손으로 상대 왼쪽 골반을 밀어 프레임을 세운다
- 상대가 구르면 → 버티지 말고 같은 방향(내 왼쪽)으로 따라 굴러 머리를 뽑는다 (아나콘다 방어)
- 이미 조여 오면 → 늦었으면 바로 탭한다
