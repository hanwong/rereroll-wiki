# 리버스 하프 → 하프가드 회복 (Guard Recovery from Reverse Half Guard)

[하프가드](../positions/half-guard.md) · 전환 · 아래 → [하프가드](../positions/half-guard.md)

다른 이름: 리버스 하프 탈출, Escape Reverse Half Guard, 힙 스위치 하프 회복

## 세팅 과정 (오른손잡이 기준)

1. 상대가 내 오른쪽에서 내 다리 쪽을 보고 앉으면 걸린 다리를 풀지 말고 꽉 조인다
2. 내 오른손으로 상대 골반을 밀어 몸이 더 내려오지 못하게 막는다
3. 내 왼발로 바닥을 밀어 엉덩이를 빼고 몸을 내 오른쪽(상대 쪽)으로 돌린다
4. 돌면서 내 오른팔을 상대 겨드랑이 밑으로 넣어 언더훅을 잡는다
5. 내 왼쪽 무릎을 상대 배 앞에 세워 하프가드(니 쉴드)로 돌아온다

## 핵심 디테일

- 상대가 다리 쪽을 보고 앉아도 걸린 다리는 절대 풀지 않는다
- 내 오른손으로 상대 골반을 먼저 막아 더 내려오지 못하게 한다
- 엉덩이를 빼며 몸을 상대 쪽으로 돌리는 것과 오른팔 언더훅을 동시에 한다
- 돌아오면 바로 왼쪽 무릎을 세워 니 쉴드로 막는다

## 흔한 실수

- 다리 꼬임을 풀면 그대로 패스된다 → 끝까지 꽉 조인다
- 등을 대고 있으면 상대가 엉덩이를 돌려 다리를 뺀다 → 상대 쪽으로 돈다
- 언더훅 없이 무릎만 넣으면 상대가 다시 등을 돌려 앉는다 → 언더훅 먼저

## 막히면

- 상대가 계속 엉덩이를 돌려 다리를 빼려 하면 → [피쉬넷 스윕 (리버스 하프가드)](../techniques/fishnet-sweep-from-reverse-half-guard.md)
- 다리가 빠져 사이드가 되면 → [사이드 이스케이프 (프레임 · 쉬림프)](../techniques/side-control-escape.md)
- 하프로 돌아왔는데 상대가 누르면 → [니 쉴드 유지 (눌릴 때)](../techniques/knee-shield-retention.md)

## 방어하는 쪽 (상대 입장)

- 상대 오른손이 내 골반을 밀고 상대가 내 쪽으로 몸을 돌리면 신호
- 엉덩이를 상대 상체 쪽으로 더 미끄러뜨려 체중을 실어 못 돌게 한다
- 상대 오른팔이 내 겨드랑이 밑으로 들어오기 전에 팔을 막는다
- 하프로 돌아갔으면 → 하프 탑 기본 자세에서 다시 시작
