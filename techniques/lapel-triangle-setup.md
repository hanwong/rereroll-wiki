# 트라이앵글 (라펠) (Lapel Triangle Setup)

[라펠 가드](../positions/lapel-guard.md) · 서브미션 · 아래

다른 이름: 라펠 트라이앵글

## 세팅 과정 (오른손잡이 기준)

1. 라펠로 상대 오른팔을 묶어 내 왼다리 바깥에 두고, 상대 왼팔은 내 다리 사이에 둔다
2. 내 왼다리를 상대 오른쪽 어깨 위로 넘겨 상대 목 뒤에 건다
3. 상대 머리를 당겨 내리며 내 오른다리 오금으로 내 왼쪽 발목을 걸어 잠근다
4. 안에 남은 상대 왼팔을 내 왼쪽으로 넘기고 무릎을 모으며 조인다

## 핵심 디테일

- 라펠이 상대 오른팔을 바깥에 묶어 두니 상대 왼팔 하나만 안에 두기 쉽다
- 상대 머리를 당겨 숙이게 한 뒤 엉덩이를 들어 왼다리를 높게 넘긴다
- 잠근 뒤 안에 갇힌 상대 왼팔을 내 왼쪽으로 넘겨 목과 어깨를 같이 조인다
- 각도를 틀고 무릎을 모아 조른다

## 흔한 실수

- 상대가 자세를 세운 채 다리를 넘기면 목에 안 걸린다 → 먼저 숙이게 한다
- 갇힌 팔을 넘기지 않고 조이면 상대가 버틴다 → 팔을 가로질러 넘긴다
- 왼쪽 발목을 오금에 얕게 걸면 풀린다 → 깊게 건다

## 막히면

- 상대가 자세를 세우면 → [오모플라타 (라펠)](../techniques/lapel-omoplata-entry.md)
- 잠갔는데 안 조여지면 → [트라이앵글 → 암바](../techniques/triangle-to-armbar.md)
- 상대가 스택으로 누르면 → 각도를 다시 틀거나 [트라이앵글 → 오모플라타](../techniques/triangle-to-omoplata.md)

## 방어하는 쪽 (상대 입장)

- 라펠에 오른팔이 묶이고 상대 왼다리가 내 오른쪽 어깨 위로 올라오면 트라이앵글 신호
- 머리를 들어 등을 세우고 내 왼팔을 상대 다리 사이에서 빼 두 팔을 같이 둔다
- 다리가 목에 걸렸으면 잠기기 전에 → 트라이앵글 탈출 (자세 세우기)
- 이미 잠겼으면 → 트라이앵글 스택 탈출
