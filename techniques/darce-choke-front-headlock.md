# 다스 초크 (프론트 헤드락) (D'Arce Choke from Front Headlock)

[프론트 헤드락 · 길로틴](../positions/front-headlock.md) · 서브미션 · 위

다른 이름: 다스, 브라보 초크, 다르스, 다스초크

## 세팅 과정 (오른손잡이 기준)

1. 내 오른팔을 상대 왼쪽 겨드랑이 아래로 넣어 상대 목 오른쪽까지 깊게 꿰어 넣는다
2. 꿴 오른손으로 내 왼팔 이두를 잡고 내 왼손은 상대 머리 뒤에 둔다(8자 그립)
3. 상대 머리를 아래로 누르며 내 가슴을 상대 왼쪽 어깨에 싣는다
4. 엉덩이를 바닥에 내리고 상대 머리 쪽으로 걸어가며 가슴을 조인다
5. 천천히 조이고 탭하면 바로 푼다

## 핵심 디테일

- 오른팔을 상대 왼쪽 겨드랑이 아래로 넣어 목 오른쪽까지 깊게 꿴다
- 오른손이 왼팔 이두, 왼손은 상대 머리 뒤 — 그립을 잠근 뒤에 움직인다
- 가슴을 상대 왼쪽 어깨에 실어 갇힌 팔을 목에 붙인다
- 엉덩이를 내리고 상대 머리 쪽으로 걸어가며 조인다

## 흔한 실수

- 그립 없이 먼저 돌면 상대가 팔을 뺀다 → 8자 그립부터 잠근다
- 가슴과 어깨 사이가 뜨면 안 조인다 → 가슴을 어깨에 무겁게 붙인다
- 팔힘으로 짜면 지친다 → 걸어 들어가는 각도로 조인다

## 막히면

- 상대가 갇힌 팔을 빼거나 각이 안 나오면 → [다스 ↔ 아나콘다 전환](../techniques/darce-to-anaconda-switch.md)
- 상대가 엎드려 버티면 → [재패니즈 넥타이](../techniques/japanese-necktie.md)
- 조임이 안 들어오면 → 그립을 풀고 [프론트 헤드락 → 백](../techniques/front-headlock-to-back.md)

## 방어하는 쪽 (상대 입장)

- 상대 오른팔이 내 왼쪽 겨드랑이 아래로 꿰어 들어오면 → 왼쪽 팔꿈치를 몸에 붙이고 턱을 당긴다
- 그립이 잠기기 전에 → 왼팔을 빼내거나 오른손으로 상대 골반을 밀어 프레임을 세운다 (다스 방어)
- 깊게 잠겼으면 → 백 도어 이스케이프 (다스), 늦었으면 바로 탭한다
