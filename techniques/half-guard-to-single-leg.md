# 하프가드 → 싱글 레그 (Half Guard to Single Leg)

[하프가드](../positions/half-guard.md) · 스윕 · 아래 → [사이드 컨트롤](../positions/side-control.md) / [하프가드](../positions/half-guard.md)

다른 이름: 하프 싱글, 언더훅 싱글 레그

## 세팅 과정 (오른손잡이 기준)

1. 상대 오른다리를 감은 하프에서 내 왼팔 언더훅, 오른쪽 어깨와 엉덩이를 바닥에 대고 머리를 상대 오른쪽 겨드랑이 아래로 뺀다
2. 무릎으로 일어나며 감았던 상대 오른다리를 양팔로 안는다
3. 머리를 상대 오른쪽 옆구리에 붙이고 일어선다
4. 안은 오른다리를 들어 올리며 밀어 넘어뜨리고 위로 올라온다

## 핵심 디테일

- 내 왼팔 언더훅을 깊게 잡은 뒤 머리를 상대 오른쪽 겨드랑이 밑으로 빼낸다
- 머리는 상대 가슴 앞이 아니라 상대 오른쪽 옆구리에 붙인다
- 무릎으로 올라오면 멈추지 말고 상대 오른다리를 안고 바로 일어선다
- 일어서면 다리를 들어 올리며 상대 오른쪽 뒤로 밀어 넘긴다

## 흔한 실수

- 언더훅 없이 일어나면 위저에 눌려 다시 눕는다 → 언더훅 먼저
- 머리가 상대 가슴 앞에 있으면 길로틴·프론트 헤드락을 당한다 → 머리를 옆구리로
- 무릎 꿇은 채 오래 있으면 상대가 스프롤로 누른다 → 바로 일어선다

## 막히면

- 상대가 위저로 눌러 오면 → [도그파이트 → 하프가드 복귀](../techniques/re-pull-half-guard-from-dogfight.md)
- 상대가 엉덩이를 빼 스프롤하면 → [도그파이트 전진 스윕](../techniques/forward-drive-sweep-from-dogfight.md)
- 서서 다리를 안았는데 버티면 → [싱글 레그 테이크다운](../techniques/single-leg-takedown.md)

## 방어하는 쪽 (상대 입장)

- 상대 왼팔 언더훅이 깊어지고 상대 머리가 내 오른쪽 겨드랑이 밑으로 빠져나오면 신호
- 내 오른팔 위저로 상대 왼팔을 감고 엉덩이를 뒤로 빼 스프롤한다
- 상대 머리를 눌러 낮게 묶어 둔다
- 다리를 안고 일어섰으면 → 스프롤 (테이크다운 방어)
