# 마운티드 트라이앵글 이스케이프 (Escape Mounted Triangle)

[마운트](../positions/mount.md) · 탈출 · 아래 → [하프가드](../positions/half-guard.md) / [클로즈드 가드](../positions/closed-guard.md)

다른 이름: 마운트 트라이앵글 탈출

## 세팅 과정 (오른손잡이 기준)

1. 상대가 내 오른팔을 안에 넣고 걸면 턱을 당기고 오른 팔꿈치를 몸 쪽으로 당겨 목에 공간을 만든다
2. 양손으로 상대 허벅지나 골반을 잡고 내 머리 쪽으로 강하게 브릿지한다
3. 상대가 앞으로 넘어가 손을 짚으면 다리 걸림이 느슨해진 틈에 머리를 뺀다
4. 엉덩이를 빼며 무릎을 넣어 하프가드나 가드로 돌아온다

## 핵심 디테일

- 먼저 턱을 당기고 오른 팔꿈치를 몸 쪽으로 당겨 목 공간을 확보한다
- 양손을 상대 허벅지·골반에 대고 내 머리 쪽으로 크게 브릿지한다
- 상대가 앞으로 쏠려 손을 짚는 순간 다리가 느슨해진다 — 그때 머리를 뺀다
- 머리가 빠지면 바로 엉덩이를 빼고 무릎을 넣는다

## 흔한 실수

- 갇힌 오른팔을 뻗어 밀면 바로 암바가 온다 → 팔꿈치를 굽혀 몸에 붙인다
- 누운 채 힘으로 다리를 벌리려 하면 조임만 깊어진다 → 브릿지로 상대 무게부터 띄운다
- 머리를 뺀 뒤 멈추면 다시 마운트를 내준다 → 바로 무릎을 넣어 가드로 간다

## 막히면

- 상대가 갇힌 오른팔을 펴 암바로 바꾸면 → [히치하이커 이스케이프](../techniques/hitchhiker-escape.md)
- 상대가 뒤로 굴러 가드 트라이앵글로 가면 → [트라이앵글 탈출 (자세 세우기)](../techniques/triangle-escape-posture.md)

## 방어하는 쪽 (상대 입장)

- 상대가 내 허벅지를 잡고 팔꿈치를 붙이면 브릿지 탈출 신호
- 손을 상대 머리 위쪽 바닥에 짚고 무릎을 넓혀 브릿지를 받아 낸다
- 상대가 팔꿈치를 붙여 버티면 → 갇힌 오른팔로 마운트 암바
- 크게 넘어가면 그대로 굴러 트라이앵글 초크로 마무리한다
