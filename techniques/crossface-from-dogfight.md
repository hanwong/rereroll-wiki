# 크로스페이스 (도그파이트 탑) (Crossface from Dogfight)

[하프가드](../positions/half-guard.md) · 패스 · 위 → [사이드 컨트롤](../positions/side-control.md)

다른 이름: 도그파이트 크로스페이스

## 세팅 과정 (오른손잡이 기준)

1. 내 오른팔 위저를 겨드랑이에 꽉 붙여 상대 왼팔 언더훅을 묶는다
2. 내 왼팔뚝을 상대 턱 앞으로 넣고 왼쪽 어깨로 얼굴을 상대 오른쪽으로 돌린다
3. 상대 등이 바닥에 닿게 몸으로 눌러 눕힌다
4. 감긴 오른다리를 빼고 가슴을 붙여 사이드 컨트롤로

## 핵심 디테일

- 내 오른팔 위저는 끝까지 조여 상대 왼팔 언더훅을 묶어 둔다
- 손바닥으로 얼굴을 미는 게 아니라 왼팔뚝과 왼쪽 어깨를 상대 턱에 대고 아래로 누른다
- 엉덩이를 낮게 떨어뜨려 무게를 상대 몸에 싣는다
- 상대 등이 완전히 바닥에 닿은 뒤에 감긴 오른다리를 뺀다

## 흔한 실수

- 눕히기 전에 다리부터 빼면 상대가 다시 무릎으로 올라온다 → 먼저 등을 바닥에 붙인다
- 손으로 얼굴을 밀면 상대가 쉽게 고개를 돌려 버틴다 → 팔뚝과 어깨로 턱을 누른다
- 엉덩이를 들고 누르면 상대가 밑에서 밀어 올린다 → 엉덩이를 낮춘다

## 막히면

- 상대가 머리를 내 가슴에 박아 크로스페이스가 안 들어가면 → [스냅 다운 (도그파이트 탑)](../techniques/snap-down-from-dogfight.md)
- 상대가 눕긴 했는데 다리를 꽉 감으면 → [하프가드 → 쿼터 가드 (탑)](../techniques/half-guard-to-quarter-guard.md)
- 상대가 왼쪽 무릎 니 쉴드를 세우면 → [레그 위브 패스](../techniques/leg-weave-pass.md)

## 방어하는 쪽 (상대 입장)

- 상대 왼팔뚝이 내 턱 앞으로 들어오면 신호
- 턱을 당기고 머리를 상대 가슴에 붙여 팔이 들어올 틈을 안 준다
- 왼팔 언더훅을 깊게 유지하고 앞으로 밀어 상대가 누를 시간을 주지 않는다
- 이미 눌렸으면 → 눌린 하프가드에서 회복
