# 고고플라타 마무리 (Gogoplata Finish)

[서브미션 걸린 뒤 (암바 · 기무라 · 오모플라타 · 트라이앵글)](../positions/submission-control.md) · 서브미션 · 아래

다른 이름: 고고플라타, Gogoplata, 정강이 초크

## 세팅 과정 (오른손잡이 기준)

1. 내 왼쪽 정강이를 상대 목 앞에 가로로 대고, 왼발은 상대 오른쪽 어깨 너머로 넘긴 상태에서 시작한다
2. 양손으로 상대 뒷머리를 깍지 끼어 잡는다(손이 닿으면 내 왼발끝을 잡아도 된다)
3. 내 오른다리로 상대 등이나 골반을 눌러 상대가 자세를 세우지 못하게 한다
4. 머리를 당기면서 왼쪽 정강이를 목 쪽으로 밀어 넣어 탭을 받는다

## 핵심 디테일

- 상대 자세를 완전히 무너뜨려 머리가 내 가슴 가까이 와 있어야 한다
- 종아리 살이 아니라 왼쪽 정강이 뼈를 목 앞에 가로로 댄다
- 내 오른다리로 상대 등이나 골반을 눌러 자세를 못 세우게 한다
- 두 손으로 뒷머리를 당기며 정강이를 천천히 밀어 넣는다

## 흔한 실수

- 상대가 자세를 세운 채 정강이를 넣으면 밀려 나간다 → 먼저 머리를 당겨 무너뜨린다
- 종아리 쪽이 목에 닿으면 안 조인다 → 정강이 뼈가 목에 오게 한다
- 세게 밀면 목이 다칠 수 있다 → 천천히 밀고 탭하면 바로 푼다

## 막히면

- 상대가 머리를 빼며 일어서면 → 왼다리로 상대 오른쪽 어깨를 감아 [오모플라타](../techniques/omoplata.md)
- 정강이가 목까지 안 들어가면 → [트라이앵글 초크](../techniques/triangle-choke.md)

## 방어하는 쪽 (상대 입장)

- 상대 왼발이 내 오른쪽 어깨 너머로 올라오고 정강이가 목 쪽으로 오면 고고플라타 신호
- 바로 턱을 당기고 자세를 세워 머리를 상대 가슴에서 뗀다
- 이미 걸렸으면 두 손으로 정강이를 밀어 목에서 떼고 고고플라타 방어 (자세 세우기), 숨이 막히면 탭
