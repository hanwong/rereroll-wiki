# 밭뒤축후리기 (Kosoto Gari)

[스탠딩 · 테이크다운](../positions/standing.md) · 테이크다운 · 서서 → [사이드 컨트롤](../positions/side-control.md)

다른 이름: 코소토가리, 바깥 발목 후리기, 코소토

## 세팅 과정 (오른손잡이 기준)

1. 상대를 상대 오른쪽 뒤로 밀어 상대 오른발 뒤꿈치에 체중을 싣게 한다
2. 내 왼발 발바닥으로 상대 오른발 뒤꿈치 바깥쪽을 쓸어 낸다
3. 상체는 상대 오른쪽 뒤로 눌러 넘긴다
4. 넘어가면 바로 사이드로

## 핵심 디테일

- 상대를 상대 오른쪽 뒤로 밀어 체중을 상대 오른발 뒤꿈치에 싣는다
- 내 왼발 발바닥으로 상대 오른발 뒤꿈치 바깥을 상대 발끝 방향으로 쓸어 낸다
- 쓸 때 상체는 상대 오른쪽 뒤로 눌러 발과 손이 함께 움직이게 한다
- 크게 휘두르지 말고 바닥을 스치듯 빠르게

## 흔한 실수

- 체중이 실리지 않은 발을 쓸면 발만 움직이고 상대는 선다 → 먼저 뒤꿈치에 체중을 싣는다
- 발로만 쓸고 상체를 안 누르면 상대가 다시 딛는다 → 손과 발을 같은 순간에
- 거리가 멀면 내 다리가 펴져 내가 흔들린다 → 왼발이 닿을 거리까지 붙는다

## 막히면

- 상대가 오른발을 빼면 → 체중이 남은 왼발에 [안다리후리기](../techniques/o-uchi-gari.md)
- 상대가 뒤로 버티며 서 있으면 → 다리를 감아 [밭뒤축걸기](../techniques/kosoto-gake.md)
- 상대가 앞으로 밀고 들어오면 → [업어치기](../techniques/seoi-nage.md)

## 방어하는 쪽 (상대 입장)

- 상대가 나를 내 오른쪽 뒤로 밀고 상대 왼발이 내 오른발 뒤꿈치 바깥으로 오면 밭뒤축후리기 신호
- 뒤꿈치에 체중을 두지 말고 무릎을 굽혀 체중을 가운데로 되돌린다
- 쓸리는 순간 오른발을 들어 피하고 다시 넓게 딛는다
- 이미 넘어가면 낙법하고 바로 상대 쪽으로 몸을 돌려 하프가드나 가드를 잡는다
