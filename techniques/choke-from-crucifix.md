# 초크 (크루시픽스) (Choke from Crucifix)

[터틀 · 크루시픽스](../positions/turtle.md) · 서브미션 · 위

다른 이름: 크루시픽스 초크, 크루시픽스 깃 초크

## 세팅 과정 (오른손잡이 기준)

1. 크루시픽스에서 상대 왼팔은 내 다리로, 오른팔은 내 왼손으로 가둔 상태를 유지한다
2. 내 오른손을 상대 턱 아래로 넣어 상대 오른쪽 깃(노기는 팔뚝)을 깊게 잡는다
3. 가슴을 펴고 등을 뒤로 눕히며 상대 턱을 올린다
4. 천천히 조이고 탭하면 바로 푼다

## 핵심 디테일

- 상대 두 팔이 다 묶여 있어야 한다 — 왼팔은 내 다리, 오른팔은 내 왼손
- 오른손을 턱 아래로 깊게 넣어 상대 오른쪽 깃(노기는 팔뚝)을 건다
- 등을 뒤로 눕히며 가슴을 펴 상대 턱을 들어 올린다
- 천천히 조이고 탭하면 바로 푼다

## 흔한 실수

- 오른팔을 잡은 왼손을 놓으면 상대가 그 손으로 깃을 막는다 → 왼손은 끝까지 잡는다
- 깃을 얕게 잡으면 조이지 않는다 → 손을 목 뒤까지 깊게 넣는다
- 다리 잠금이 풀리면 상대 왼팔이 빠진다 → 발을 걸어 둔다

## 막히면

- 상대가 턱을 당겨 손이 안 들어가면 → [암바 (크루시픽스)](../techniques/armbar-from-crucifix.md)
- 상대 오른팔이 굽어 있으면 → [기무라 (크루시픽스)](../techniques/kimura-from-crucifix.md)

## 방어하는 쪽 (상대 입장)

- 내 왼팔이 상대 다리에, 오른팔이 상대 왼손에 묶이고 상대 오른손이 내 턱 아래로 오면 초크 신호
- 턱을 당기고 오른팔을 빼 손으로 목과 깃을 지킨다
- 두 팔이 묶이기 전에 빠져야 한다 — 이미 조여 오면 바로 탭한다
