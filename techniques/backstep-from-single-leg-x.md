# 백스텝 (싱글 레그 X 상대) (Backstep from Single Leg X)

[X 가드 · 싱글 레그 X · 앵클락](../positions/x-guard.md) · 패스 · 위 → [사이드 컨트롤](../positions/side-control.md)

다른 이름: SLX 백스텝

## 세팅 과정 (오른손잡이 기준)

1. 상대가 내 왼다리에 싱글 레그 X를 걸었을 때, 내 왼쪽 골반에 댄 상대 오른발을 손으로 눌러 떼어낸다
2. 자유로운 오른다리에 체중을 싣는다
3. 오른다리를 상대 엉덩이 뒤로 돌려 디디며 몸을 반 바퀴 돌린다
4. 잡힌 왼다리가 풀리면 가슴을 붙이고 크로스페이스로 사이드를 잡는다

## 핵심 디테일

- 내 왼쪽 골반에 댄 상대 오른발부터 떼야 돌 때 상대가 따라붙지 못한다
- 돌기 전에 체중을 오른다리에 완전히 싣는다
- 한 번 돌기 시작하면 멈추지 않는다 — 중간에 멈추면 등이 보인다
- 착지하자마자 엉덩이를 내리고 크로스페이스로 붙인다

## 흔한 실수

- 골반 훅이 그대로인 채 돌면 → 상대가 훅으로 따라와 다시 가드 → 먼저 뗀다
- 선 채로 크게 돌면 → 균형을 잃고 넘어간다 → 무릎 굽혀 낮게 돈다
- 돌고 나서 머뭇거리면 → 상대가 무릎을 넣어 가드를 되찾는다 → 바로 가슴을 붙인다

## 막히면

- 상대가 발로 따라와 다시 걸면 → [싱글 레그 X 빠져나오기 (서서)](../techniques/standing-escape-from-slx.md)
- 상대가 내 왼발을 겨드랑이에 끼워 앵클락을 노리면 → [앵클락 빠져나오기](../techniques/ankle-lock-escape.md)
- 착지 뒤 상대가 다리를 하프가드로 감으면 → [하프가드 패스 (크로스페이스 · 언더훅)](../techniques/half-guard-pass.md)
- 상대가 내 다리를 삼각형으로 감아 오면 → [하체 관절기 방어 (무릎 선 지키기 · 뒤꿈치 숨기기)](../techniques/heel-hook-defense-knee-line.md)

## 방어하는 쪽 (상대 입장)

- 상대가 내 오른발을 골반에서 떼고 오른다리에 체중을 실으면 백스텝 신호
- 돌기 전에 오른발을 다시 골반에 대고 상대 왼다리를 가슴으로 당겨 균형을 뺏는다
- 돌기 시작하면 엉덩이로 따라가며 발을 다시 건다
- 이미 돌았으면 팔로 상대 골반에 프레임하고 무릎을 넣어 가드를 되찾는다
