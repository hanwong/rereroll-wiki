# 터틀에서 싱글 레그 (Single Leg from Turtle)

[터틀 · 크루시픽스](../positions/turtle.md) · 탈출 · 아래 → [패스](../positions/passing.md) / [사이드 컨트롤](../positions/side-control.md)

다른 이름: 터틀 싱글렉, 싱글 레그 (터틀), 레슬 업

## 세팅 과정 (오른손잡이 기준)

1. 상대가 내 왼쪽 옆에 있을 때, 터틀에서 두 팔로 상대 왼다리를 감싸 가슴에 붙인다
2. 내 머리를 상대 왼쪽 옆구리에 붙이고 내 왼발을 바닥에 세운다
3. 상대 왼다리를 잡은 채 베이스를 잡고 일어선다
4. 상대 왼다리를 들어 올려 넘어뜨리고 탑 포지션을 잡는다

## 핵심 디테일

- 상대가 내 등에 무게를 덜 싣고 옆에 떠 있을 때 바로 다리를 잡는다
- 두 팔로 상대 왼다리를 감아 내 가슴에 꽉 붙인다
- 머리를 상대 왼쪽 옆구리에 붙이고 등을 곧게 세운다
- 왼발부터 바닥에 세워 다리를 몸에 붙인 채 일어선다

## 흔한 실수

- 머리가 처지면 길로틴이나 다스에 걸린다 → 머리를 상대 옆구리에 붙이고 턱을 든다
- 무릎으로만 밀고 들어가면 상대가 다리를 빼고 누른다 → 발을 세워 먼저 일어선다
- 다리를 손끝으로만 잡으면 빠진다 → 가슴에 붙여 안는다

## 막히면

- 상대가 다리를 뒤로 빼며 누르면 → [싯아웃 (터틀 탈출)](../techniques/sit-out.md) 이나 [터틀 → 가드 회복](../techniques/turtle-to-guard.md)
- 상대가 내 목을 감으면 → [길로틴 방어](../techniques/guillotine-defense.md)
- 일어선 뒤 상대가 외다리로 버티면 → [싱글 레그 테이크다운](../techniques/single-leg-takedown.md) 마무리로 넘어뜨린다

## 방어하는 쪽 (상대 입장)

- 터틀한 상대가 두 팔로 내 왼다리를 감으면 → 왼다리를 뒤로 빼며 엉덩이를 낮춰 스프롤한다
- 가슴으로 상대 등을 누르고 상대 머리를 바닥 쪽으로 낮춘다
- 상대 머리가 내려와 있으면 → 프론트 헤드락이나 길로틴 그립을 잡는다
- 이미 일어섰으면 → 한 발로 균형을 잡고 상대 머리를 아래로 누르며 잡힌 왼다리를 빼낸다
