# 더블 슬리브 가드 (Double Sleeve Guard)

[스파이더 · 라쏘 · 소매 가드](../positions/spider-lasso.md) · 자세 · 컨트롤 · 아래 → [스파이더 · 라쏘 · 소매 가드](../positions/spider-lasso.md)

다른 이름: 양 소매 가드, 더블 슬리브, 양소매

## 세팅 과정 (오른손잡이 기준)

1. 내 왼손으로 상대 오른쪽 소매를, 오른손으로 상대 왼쪽 소매를 잡고 팔을 뻗게 한다
2. 내 왼발은 상대 오른쪽 이두나 골반에, 오른발은 상대 왼쪽 이두나 골반에 둔다
3. 왼발로 밀 때 오른발은 당기며 상대 자세를 흔든다
4. 스파이더 · 라쏘 · 데라히바로 바꿀 준비

## 핵심 디테일

- 두 소매를 잡아 상대 팔을 펴 두면 상대가 내 다리를 잡거나 누르지 못한다
- 발은 이두나 골반에 두고 밀고 당기기를 번갈아 상대 자세를 흔든다
- 상대 반응에 따라 스파이더 · 라쏘 · 데라히바로 바로 바꾼다

## 흔한 실수

- 소매만 잡고 발이 쉬면 상대가 다리를 넘어 패스한다 → 발로 계속 밀고 당긴다
- 팔을 굽혀 소매를 당기기만 하면 상대가 다가와 눌러 온다 → 상대 팔을 펴 둬 거리를 지킨다

## 막히면

- 상대가 소매를 뿌리치려 팔을 당기면 → [라쏘 가드](../techniques/lasso-guard.md)로 팔을 감는다
- 상대가 다리를 앞으로 내디디면 → [더블 슬리브 → 데라히바](../techniques/double-sleeve-to-de-la-riva.md)
- 상대가 앞으로 기대면 → [오모플라타 (더블 슬리브)](../techniques/omoplata-from-double-sleeve.md)

## 방어하는 쪽 (상대 입장)

- 상대 두 손이 내 두 소매를 잡고 팔을 펴게 밀면 더블 슬리브 신호
- 팔꿈치를 몸 쪽으로 당겨 붙이고 손목을 돌려 소매 그립을 끊는다
- 그립이 남아 있으면 자세를 세우고 엉덩이를 낮춰 끌려가지 않게 한 뒤 스파이더 가드 패스로 간다
