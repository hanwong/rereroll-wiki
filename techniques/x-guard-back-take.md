# X 가드 → 백 테이크 (X-Guard to Back Take)

[X 가드 · 싱글 레그 X · 앵클락](../positions/x-guard.md) · 백 테이크 · 아래 → [백 컨트롤](../positions/back-control.md)

다른 이름: X가드 백, 엑스 가드 백 잡기

## 세팅 과정 (오른손잡이 기준)

1. X 가드에서 두 훅으로 상대 오른다리를 밀어 상대가 몸을 돌리게 한다
2. 상대 등이 보이면 오른쪽 어깨의 상대 왼다리를 내리고 내 오른손으로 허리띠나 허리를 잡는다
3. 내 왼발 훅으로 상대 오른쪽 무릎 뒤를 당겨 앉히며 등 뒤로 올라온다
4. 가슴을 등에 붙이고 훅을 넣어 백 컨트롤을 완성한다

## 핵심 디테일

- 상대가 X 가드에서 버티며 몸을 돌릴 때가 기회 — 억지로 돌리지 않는다
- 상대 왼다리를 내리는 순간 내 오른손으로 허리띠를 잡아 연결을 유지한다
- 내 왼발 훅으로 상대 오른쪽 무릎 뒤를 당겨 엉덩이를 바닥에 앉힌다
- 올라가면 가슴을 등에 붙이고 시트벨트 먼저, 훅은 그다음

## 흔한 실수

- 상대가 정면일 때 무리하면 → 등이 안 보인다 → X 가드 스윕을 먼저 보여 상대가 돌게 만든다
- 허리띠를 놓고 오르면 → 상대가 앞으로 기어 빠진다 → 허리띠를 끝까지 잡는다
- 상대를 앉히지 않고 오르면 → 서 있는 상대 등에 매달린다 → 무릎 뒤를 당겨 앉힌다

- 상대가 다리를 빼려 하면 → [X 가드 → 싱글 레그 X](../techniques/x-guard-to-single-leg-x.md)

## 방어하는 쪽 (상대 입장)

- 상대 두 훅이 내 오른다리를 밀어 몸이 돌아가고 상대 손이 내 허리띠로 오면 백 신호
- 등을 보이게 돌지 말고 엉덩이를 낮추며 상대 쪽으로 몸을 다시 돌린다
- 상대 오른손의 허리띠 그립을 떼어 상대가 붙을 손잡이를 없앤다
- 이미 등에 붙었으면 훅이 들어오기 전에 손 싸움부터 → 핸드 파이팅 (백 아래)
