# 신 투 신 가드 풀링 (Shin-to-Shin Guard Pull)

[클린치 · 가드 풀링](../positions/clinch.md) · 가드 풀링 · 서서 → [오픈 가드](../positions/open-guard.md)

다른 이름: 신투신 풀링, 시팅 신 투 신, Pull to Shin-to-Shin

## 세팅 과정 (오른손잡이 기준)

1. 내 오른손으로 상대 왼쪽 소매(또는 깃)를 잡고 상대에게 가까이 다가선다
2. 상대 오른발(앞다리) 쪽으로 엉덩이를 낮춰 앉는다
3. 앉으면서 내 왼쪽 정강이를 상대 오른쪽 정강이 안쪽에 댄다
4. 내 왼손으로 상대 오른쪽 발목(바지)을 잡고, 오른발은 바닥에 두어 버틴다
5. 신 투 신 가드로 끝난다

## 핵심 디테일

- 앉기 전 내 오른손 그립으로 상대를 붙잡아 상대가 물러나지 못하게 한다
- 상대 오른발(앞다리) 바로 앞에 엉덩이를 내려야 정강이가 닿는다
- 내 왼쪽 정강이를 상대 오른쪽 정강이 안쪽에 비스듬히 붙여 계속 압력을 준다
- 왼손 발목 그립과 왼쪽 정강이로 상대 오른다리를 한 묶음으로 잡는다

## 흔한 실수

- 상대 다리에서 멀리 앉으면 정강이가 안 닿고 상대가 돌아간다 → 앞다리 바로 앞에 앉는다
- 등을 대고 누우면 상대가 다리를 눌러 패스한다 → 상체를 세워 앉는다
- 발목 그립 없이 정강이만 대면 상대가 다리를 뺀다 → 왼손으로 오른쪽 발목을 잡는다

## 막히면

- 상대가 체중을 오른다리에 실으면 → [신 투 신 스윕](../techniques/shin-to-shin-sweep.md)
- 상대가 무릎을 굽혀 눌러 오면 → [신 투 신 → 싱글 레그 X](../techniques/shin-to-shin-to-single-leg-x.md)
- 상대가 오른다리를 뒤로 빼면 → [테크니컬 스탠드업 → 싱글 레그](../techniques/technical-stand-up-to-single-leg.md)

## 방어하는 쪽 (상대 입장)

- 상대가 내 오른발 앞에 앉으며 정강이를 대면 → 신 투 신 신호
- 앉기 전에 내 오른발을 뒤로 빼 거리를 둔다
- 내 오른쪽 발목을 잡은 상대 왼손부터 떼어 낸다
- 이미 자리 잡았으면 → 신 투 신 가드 패스
