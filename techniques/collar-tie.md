# 칼라 타이 (Collar Tie)

[클린치 · 가드 풀링](../positions/clinch.md) · 자세 · 컨트롤 · 서서 → [클린치 · 가드 풀링](../positions/clinch.md)

다른 이름: 칼라타이, 목 잡기, 넥 타이, 헤드 컨트롤

## 세팅 과정 (오른손잡이 기준)

1. 내 오른손으로 상대 목 뒤를 잡고 오른쪽 팔꿈치를 아래로 내려 머리를 누른다
2. 내 왼손은 상대 오른쪽 팔꿈치나 손목을 잡아 팔을 묶는다
3. 머리를 당기고 밀어 상대가 발을 옮기게 하며 균형을 흔든다
4. 상대가 머리를 들면 스냅 다운, 자세를 세우면 덕 언더나 테이크다운으로 잇는다

## 핵심 디테일

- 손바닥으로 목 뒤를 감싸 쥐고 팔뚝을 상대 쇄골 앞에 두어 거리를 막는다
- 머리를 끌어내릴 땐 오른쪽 팔꿈치를 아래로 떨어뜨리며 체중을 싣는다
- 내 왼손으로 상대 오른팔을 묶어 상대가 내 목을 잡지 못하게 한다
- 밀고 당기기를 섞어 상대 발이 따라오게 만든다

## 흔한 실수

- 오른쪽 팔꿈치가 벌어지면 상대가 그 팔 아래로 파고든다 → 팔꿈치를 내려 상대 가슴 앞에 둔다
- 목만 잡고 서 있으면 상대가 다리를 공격한다 → 계속 흔들어 자세를 무너뜨린다
- 나도 같이 숙이면 머리 싸움에서 진다 → 허리를 세운다

## 막히면

- 상대가 머리를 숙이면 → [스냅 다운](../techniques/snap-down-from-standing.md)
- 상대가 자세를 세우고 버티면 → [덕 언더](../techniques/duck-under.md)
- 상대가 오른팔을 빼려 하면 → [암 드래그 (스탠딩)](../techniques/arm-drag-standing.md)

## 방어하는 쪽 (상대 입장)

- 상대 오른손이 내 목 뒤를 잡고 누르면 → 턱을 들고 허리를 세워 머리가 끌려 내려가지 않게 한다
- 내 왼팔을 상대 오른팔 안쪽으로 넣어 팔꿈치를 바깥으로 밀어낸다
- 나도 오른손으로 상대 목 뒤를 잡아 맞선다
- 상대 오른팔이 들려 공간이 생기면 → 덕 언더
