# 텐 핑거 길로틴 (Ten Finger Guillotine)

[프론트 헤드락 · 길로틴](../positions/front-headlock.md) · 서브미션 · 위

다른 이름: 열 손가락 길로틴, 텐핑거 길로틴

## 세팅 과정 (오른손잡이 기준)

1. 상대 목을 감은 내 오른손과 왼손을 열 손가락으로 깍지 끼듯 맞잡는다
2. 두 팔꿈치를 모아 상대 머리를 내 가슴에 붙인다
3. 오른쪽 손목 날로 상대 턱을 위로 들어 올리며 가슴을 편다
4. 천천히 조이고 탭하면 바로 푼다

## 핵심 디테일

- 그립을 바꾸기 전에 팔이 목 앞에 깊이 들어가 있는지 먼저 확인한다
- 두 팔꿈치를 모아 상대 머리를 내 가슴에 붙인다
- 오른손목 날을 위로 올리며 가슴을 편다 — 이두보다 어깨와 등으로 당긴다
- 그립을 바꾸는 동안 다리와 머리 압박을 놓지 않는다

## 흔한 실수

- 깍지를 끼느라 압박이 풀리면 상대가 자세를 세운다 → 오른팔로 머리를 누른 채 손만 바꾼다
- 이두로만 짜면 금방 지친다 → 팔꿈치를 몸에 붙이고 어깨를 으쓱하듯 당긴다
- 홱 당기면 목을 다친다 → 천천히 조이고 탭하면 바로 푼다

## 막히면

- 상대가 손목을 당겨 깍지를 떼면 → [길로틴 마무리](../techniques/guillotine-choke-finish.md) 기본 그립으로 바꾼다
- 상대 왼팔이 같이 들어오면 → [암 인 길로틴](../techniques/arm-in-guillotine.md)
- 상대가 자세를 세우면 → [힙 범프 스윕](../techniques/hip-bump-sweep.md)

## 방어하는 쪽 (상대 입장)

- 상대 두 손이 내 목 앞에서 깍지로 잠기면 → 턱을 당기고 두 손으로 상대 손목을 당겨 공간을 만든다
- 상대가 가슴을 펴기 전에 → 길로틴 방어처럼 내 왼팔을 상대 오른쪽 어깨 너머로 넘겨 옆으로 돈다
- 이미 조여 오면 → 늦었으면 바로 탭한다
