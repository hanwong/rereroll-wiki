# 트라이앵글 (스파이더) (Triangle from Spider Guard)

[스파이더 · 라쏘 · 소매 가드](../positions/spider-lasso.md) · 서브미션 · 아래

다른 이름: 스파이더 트라이앵글

## 세팅 과정 (오른손잡이 기준)

1. 내 왼발로 상대 오른팔을 바깥으로 밀어 두고, 오른손으로 상대 왼쪽 소매를 당겨 안쪽에 둔다
2. 이두를 밀던 내 왼다리를 떼어 상대 목 뒤로 넘긴다
3. 내 오른쪽 오금에 왼쪽 발목을 걸어 삼각형을 만든다(상대 왼팔은 삼각형 안에 갇힌다)
4. 머리를 당기며 무릎을 조여 조른다

## 핵심 디테일

- 왼발로 상대 오른팔을 밀어내고 오른손으로 상대 왼팔을 당겨 두 팔을 벌려 놓는다
- 이두에서 왼발을 뗄 때도 오른손 소매 그립은 놓지 않는다
- 팔로 당기지 말고 엉덩이를 들어 왼다리를 상대 목 뒤 높이 넘긴다
- 잠근 뒤 정면에서 조이지 말고 엉덩이를 틀어 각도를 만들고 머리를 당긴다

## 흔한 실수

- 두 팔이 다 안쪽이거나 다 바깥이면 조르기가 안 된다 → 상대 왼팔만 안에 가둔다
- 정면에서 조이면 힘만 들고 안 조여진다 → 각도를 틀어 조인다
- 머리를 안 당기면 상대가 자세를 세워 빠진다 → 머리를 계속 당긴다

## 막히면

- 상대가 자세를 세워 버티면 → [트라이앵글 → 암바](../techniques/triangle-to-armbar.md)
- 상대가 스택으로 누르면 → 각도를 다시 틀거나 [트라이앵글 → 오모플라타](../techniques/triangle-to-omoplata.md)
- 다리를 목으로 못 넘기면 → [오모플라타 (스파이더)](../techniques/spider-guard-to-omoplata.md)

## 방어하는 쪽 (상대 입장)

- 상대 왼발이 내 오른쪽 이두에서 떨어지고 내 왼팔이 상대 쪽으로 끌려가면 트라이앵글 신호
- 내 왼팔을 빼 두 팔을 같이 몸 앞에 두고 자세를 세워 다리가 목에 못 오게 한다
- 다리가 목에 걸렸으면 잠기기 전에 → 트라이앵글 탈출 (자세 세우기)
- 이미 잠겼으면 → 트라이앵글 스택 탈출
