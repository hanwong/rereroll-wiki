# 곁누르기 → 사이드 (Kesa Gatame to Side Control)

[곁누르기](../positions/kesa-gatame.md) · 전환 · 위 → [사이드 컨트롤](../positions/side-control.md)

다른 이름: 케사가타메 → 사이드, 케사 사이드, 케사가타메 사이드 전환

## 세팅 과정 (오른손잡이 기준)

1. 목 감은 내 오른팔과 끼운 왼팔을 유지한 채 엉덩이를 들어 상대 쪽으로 돌린다
2. 뒤로 접었던 내 왼다리의 무릎을 상대 오른 옆구리에 붙이고 가슴을 상대 가슴에 포갠다
3. 목 감은 내 오른팔을 크로스페이스로 바꿔 상대 얼굴을 상대 왼쪽으로 돌린다
4. 끼웠던 내 왼팔은 상대 오른팔 아래 언더훅으로 바꾸고 왼 무릎과 왼 팔꿈치 사이를 붙인다

## 핵심 디테일

- 목 감은 팔을 크로스페이스로 바꾼 뒤에 끼운 팔을 푼다 → 잡는 곳을 한꺼번에 놓지 않는다
- 돌아오는 동안 가슴을 상대 가슴에서 떼지 않는다
- 왼 무릎을 상대 오른 옆구리에 붙여 무릎이 들어올 틈을 막는다

## 흔한 실수

- 머리 컨트롤을 먼저 놓으면 상대가 내 쪽으로 돌아 들어온다 → 크로스페이스부터 잡는다
- 곁누르기와 사이드 중간에서 멈추면 상대가 프레임을 만든다 → 한 번에 돌아온다
- 엉덩이를 높이 들고 돌면 → 상대가 무릎을 넣는다 → 엉덩이를 낮게 끌며 돈다

## 막히면

- 상대가 무릎을 넣으려 하면 → 무릎을 눌러 내리고 다시 [곁누르기](../positions/kesa-gatame.md)
- 상대가 엎드려 터틀로 가면 → [터틀에서 백 테이크](../techniques/turtle-back-take.md)
- 상대가 왼팔을 뻗어 밀면 → [사이드에서 마운트 가기](../techniques/side-to-mount.md) 또는 [아메리카나 (사이드)](../techniques/americana-side.md)

## 방어하는 쪽 (상대 입장)

- 상대가 엉덩이를 들어 내 몸 쪽으로 돌아오기 시작하면 → 사이드로 바꾸는 신호
- 그 순간 끼였던 오른팔을 빼 프레임을 만들고 엉덩이를 내 왼쪽으로 뺀다
- 상대와 나 사이에 오른 무릎을 넣어 가드로 돌아온다
- 이미 사이드가 되면 → 사이드 이스케이프 (프레임 · 쉬림프)
