# 암바 마무리 (Armbar Finish)

[서브미션 걸린 뒤 (암바 · 기무라 · 오모플라타 · 트라이앵글)](../positions/submission-control.md) · 서브미션 · 아래

다른 이름: 암바 피니시, 암바, 주지 가타메

## 세팅 과정 (오른손잡이 기준)

1. 두 손으로 상대 오른쪽 손목을 엄지가 천장으로 가게 잡고 오른팔을 내 가슴에 붙인다
2. 두 무릎을 모아 상대 오른쪽 팔꿈치를 가둔다
3. 두 뒤꿈치를 당겨 상대를 내 몸 쪽으로 조인다
4. 엉덩이를 천천히 들어 상대 오른쪽 팔꿈치를 편다
5. 탭하면 바로 푼다

## 핵심 디테일

- 상대 엄지가 천장을 보게 손목을 잡아 팔꿈치 방향을 맞춘다
- 두 무릎을 모아 상대 위팔을 조여 팔이 돌지 못하게 한다
- 엉덩이를 상대 어깨에 바짝 붙인 뒤 든다 — 팔을 당기기보다 엉덩이로 편다
- 뒤꿈치를 당겨 상대 몸을 바닥에 눌러 둔다

## 흔한 실수

- 엉덩이와 상대 어깨 사이가 뜨면 팔이 빠진다 → 엉덩이를 어깨 쪽으로 당겨 붙인다
- 엄지가 옆이나 아래로 돌아가 있으면 안 꺾인다 → 손목을 돌려 엄지를 위로 맞춘다
- 홱 들면 팔꿈치를 다친다 → 천천히 엉덩이를 들고 탭하면 바로 푼다

## 막히면

- 상대가 두 손을 맞잡아 버티면 → [암바 그립 풀기](../techniques/armbar-grip-break.md)
- 상대가 돌아 엎드리려 하면 → [벨리 다운 암바](../techniques/belly-down-armbar.md)
- 상대가 일어서며 스택하면 → [암바 → 트라이앵글](../techniques/triangle-from-armbar.md)

## 방어하는 쪽 (상대 입장)

- 상대 두 손이 내 오른쪽 손목을 잡고 다리가 내 얼굴 위로 오면 → 왼손으로 오른손을 맞잡아 팔꿈치를 굽힌다
- 그립이 풀리기 시작하면 → 히치하이커 이스케이프로 팔꿈치 방향을 바꾼다
- 상대 엉덩이가 올라오며 팔꿈치가 펴지면 → 늦었으면 바로 탭한다
