# 아메리카나 (테크니컬 마운트) (Americana from Technical Mount)

[마운트](../positions/mount.md) · 서브미션 · 위

다른 이름: 테크니컬 키락

## 세팅 과정 (오른손잡이 기준)

1. 내 왼손으로 상대 왼 손목을 잡아 상대 어깨 위쪽 바닥으로 밀어 눕힌다
2. 손목을 바닥에 눌러 상대 왼 팔꿈치를 90도로 만든다
3. 내 오른팔을 상대 왼팔 아래로 넣어 내 왼 손목을 잡는다(8자 그립)
4. 가슴으로 상대 왼 어깨를 고정하고 손목은 바닥에 둔 채 팔꿈치를 들어 꺾는다

## 핵심 디테일

- 상대 왼 손목을 상대 머리 위쪽 바닥에 붙여 팔꿈치를 90도로 만든다
- 내 오른팔은 상대 왼팔 아래로 깊게 넣어 내 왼 손목을 잡는다
- 가슴으로 상대 왼 어깨를 눌러 어깨가 뜨지 않게 한다
- 손목을 바닥에서 떼지 말고 상대 엉덩이 쪽으로 끌면서 팔꿈치를 든다

## 흔한 실수

- 손목이 바닥에서 뜨면 힘이 안 걸린다 → 손등을 바닥에 끌듯이 움직인다
- 팔꿈치가 펴져 90도가 무너지면 빠진다 → 다시 굽혀 팔꿈치를 상대 몸 가까이 둔다
- 어깨를 누르지 않으면 상대가 몸을 돌려 압력을 흘린다 → 가슴 체중을 어깨에 싣는다

## 막히면

- 상대가 팔을 쭉 펴서 버티면 → [암바 (테크니컬 마운트)](../techniques/armbar-from-technical-mount.md)
- 상대 왼손이 엉덩이 쪽으로 내려가면 → [기무라 (모디파이드 마운트)](../techniques/kimura-from-modified-mount.md)
- 상대가 엎드려 등을 보이면 → [테크니컬 마운트 → 백](../techniques/technical-mount-to-back.md)

## 방어하는 쪽 (상대 입장)

- 상대 왼손이 내 왼 손목을 잡아 머리 위쪽 바닥으로 밀면 아메리카나 신호
- 손목이 바닥에 닿기 전에 왼 팔꿈치를 몸에 붙이고 왼손으로 내 오른쪽 깃을 잡는다
- 8자 그립까지 잡히고 어깨가 눌렸으면 버티지 말고 탭한다
