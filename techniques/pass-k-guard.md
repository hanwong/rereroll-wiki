# 케이 가드 패스 (Pass K-Guard)

[오픈 가드](../positions/open-guard.md) · 패스 · 위 → [사이드 컨트롤](../positions/side-control.md)

다른 이름: K가드 패스, K-Guard Pass, Backstep from K-Guard

## 세팅 과정 (오른손잡이 기준)

1. 상대가 왼다리를 내 다리 사이에 넣어 K 가드를 만들면 허리를 낮추고 무릎을 모아 공간을 막는다
2. 내 오른손으로 상대 왼쪽 무릎을 바닥에 눌러 고정한다
3. 걸린 내 오른다리를 뒤로 빼면서 엉덩이를 낮춘다
4. 내 오른쪽 무릎을 상대 왼쪽 허벅지 위로 넘겨 니슬라이스로 지나간다
5. 상대 왼쪽에서 사이드 컨트롤로 끝난다

## 핵심 디테일

- 허리를 낮추고 무릎을 모아 상대가 밑으로 들어올 공간을 없앤다
- 내 오른손으로 상대 왼 무릎을 바닥에 눌러 다리를 고정한다
- 걸린 내 오른다리는 엉덩이를 낮춘 채 뒤로 빼야 들리지 않는다
- 오른 무릎을 상대 왼 허벅지 위로 넘겨 니슬라이스로 지나간다

## 흔한 실수

- 다리를 빼려고 똑바로 서면 상대가 밑으로 들어와 싱글 레그 X를 잡는다 → 엉덩이를 낮게 유지한다
- 걸린 다리를 힘으로 잡아 빼면 균형을 잃는다 → 상대 무릎을 먼저 누르고 다리를 뺀다
- 상체 컨트롤 없이 지나가면 상대가 다시 다리를 넣는다 → 크로스페이스나 깃 그립으로 상체를 잡고 지나간다

## 막히면

- 상대가 밑으로 들어와 다리를 감으면 → [싱글 레그 X 빠져나오기 (서서)](../techniques/standing-escape-from-slx.md)
- 상대가 쉬림프로 각도를 되찾으면 → 따라가 다시 무릎을 누르고 [니슬라이스 패스](../techniques/knee-slice-pass.md)
- 상대가 무릎을 세워 막으면 → [하프가드](../positions/half-guard.md)로 받아 [하프가드 패스 (크로스페이스 · 언더훅)](../techniques/half-guard-pass.md)

## 방어하는 쪽 (상대 입장)

- 상대가 엉덩이를 낮추고 오른손으로 내 왼 무릎을 바닥에 누르면 패스 신호
- 왼 무릎이 눌리기 전에 상대 오른 발목을 끌어 엉덩이를 그 다리 밑으로 넣어 케이 가드 → 싱글 레그 X
- 상대 오른 무릎이 내 왼 허벅지를 넘어오면 무릎을 세워 니 쉴드 하프가드로 받는다
