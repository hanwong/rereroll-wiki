# 테크니컬 마운트 → 백 (Technical Mount to Back Control)

[마운트](../positions/mount.md) · 백 테이크 · 위 → [백 컨트롤](../positions/back-control.md)

다른 이름: 테크니컬 마운트 백

## 세팅 과정 (오른손잡이 기준)

1. 테크니컬 마운트에서 내 왼팔은 상대 왼 어깨 위, 오른팔은 상대 오른 겨드랑이 아래로 시트벨트를 잡는다
2. 상대 머리 옆에 세웠던 내 왼발을 상대 배 앞으로 넘겨 상대 왼 허벅지 안쪽에 훅으로 넣는다
3. 등 뒤에 붙였던 오른 무릎 쪽(내 오른쪽)으로 눕히며 오른발도 상대 오른 허벅지 안쪽에 넣는다
4. 가슴을 상대 등에 붙여 백 컨트롤을 완성한다

## 핵심 디테일

- 다리를 옮기기 전에 시트벨트부터 잡는다
- 왼발은 상대 배 앞을 지나 왼 허벅지 안쪽에 훅으로 넣는다
- 눕는 방향은 언더훅 쪽인 내 오른쪽
- 끝까지 가슴을 상대 등에 붙여 둔다

## 흔한 실수

- 시트벨트 없이 왼발부터 빼면 상대가 다시 등을 대고 눕는다 → 상체부터 잡는다
- 훅을 얕게 넣으면 상대가 다리를 펴 빼낸다 → 허벅지 안쪽 깊이 넣는다
- 조르는 왼팔 쪽으로 누우면 상대가 그쪽 어깨를 바닥에 대고 빠진다 → 내 오른쪽으로 눕는다

## 막히면

- 상대가 엎드려 터틀로 가면 → [터틀에서 백 테이크](../techniques/turtle-back-take.md) 또는 [클락 초크](../techniques/clock-choke.md)
- 상대가 다시 등을 대면 → [마운트](../positions/mount.md)로 돌아가 [마운트 유지](../techniques/mount-maintain.md)
- 상대 왼팔이 뻗어 나오면 → [암바 (테크니컬 마운트)](../techniques/armbar-from-technical-mount.md)

## 방어하는 쪽 (상대 입장)

- 상대 왼팔이 내 왼 어깨 위로, 오른팔이 내 오른 겨드랑이 아래로 들어와 맞잡으면 → 백 테이크 신호
- 양손으로 목 앞의 상대 왼손을 잡아 목을 지킨다
- 상대 왼발이 내 배 앞으로 넘어오기 전에 → 테크니컬 마운트 이스케이프
- 이미 양 훅이 들어오면 → 백 이스케이프
