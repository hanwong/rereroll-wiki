# 암바 그립 풀기 (Armbar Grip Break)

[서브미션 걸린 뒤 (암바 · 기무라 · 오모플라타 · 트라이앵글)](../positions/submission-control.md) · 서브미션 · 아래

다른 이름: 암바 그립 브레이크, 암바 손 풀기, 그립 브레이크

## 세팅 과정 (오른손잡이 기준)

1. 상대가 손을 맞잡아 버티면 무릎을 모은 채 상대 오른쪽 손목을 내 두 손으로 잡는다
2. 왼다리로 얼굴을 누른 채 엉덩이를 들며 내 오른발로 상대 왼쪽 옆구리를 밀어 힘을 키운다
3. 맞잡은 손이 벌어지면 바로 상대 오른팔을 가슴에 붙이고 엄지가 위로 가게 한다
4. 엉덩이를 천천히 들어 팔꿈치를 편다
5. 탭하면 바로 푼다

## 핵심 디테일

- 무릎을 모으고 엉덩이를 상대 어깨에 붙인 채 손을 푼다
- 왼다리로 얼굴을 누르고 오른발로 상대 왼쪽 옆구리를 밀어 몸 전체 힘으로 당긴다
- 손이 벌어지는 순간 바로 상대 오른팔을 가슴에 붙이고 엄지를 위로 한다

## 흔한 실수

- 손을 풀 때 무릎이 벌어지면 상대가 돌아 빠진다 → 무릎을 모은 채 푼다
- 팔 힘으로만 당기면 안 풀린다 → 엉덩이와 다리로 민다
- 손이 풀리자마자 확 펴면 다친다 → 천천히 펴고 탭하면 바로 푼다

## 막히면

- 상대가 손을 끝까지 맞잡고 버티면 → [암바 → 기무라](../techniques/kimura-from-armbar-control.md)
- 상대가 팔을 굽혀 당겨 오면 → [암바 → 트라이앵글](../techniques/triangle-from-armbar.md)이나 [암바 → 오모플라타](../techniques/omoplata-from-armbar.md)
- 상대가 내 쪽으로 돌아 빠지려 하면 → [암바 안 되면 백 테이크](../techniques/back-take-from-armbar.md)

## 방어하는 쪽 (상대 입장)

- 상대가 두 손으로 내 오른쪽 손목을 잡고 오른발로 내 왼쪽 옆구리를 밀면 그립 풀기 신호
- 두 손을 깊게 맞잡고 오른쪽 팔꿈치를 몸에 붙인다
- 상대 무릎이 벌어지면 상대 쪽으로 몸을 돌려 팔을 뺀다 (암바 방어 (팔 빼기))
- 팔이 펴지기 시작하면 버티지 말고 탭한다
