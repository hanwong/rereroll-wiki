# 팔 빼내기 (사이드 아래) (Arm Extraction from Side Control)

[사이드 컨트롤](../positions/side-control.md) · 탈출 · 아래 → [하프가드](../positions/half-guard.md) / [클로즈드 가드](../positions/closed-guard.md)

다른 이름: 끼인 팔 빼기

## 세팅 과정 (오른손잡이 기준)

1. 상대가 내 오른쪽에서 사이드를 잡고 내 오른팔을 끼우면 브릿지로 상대 체중을 띄운다
2. 내 오른쪽 팔꿈치를 내 몸 쪽으로 당기며 오른팔을 빼낸다
3. 빼낸 오른팔로 상대 골반에, 왼팔로 상대 목에 프레임을 만든다
4. 엉덩이를 내 왼쪽으로 빼(쉬림프) 공간을 만들고 하프나 가드를 되찾는다

## 핵심 디테일

- 브릿지로 상대 체중을 먼저 띄워야 끼인 팔이 빠진다
- 팔꿈치를 바닥을 따라 내 몸 쪽으로 당겨 빼낸다
- 빼낸 오른팔은 바로 상대 골반에 프레임으로 댄다
- 프레임이 서면 쉬림프로 공간을 만들고 무릎을 넣는다

## 흔한 실수

- 브릿지 없이 팔만 당기면 안 빠진다 → 띄운 순간 당긴다
- 팔을 빼고 바로 밀면 다시 잡힌다 → 프레임부터 세운다
- 팔을 빼면서 등을 보이면 백을 내준다 → 상대 쪽을 보고 움직인다

## 막히면

- 상대가 가슴 압박으로 계속 따라오면 → [터틀로 돌기 (사이드)](../techniques/roll-to-turtle.md)
- 상대가 남북으로 돌면 → [남북 이스케이프](../techniques/north-south-escape.md)
- 상대가 크로스페이스로 얼굴을 돌리면 → [사이드 이스케이프 (프레임 · 쉬림프)](../techniques/side-control-escape.md)

## 방어하는 쪽 (상대 입장)

- 상대가 브릿지하며 끼인 오른 팔꿈치를 몸 쪽으로 당기면 팔을 빼려는 신호
- 브릿지가 가라앉을 때 가슴 체중을 그 팔 위에 다시 싣는다
- 팔이 빠져 프레임을 대면 크로스페이스를 세게 걸고 남북으로 돌아 각도를 바꾼다
- 공간이 생겼으면 사이드 → 니 온 밸리로 바꿔 압박한다
