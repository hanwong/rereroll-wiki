# 신 투 신 스윕 (Shin-to-Shin Sweep)

[오픈 가드](../positions/open-guard.md) · 스윕 · 아래 → [패스](../positions/passing.md)

다른 이름: 정강이 스윕

## 세팅 과정 (오른손잡이 기준)

1. 신 투 신에서 내 오른손은 상대 왼쪽 발목, 왼손은 오른쪽 깃이나 소매를 당겨 상대를 앞으로 기울인다
2. 그대로 뒤로 누우며 내 오른 정강이로 상대 왼다리를 들어 올려 오른발로만 서게 만든다
3. 내 왼발로 상대 오른쪽 무릎이나 골반을 밀어 넘어뜨린다
4. 왼쪽 발목을 놓지 않고 따라 올라가 패스 자세로 간다

## 핵심 디테일

- 상체 그립으로 상대를 앞으로 기울인 뒤 시작한다
- 뒤로 누우며 오른 정강이로 상대 왼다리를 들어 상대가 오른발로만 서게 만든다
- 내 왼발로 상대 오른 무릎 위 허벅지나 골반을 밀어 버티는 다리를 무너뜨린다
- 넘어가는 동안 오른손 발목 그립을 놓지 않는다

## 흔한 실수

- 들기만 하고 밀지 않으면 상대가 깡충 뛰며 버틴다 → 들면서 동시에 왼발로 오른다리를 민다
- 앉은 채 힘으로 들면 안 뜬다 → 뒤로 누우며 체중으로 든다
- 넘긴 뒤 누워 있으면 상대가 가드를 만든다 → 발목을 쥐고 바로 일어나 패스 자세를 잡는다

## 막히면

- 상대가 엉덩이를 빼며 넓게 서면 → [신 투 신 → 싱글 레그 X](../techniques/shin-to-shin-to-single-leg-x.md)
- 상대가 오른발로 깡충 뛰며 버티면 → 다리를 계속 들고 [테크니컬 스탠드업 → 싱글 레그](../techniques/technical-stand-up-to-single-leg.md)로 일어난다

## 방어하는 쪽 (상대 입장)

- 상대가 뒤로 누우며 정강이로 내 왼다리를 들어 올리면 신 투 신 스윕 신호
- 무릎을 굽혀 낮게 버티고 내 오른 무릎·골반을 미는 상대 왼발을 손으로 걷어낸다
- 들린 왼다리를 상대 쪽으로 내려 무릎을 꿇으면 뒤로 넘어가지 않는다
- 넘어가면 바로 다리를 올려 가드를 만든다
