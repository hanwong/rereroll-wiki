# 하프 탑 기본 자세 (Half Guard Top Control Basics)

[하프가드](../positions/half-guard.md) · 자세 · 컨트롤 · 위 → [하프가드](../positions/half-guard.md)

다른 이름: 하프 탑, 하프가드 위에서 누르기, 하프 탑 컨트롤

## 세팅 과정 (오른손잡이 기준)

1. 내 오른다리가 감기면 내 오른팔로 크로스페이스를 걸어 상대 얼굴을 상대 오른쪽으로 돌린다
2. 내 왼팔은 상대 오른쪽 겨드랑이 아래로 넣어 언더훅을 먼저 잡는다
3. 가슴을 상대 가슴에 붙이고 엉덩이를 낮춰 등을 바닥에 눌러 둔다
4. 내 왼발로 감긴 오른발을 밀거나 오른쪽 무릎을 바닥에 붙여 다리를 뺄 준비를 한다

## 핵심 디테일

- 크로스페이스를 먼저 걸어 상대 얼굴을 상대 오른쪽으로 돌린다 → 상대가 내 쪽으로 못 돈다
- 내 왼팔로 상대 오른쪽 겨드랑이 밑 언더훅을 먼저 차지한다
- 가슴을 붙이고 엉덩이를 낮춰 상대 등을 바닥에 눌러 둔다
- 내 왼다리는 넓게 디뎌 스윕에 대비한다

## 흔한 실수

- 상체를 세우면 상대가 언더훅과 니 쉴드를 넣는다 → 가슴을 붙인다
- 상체를 잡기 전에 다리부터 빼려 하면 상대가 돌아누워 막는다 → 크로스페이스·언더훅 먼저
- 두 무릎을 모아 꿇으면 쉽게 넘어간다 → 왼다리를 넓게 디딘다

## 막히면

- 상대가 니 쉴드를 세우면 → [레그 위브 패스](../techniques/leg-weave-pass.md)
- 상대가 언더훅을 잡으면 → [하프 탑 위저 카운터](../techniques/half-guard-whizzer-counter.md)
- 다리가 꽉 감겨 있으면 → [하프가드 → 쿼터 가드 (탑)](../techniques/half-guard-to-quarter-guard.md)

## 방어하는 쪽 (상대 입장)

- 상대 오른팔이 내 머리 밑으로 들어와 얼굴을 내 오른쪽으로 돌리면 신호
- 크로스페이스가 들어오기 전에 내 왼팔 언더훅을 먼저 잡는다
- 왼쪽 무릎 니 쉴드와 오른팔뚝 목 프레임으로 가슴이 붙지 못하게 한다
- 이미 눌렸으면 → 눌린 하프가드에서 회복
