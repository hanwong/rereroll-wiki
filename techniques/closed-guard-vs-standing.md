# 상대가 섰을 때 클로즈드 가드 유지 (Closed Guard vs Standing Opponent)

[클로즈드 가드](../positions/closed-guard.md) · 자세 · 컨트롤 · 아래 → [클로즈드 가드](../positions/closed-guard.md)

다른 이름: 가드 매달리기, 스탠딩 가드 브레이크 방어, 클로즈드 가드 유지

## 세팅 과정 (오른손잡이 기준)

1. 상대가 일어서면 내 오른손으로 상대 왼쪽, 왼손으로 오른쪽 소매(또는 손목)를 잡아 내 다리를 못 밀게 한다
2. 다리로 매달려 엉덩이를 상대 골반 쪽으로 끌어올린다(무릎은 상대 갈비 높이)
3. 상대가 오른쪽 무릎을 들어 뿌리치려 하면 엉덩이를 상대 오른다리 쪽(내 왼쪽)으로 틀어 따라간다
4. 소매를 당기며 100% 스윕이나 발목 잡아 넘기기로 잇는다

## 핵심 디테일

- 양 소매를 잡아 상대 손이 내 무릎·허벅지를 밀지 못하게 한다
- 다리로 매달려 엉덩이를 높이 올리면 상대가 무릎으로 가드를 깨기 어렵다
- 상대가 오른쪽 무릎을 넣으려 하면 엉덩이를 내 왼쪽으로 틀어 무릎 길을 피한다
- 상대 무게가 뒤로 가면 바로 스윕으로 잇는다

## 흔한 실수

- 손을 놓고 매달려만 있으면 상대가 내 다리를 밀어 가드를 연다 → 소매부터 잡는다
- 엉덩이가 아래로 처지면 상대가 다리를 쉽게 푼다 → 다리로 당겨 엉덩이를 띄운다
- 상대가 나를 들어 올리면 내리꽂힐 수 있다 → 위험하면 가드를 풀고 발로 골반을 막는다

## 막히면

- 상대가 가드를 풀어내면 → [발 골반 가드 (피트 온 힙스)](../techniques/feet-on-hips-guard.md)나 [데라히바 가드](../techniques/de-la-riva-guard.md)
- 상대가 뒤로 무게를 빼면 → 100% 스윕이나 [머슬 스윕](../techniques/muscle-sweep.md)
- 상대가 다시 무릎을 꿇으면 → 끌어내려 [클로즈드 가드 (자세 · 포스처 깨기)](../techniques/closed-guard-basics.md)

## 방어하는 쪽 (상대 입장)

- 내가 일어섰을 때 상대가 양 소매를 잡고 다리로 매달리면 가드를 지키려는 신호다
- 먼저 소매 그립을 끊고 손을 상대 골반·무릎에 둔다
- 한쪽 무릎을 상대 엉덩이 밑에 쐐기로 넣고 손으로 상대 무릎을 눌러 연다 (스탠딩 가드 브레이크)
- 발목이 잡히면 무게를 앞에 두고 발을 넓게 디뎌 100% 스윕을 막는다
