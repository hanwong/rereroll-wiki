# 니슬라이스 패스 (Knee Slice Pass)

[패스](../positions/passing.md) · 패스 · 위 → [사이드 컨트롤](../positions/side-control.md)

다른 이름: 니컷, 니스루, 니 스플릿, knee cut, 니 슬라이스, 니 슬라이드, knee slice

## 세팅 과정 (오른손잡이 기준)

1. 내 오른쪽 무릎(정강이)을 상대 오른쪽 허벅지 안쪽 위에 올리고 왼발은 뒤에 세워 미는 힘을 만든다
2. 내 오른팔로 상대 왼팔 언더훅(또는 왼쪽 깃)을 잡아 상대 왼쪽 어깨를 바닥에 붙인다
3. 오른쪽 정강이를 바닥까지 미끄러뜨리며 오른발까지 끝까지 빼낸다 — 다리가 다 빠지기 전에 골반을 돌리지 않는다
4. 빠지면 골반을 돌려 가슴을 붙이고 상대 오른쪽 사이드 컨트롤로

## 핵심 디테일

- 오른쪽 정강이는 상대 오른쪽 허벅지 위에 비스듬히 낮게 걸쳐 누른다
- 내 오른팔 언더훅(또는 왼쪽 깃)으로 상대 왼쪽 어깨를 바닥에 붙여 상대가 일어나 붙지 못하게 한다
- 뒤에 세운 왼발로 밀며 엉덩이는 낮게, 체중은 상대 쪽으로 싣는다
- 오른발까지 완전히 빠진 뒤에 골반을 돌려 가슴을 붙인다

## 흔한 실수

- 무릎을 높이 들고 넘으면 상대가 무릎을 다시 넣어 가드를 잡는다 → 정강이를 허벅지에 붙여 낮게 민다
- 상대 왼쪽 어깨를 못 눌러 두면 상대가 언더훅을 잡고 일어난다 → 언더훅이나 깃 그립으로 먼저 어깨를 바닥에 붙인다
- 다리가 다 빠지기 전에 골반을 돌리면 오른발이 하프가드에 걸린다 → 발끝까지 뺀 뒤 돈다

- 상대가 내 오른발을 감아 하프가드를 잡으면 → [하프가드 패스 (크로스페이스 · 언더훅)](../techniques/half-guard-pass.md)

## 방어하는 쪽 (상대 입장)

- (상대가 내 오른쪽으로 니슬라이스해 올 때) 상대 오른쪽 무릎이 내 오른쪽 허벅지 위로 비스듬히 올라오고 상대 오른팔이 내 왼팔 밑을 파고들면 신호
- 누르기 전에 내 오른팔로 상대 왼쪽 겨드랑이 밑 언더훅을 잡고 옆으로 돌아누워 등이 바닥에 붙지 않게 한다
- 상대 정강이가 바닥으로 미끄러지면 내 오른 팔꿈치로 상대 골반을 막고 엉덩이를 내 왼쪽으로 빼 오른 무릎을 다시 넣는다
- 거의 다 빠졌으면 상대 오른발을 내 두 다리로 감아 하프가드로라도 붙잡는다
