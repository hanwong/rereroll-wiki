# 싱글 레그 X → X 가드 (SLX to X-Guard)

[X 가드 · 싱글 레그 X · 앵클락](../positions/x-guard.md) · 전환 · 아래 → [X 가드 · 싱글 레그 X · 앵클락](../positions/x-guard.md)

다른 이름: X가드 전환, 싱글렉스 X 가드

## 세팅 과정 (오른손잡이 기준)

1. 상대 왼다리에 싱글 레그 X를 건 채 엉덩이를 상대 아래로 더 넣는다
2. 겨드랑이에 안은 상대 왼다리를 내 오른쪽 어깨 위로 올려 오른팔로 안는다
3. 내 왼발은 상대 오른쪽 오금, 내 오른발은 상대 오른쪽 골반으로 옮겨 X 훅을 건다
4. X 가드 스윕으로 잇는다

## 핵심 디테일

- 엉덩이를 상대 아래로 더 넣어 상대 오른다리까지 발이 닿게 한다
- 상대 왼다리를 오른쪽 어깨로 옮기는 동안 다리 감기를 풀지 않는다
- 상대 체중이 왼다리에 실려 오른다리가 멈춰 있을 때 바꾼다
- 오른발이 골반을 떠난 순간이 가장 약하다 → 빠르게 X 훅을 완성한다

## 흔한 실수

- 상대가 앞으로 누를 때 바꾸면 → 오른발 프레임이 빠져 그대로 눌린다 → 상대가 서 있을 때 한다
- 다리를 확 휘둘러 넣으면 → 상대가 오른다리를 뒤로 뺀다 → 허벅지 안쪽을 따라 미끄러지듯 넣는다
- 오른팔 그립을 그대로 두면 → 상대 왼다리가 어깨에서 빠진다 → 어깨에 얹고 다시 꽉 안는다

## 막히면

- 상대가 오른다리를 뒤로 빼면 → 싱글 레그 X로 남아 [싱글 레그 X 스윕](../techniques/single-leg-x-sweep.md) · [X 가드 · 싱글 레그 X · 앵클락](../positions/x-guard.md)
- X 가드가 잡히면 → [X 가드 스윕](../techniques/x-guard-sweep.md)
- 상대가 버티며 몸을 돌리면 → [X 가드 → 백 테이크](../techniques/x-guard-back-take.md)

## 방어하는 쪽 (상대 입장)

- 상대 오른발이 내 왼쪽 골반에서 떨어져 내 오른다리 쪽으로 오면 X 가드로 바꾸려는 신호
- 그 순간 오른다리를 뒤로 빼 닿지 않게 한다
- 골반을 받치던 발이 빠졌으니 앞으로 체중을 실어 눌러 버린다
- 이미 X 가드가 됐으면 엉덩이를 낮추고 X 가드 빠져나오기 (서서)
