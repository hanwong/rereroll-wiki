# 오모플라타 마무리 (Omoplata Finish)

[서브미션 걸린 뒤 (암바 · 기무라 · 오모플라타 · 트라이앵글)](../positions/submission-control.md) · 서브미션 · 아래

다른 이름: 오모플라타 피니시, 오모플라타

## 세팅 과정 (오른손잡이 기준)

1. 상대 오른쪽 어깨를 두 다리로 누른 채 내 오른팔로 상대 허리를 감아 앞구르기를 막는다
2. 상대 골반을 바닥에 눕히고 엉덩이를 상대에게서 멀리 뺀다
3. 앉아 올라오며 엉덩이를 앞으로 민다
4. 천천히 상대 오른쪽 어깨를 꺾고 탭하면 바로 푼다

## 핵심 디테일

- 앉기 전에 내 오른팔로 상대 허리부터 감아 앞구르기를 막는다
- 상대 골반이 바닥에 깔려야 어깨가 비틀린다
- 엉덩이를 상대에게서 빼 직각을 만들고 두 다리로 상대 오른쪽 어깨를 계속 누른다
- 팔 힘이 아니라 앉아 오르며 엉덩이를 앞으로 밀어 꺾는다

## 흔한 실수

- 허리를 안 잡고 앉으면 상대가 앞구르기로 빠진다 → 허리부터 감는다
- 상대가 무릎을 꿇고 버티면 압력이 안 걸린다 → 다리를 뻗어 상대 골반을 바닥에 눕힌다
- 확 꺾으면 어깨가 크게 다친다 → 천천히 꺾고 탭하면 바로 푼다

## 막히면

- 상대가 앞구르기를 하려 하면 → [오모플라타 → 백](../techniques/omoplata-to-back.md)
- 상대가 왼손으로 짚고 버티면 → [오모플라타 → 스윕](../techniques/omoplata-to-sweep.md)

## 방어하는 쪽 (상대 입장)

- 상대 왼다리가 내 오른쪽 어깨를 감고 상대가 앉아 오르려 하면 오모플라타 신호
- 허리를 잡히기 전에 오른쪽 어깨 위로 앞구르기하거나 상대 다리 위로 체중을 실어 누른다
- 이미 허리가 잡히고 골반이 깔렸으면 버티지 말고 탭한다
