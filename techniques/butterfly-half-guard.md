# 버터플라이 하프가드 (Butterfly Half Guard)

[버터플라이 가드](../positions/butterfly-guard.md) · 자세 · 컨트롤 · 아래 → [버터플라이 가드](../positions/butterfly-guard.md)

다른 이름: 하프 버터플라이

## 세팅 과정 (오른손잡이 기준)

1. 상대 오른다리를 하프가드로 감은 상태에서 내 오른발을 상대 오른쪽 허벅지 안쪽 훅으로 바꾼다
2. 내 왼다리는 상대 오른다리를 계속 감는다
3. 내 왼팔로 상대 오른팔 밑 언더훅을 잡고 상체를 세운다
4. 오른발 훅으로 들어 스윕이나 백 테이크로 간다

## 핵심 디테일

- 내 왼다리로 상대 오른다리를 감은 채 오른발을 상대 오른 허벅지 안쪽 훅으로 바꾼다
- 내 왼팔로 상대 오른팔 밑 언더훅을 깊게 잡는다
- 등을 바닥에 두지 말고 언더훅 쪽으로 상체를 세운다
- 오른발 훅에 상대 체중이 실리게 해 들어 올릴 준비를 한다

## 흔한 실수

- 등을 바닥에 대고 있으면 상대가 크로스페이스로 누른다 → 언더훅 쪽으로 몸을 세운다
- 언더훅 없이 훅만 넣으면 상대 체중을 못 든다 → 언더훅부터 잡는다
- 오른발 훅이 얕으면 상대가 무릎으로 눌러 죽인다 → 허벅지 안쪽 깊이 넣는다

## 막히면

- 상대가 앞으로 체중을 실으면 → [버터플라이 하프가드 스윕](../techniques/butterfly-half-guard-sweep.md)
- 상대가 크로스페이스로 눌러 오면 → [눌린 하프 → 딥 하프](../techniques/deep-half-entry-from-flattened.md)
- 언더훅이 깊으면 → [버터플라이 하프 → 도그파이트](../techniques/half-butterfly-to-dogfight.md)나 [롤링 백 테이크 (버터플라이 하프)](../techniques/rolling-back-take-from-half-butterfly.md)

## 방어하는 쪽 (상대 입장)

- 상대 왼팔이 내 오른팔 밑으로 파고들고 오른발이 내 오른 허벅지 안쪽에 걸리면 버터플라이 하프
- 내 오른팔로 언더훅을 위에서 감아 막고 왼팔 크로스페이스로 상대를 바닥에 눕힌다
- 훅이 살아 있으면 내 왼손으로 상대 오른쪽 훅 무릎을 눌러 버터플라이 훅 컨트롤 패스
