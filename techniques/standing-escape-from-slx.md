# 싱글 레그 X 빠져나오기 (서서) (Standing Escape from SLX)

[X 가드 · 싱글 레그 X · 앵클락](../positions/x-guard.md) · 탈출 · 위 → [패스](../positions/passing.md)

다른 이름: SLX 이스케이프

## 세팅 과정 (오른손잡이 기준)

1. 상대가 내 왼다리에 싱글 레그 X를 걸었을 때, 잡힌 왼쪽 무릎을 바깥으로 돌리지 않게 안쪽으로 유지한다
2. 내 왼쪽 골반에 댄 상대 오른발을 손으로 눌러 떼어낸다
3. 왼다리를 빼며 뒤로 물러난다
4. 다시 패스 자세를 잡는다

## 핵심 디테일

- 자유로운 오른다리를 넓게 디디고 무릎을 굽혀 엉덩이를 낮춘다 — 이 다리가 버팀목
- 잡힌 왼쪽 무릎은 안쪽으로 유지한다 — 바깥으로 돌면 바로 넘어간다
- 순서: 내 왼쪽 골반에 댄 상대 오른발 떼기 → 왼다리 빼기
- 몸을 앞으로 숙이지 말고 엉덩이를 뒤로 두어 상대가 당겨 넘기지 못하게 한다

## 흔한 실수

- 훅을 그대로 두고 다리부터 뜯어내면 → 스윕 당한다 → 골반의 상대 발부터 뗀다
- 무릎을 펴고 꼿꼿이 서면 → 쉽게 넘어간다 → 낮게 버틴다
- 상대가 내 소매를 잡고 있는데 무시하면 → 당겨서 넘긴다 → 그 그립부터 끊는다

## 막히면

- 상대가 발을 골반에 다시 대면 → [백스텝 (싱글 레그 X 상대)](../techniques/backstep-from-single-leg-x.md)
- 상대가 두 번째 훅을 넣어 X 가드로 바꾸면 → [X 가드 빠져나오기 (서서)](../techniques/standing-escape-from-x-guard.md)
- 상대가 앉아 발목을 잡고 따라오면 → 손으로 상대 어깨를 밀어 눕히고 다시 뺀다
- 상대가 내 뒤꿈치를 겨드랑이에 끼우면 → [하체 관절기 방어 (무릎 선 지키기 · 뒤꿈치 숨기기)](../techniques/heel-hook-defense-knee-line.md)

## 방어하는 쪽 (상대 입장)

- 상대가 무릎을 굽혀 낮아지고 손이 내 오른발(골반에 댄 발)로 내려오면 빠지려는 신호
- 발이 떼어지면 바로 다시 골반에 대고, 상대가 숙이는 순간 싱글 레그 X 스윕
- 상대가 다리를 빼면 엉덩이로 따라가 발목을 다시 안는다
- 다 빠졌으면 발을 상대 골반에 대 오픈 가드를 다시 세운다
