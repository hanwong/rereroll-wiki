# 팔 빼고 가드 회복 (변형 곁누르기 아래) (Arm Recovery to Guard from Kuzure Kesa)

[곁누르기](../positions/kesa-gatame.md) · 탈출 · 아래 → [하프가드](../positions/half-guard.md) / [클로즈드 가드](../positions/closed-guard.md)

다른 이름: 쿠즈레 케사 상대 팔 빼고 가드, 쿠즈레 탈출, 쿠즈레 케사 가드 회복

## 세팅 과정 (오른손잡이 기준)

1. 상대가 내 오른쪽에서 누르면 끼인 내 오른팔은 팔꿈치를 굽혀 몸 쪽으로 붙여 둔다
2. 내 왼 팔뚝으로 상대 골반이나 목에 프레임을 댄다
3. 내 오른쪽(상대 쪽)으로 짧게 브릿지해 무게가 뜬 순간 끼인 오른 팔꿈치를 뽑아낸다
4. 내 왼쪽으로 엉덩이를 빼며 오른 무릎을 상대 몸 앞에 넣는다
5. 왼다리도 넣어 하프가드나 가드로 돌아온다

## 핵심 디테일

- 끼인 오른팔은 팔꿈치를 굽혀 몸 쪽에 붙여 두고 펴지 않는다
- 왼 팔뚝 프레임으로 상대 무게를 먼저 막아 숨 쉴 틈을 만든다
- 짧게 브릿지해 무게가 뜬 순간에만 오른 팔꿈치를 뽑는다
- 팔이 빠지면 쉬지 말고 바로 엉덩이를 빼 무릎을 넣는다

## 흔한 실수

- 상대가 누를 때 힘으로 팔을 잡아 빼면 안 빠진다 → 브릿지로 무게를 띄운 순간 뽑는다
- 팔을 빼고 그대로 누워 있으면 상대가 다시 잡는다 → 바로 무릎을 넣는다
- 끼인 팔을 펴면 아메리카나·스트레이트 암락을 당한다 → 팔꿈치를 굽혀 둔다

## 막히면

- 상대가 겨드랑이를 조여 팔이 안 빠지면 → [백 테이크 (곁누르기 아래)](../techniques/back-take-from-kesa.md)
- 상대 머리가 높이 들려 있으면 → [다리로 머리 걸어 빼기 (곁누르기 아래)](../techniques/kesa-leg-hook-escape.md)
- 무릎을 넣을 틈이 없으면 → [브릿지 이스케이프 (곁누르기)](../techniques/bridge-escape-from-kesa.md)

## 방어하는 쪽 (상대 입장)

- 상대가 짧게 브릿지하며 끼인 오른 팔꿈치를 뽑으려 하면 → 탈출 신호
- 왼 겨드랑이를 조이고 엉덩이를 상대 옆구리에 더 붙인다
- 상대 오른 무릎이 들어오기 시작하면 → 무릎을 눌러 내리고 곁누르기 → 사이드
