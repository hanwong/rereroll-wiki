# 하프가드 패스 (크로스페이스 · 언더훅) (Half Guard Pass (Crossface & Underhook))

[하프가드](../positions/half-guard.md) · 패스 · 위 → [사이드 컨트롤](../positions/side-control.md)

다른 이름: 하프 패스, 크로스페이스 패스, 언더훅 패스

## 세팅 과정 (오른손잡이 기준)

1. 내 오른다리가 감기면 내 왼팔로 상대 오른팔 언더훅을 먼저 잡고 상대 오른쪽 어깨를 바닥에 눌러 평평하게 만든다
2. 내 오른팔로 크로스페이스를 걸어 상대 얼굴을 상대 오른쪽으로 돌린다
3. 자유로운 내 왼다리로 상대 오른다리를 걸어 눌러 가드 회복을 막는다
4. 감긴 오른다리를 빼내고 가슴을 붙여 사이드 컨트롤로

## 핵심 디테일

- 다리보다 상체가 먼저: 내 왼팔 언더훅 + 내 오른팔 크로스페이스로 상대를 평평하게 만든다
- 상대 얼굴이 상대 오른쪽으로 돌아가 있으면 상대가 몸을 세워 언더훅을 잡지 못한다
- 엉덩이를 낮추고 가슴 체중을 상대 가슴·어깨에 싣는다
- 다리는 힘으로 뜯지 말고 내 왼다리로 상대 다리를 눌러 둔 채 조금씩 뺀다

## 흔한 실수

- 다리만 빼려고 애쓰면 → 상대가 언더훅을 잡고 올라온다 → 상체부터 잡는다
- 엉덩이가 높으면 → 상대가 다리로 밀어 스윕한다 → 낮게 붙는다
- 상대 언더훅을 내버려두면 → 백이나 스윕을 내준다 → 바로 위저로 막는다

## 막히면

- 상대가 언더훅을 잡으면 → [하프 탑 위저 카운터](../techniques/half-guard-whizzer-counter.md)
- 상대가 니 쉴드를 세우면 → [스매시 패스](../techniques/smash-pass.md)
- 상대가 머리를 내 아래로 넣어 딥 하프로 가면 → [위저 (딥 하프 상대)](../techniques/whizzer-from-deep-half.md)
- 상대가 니 쉴드 다리를 쭉 펴 밀면 → [니바 (하프가드 탑 · 스텝 오버)](../techniques/kneebar-half-guard-top.md)

## 방어하는 쪽 (상대 입장)

- 상대 왼팔이 내 오른쪽 겨드랑이로 들어오고 상대 오른팔이 내 얼굴을 돌리면 납작하게 누르려는 신호
- 크로스페이스가 걸리기 전에 내 오른쪽 팔뚝으로 상대 목에 프레임하고 내 왼팔 언더훅을 먼저 잡는다
- 이미 눌렸으면 니 쉴드로 거리를 만들거나 머리를 상대 아래로 넣어 눌린 하프 → 딥 하프
- 다리가 빠지려 하면 상대 다리를 꽉 감고 → 눌린 하프가드에서 회복
