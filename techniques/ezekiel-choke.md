# 에제키엘 초크 (Ezekiel Choke)

[마운트](../positions/mount.md) · 서브미션 · 위

다른 이름: 이지키엘, 소매 초크, 에제키엘, 이제키엘

## 세팅 과정 (오른손잡이 기준)

1. 마운트에서 내 오른팔을 상대 머리 아래로 넣는다
2. 머리 아래로 넣은 오른손으로 내 왼팔 소매 안쪽(손목 부분)을 잡는다
3. 소매가 잡힌 내 왼손의 손날을 상대 목 앞으로 가로질러 넣는다
4. 오른손으로 소매를 당기고 왼 손날을 밀어 넣으며 팔꿈치를 모아 조인다

## 핵심 디테일

- 머리 아래로 넣은 오른팔은 깊게 넣어 소매를 단단히 잡는다
- 목 앞에는 주먹이 아니라 왼 손날을 넣는다
- 소매를 당기는 힘과 손날을 미는 힘을 함께 쓰며 팔꿈치를 모은다
- 머리를 낮춰 양팔을 쓰는 동안에도 베이스를 지킨다

## 흔한 실수

- 오른팔이 머리 밑에 얕게 들어가면 조임이 안 된다 → 목 뒤까지 넣는다
- 주먹으로 목을 누르면 안 조인다 → 손날을 세워 넣는다
- 상체를 세우고 당기면 상대가 업파로 굴린다 → 몸을 낮춘다

## 막히면

- 상대가 턱을 당겨 손날이 안 들어가면 → [크로스 칼라 초크 (마운트)](../techniques/mount-cross-collar-choke.md)
- 상대가 내 팔을 밀어 올리면 → [마운트 암바](../techniques/mount-armbar.md)

## 방어하는 쪽 (상대 입장)

- 상대 오른팔이 내 머리 밑으로 들어와 상대 왼 소매를 잡으면 → 에제키엘 신호
- 턱을 당기고 상대 왼 손목을 양손으로 잡아 목 앞으로 못 오게 한다
- 상대가 양팔을 다 쓰면 짚을 손이 없으니 → 마운트 이스케이프 (업파)로 굴린다
- 이미 조여 오면 → 일찍 탭한다
