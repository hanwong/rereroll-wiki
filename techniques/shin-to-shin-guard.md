# 신 투 신 가드 (Shin-to-Shin Guard)

[오픈 가드](../positions/open-guard.md) · 자세 · 컨트롤 · 아래 → [오픈 가드](../positions/open-guard.md)

다른 이름: 정강이 가드, 신투신

## 세팅 과정 (오른손잡이 기준)

1. 상대가 왼발을 앞에 두면 앉은 자세에서 내 오른쪽 정강이를 상대 왼쪽 정강이 앞에 가로로 댄다
2. 내 오른손으로 상대 왼쪽 발목이나 바지를 잡는다
3. 내 왼손으로 상대 오른쪽 깃이나 소매를 잡아 상대를 당긴다
4. 싱글 레그 X · 스윕으로 잇는다

## 핵심 디테일

- 상대 왼발이 앞에 나왔을 때 내 오른 정강이를 상대 왼 정강이 앞에 가로로 대어 묶는다
- 내 오른손으로 상대 왼 발목이나 바지를 잡아 다리가 빠지지 않게 한다
- 내 왼손으로 상대 오른쪽 깃·소매를 당겨 체중이 왼다리에 실리게 한다
- 상체를 세워 앉아 있어야 다음 기술로 빨리 넘어간다

## 흔한 실수

- 뒤로 누워 버리면 상대가 다리를 빼고 패스한다 → 상체를 세워 앉는다
- 발목 그립 없이 정강이만 대면 상대가 다리를 빼 돌아간다 → 발목이나 바지를 꼭 잡는다
- 상체 그립이 없으면 상대가 체중을 뒤로 빼 버틴다 → 깃·소매를 당겨 상대를 앞으로 기울인다

## 막히면

- 상대가 앞으로 체중을 실으면 → [신 투 신 스윕](../techniques/shin-to-shin-sweep.md)
- 상대가 엉덩이를 뒤로 빼 버티면 → [신 투 신 → 싱글 레그 X](../techniques/shin-to-shin-to-single-leg-x.md)
- 상대가 다리를 빼 옆으로 돌면 → [가드 리텐션 (다리 되돌리기)](../techniques/open-guard-retention.md)로 정면을 되찾는다

## 방어하는 쪽 (상대 입장)

- 상대 오른 정강이가 내 왼 정강이 앞에 붙고 상대 오른손이 내 왼 발목을 잡으면 신 투 신
- 상대 왼손의 깃·소매 그립부터 끊고 엉덩이를 낮춰 왼다리에 체중을 싣지 않는다
- 이미 붙었으면 왼다리를 뒤로 빼거나 바깥으로 돌려 연결을 떼고 신 투 신 가드 패스로 간다
