# 브레드커터 초크 (Breadcutter Choke)

[사이드 컨트롤](../positions/side-control.md) · 서브미션 · 위

다른 이름: 빵칼 초크, 브레드 커터, breadcutter

## 세팅 과정 (오른손잡이 기준)

1. 상대 오른쪽에서 사이드: 내 왼손으로 상대 왼쪽 깃을 당겨 느슨하게 만든다
2. 내 오른손을 상대 목 뒤로 넣어 상대 왼쪽 깃을 깊게 잡는다
3. 내 왼팔뚝 날을 상대 목 앞에 가로로 댄다
4. 엉덩이를 뒤로 빼 체중을 팔뚝에 실으며 깃을 당겨 조인다

## 핵심 디테일

- 내 왼손으로 상대 왼쪽 깃을 먼저 당겨 빼 두어야 목 뒤로 넣은 내 오른손이 깊게 잡힌다
- 내 오른손은 상대 왼쪽 깃을 최대한 깊게 잡는다 — 깊을수록 조금만 당겨도 조여진다
- 내 왼팔뚝은 평평한 면이 아니라 날을 상대 목 앞에 가로로 댄다
- 팔 힘으로 짜지 말고 엉덩이를 뒤로 빼 체중을 팔뚝에 싣는다

## 흔한 실수

- 사이드를 굳히기 전에 깃부터 잡으면 상대가 돌아 들어온다 → 크로스페이스와 골반 압박으로 먼저 눌러 둔다
- 오른손 그립이 얕으면 아무리 당겨도 안 조여진다 → 깃 여유를 다 당겨 낸 뒤 깊게 다시 잡는다
- 마무리 때 엉덩이를 들면 상대가 브릿지로 공간을 만든다 → 엉덩이는 낮게 뒤로 빼고 가슴 무게만 팔뚝에 싣는다

## 막히면

- 상대가 목 뒤 그립을 양손으로 떼어 내면 → [사이드 컨트롤 유지](../techniques/side-control-maintain.md)로 다시 눌러 두고 작게 다시 넣는다
- 상대가 양손으로 팔뚝을 밀어내면 → 뜬 팔을 노려 [아메리카나 (사이드)](../techniques/americana-side.md) · [기무라 (사이드)](../techniques/kimura-side.md)
- 상대가 나를 향해 돌아 무릎을 넣으려 하면 → 초크를 멈추고 골반을 다시 붙여 [사이드 컨트롤 유지](../techniques/side-control-maintain.md)

## 방어하는 쪽 (상대 입장)

- 상대 왼손이 내 왼쪽 깃을 당겨 빼거나 상대 오른손이 내 목 뒤로 파고들면 초크 신호다
- 팔뚝이 목에 오기 전에 목 뒤로 들어온 상대 오른손 그립을 양손으로 떼어 낸다
- 상대가 그립에 손을 쓰는 사이 엉덩이를 내 왼쪽으로 빼고 오른 무릎을 넣는다
- 이미 팔뚝이 목에 걸렸으면 팔꿈치를 붙인 채 상대 왼쪽 손목을 밀어 틈을 만들고, 조여 오면 일찍 탭한다
