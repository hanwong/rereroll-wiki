# 아메리카나 (마운트) (Americana from Mount)

[마운트](../positions/mount.md) · 서브미션 · 위

다른 이름: 마운트 키락, 마운트 아메리카나, 키락 (마운트)

## 세팅 과정 (오른손잡이 기준)

1. 내 왼손으로 상대 왼 손목을 잡아 상대 머리 옆 바닥에 눌러 팔꿈치가 90도가 되게 한다
2. 내 오른팔을 상대 왼팔 아래로 넣어 내 왼 손목을 잡는다(8자 그립)
3. 가슴을 낮춰 상대 왼 어깨를 바닥에 고정한다
4. 손목은 바닥에 붙인 채 상대 왼 팔꿈치를 들어 올려 어깨를 꺾는다

## 핵심 디테일

- 상대 왼 손목을 머리 가까이 바닥에 붙이고 팔꿈치를 90도로 접는다
- 가슴을 낮춰 상대 왼 어깨를 바닥에 고정한다
- 손목은 바닥에 끌듯이 두고 팔꿈치만 들어 올린다

## 흔한 실수

- 손목이 바닥에서 뜨면 상대가 팔을 빼낸다 → 손목을 바닥에 붙인 채 꺾는다
- 팔꿈치가 펴져 있으면 걸리지 않는다 → 90도로 접는다
- 상체를 세우면 상대가 브릿지로 버틴다 → 가슴을 낮춘다

## 막히면

- 상대가 왼팔을 엉덩이 쪽으로 내려 버티면 → 같은 팔에 기무라 그립으로 바꾼다 · [기무라 마무리](../techniques/kimura-finish.md)
- 상대가 팔을 쭉 펴 버티면 → [마운트 암바](../techniques/mount-armbar.md)

## 방어하는 쪽 (상대 입장)

- 상대 왼손이 내 왼 손목을 잡아 머리 옆 바닥으로 누르면 → 아메리카나 신호
- 팔꿈치를 몸 쪽으로 당겨 팔이 접히지 않게 한다
- 8자 그립이 잡히면 손을 맞잡아 버티고 마운트 이스케이프 (업파)를 노린다
- 어깨가 돌기 시작하면 → 일찍 탭한다
