# 루프 초크 (터틀) (Loop Choke from Turtle)

[터틀 · 크루시픽스](../positions/turtle.md) · 서브미션 · 위

다른 이름: 터틀 루프, 루프 초크, 루프초크

## 세팅 과정 (오른손잡이 기준)

1. 터틀 상대 앞에서 내 오른손으로 상대 오른쪽 깃(내 왼쪽에 보이는 깃)을 깊게 잡는다
2. 내 왼손으로 상대 뒤통수를 눌러 머리를 내 오른쪽 겨드랑이 아래로 넣는다
3. 깃 잡은 오른쪽 팔꿈치를 상대 목 뒤로 넘겨 고리를 만든다
4. 내 오른쪽 어깨를 바닥에 대고 상대 몸 아래로 구르며 깃을 당긴다
5. 천천히 조이고 탭하면 바로 푼다

## 핵심 디테일

- 내 오른손 네 손가락을 상대 오른쪽 깃 안쪽 깊이 넣는다 — 깃이 얕으면 고리가 안 조인다
- 내 왼손으로 상대 뒤통수를 눌러 머리가 빠지지 않게 고정한다
- 구르는 동안 깃 잡은 오른손을 놓지 않고 계속 당겨 느슨해지지 않게 한다
- 팔힘보다 구르는 회전으로 조인다

## 흔한 실수

- 깃을 얕게 잡고 구르면 조임 없이 자리만 잃는다 → 손가락이 목 옆까지 들어갈 때까지 깃을 먼저 깊게 판다
- 구르다 중간에 멈추면 상대가 위로 올라온다 → 구르기로 정했으면 끝까지 돈다
- 머리를 안 누르면 상대가 고개를 들어 빠진다 → 왼손으로 뒤통수를 계속 누른다

## 막히면

- 상대가 턱을 당겨 깃이 안 들어가면 → [터틀에서 백 테이크](../techniques/turtle-back-take.md)로 바꾼다
- 상대가 고개를 들고 일어서려 하면 → [길로틴 (터틀)](../techniques/guillotine-from-turtle.md)
- 구른 뒤 조임이 약하면 → 깃을 놓지 말고 다리로 상대 몸을 감아 다시 조인다

## 방어하는 쪽 (상대 입장)

- 상대 오른손이 내 오른쪽 깃 깊이 들어오면 → 내 오른손으로 그 손목을 잡아 떼고 턱을 당긴다
- 상대 왼손이 내 뒤통수를 누르면 → 고개를 들지 말고 턱을 붙인 채 깃이 잡힌 손을 계속 떼어 낸다
- 상대 오른쪽 팔꿈치가 내 목 뒤로 넘어오면 → 구르기 전에 앉거나 가드로 돌아가 상대 각도를 없앤다
- 이미 굴러서 조여 오면 → 늦었으면 바로 탭한다
