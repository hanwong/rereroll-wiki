# 암 드래그로 빠져나오기 (프론트 헤드락) (Arm Drag Escape)

[프론트 헤드락 · 길로틴](../positions/front-headlock.md) · 탈출 · 아래 → [오픈 가드](../positions/open-guard.md) / [백 컨트롤](../positions/back-control.md)

다른 이름: 헤드락 암드랙, 암 드래그 탈출, 암드래그

## 세팅 과정 (오른손잡이 기준)

1. 상대가 오른팔로 머리를 감으면 내 오른손으로 상대 오른쪽 팔꿈치(삼두)를 잡는다
2. 그 팔꿈치를 내 오른쪽으로 끌어내며 머리를 뽑아낸다
3. 상대 오른쪽 옆(내 왼쪽)으로 돌아가거나 앉으며 다리를 상대 앞에 둔다
4. 오픈 가드나 백을 잡는다

## 핵심 디테일

- 오른손으로 상대 오른쪽 팔꿈치(삼두)를 잡는다
- 팔을 내 오른쪽으로 끌어내는 것과 머리 빼기를 동시에 한다
- 머리는 위로 들지 말고 턱을 당긴 채 옆으로 뺀다
- 머리가 빠지면 바로 상대 오른쪽 옆으로 돌아 등을 노리거나 앉아 다리를 세운다

## 흔한 실수

- 팔만 끌고 머리를 안 빼면 다시 감긴다 → 끌면서 머리를 같이 뺀다
- 턱을 들면 길로틴에 걸린다 → 끝까지 턱을 당긴다
- 빠진 뒤 멈추면 상대가 다시 덮친다 → 바로 옆으로 돌거나 다리를 세운다

## 막히면

- 상대가 팔꿈치를 몸에 붙여 안 끌리면 → [프론트 헤드락 빠져나오기 (서서 돌기)](../techniques/stand-and-circle-away.md)
- 상대가 길로틴 그립을 잠그면 → [길로틴 방어](../techniques/guillotine-defense.md)

## 방어하는 쪽 (상대 입장)

- 상대 오른손이 내 오른쪽 삼두를 잡으면 → 오른쪽 팔꿈치를 옆구리로 당겨 붙여 끌려가지 않게 한다
- 상대가 내 오른쪽 옆으로 돌아오면 → 그쪽으로 같이 돌아 정면을 지키고 머리를 누른다
- 상대가 등 뒤로 왔으면 → 엎드리지 말고 앉아 상대를 마주 보며 다리를 세운다
