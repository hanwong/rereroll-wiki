# 애시 가라미 (스트레이트 애시) (Ashi Garami (Straight Ashi))

[X 가드 · 싱글 레그 X · 앵클락](../positions/x-guard.md) · 자세 · 컨트롤 · 아래 → [X 가드 · 싱글 레그 X · 앵클락](../positions/x-guard.md)

다른 이름: 아시 가라미, 스트레이트 애시, 싱글 레그 X (하체 관절기 자세), ashi garami, straight ashi, 애시 가라미

## 규정 · 안전

- 도복 · 노기: 둘 다. 노기에서 더 흔하다
- 대회 규정: 자세 자체는 IBJJF 어느 띠나 허용. 단 안쪽 발이 상대 몸 가운데 선을 넘으면 '니 리핑' — 성인 브라운 · 블랙 노기 외엔 중대 반칙 (IBJJF 규정집 v6.1 · 2026-11 확인)
- 안전: 무릎 인대를 다치기 쉬운 자세 — 상대 무릎을 비틀지 말고 천천히, 연습 상대와 미리 정하고 도장 규칙을 먼저 확인한다

## 세팅 과정 (오른손잡이 기준)

1. 싱글 레그 X 처럼 상대 왼다리를 내 다리 사이에 넣고, 내 왼다리(안쪽)를 상대 왼쪽 허벅지 안쪽에 걸어 내 왼발은 상대 오른쪽 골반 앞에 둔다
2. 내 오른발(바깥)은 상대 왼쪽 골반에 대고, 두 무릎을 모아 상대 왼쪽 무릎을 꽉 끼운다
3. 상대 왼쪽 발목을 내 오른쪽 겨드랑이 아래에 끼우고 내 오른팔로 발목 아래를 감는다 — 발목은 늘 가슴에 붙인다
4. 내 오른쪽 어깨와 엉덩이를 바닥에 대고 옆으로 누워 상대가 일어서거나 다리를 빼지 못하게 골반으로 밀며 거리를 지킨다
5. 여기서 스트레이트 앵클락 · 아웃사이드 힐훅 · 토홀드로 잇고, 상대가 빠지면 싱글 레그 X 스윕으로 바꾼다

## 핵심 디테일

- 힘은 팔이 아니라 두 무릎의 끼움 — 상대 왼쪽 무릎이 내 무릎 사이에서 빠지면 어떤 관절기도 안 걸린다
- 내 오른발은 상대 왼쪽 골반을 밀어 상대가 다가와 눌러 앉지 못하게 거리를 만든다
- 상대 발목은 겨드랑이 깊숙이, 가슴에 붙여서 발이 돌아가거나 빠질 틈을 없앤다
- 내 왼발이 상대 몸 가운데 선(배꼽 선)을 넘어가면 니 리핑(반칙 · 무릎 부상)이 된다 — 발은 상대 오른쪽 골반 앞까지만

## 흔한 실수

- 무릎을 벌린 채 발목만 잡으면 상대가 무릎을 돌려 그대로 빠진다 → 무릎을 먼저 모은다
- 상대 쪽으로 누워 가슴을 열면 상대가 위에서 눌러 패스한다 → 옆으로 누워 오른발로 골반을 민다
- 안쪽 발을 상대 배 위로 넘기면 반칙(니 리핑)이자 상대 무릎을 다치게 한다 → 발은 골반 앞에 둔다

## 막히면

- 상대가 무릎을 돌려 빼려 하면 → [스트레이트 앵클락](../techniques/straight-ankle-lock.md)
- 상대가 일어서서 발을 빼면 → [싱글 레그 X 스윕](../techniques/single-leg-x-sweep.md)
- 상대가 내 다리 위로 눌러 앉으면 → [싱글 레그 X 가드](../techniques/single-leg-x-guard.md) 로 돌아가 거리를 만든다

## 방어하는 쪽 (상대 입장)

- 상대가 내 왼다리를 다리 사이에 넣고 무릎을 모으며 내 왼쪽 발목을 겨드랑이에 끼우면 하체 관절기 신호
- 내 왼쪽 무릎을 상대 두 무릎 사이에서 빼내고(무릎 빼기), 발뒤꿈치는 내 엉덩이 쪽으로 당겨 숨긴다
- 내 왼쪽 무릎이 상대 발목 · 골반을 잇는 선 바깥에 있으면 안전하다 — 그 선 안으로 넘어가지 않게 한다
- 이미 깊게 잡혔으면 상대 쪽으로 몸을 돌려 눌러 앉으며 상대 오른발을 내 왼손으로 밀어 훅을 뗀다
