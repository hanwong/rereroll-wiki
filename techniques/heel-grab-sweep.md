# 힐 그랩 스윕 (Heel Grab Sweep)

[X 가드 · 싱글 레그 X · 앵클락](../positions/x-guard.md) · 스윕 · 아래 → [사이드 컨트롤](../positions/side-control.md)

다른 이름: 뒤꿈치 잡아 넘기기

## 세팅 과정 (오른손잡이 기준)

1. 상대 왼다리에 싱글 레그 X를 건 채 내 왼손으로 상대 오른발 뒤꿈치를 잡는다
2. 내 오른발로 상대 왼쪽 골반을 밀며 오른발 뒤꿈치를 당긴다
3. 상대가 뒤로 넘어진다
4. 상대 왼다리를 든 채 일어나 사이드로 간다

## 핵심 디테일

- 내 왼손은 발목이 아니라 상대 오른발 뒤꿈치를 감싸 잡는다
- 내 오른발로 골반을 미는 것과 뒤꿈치 당기기를 한 번에 한다
- 상대 체중이 앞으로 실렸을 때 하면 쉽게 뒤로 넘어간다
- 넘어가면 상대 왼다리를 놓지 않고 바로 일어나 따라 붙는다

## 흔한 실수

- 뒤꿈치만 당기고 다리로 밀지 않으면 → 상대가 오른발을 뒤로 빼고 선다 → 밀기와 당기기를 동시에
- 바지 끝이나 발목을 잡으면 → 손이 미끄러진다 → 뒤꿈치를 감싼다
- 넘긴 뒤 누워 있으면 → 상대가 가드를 다시 잡는다 → 바로 일어나 사이드로

## 막히면

- 상대가 오른발을 뒤로 넓게 빼면 → [싱글 레그 X 스윕](../techniques/single-leg-x-sweep.md)
- 상대가 바로 앉아 버리면 → 상대 왼다리를 안은 채 일어나 패스 자세로 · [오픈 가드 패스 자세 · 거리](../techniques/open-guard-passing-posture.md)
- 상대가 앞으로 눌러 오면 → [싱글 레그 X → X 가드](../techniques/slx-to-x-guard.md)

## 방어하는 쪽 (상대 입장)

- 상대 왼손이 내 오른발 뒤꿈치로 오면 뒤로 넘기려는 신호
- 그 손을 떼거나 오른발을 뒤로 넓게 빼 받침을 만든다
- 몸을 앞으로 숙이지 말고 엉덩이를 낮춰 들리지 않게 한다
- 이미 넘어가면 엉덩이부터 낮게 앉아 다리를 빼고 가드를 세운다
