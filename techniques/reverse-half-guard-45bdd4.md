# 리버스 하프가드 (Reverse Half Guard)

[하프가드](../positions/half-guard.md) · 자세 · 컨트롤 · 아래 → [하프가드](../positions/half-guard.md)

다른 이름: 리버스 하프, 역 하프가드, 리버스 하프 가드

## 세팅 과정 (오른손잡이 기준)

1. 상대 오른다리를 내 두 다리 사이에 둔 채 몸을 내 왼쪽으로 돌려 왼쪽 어깨를 바닥에 댄다
2. 내 왼다리로 상대 오른다리 안쪽을 감아 건다
3. 내 오른발로 상대 오른쪽 골반이나 허벅지를 민다
4. 내 왼손으로 상대 오른쪽 발목을, 오른손으로 오른쪽 무릎을 잡아 거리를 유지한다
5. 상대 오른다리를 끌며 피쉬넷이나 스윕으로 이어 간다

## 핵심 디테일

- 상대 오른다리를 내 두 다리 사이에 끼우고 내 왼다리로 안쪽을 감아 건다
- 등을 평평하게 대지 말고 왼쪽 어깨를 바닥에 대 옆으로 선다
- 내 오른발로 상대 오른쪽 골반이나 허벅지를 밀어 거리를 지킨다
- 왼손 상대 오른쪽 발목, 오른손 오른쪽 무릎을 잡아 다리를 못 빼게 한다

## 흔한 실수

- 등이 평평하면 상대가 눌러 패스한다 → 왼쪽 어깨를 바닥에 대고 옆으로 선다
- 발목을 안 잡으면 상대가 다리를 빼 넘어간다 → 발목부터 잡는다
- 가만히 버티면 상대가 체중을 실어 누른다 → 계속 다리를 끌어 상대를 흔든다

## 막히면

- 상대가 체중을 실어 눌러 오면 → [리버스 하프 → 하프가드 회복](../techniques/guard-recovery-from-reverse-half-guard.md)
- 상대 중심이 뒤로 빠지면 → [피쉬넷 스윕 (리버스 하프가드)](../techniques/fishnet-sweep-from-reverse-half-guard.md)

## 방어하는 쪽 (상대 입장)

- 상대가 내 오른다리를 두 다리 사이에 끼우고 왼손으로 내 오른쪽 발목을 잡으면 리버스 하프 신호
- 체중을 상대 상체 쪽으로 실어 상대가 몸을 세우지 못하게 한다
- 이미 자리 잡혔으면 리버스 하프 패스로 끼인 다리를 빼 넘어간다
