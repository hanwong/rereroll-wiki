# 하이 엘보 길로틴 (High Elbow Guillotine)

[프론트 헤드락 · 길로틴](../positions/front-headlock.md) · 서브미션 · 위

다른 이름: 마르셀로 길로틴, 하이엘보 길로틴, 마르셀로틴

## 세팅 과정 (오른손잡이 기준)

1. 내 오른팔로 목을 감아 오른손목이 상대 턱 아래 목 앞에 오게 깊게 넣는다
2. 내 왼팔을 상대 오른쪽 어깨 위로 넘겨 내 오른손을 잡는다
3. 오른쪽 팔꿈치를 높게 들어 상대 머리 뒤쪽으로 넘긴다
4. 두 다리로 상대 허리를 감고 오른손목을 위로 당기며 조인다
5. 천천히 조이고 탭하면 바로 푼다

## 핵심 디테일

- 오른손목을 목 앞에 깊게 넣은 뒤에 팔꿈치를 든다 — 깊이 먼저, 높이는 나중
- 내 왼팔을 상대 오른쪽 어깨 위로 넘겨 내 오른손을 잡는다
- 오른쪽 팔꿈치를 상대 머리 뒤쪽으로 높이 넘겨 목을 감아 올린다
- 다리로 허리를 감고 무릎을 당겨 상대 자세를 낮게 묶는다

## 흔한 실수

- 그립이 얕은데 팔꿈치만 들면 턱만 눌린다 → 손목을 다시 깊게 넣고 든다
- 다리가 풀리면 상대가 자세를 세워 빠진다 → 허리를 감고 무릎을 가슴 쪽으로 당긴다
- 급하게 당기면 목을 다친다 → 천천히 조이고 탭하면 바로 푼다

## 막히면

- 상대 왼팔이 같이 갇히면 → [암 인 길로틴](../techniques/arm-in-guillotine.md)
- 상대가 손목을 떼어 그립이 풀리면 → [길로틴 마무리](../techniques/guillotine-choke-finish.md) 기본 그립으로 다시 잡는다
- 상대가 자세를 세워 버티면 → [힙 범프 스윕](../techniques/hip-bump-sweep.md)

## 방어하는 쪽 (상대 입장)

- 상대 오른쪽 팔꿈치가 내 머리 뒤로 높이 올라오면 → 턱을 당기고 두 손으로 상대 오른쪽 손목을 당겨 내린다
- 상대 다리가 허리를 감기 전에 → 엉덩이를 낮추고 길로틴 방어처럼 내 왼쪽(상대 오른쪽)으로 돈다
- 이미 조여 오면 → 늦었으면 바로 탭한다
