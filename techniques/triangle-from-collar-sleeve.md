# 트라이앵글 (칼라 슬리브) (Triangle from Collar Sleeve Guard)

[스파이더 · 라쏘 · 소매 가드](../positions/spider-lasso.md) · 서브미션 · 아래

다른 이름: 칼라 슬리브 트라이앵글, 깃 소매 트라이앵글, 칼라슬리브 삼각

## 세팅 과정 (오른손잡이 기준)

1. 내 오른손은 상대 왼쪽 깃, 왼손은 오른쪽 소매를 잡고 왼발은 오른쪽 이두, 오른발은 왼쪽 골반에 댄다
2. 깃을 당겨 무너뜨리면서 소매 잡은 상대 오른팔을 바깥 아래로 밀어 낸다
3. 이두를 밀던 내 왼다리를 떼어 상대 목 뒤로 넘긴다
4. 골반에 댔던 내 오른다리 오금에 왼쪽 발목을 걸어 삼각형을 만든다
5. 깃을 놓고 상대 머리를 당기며 무릎을 조여 조른다

## 핵심 디테일

- 내 오른손 깃 그립으로 상대 머리를 당겨 자세부터 무너뜨린다
- 소매 잡은 내 왼손으로 상대 오른팔을 바깥 아래로 밀어 내 다리 밖에 둔다
- 오른발로 상대 왼쪽 골반을 밀어 엉덩이를 들 공간을 만든다
- 잠근 뒤 깃을 놓고 두 손으로 머리를 당기며 무릎을 조인다

## 흔한 실수

- 깃을 안 당기고 다리만 올리면 상대가 자세를 세워 막는다 → 먼저 숙이게 한다
- 상대 오른팔이 안으로 들어오면 두 팔이 다 갇혀 안 조여진다 → 소매로 바깥에 밀어 둔다
- 왼쪽 발목을 오금에 얕게 걸면 쉽게 풀린다 → 깊게 건다

## 막히면

- 상대가 오른팔을 빼며 자세를 세우면 → [오모플라타 (칼라 슬리브)](../techniques/omoplata-from-collar-sleeve.md)
- 상대가 머리를 세워 다리가 목에 안 걸리면 → [칼라 슬리브 스윕](../techniques/collar-sleeve-sweep.md)
- 잠갔는데 조여지지 않으면 → [트라이앵글 → 암바](../techniques/triangle-to-armbar.md)

## 방어하는 쪽 (상대 입장)

- 상대가 내 왼쪽 깃을 당겨 머리를 숙이게 하고 상대 왼발이 내 오른쪽 이두에서 떨어지면 트라이앵글 신호
- 깃 그립부터 끊고 등을 세워 머리를 들며 두 팔을 같이 몸 앞에 붙인다
- 다리가 목에 걸렸으면 잠기기 전에 → 트라이앵글 탈출 (자세 세우기)
- 이미 잠겼으면 → 트라이앵글 스택 탈출
