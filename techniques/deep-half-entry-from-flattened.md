# 눌린 하프 → 딥 하프 (Deep Half Entry from Flattened)

[하프가드](../positions/half-guard.md) · 전환 · 아래 → [딥 하프가드](../positions/deep-half.md)

다른 이름: 눌렸을 때 딥 하프

## 세팅 과정 (오른손잡이 기준)

1. 상대 오른다리를 감은 채 브릿지 후 엉덩이를 내 오른쪽으로 빼며 오른쪽 어깨와 엉덩이를 바닥에 대 공간을 만든다
2. 내 오른팔로 상대 오른쪽 허벅지 안쪽을 깊게 감는다
3. 머리를 상대 오른다리 밑으로 넣으며 몸을 상대 아래로 밀어 넣는다
4. 상대 오른쪽 허벅지를 가슴에 꼭 붙여 딥 하프를 만든다

## 핵심 디테일

- 상대가 패스하려고 체중을 앞으로 옮기는 순간에 들어간다
- 내 오른팔로 상대 오른쪽 허벅지 안쪽을 깊게 감아 몸을 끌어당기는 손잡이로 쓴다
- 몸을 천장 쪽이 아니라 상대 다리 쪽으로 돌리며 머리를 상대 오른다리 밑으로 넣는다
- 다 들어갈 때까지 하프가드 다리 감기를 풀지 않는다

## 흔한 실수

- 상대 체중이 뒤에 있을 때 들어가면 밀려 나온다 → 상대가 앞으로 기울 때 들어간다
- 머리가 상대 다리 바깥에 남으면 크로스페이스·위저를 맞는다 → 머리를 다리 밑까지 넣는다
- 반만 들어가고 멈추면 프레임도 딥 하프도 없는 상태가 된다 → 한 번에 끝까지 들어간다

## 막히면

- 상대가 오른다리를 뒤로 빼 버티면 → [눌린 하프가드에서 회복](../techniques/flattened-half-guard.md)
- 상대가 일어서면 → [딥 하프 → X 가드](../techniques/deep-half-to-x-guard.md)
- 들어간 뒤 상대가 앞으로 무게를 실으면 → [웨이터 스윕](../techniques/waiter-sweep.md)

## 방어하는 쪽 (상대 입장)

- 상대 오른팔이 내 오른쪽 허벅지 안쪽을 파고들고 상대 머리가 내 다리 쪽으로 내려가면 신호
- 크로스페이스로 상대 머리를 내 쪽 위로 끌어올려 밑으로 못 내려가게 한다
- 체중은 상대 가슴 위에 두고 오른쪽 무릎을 바닥에 붙여 다리 밑 공간을 막는다
- 이미 딥 하프면 → 위저 (딥 하프 상대) · 백스텝 (딥 하프 상대)
