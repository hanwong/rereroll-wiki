# 헤드쿼터 상대 신 투 신 (Shin-to-Shin from Headquarters)

[패스](../positions/passing.md) · 전환 · 아래 → [오픈 가드](../positions/open-guard.md)

다른 이름: HQ 신투신

## 세팅 과정 (오른손잡이 기준)

1. 상대가 내 오른다리를 허벅지 사이에 끼운 헤드쿼터일 때
2. 내 오른손으로 상대 왼쪽 소매나 깃을 잡아 밀고 들어오지 못하게 한다
3. 상대 체중이 앞다리(상대 오른다리)로 쏠릴 때 엉덩이를 빼 각도를 만든다
4. 자유로운 내 왼다리 정강이를 상대 오른다리 정강이에 가로로 댄다
5. 내 왼손으로 상대 오른쪽 발목이나 바지 끝을 잡아 신 투 신을 만든다

## 핵심 디테일

- 내 오른손 그립으로 상대 왼쪽 소매·깃을 밀어 상대가 체중을 싣고 들어오지 못하게 한다
- 상대 체중이 앞다리(오른다리)에 실린 순간 엉덩이를 빼 각도를 만든다
- 내 왼쪽 정강이를 상대 오른쪽 정강이에 가로로 대고 내 왼손으로 상대 오른쪽 발목을 잡아 다리를 묶는다

## 흔한 실수

- 정면에서 버티면 상대 체중에 눌린다 → 엉덩이를 빼 각도를 먼저 만든다
- 정강이만 대고 발목을 안 잡으면 상대가 다리를 빼 다시 헤드쿼터로 온다 → 왼손으로 발목을 꼭 잡는다
- 오른손 그립이 없으면 상대가 상체로 눌러 온다 → 소매·깃을 밀어 거리를 둔다

## 막히면

- 상대가 앞으로 버티면 → [신 투 신 스윕](../techniques/shin-to-shin-sweep.md)
- 상대가 다리를 빼고 물러나면 → [신 투 신 → 싱글 레그 X](../techniques/shin-to-shin-to-single-leg-x.md)
- 상대가 무릎을 꿇어 정강이를 누르면 → [가드 리텐션 (다리 되돌리기)](../techniques/open-guard-retention.md)

## 방어하는 쪽 (상대 입장)

- 상대 왼쪽 정강이가 내 오른쪽 정강이에 가로로 붙고 상대 왼손이 내 오른쪽 발목을 잡으면 신 투 신 신호
- 앞다리에 체중을 다 싣지 말고 발목이 잡히기 전에 오른다리를 뒤로 빼 거리를 둔다
- 걸렸으면 오른쪽 무릎을 바닥 쪽으로 꿇어 상대 정강이를 눌러 죽이고 패스한다 (신 투 신 가드 패스)
