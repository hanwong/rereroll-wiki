# 크로스페이스 → 컴뱃 베이스 (Crossface to Combat Base)

[하프가드](../positions/half-guard.md) · 전환 · 위 → [패스](../positions/passing.md)

다른 이름: 하프 탑 리셋

## 세팅 과정 (오른손잡이 기준)

1. 내 오른다리가 감기면 내 오른팔 크로스페이스로 상대를 눌러 둔다
2. 감긴 오른다리 무릎을 세워 컴뱃 베이스 자세
3. 내 왼손으로 상대 오른쪽 무릎을 누른다
4. 니슬라이스로

## 핵심 디테일

- 무릎을 세우는 동안에도 내 오른팔 크로스페이스를 유지한다
- 감긴 오른다리 무릎을 세울 때 엉덩이는 높이 들지 않는다
- 내 왼손으로 상대 오른쪽 무릎을 바닥에 눌러 다리를 못 올리게 한다

## 흔한 실수

- 상체를 세우며 크로스페이스를 풀면 상대가 언더훅을 잡는다 → 끝까지 유지
- 무릎을 세울 때 공간이 생기면 상대가 밑으로 파고든다 → 무게를 상대 가슴에 둔다
- 무릎만 세우고 기다리면 상대가 다리를 다시 감는다 → 바로 니슬라이스로 잇는다

## 막히면

- 상대가 언더훅을 잡고 올라오면 → [하프 탑 위저 카운터](../techniques/half-guard-whizzer-counter.md)
- 상대가 밑으로 파고들면 → [위저 (딥 하프 상대)](../techniques/whizzer-from-deep-half.md)
- 상대 무릎이 눌렸으면 → [니 슬라이드 (컴뱃 베이스)](../techniques/knee-slide-from-combat-base.md)

## 방어하는 쪽 (상대 입장)

- 상대가 크로스페이스를 건 채 감긴 오른다리 무릎을 세우면 신호
- 무릎이 서며 생긴 공간에 내 왼쪽 무릎을 넣어 니 쉴드를 만든다
- 공간이 크면 상대 다리 밑으로 들어간다 → 눌린 하프 → 딥 하프
- 니슬라이스가 시작되면 → 컴뱃 베이스 상대 가드 회복
