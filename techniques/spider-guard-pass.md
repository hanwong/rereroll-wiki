# 스파이더 가드 패스 (Spider Guard Pass)

[스파이더 · 라쏘 · 소매 가드](../positions/spider-lasso.md) · 패스 · 위 → [사이드 컨트롤](../positions/side-control.md)

다른 이름: 스파이더 패스, 더블 슬리브 가드 패스, 소매 그립 패스, 칼라 슬리브 가드 패스, 칼라슬리브 패스

## 세팅 과정 (오른손잡이 기준)

1. 내 오른쪽 팔꿈치를 몸에 붙이고 손을 돌려 내 오른쪽 소매 그립을 끊는다
2. 끊은 내 오른손으로 상대 왼발을 잡아 바닥으로 내린다
3. 내 오른쪽 무릎을 상대 왼쪽 허벅지 위로 올린다
4. 니슬라이스나 토레안도로 상대 왼쪽으로 패스한다

## 핵심 디테일

- 그립이 살아 있는 채 패스하지 않는다 — 내 오른쪽 소매 그립부터 끊는다
- 팔꿈치를 옆구리에 붙이고 손목을 돌려 엄지 쪽으로 빼면 그립이 쉽게 끊긴다
- 끊자마자 상대 왼발을 바닥으로 눌러 다시 내 이두에 못 올리게 한다
- 등을 세우고 발을 넓게 서서 상대 발이 미는 힘에 끌려가지 않는다

## 흔한 실수

- 팔만 당겨 그립을 끊으려 하면 상대 발에 밀려 힘만 쓴다 → 팔꿈치를 몸에 붙이고 몸 전체로 뺀다
- 그립을 끊고 멈추면 상대가 바로 다시 잡는다 → 끊자마자 발을 누른다
- 상체를 숙이면 트라이앵글·오모플라타 각이 생긴다 → 등을 세운다

## 막히면

- 상대가 내 왼쪽 소매까지 잡고 버티면 → 두 그립을 끊고 [스택 패스 (스파이더 상대)](../techniques/stack-pass-from-spider.md)
- 상대가 다리를 감아 라쏘로 바꾸면 → [라쏘 가드 패스](../techniques/lasso-guard-pass.md)
- 상대 왼쪽 무릎이 세워져 니슬라이스가 막히면 → [토레안도 패스](../techniques/toreando-pass.md)

## 방어하는 쪽 (상대 입장)

- 상대가 오른쪽 팔꿈치를 몸에 붙이며 손목을 돌리면 내 왼손 그립을 끊으려는 신호
- 소매를 깊게(팔꿈치 쪽) 잡고 내 왼발로 상대 오른쪽 이두를 계속 밀어 팔을 펴 둔다
- 그립이 끊기면 바로 다리를 감아 라쏘나 데라히바로 다시 건다
- 상대 오른쪽 무릎이 내 왼쪽 허벅지 위로 넘어오면 무릎을 가슴 쪽으로 당겨 막고, 지나가면 하프가드라도 잡는다
