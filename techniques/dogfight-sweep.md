# 도그파이트 스윕 (Dogfight Sweep)

[하프가드](../positions/half-guard.md) · 스윕 · 아래 → [사이드 컨트롤](../positions/side-control.md)

다른 이름: 도그파이트에서 넘기기

## 세팅 과정 (오른손잡이 기준)

1. 도그파이트(내 왼팔 언더훅)에서 상대가 몸을 상대 왼쪽으로 돌리면 내 오른손으로 상대 왼쪽 발목을 잡아 당긴다
2. 상대가 내 쪽으로 돌면 내 오른손으로 상대 오른쪽 무릎을 밀어 엉덩이를 바닥으로
3. 내 왼쪽 어깨와 머리로 상대 오른쪽 가슴을 밀어붙인다
4. 위로 올라와 사이드

## 핵심 디테일

- 손보다 먼저 언더훅과 머리로 앞으로 미는 압박을 만든다
- 상대가 도는 방향을 본다 — 상대 왼쪽으로 돌면 왼쪽 발목, 내 쪽으로 돌면 오른쪽 무릎
- 똑바로가 아니라 잡은 다리 쪽으로 비스듬히 밀고 들어간다
- 상대 등이 닿을 때까지 멈추지 말고 다리를 빼 사이드까지 간다

## 흔한 실수

- 압박 없이 손만 뻗으면 → 상대가 다리를 빼고 위저로 누른다 → 먼저 민다
- 언더훅이 얕아지면 → 미는 힘이 안 들어간다 → 깊게 유지
- 넘어뜨리고 멈추면 → 상대가 다시 하프가드로 감는다 → 바로 사이드까지

## 막히면

- 상대가 위저로 강하게 눌러 오면 → [도그파이트 → 하프가드 복귀](../techniques/re-pull-half-guard-from-dogfight.md)
- 상대가 다리를 빼며 등이 보이면 → [하프가드 백 테이크](../techniques/half-guard-back-take.md)
- 상대가 넓게 짚고 버티면 → [도그파이트 전진 스윕](../techniques/forward-drive-sweep-from-dogfight.md)

## 방어하는 쪽 (상대 입장)

- 상대 오른손이 내 왼쪽 발목이나 오른쪽 무릎으로 오면 스윕 신호
- 내 오른팔 위저와 왼팔 크로스페이스로 상대를 다시 눕히고 엉덩이를 뒤로 뺀다
- 잡히기 쉬운 다리는 몸 쪽으로 당겨 두고 멀리 넓게 짚지 않는다
- 이미 넘어가면 바로 상대 쪽으로 돌아 다리를 감아 하프가드로 막는다
