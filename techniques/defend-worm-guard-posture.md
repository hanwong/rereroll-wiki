# 웜 가드 상대 자세 지키기 (Posture Defense vs Worm Guard)

[라펠 가드](../positions/lapel-guard.md) · 방어 · 위 → [오픈 가드](../positions/open-guard.md)

다른 이름: 라펠 가드 방어, 웜가드 디펜스

## 세팅 과정 (오른손잡이 기준)

1. 상대가 내 오른쪽 라펠을 빼려 하면 내 오른손으로 오른쪽 깃을 가슴에 눌러 못 빼게 막는다
2. 이미 감겼으면 엉덩이를 뒤로 빼고 등을 세워 숙여지지 않게 한다
3. 라펠 끝을 쥔 상대 손목을 내 두 손으로 잡아 손가락을 떼어낸다
4. 풀린 라펠을 내 오른다리에서 빼내 몸 쪽에 붙이고 바로 패스 그립을 잡는다

## 핵심 디테일

- 라펠이 빠지기 전에 내 오른손으로 오른쪽 깃을 가슴에 눌러 두는 게 가장 쉬운 방어
- 감겼으면 발을 넓게 서고 엉덩이를 뒤로 빼 숙여지지 않게 한다
- 라펠 끝을 쥔 상대 손목은 두 손을 다 써서 손가락을 떼어 낸다
- 풀리면 바로 패스 그립을 잡아 다시 감을 틈을 안 준다

## 흔한 실수

- 숙인 채 라펠을 풀면 스윕 당한다 → 등을 세운 뒤 푼다
- 라펠이 감긴 길을 안 보고 당기면 더 조인다 → 감긴 방향을 거꾸로 풀어 나간다
- 그립 싸움에 집중하다 균형이 무너지면 넘어간다 → 넘어갈 것 같으면 균형 먼저

## 막히면

- 손가락이 안 떨어지면 → [거리 만들어 리셋 (라펠 상대)](../techniques/distance-creation-to-reset.md)
- 라펠이 다리에 묶인 채로 패스하고 싶으면 → [니슬라이스 (라펠 잡힌 채)](../techniques/knee-slice-despite-lapel.md)
- 상대가 스윕으로 흔들어 오면 → 넓게 서서 버틴 뒤 [스택 패스 (라펠 상대)](../techniques/stack-pass-over-lapel.md)

## 방어하는 쪽 (상대 입장)

- 상대가 엉덩이를 빼고 등을 세우면 라펠을 더 당겨 숙이게 하며 흔든다
- 상대 두 손이 라펠 쥔 내 손목에 오면 받침이 약해진 때 → 웜 가드 스윕
- 라펠이 벗겨지면 바로 데라히바 가드나 스파이더 가드로 바꾼다
