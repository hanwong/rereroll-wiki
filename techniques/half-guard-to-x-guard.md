# 하프가드 → X 가드 (Half Guard to X-Guard)

[하프가드](../positions/half-guard.md) · 전환 · 아래 → [X 가드 · 싱글 레그 X · 앵클락](../positions/x-guard.md)

다른 이름: 하프 X가드

## 세팅 과정 (오른손잡이 기준)

1. 상대 오른다리를 감은 하프에서 상대가 일어서면 상대 오른다리 밑으로 머리와 어깨를 넣는다
2. 상대 오른다리를 내 오른쪽 어깨에 얹어 오른팔로 끌어안는다
3. 내 오른발은 상대 왼쪽 무릎 뒤, 왼발은 상대 왼쪽 골반 앞에 건다
4. 두 발을 X로 엇갈려 X 가드를 잡는다

## 핵심 디테일

- 상대가 일어서서 체중이 위로 뜰 때 들어간다
- 팔로만 안지 말고 머리와 오른쪽 어깨를 상대 오른다리 밑까지 깊게 넣는다
- 내 오른팔로 안은 상대 오른다리를 놓기 전에 두 발 훅을 먼저 건다
- 훅을 건 뒤 다리를 펴서 상대를 내 몸 위에 띄운다

## 흔한 실수

- 상대가 무릎 꿇고 눌러 있을 때 하면 밑으로 못 들어간다 → 상대가 설 때 쓴다
- 하프 다리를 너무 일찍 풀면 상대가 다리를 빼고 패스한다 → 오른팔로 안은 뒤 푼다
- 어깨가 덜 들어가면 상대가 다리를 빼 버린다 → 어깨를 무릎 위쪽까지 넣는다

## 막히면

- 상대가 다시 무릎을 꿇고 내려앉으면 → [딥 하프가드](../techniques/deep-half-guard.md)
- X 가드가 잡히면 → [X 가드 스윕](../techniques/x-guard-sweep.md)
- 상대가 왼다리를 빼 디디면 → [X 가드 → 싱글 레그 X](../techniques/x-guard-to-single-leg-x.md)
- 상대 왼다리가 떠서 무릎이 안으로 돌면 → [애시 가라미 (스트레이트 애시)](../techniques/ashi-garami.md)

## 방어하는 쪽 (상대 입장)

- 내가 일어설 때 상대가 내 오른다리 밑으로 머리와 어깨를 넣어 오면 신호
- 일어서기 전에 상대 머리와 어깨를 눌러 둔다
- 상대가 다리를 안으면 무릎을 꿇고 체중을 상대 위로 실어 앉는다
- X 가드가 잡혔으면 → 무릎 눌러 X 가드 패스 · X 가드 빠져나오기 (서서)
