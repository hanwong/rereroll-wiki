# 스위블 테이크다운 (RDLR) (Swivel Takedown from RDLR)

[데라히바 · 리버스 데라히바](../positions/de-la-riva.md) · 스윕 · 아래 → [패스](../positions/passing.md)

다른 이름: 리버스 데라 테이크다운

## 세팅 과정 (오른손잡이 기준)

1. 리버스 데라히바(내 오른다리 훅·상대 오른다리)에서 골반에 댄 왼발을 떨어뜨려 차며 180도 돈다
2. 내 오른쪽 어깨를 상대 오른쪽 무릎 뒤에 붙인다
3. 훅 건 오른다리를 접어 상대 오른발을 가둔 채 뒤로 당긴다
4. 상대가 앉으면 상대 오른쪽 발목을 잡고 일어나 패스한다

## 핵심 디테일

- 골반의 왼발을 떨어뜨려 차는 힘으로 180도 돌아 오른쪽 어깨를 상대 오른쪽 무릎 뒤에 붙인다
- 훅 건 오른다리를 접어 상대 오른발을 가둬야 상대가 발을 빼 버티지 못한다
- 상대가 뒤로 앉으면 바로 오른쪽 발목을 잡고 일어나 패스로 이어 위를 잡는다

## 흔한 실수

- 어깨가 무릎 뒤에 붙지 않으면 상대가 다리를 빼고 걸어 나간다 → 회전하며 어깨를 오금에 바짝 붙인다
- 상대 오른발을 가두지 않고 당기면 상대가 발을 빼 버틴다 → 오른다리로 발을 감아 둔다
- 넘긴 뒤 누워 있으면 상대가 다시 가드를 잡는다 → 발목을 잡은 채 바로 일어난다

## 막히면

- 상대가 앞으로 숙여 버티면 → [리버스 데라히바 → 크랩 라이드](../techniques/rdlr-to-crab-ride.md)
- 상대가 다리를 빼고 돌아서면 → [리버스 데라히바 유지 · 회복](../techniques/reverse-de-la-riva-recovery.md)

## 방어하는 쪽 (상대 입장)

- 상대가 골반에 댄 왼발을 떼고 몸을 돌려 상대 오른쪽 어깨가 내 오른쪽 무릎 뒤로 오면 신호
- 내 오른발이 갇히기 전에 오른다리를 빼고 체중을 앞으로 실어 뒤로 앉혀지지 않게 한다
- 앉혀지면 바로 다리를 세워 가드를 만들어 상대가 일어나며 패스하지 못하게 한다
