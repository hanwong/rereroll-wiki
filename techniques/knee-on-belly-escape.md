# 니 온 밸리 이스케이프 (Knee on Belly Escape)

[니 온 밸리](../positions/knee-on-belly.md) · 탈출 · 아래 → [오픈 가드](../positions/open-guard.md) / [하프가드](../positions/half-guard.md) / [터틀 · 크루시픽스](../positions/turtle.md)

다른 이름: 니온벨리 탈출, 니온밸리 이스케이프, KOB 이스케이프, 무릎 밀어 가드 회복 (니 온 밸리 아래), KOB 리가드, 니온밸리 가드 회복

## 세팅 과정 (오른손잡이 기준)

1. 상대가 내 오른쪽에서 니 온 밸리를 잡으면 무릎을 손으로 치우지 말고 양 팔뚝으로 상대 오른쪽 무릎과 골반에 프레임을 만든다
2. 내 오른쪽(상대 쪽)으로 돌며 엉덩이를 내 왼쪽으로 빼서 무릎을 떨어뜨린다
3. 내 오른쪽 무릎을 상대와 나 사이로 넣는다
4. 가드로 돌아오거나 터틀로 돌아 일어난다

## 핵심 디테일

- 손바닥으로 무릎을 밀지 말고 양 팔뚝으로 상대 오른 무릎과 골반에 프레임을 만든다
- 옆으로 돌아누운 뒤에 엉덩이를 뺀다 — 등이 바닥에 붙은 채로는 엉덩이가 안 빠진다
- 살짝 브릿지해 무릎 무게가 뜬 순간 엉덩이를 내 왼쪽으로 빼 무릎을 떨어뜨린다
- 팔꿈치를 몸에 붙인 채 오른 무릎을 바로 사이로 넣는다

## 흔한 실수

- 팔을 쭉 뻗어 무릎을 밀면 암바를 당한다 → 팔꿈치를 굽힌 팔뚝으로 막는다
- 무릎 쪽으로 엉덩이를 빼면 더 깊이 깔린다 → 상대 무릎에서 멀어지는 내 왼쪽으로 뺀다
- 공간을 만들고 무릎을 늦게 넣으면 상대가 다시 올라탄다 → 공간이 생기면 바로 무릎을 넣는다

## 막히면

- 상대가 무릎을 옮겨 다시 올라타면 → 프레임을 다시 세우고 엉덩이를 한 번 더 뺀다
- 상대가 마운트로 넘어오면 → [마운트 이스케이프 (엘보)](../techniques/mount-escape-elbow.md)
- 엉덩이를 뺄 공간이 없으면 → [터틀로 돌기 (니 온 밸리 아래)](../techniques/turn-to-turtle-from-kob.md)

## 방어하는 쪽 (상대 입장)

- 아래 상대가 양 팔뚝을 내 오른 무릎 · 골반에 대고 옆으로 돌기 시작하면 신호다
- 상대 엉덩이가 빠지는 쪽으로 무릎을 옮겨 다시 배를 누른다
- 공간이 생기면 무릎이 들어오기 전에 니 온 밸리 → 마운트로 넘어간다
- 뻗어 나온 팔이 보이면 암바 (니 온 밸리, 가까운 팔)로 잡는다
