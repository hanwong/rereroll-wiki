# 변형 곁누르기 (Kuzure Kesa Gatame)

[곁누르기](../positions/kesa-gatame.md) · 자세 · 컨트롤 · 위 → [곁누르기](../positions/kesa-gatame.md)

다른 이름: 쿠즈레 케사가타메, 언더훅 케사, 변형곁누르기, 모디파이드 스카프 홀드

## 세팅 과정 (오른손잡이 기준)

1. 상대 오른쪽 곁누르기에서 목을 감는 대신 내 오른팔을 상대 왼 겨드랑이 아래로 넣어 언더훅을 잡는다
2. 상대 오른팔은 내 왼 겨드랑이에 끼운다
3. 내 오른다리는 앞, 왼다리는 뒤로 벌려 베이스를 잡고 엉덩이를 상대 오른 옆구리에 붙인다
4. 여기서 기무라 · 아메리카나 · 마운트 전환을 노린다

## 핵심 디테일

- 오른팔 언더훅을 상대 왼 겨드랑이 깊숙이 넣어 상대 상체가 못 돌게 한다
- 목을 감지 않아 상대가 머리를 빼 백을 노리기 어렵다
- 엉덩이를 상대 오른 옆구리에 붙이고 오른다리 앞 · 왼다리 뒤로 넓게 벌린다

## 흔한 실수

- 언더훅이 얕으면 상대가 왼팔을 빼고 돌아 들어온다 → 어깨까지 깊게 넣는다
- 엉덩이가 뜨면 상대가 무릎을 넣는다 → 옆구리에 붙인다
- 다리를 모으면 브릿지에 넘어간다 → 넓게 벌린다

## 막히면

- 상대가 끼인 오른팔을 빼려 하면 → [아메리카나 (변형 곁누르기)](../techniques/americana-from-kuzure-kesa.md)
- 상대 목 앞이 열려 있으면 → [브레드커터 (변형 곁누르기)](../techniques/breadcutter-from-kuzure-kesa.md) 또는 [페이퍼 커터 초크](../techniques/paper-cutter-choke.md)
- 상대가 브릿지로 버티면 → [곁누르기 → 마운트](../techniques/kesa-to-mount.md)

## 방어하는 쪽 (상대 입장)

- 상대 오른팔이 내 목 대신 내 왼 겨드랑이 아래로 들어오면 → 변형 곁누르기 신호
- 왼 팔꿈치를 옆구리에 붙여 언더훅이 깊게 못 들어오게 한다
- 끼인 내 오른팔은 팔꿈치를 굽혀 몸 쪽으로 붙여 둔다
