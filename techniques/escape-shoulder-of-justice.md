# 숄더 오브 저스티스 이스케이프 (Escape Shoulder of Justice)

[사이드 컨트롤](../positions/side-control.md) · 탈출 · 아래 → [하프가드](../positions/half-guard.md)

다른 이름: 어깨 압박 빠져나오기, 숄더 프레셔 탈출, Shoulder of Justice Escape

## 세팅 과정 (오른손잡이 기준)

1. 상대가 내 오른쪽에서 누르면 턱을 당기고 내 오른쪽 팔꿈치로 상대 골반을 막는다
2. 내 왼팔 팔뚝을 상대 목 아래에 끼워 프레임을 만든다
3. 브릿지로 상대를 살짝 띄우고 고개를 내 오른쪽(상대 쪽)으로 돌린다
4. 엉덩이를 내 왼쪽으로 빼며 오른쪽 무릎을 넣어 다리를 감는다 → 하프가드

## 핵심 디테일

- 턱을 당기고 코로 천천히 숨을 쉬어 당황하지 않는다
- 오른 팔꿈치는 상대 골반, 왼 팔뚝은 상대 목 아래 — 팔을 굽힌 채 짧게 프레임을 만든다
- 브릿지로 무게가 잠깐 뜰 때 고개를 내 오른쪽으로 돌려 어깨에서 턱을 뺀다
- 엉덩이를 내 왼쪽으로 빼고 오른 무릎을 넣어 상대 다리를 감는다

## 흔한 실수

- 팔을 쭉 뻗어 밀면 기무라 · 아메리카나를 당한다 → 팔꿈치를 굽혀 몸에 붙인 프레임만 쓴다
- 압박이 가장 셀 때 억지로 움직이면 힘만 빠진다 → 상대가 체중을 옮길 때 맞춰 움직인다
- 왼팔을 내 얼굴 앞으로 넘기면 암 트라이앵글이 걸린다 → 왼 팔뚝은 상대 목 아래 프레임에 둔다

## 막히면

- 상대가 골반을 다시 붙이며 누르면 → 프레임을 유지하고 다음 틈을 기다린다
- 상대가 내 무릎을 넘어 마운트로 가면 → [마운트 이스케이프 (엘보)](../techniques/mount-escape-elbow.md)
- 엉덩이를 뺄 공간이 없으면 → [터틀로 돌기 (사이드)](../techniques/roll-to-turtle.md)

## 방어하는 쪽 (상대 입장)

- 아래 상대가 왼 팔뚝을 내 목 아래에 넣고 발을 딛어 브릿지를 준비하면 신호다
- 엉덩이를 상대 골반에 다시 붙이고 어깨 압박을 더 걸어 프레임을 무너뜨린다
- 상대 팔이 뻗어 나오면 기무라 (사이드)로 그 팔을 잡는다
- 상대 엉덩이가 빠져 공간이 생기면 무릎이 들어오기 전에 따라붙거나 마운트로 넘어간다
