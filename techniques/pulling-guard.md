# 가드 풀링 (Pulling Guard)

[클린치 · 가드 풀링](../positions/clinch.md) · 가드 풀링 · 서서 → [클로즈드 가드](../positions/closed-guard.md)

다른 이름: 풀 가드, 가드 당기기, 가드 풀, 풀링 가드, 클린치에서 가드 풀링, 클린치 가드 풀

## 세팅 과정 (오른손잡이 기준)

1. 내 오른손은 상대 왼쪽 깃, 내 왼손은 상대 오른쪽 소매(또는 손목)를 잡는다
2. 내 오른발을 상대 왼쪽 골반에 밟고 엉덩이를 뒤로 떨어뜨리며 상대를 당긴다
3. 내 왼다리를 상대 오른쪽 허리 뒤로 감는다
4. 내 오른발도 골반에서 빼 상대 등 뒤로 감고 두 발목을 걸어 클로즈드 가드를 완성한다(또는 바로 오픈 가드)

## 핵심 디테일

- 앉기 전에 깃 · 소매 그립 두 개를 먼저 잡는다
- 내 오른발로 상대 왼쪽 골반을 밟아 상대를 앞으로 끌며 엉덩이를 상대 발 가까이 떨어뜨린다
- 떨어지면서 바로 다리로 상대 허리를 감아 공간을 없앤다
- 엉덩이 → 등 순서로 둥글게 앉아 뒤로 털썩 넘어지지 않는다

## 흔한 실수

- 그립 없이 앉으면 상대가 바로 다리를 피해 패스한다 → 그립 두 개 먼저
- 멀리 떨어지면 상대가 서서 다리를 피한다 → 상대를 내 쪽으로 끌어당기며 앉는다
- 뛰어올라 매달리면 둘 다 다칠 수 있다 → 엉덩이를 바닥에 먼저 내린다

## 막히면

- 상대가 뒤로 빠져 다리를 못 감으면 → 왼다리로 [데라히바 가드](../techniques/de-la-riva-guard.md)나 [발 골반 가드 (피트 온 힙스)](../techniques/feet-on-hips-guard.md)
- 상대가 다리 사이에서 일어서면 → [상대가 섰을 때 클로즈드 가드 유지](../techniques/closed-guard-vs-standing.md)
- 상대가 무릎을 꿇고 들어오면 → [클로즈드 가드 (자세 · 포스처 깨기)](../techniques/closed-guard-basics.md)

## 방어하는 쪽 (상대 입장)

- 상대 오른손이 내 왼쪽 깃, 왼손이 내 오른쪽 소매를 잡고 상대 오른발이 내 왼쪽 골반에 올라오면 가드 풀링 신호
- 상체를 세우고 엉덩이를 뒤로 빼 거리를 두며 골반에 올라온 상대 발을 쳐낸다
- 상대가 앉는 순간 소매 그립을 끊고 다리가 감기기 전에 옆으로 돈다
- 이미 앉았으면 가드 풀링 당했을 때 패스 시작
