# 웜 가드 진입 (Worm Guard Entry)

[라펠 가드](../positions/lapel-guard.md) · 전환 · 아래 → [라펠 가드](../positions/lapel-guard.md)

다른 이름: 웜가드, 웜 가드, 벌레 가드

## 세팅 과정 (오른손잡이 기준)

1. 상대 오른쪽 라펠 끝을 빼서 상대 오른다리 뒤(오금)로 돌려 바깥으로 꺼낸다
2. 꺼낸 라펠을 내 왼쪽 정강이 위로 넘겨 왼다리로 라펠을 감는다
3. 라펠 끝은 내 오른손으로 잡고 감은 왼발은 상대 오른쪽 골반에 둔다
4. 라펠을 당겨 상대 상체를 앞으로 숙이게 하며 스윕을 노린다

## 핵심 디테일

- 라펠을 상대 오른쪽 오금 깊이 돌려야 감은 뒤 힘이 걸린다
- 꺼낸 라펠을 내 왼쪽 정강이 위로 넘겨 감고 남은 늘어짐을 바로 당겨 없앤다
- 감은 왼발은 상대 오른쪽 골반을 밀어 거리를 지킨다
- 상대가 앞으로 디디거나 일어서려 할 때 감으면 쉽게 들어간다

## 흔한 실수

- 라펠을 허벅지 겉으로만 걸면 당길 때 풀린다 → 오금 깊이 돌린다
- 감는 동안 거리를 놓치면 상대가 무릎으로 눌러 패스한다 → 엉덩이를 빼고 발로 골반을 민다
- 감고 나서 라펠을 느슨하게 두면 상대가 벗겨 낸다 → 늘 당긴다

- 상대가 자세를 세워 버티면 → [웜 가드 스윕](../techniques/worm-guard-sweep.md)
- 상대가 숙여 손을 짚으면 → [라펠 스윕 → 백](../techniques/lapel-sweep-to-back.md)
- 상대가 뒤로 물러나 라펠을 풀면 → [라펠 → 데라히바](../techniques/lapel-to-de-la-riva.md)

## 방어하는 쪽 (상대 입장)

- 상대가 내 오른쪽 라펠을 내 오른다리 뒤로 돌려 꺼내면 웜 가드 신호
- 꺼내기 전에 내 오른손으로 깃을 가슴에 눌러 막고 오른다리를 뒤로 뺀다
- 이미 감겼으면 엉덩이를 빼고 등을 세워 숙여지지 않게 한 뒤 → 웜 가드 상대 자세 지키기
