# 보우 앤 애로우 초크 (Bow and Arrow Choke)

[백 컨트롤](../positions/back-control.md) · 서브미션 · 위

다른 이름: 활 조르기, 보우앤애로우, 보우 앤 애로, 보우 앤 애로우

## 세팅 과정 (오른손잡이 기준)

1. 뒤에서 내 오른팔을 상대 오른쪽 어깨 위로 넘겨 상대 왼쪽 깃을 네 손가락을 넣어 깊게 잡는다
2. 오른손 반대쪽인 내 왼쪽으로 엉덩이를 빼며 왼발 훅을 풀고 왼쪽 옆으로 눕는다
3. 내 왼손으로 상대 왼쪽 바지 무릎 부분을 잡는다
4. 내 오른다리를 상대 왼쪽 어깨 위로 넘긴다
5. 깃은 당기고 바지는 아래로 당겨 몸을 활처럼 펴며 조인다

## 핵심 디테일

- 오른손은 상대 왼쪽 깃에 네 손가락을 넣어 깊게 잡는다
- 내 왼쪽으로 엉덩이를 빼며 옆으로 누워 각도를 만든다
- 왼손으로 상대 왼쪽 바지 무릎을 잡는다
- 깃은 당기고 바지는 아래로 당겨 몸을 활처럼 펴며 조인다

## 흔한 실수

- 깃 그립이 얕으면 조여도 안 걸린다 → 깃을 귀 아래까지 깊게 잡는다
- 옆으로 눕지 않고 등 뒤에서만 당기면 각도가 안 난다 → 왼쪽으로 엉덩이를 빼고 눕는다
- 다리를 넘기지 않으면 상대가 돌아 나온다 → 오른다리를 상대 왼쪽 어깨 위로 넘긴다

## 막히면

- 상대가 양손으로 깃 잡은 손을 막으면 → [암바 (백)](../techniques/armbar-from-back.md)
- 상대가 내 쪽으로 돌아 나오려 하면 → [백 컨트롤 유지 (시트벨트 · 훅)](../techniques/back-control-maintain.md)
- 깃이 안 잡히면 → [리어 네이키드 초크](../techniques/rear-naked-choke.md)

## 방어하는 쪽 (상대 입장)

- 상대 오른손이 내 왼쪽 깃에 깊게 들어오면 보우 앤 애로우 신호
- 턱을 당기고 양손으로 그 손목을 잡아 깃에서 떼어 낸다
- 상대가 옆으로 누우며 내 바지를 잡으면 상대 쪽으로 몸을 돌려 각도를 없앤다
- 깃이 깊게 걸려 조여 오면 버티지 말고 탭한다
