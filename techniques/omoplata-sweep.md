# 오모플라타 스윕 (Omoplata Sweep)

[클로즈드 가드](../positions/closed-guard.md) · 스윕 · 아래 → [마운트](../positions/mount.md) / [사이드 컨트롤](../positions/side-control.md)

다른 이름: 오모플라타로 넘기기

## 세팅 과정 (오른손잡이 기준)

1. 오모플라타 자세(내 왼다리가 상대 오른쪽 어깨 위)에서 내 오른팔로 상대 허리를 잡아 못 구르게 한다
2. 상대가 앞으로 구르지 않고 버티면 내 몸을 상대 쪽으로 기울여 상대를 상대 왼쪽 옆으로 민다
3. 내 왼다리로 상대 오른쪽 어깨를 계속 누른다
4. 넘어가면 위로 올라와 마운트나 사이드

## 핵심 디테일

- 내 오른팔로 허리를 감아 상대가 앞으로 구르지 못하게 묶는다
- 앉아 올라와 내 체중을 상대 등 · 옆구리 쪽에 싣는다
- 내 왼다리로 상대 오른쪽 어깨를 계속 눌러 오른팔이 풀리지 않게 한다
- 상대가 넘어가면 바로 다리를 풀고 가슴부터 위로 올라간다

## 흔한 실수

- 허리를 놓으면 상대가 앞으로 굴러 빠진다 → 끝까지 감는다
- 누운 채 밀면 체중이 안 실린다 → 상체를 세워 앉는다
- 넘긴 뒤 다리를 늦게 빼면 상대가 다리를 감는다 → 바로 가슴부터 올라간다

## 막히면

- 상대가 엎드린 채 버티기만 하면 → [오모플라타 마무리](../techniques/omoplata-finish.md)
- 상대가 무릎을 세워 일어나려 하면 → [오모플라타 → 백](../techniques/omoplata-to-back.md)

## 방어하는 쪽 (상대 입장)

- 상대가 내 허리를 감고 앉아 올라오면 → 스윕 · 마무리 신호
- 허리가 감기기 전에 → 오모플라타 앞구르기 탈출
- 내 왼쪽으로 밀릴 땐 왼쪽 무릎을 넓게 벌려 짚어 버틴다
- 넘어갔으면 상대 다리를 감아 하프가드라도 잡는다
