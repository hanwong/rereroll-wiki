# 리버스 X → 백 테이크 (Reverse X to Back Take)

[X 가드 · 싱글 레그 X · 앵클락](../positions/x-guard.md) · 백 테이크 · 아래 → [백 컨트롤](../positions/back-control.md)

다른 이름: 리버스 X 백

## 세팅 과정 (오른손잡이 기준)

1. 내 왼쪽 어깨에 얹은 상대 오른다리를 안고 상대 뒤로 돈다
2. 내 오른손으로 상대 허리띠를 잡고 상대를 앉힌다
3. 상대 등 뒤로 나와 두 발로 훅을 넣는다
4. 백 컨트롤을 잡는다

## 핵심 디테일

- 상대가 다리를 빼거나 돌아설 때 따라가는 기술 — 상대 움직임을 이용한다
- 도는 동안 상대 오른다리를 계속 안아 상대가 멀어지지 못하게 한다
- 내 오른손으로 허리띠를 잡아 상대를 엉덩이로 앉혀야 등에 붙을 수 있다
- 등에 닿자마자 시트벨트와 훅부터 잡는다

## 흔한 실수

- 상대가 앞으로 단단히 버틸 때 억지로 돌면 → 깔린다 → 스윕을 먼저 보여 상대가 물러날 때 간다
- 천천히 돌면 → 상대가 돌아서 마주본다 → 한 번에 돈다
- 등에 닿고 훅이 늦으면 → 상대가 등을 바닥에 대며 빠진다 → 바로 훅

## 막히면

- 상대가 손을 짚고 돌아서 마주보면 → [리버스 X 가드 스윕](../techniques/reverse-x-guard-sweep.md)
- 상대가 엉덩이를 바닥에 앉혀 버티면 → [싱글 레그 X 가드](../techniques/single-leg-x-guard.md)로 바꿔 다시 노린다
- 상대가 엎드리면 → [터틀에서 백 테이크](../techniques/turtle-back-take.md)

## 방어하는 쪽 (상대 입장)

- 상대가 내 다리를 당기며 내 다리 아래로 몸을 돌려 들어오면 백을 노리는 신호
- 바로 엉덩이를 낮게 앉혀 상대가 돌 공간을 없앤다
- 상대 쪽으로 몸을 돌려 마주본다 — 등을 돌리면 끝
- 이미 등에 붙었으면 훅이 들어오기 전에 손 싸움부터 → 핸드 파이팅 (백 아래)
