# 인버티드 가드 패스 (Inverted Guard Pass)

[패스](../positions/passing.md) · 패스 · 위 → [사이드 컨트롤](../positions/side-control.md)

다른 이름: 인버티드 패스, 인버트 패스, 거꾸로 가드 패스, 인버티드 상대 패스, Pass Inverted Guard

## 세팅 과정 (오른손잡이 기준)

1. 상대가 뒤집히기 시작하면 한 걸음 물러나 거리를 만든다
2. 내 양손으로 상대 양 무릎 바깥쪽을 잡는다
3. 상대 두 다리를 상대 왼쪽(내 오른쪽)으로 눌러 골반 방향을 돌린다
4. 내 왼쪽으로 크게 한 걸음 돌아 상대 오른쪽 엉덩이 옆으로 간다
5. 가슴을 붙여 상대 오른쪽에서 사이드 컨트롤을 잡는다

## 핵심 디테일

- 상대가 뒤집히기 시작하면 다가가지 말고 한 걸음 물러나 다리 훅을 피한다
- 두 손으로 상대 양 무릎 바깥을 잡아 다리를 묶는다
- 상대 두 다리를 상대 왼쪽(내 오른쪽)으로 눌러 골반을 돌린다
- 내 왼쪽으로 크게 돌아 상대 오른쪽 엉덩이 옆에 가슴을 붙인다

## 흔한 실수

- 뒤집힌 상대에게 바로 붙으면 베림볼로나 백을 당한다 → 먼저 물러나 거리를 만든다
- 무릎만 잡고 골반을 안 돌리면 상대가 다리를 다시 세운다 → 다리를 바닥 쪽으로 눌러 돌린다
- 돌아간 뒤 가슴이 뜨면 상대가 무릎을 넣는다 → 바로 가슴을 붙인다

## 막히면

- 상대가 내 다리에 훅을 걸어 당기면 → 다리를 빼고 다시 물러나 [오픈 가드 패스 자세 · 거리](../techniques/open-guard-passing-posture.md)
- 상대가 다리를 다시 세우면 → [토레안도 패스](../techniques/toreando-pass.md)나 [레그 드래그](../techniques/leg-drag.md)

## 방어하는 쪽 (상대 입장)

- 상대가 물러나며 내 양 무릎을 잡고 다리를 내 왼쪽으로 눌러 오면 패스 신호
- 무릎이 눌리기 전에 다리를 다시 세워 상대 골반이나 다리에 훅을 건다
- 이미 내 오른쪽으로 돌아왔으면 내 오른쪽 어깨로 돌아누워 무릎을 다시 넣는다
