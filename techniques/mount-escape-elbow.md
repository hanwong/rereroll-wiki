# 마운트 이스케이프 (엘보) (Elbow Escape from Mount)

[마운트](../positions/mount.md) · 탈출 · 아래 → [하프가드](../positions/half-guard.md) / [클로즈드 가드](../positions/closed-guard.md)

다른 이름: 니 투 엘보, 쉬림프 이스케이프, 엘보 이스케이프

## 세팅 과정 (오른손잡이 기준)

1. 마운트 아래에서 몸을 내 오른쪽으로 돌려 오른 팔꿈치로 상대 왼 무릎이나 골반에 프레임을 만든다
2. 엉덩이를 내 왼쪽으로 빼며(쉬림프) 공간을 만든다
3. 내 오른 무릎을 상대 왼다리 안쪽으로 넣어 다리를 빼낸다
4. 왼쪽으로 돌아 왼 팔꿈치 프레임으로 왼다리도 빼서 하프가드나 클로즈드 가드로 돌아온다

## 핵심 디테일

- 바로 눕지 말고 먼저 오른쪽으로 돌아누워 오른 팔꿈치를 상대 왼 무릎에 붙인다
- 팔꿈치는 몸에 붙인 채 프레임으로 쓰고 팔을 쭉 뻗지 않는다
- 엉덩이를 내 왼쪽으로 크게 빼야 오른 무릎이 들어간다
- 한쪽 다리를 빼면 바로 다음 쪽으로 이어 간다

## 흔한 실수

- 바로 누운 채 새우빼기하면 엉덩이가 안 빠진다 → 옆으로 돌아누워 뺀다
- 팔을 뻗어 상대 가슴을 밀면 암바를 당한다 → 팔꿈치를 몸에 붙인다
- 무릎을 넣고 멈추면 상대가 다시 다리를 빼 마운트로 간다 → 다리를 감아 하프가드를 끝낸다

## 막히면

- 상대가 무릎을 붙여 다리가 안 빠지면 → [힐 드래그 이스케이프](../techniques/heel-drag-escape.md)
- 상대 무게가 앞으로 쏠리면 → [마운트 이스케이프 (업파)](../techniques/mount-escape-upa.md)
- 상대가 그레이프바인을 걸면 → 업파로 다리 훅을 먼저 푼다

## 방어하는 쪽 (상대 입장)

- 상대가 오른쪽으로 돌아 오른 팔꿈치를 내 왼 무릎에 대면 → 엘보 이스케이프 신호
- 왼 무릎을 상대 겨드랑이 쪽으로 올리거나 테크니컬 마운트로 따라간다
- 상대 엉덩이가 빠지면 엉덩이를 낮춰 따라 앉는다
- 이미 상대 무릎이 내 왼다리 안에 들어오면 → 하프 탑 기본 자세로 크로스페이스
