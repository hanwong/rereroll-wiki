# 라펠 가드 (기본) (Lapel Guard (Basics))

[라펠 가드](../positions/lapel-guard.md) · 자세 · 컨트롤 · 아래 → [라펠 가드](../positions/lapel-guard.md)

다른 이름: 라펠, 라펠가드, 옷깃 가드, 깃 가드

## 세팅 과정 (오른손잡이 기준)

1. 내 오른손으로 상대 오른쪽 앞자락 끝(라펠)을 허리띠 아래에서 빼낸다
2. 라펠을 상대 오른다리 뒤(오금)로 돌려 바깥으로 꺼내 내 왼손으로 받는다
3. 꺼낸 라펠 끝을 당겨 상대 오른다리와 자세를 묶는다
4. 내 오른발은 상대 왼쪽 골반에, 왼발은 상대 오른쪽 무릎에 대고 거리를 지킨다
5. 데라히바 · 라쏘 · 웜 가드 스윕으로 잇는다

## 핵심 디테일

- 라펠은 허리띠 아래에서 넉넉히 빼야 상대 다리 뒤로 돌려 꺼낼 수 있다
- 라펠을 상대 오른쪽 오금 깊이 돌려야 당길 때 다리와 상체가 같이 묶인다
- 라펠을 꺼내는 동안 내 오른발 골반 · 왼발 무릎으로 거리를 지킨다
- 라펠 끝은 늘 당겨 긴장을 유지한다

## 흔한 실수

- 라펠을 짧게 빼면 다리 뒤로 못 돌린다 → 충분히 뺀 뒤 돌린다
- 꺼내는 동안 발이 빠지면 상대가 들어와 패스한다 → 발로 거리를 지킨 채 꺼낸다
- 잡기만 하고 가만히 있으면 상대가 라펠을 빼 버린다 → 바로 스윕이나 다른 가드로 잇는다

- 상대가 숙여 들어오면 → [웜 가드 진입](../techniques/worm-guard-entry.md) · [라펠 엘리베이터 스윕](../techniques/lapel-elevator-sweep.md)

## 방어하는 쪽 (상대 입장)

- 상대 손이 내 허리띠 아래 오른쪽 라펠을 빼기 시작하면 라펠 가드 신호
- 내 오른손으로 오른쪽 깃을 가슴에 눌러 라펠을 못 빼게 한다
- 라펠이 내 오른다리 뒤로 돌아가면 오른다리를 뒤로 빼 감기지 않게 한다
- 이미 묶였으면 → 웜 가드 상대 자세 지키기 · 거리 만들어 리셋 (라펠 상대)
