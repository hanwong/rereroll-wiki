# 버터플라이 가드 (Butterfly Guard)

[버터플라이 가드](../positions/butterfly-guard.md) · 자세 · 컨트롤 · 아래 → [버터플라이 가드](../positions/butterfly-guard.md)

다른 이름: 버터플라이, 나비 가드, 버플

## 세팅 과정 (오른손잡이 기준)

1. 앉은 자세에서 내 오른발은 상대 왼쪽, 왼발은 오른쪽 허벅지 안쪽에 훅처럼 넣는다
2. 무릎은 바깥으로 벌리고 발등으로 들어 올린다(무릎을 모으지 않는다)
3. 상체를 세우고 내 오른팔로 상대 왼팔 밑 언더훅을, 왼손으로 상대 오른쪽 깃을 잡아 가슴을 붙인다
4. 엉덩이를 상대 가까이 당겨 거리를 없애고 스윕을 노린다

## 핵심 디테일

- 내 오른발은 상대 왼쪽, 왼발은 상대 오른쪽 허벅지 안쪽에 발등으로 건다
- 무릎은 바깥으로 벌리고 상체를 세워 앉는다
- 내 오른팔 언더훅(상대 왼팔 밑)과 왼손 상대 오른쪽 깃으로 가슴을 붙인다
- 엉덩이를 상대 가까이 붙여야 훅으로 들어 올릴 수 있다

## 흔한 실수

- 뒤로 기대 누우면 상대가 눌러 훅이 죽는다 → 상체를 세워 상대 쪽으로 기운다
- 엉덩이가 멀면 훅이 얕아 못 든다 → 엉덩이를 당겨 붙인다
- 상대에게 언더훅을 내주면 눌린다 → 내가 먼저 오른팔 언더훅을 잡는다

## 막히면

- 상대가 앞으로 체중을 실으면 → [버터플라이 스윕](../techniques/butterfly-sweep.md)
- 상대가 일어서려 하면 → [버터플라이 → X 가드](../techniques/butterfly-guard-to-x-guard.md)
- 상대가 오른손을 바닥에 짚으면 → [기무라 (버터플라이)](../techniques/kimura-from-butterfly.md)

## 방어하는 쪽 (상대 입장)

- 상대가 앉아서 양 발등을 내 허벅지 안쪽에 넣고 오른팔로 내 왼팔 밑을 파고들면 버터플라이 가드
- 내 왼팔을 몸에 붙여 언더훅을 막고 엉덩이를 뒤로 빼 훅에 체중을 싣지 않는다
- 상대 상체를 눌러 눕히고 버터플라이 스매시 패스나 버터플라이 훅 컨트롤 패스로 간다
