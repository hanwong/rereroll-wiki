# 올드 스쿨 스윕 방어 (Defend Old School Sweep)

[하프가드](../positions/half-guard.md) · 방어 · 위 → [하프가드](../positions/half-guard.md)

다른 이름: 올드스쿨 디펜스

## 세팅 과정 (오른손잡이 기준)

1. 상대가 내 오른다리를 감고 왼팔로 언더훅 잡으면 바로 내 오른팔로 위저(오버훅)를 감는다
2. 상대가 잡은 오른발목 쪽 내 오른다리를 뒤로 빼 펴며 엉덩이를 낮춘다
3. 내 왼팔로 크로스페이스를 걸어 상대 머리를 눌러 둔다
4. 다시 하프 탑

## 핵심 디테일

- 언더훅과 발목 잡기가 보이면 바로 내 오른팔 위저 — 늦을수록 상대가 각도를 만든다
- 잡힌 오른다리를 뒤로 빼 펴서 상대가 발목을 붙잡기 어렵게 하고 엉덩이를 낮춘다
- 손으로 버티지 말고 가슴 체중을 상대 위에 싣는다
- 내 왼팔 크로스페이스로 상대 머리를 돌려 상대를 다시 눕힌다

## 흔한 실수

- 엉덩이를 들고 다리를 뜯어내려 하면 → 오히려 스윕 각도를 준다 → 낮게 누른다
- 손을 바닥에 짚고 버티면 → 체중이 상대에게서 빠진다 → 가슴으로 누른다
- 크로스페이스를 놓고 다리 싸움만 하면 → 상대가 다시 올라온다 → 머리부터 누른다

## 막히면

- 상대가 무릎으로 올라와 도그파이트가 되면 → [크로스페이스 (도그파이트 탑)](../techniques/crossface-from-dogfight.md)
- 상대가 머리를 내 아래로 넣어 딥 하프로 가면 → [위저 (딥 하프 상대)](../techniques/whizzer-from-deep-half.md)
- 다시 하프 탑이 되면 → [하프가드 패스 (크로스페이스 · 언더훅)](../techniques/half-guard-pass.md)

## 방어하는 쪽 (상대 입장)

- 상대 오른팔이 내 왼팔 위로 위저를 감고 잡힌 다리를 뒤로 빼면 막으려는 신호
- 위저가 깊어지기 전에 더 빨리 무릎으로 올라와 밀고 들어간다
- 위저·크로스페이스가 다 걸리면 억지로 밀지 말고 → 도그파이트 또는 눌린 하프 → 딥 하프
