# 암바 → 오모플라타 (Omoplata from Armbar Control)

[서브미션 걸린 뒤 (암바 · 기무라 · 오모플라타 · 트라이앵글)](../positions/submission-control.md) · 서브미션 · 아래

다른 이름: 암바 오모플라타, 암바에서 오모플라타

## 세팅 과정 (오른손잡이 기준)

1. 상대 오른팔 암바가 막히면 상대 머리 위에 있던 내 왼다리를 상대 오른쪽 어깨 뒤로 돌려 팔을 감는다
2. 상대 쪽으로 앉아 올라온다
3. 내 오른팔로 상대 허리를 감아 앞구르기를 막는다
4. 엉덩이를 앞으로 밀며 천천히 상대 오른쪽 어깨를 꺾는다
5. 탭하면 바로 푼다

## 핵심 디테일

- 상대가 팔을 굽혀 당겨 빼려 할 때가 신호
- 다리를 옮기는 동안 상대 오른쪽 손목을 놓지 않는다
- 내 왼다리가 상대 오른쪽 어깨 뒤로 넘어가면 바로 앉아 올라온다
- 앉자마자 내 오른팔로 상대 허리를 감아 앞구르기를 막는다

## 흔한 실수

- 머뭇거리면 상대가 자세를 세워 암바와 오모플라타를 둘 다 놓친다 → 다리를 한 번에 넘긴다
- 허리를 안 잡으면 상대가 앞구르기로 빠진다 → 앉자마자 허리부터 감는다
- 엉덩이가 상대 어깨에서 멀어지면 팔이 빠진다 → 엉덩이를 어깨에 붙인다

## 막히면

- 상대가 앞구르기로 빠지려 하면 → [오모플라타 → 백](../techniques/omoplata-to-back.md)
- 상대가 왼손으로 바닥을 짚고 버티면 → [오모플라타 → 스윕](../techniques/omoplata-to-sweep.md)
- 상대가 팔을 다 빼면 → [가드 리텐션 (다리 되돌리기)](../techniques/open-guard-retention.md)

## 방어하는 쪽 (상대 입장)

- 상대 왼다리가 내 얼굴에서 빠져 내 오른쪽 어깨 뒤로 넘어오면 오모플라타 신호
- 바로 오른쪽 팔꿈치를 몸으로 당기고 체중을 실어 상대가 앉아 오르지 못하게 한다
- 상대가 허리를 잡기 전이면 오른쪽 어깨 위로 앞구르기해 빠진다
- 이미 허리가 잡히고 어깨가 꺾이면 바로 탭한다
