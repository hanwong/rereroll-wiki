# 레그 훅 상대 니 쉴드 회복 (Shin Shield Recovery)

[패스](../positions/passing.md) · 탈출 · 아래 → [하프가드](../positions/half-guard.md)

다른 이름: 레그 훅 디펜스

## 세팅 과정 (오른손잡이 기준)

1. 상대가 내 오른다리를 걸어 누르고 내 오른쪽으로 넘어오려 할 때
2. 걸린 내 오른다리를 빼며 엉덩이를 뒤로 뺀다
3. 내 오른쪽 옆구리를 바닥에 대고 위쪽 내 왼쪽 무릎을 상대 배 앞에 세워 쉴드를 만든다
4. 빼낸 아래쪽 내 오른다리로 상대 오른다리를 감는다
5. 니 쉴드 하프가드로 거리를 지킨다

## 핵심 디테일

- 상대가 넘어오기 시작할 때 바로 한다 — 눌려 등이 바닥에 붙으면 늦다
- 내 오른쪽 옆구리를 대고 상대 쪽으로 돌아 누운 각도를 지킨다
- 내 왼쪽 무릎은 상대 배 앞에 가로로 세우고 밀어서 거리를 유지한다
- 아래쪽 내 오른다리로 상대 오른다리를 감아 상대가 다리를 빼지 못하게 한다

## 흔한 실수

- 쉴드를 배 아래 낮게 대면 쉽게 눌린다 → 무릎이 가슴 높이까지 오게 세운다
- 무릎만 세우고 가만히 두면 상대가 접어 버린다 → 정강이로 계속 밀어 준다
- 다리만 신경 쓰고 상체를 놓으면 크로스페이스에 눌린다 → 내 왼팔 언더훅도 같이 노린다

## 막히면

- 상대가 어깨로 쉴드를 눌러 접으면 → [니 쉴드 유지 (눌릴 때)](../techniques/knee-shield-retention.md)
- 상대가 계속 눌러 오면 → [눌린 하프 → 딥 하프](../techniques/deep-half-entry-from-flattened.md)
- 상대가 백스텝해 다리를 빼면 → [하프가드 → X 가드](../techniques/half-guard-to-x-guard.md)로 다리를 쫓는다

## 방어하는 쪽 (상대 입장)

- 상대가 엉덩이를 빼며 왼쪽 무릎을 내 배 앞에 세우려 하면 쉴드 신호
- 무릎이 서기 전에 가슴과 어깨로 상대 왼쪽 무릎 위를 눌러 접고 크로스페이스를 건다
- 쉴드가 섰으면 무리하게 밀지 말고 백스텝 패스나 니슬라이스 패스로 각도를 바꾼다
