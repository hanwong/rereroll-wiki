# 엘리베이션 스윕 (리버스 X) (Elevation Sweep to Mount)

[X 가드 · 싱글 레그 X · 앵클락](../positions/x-guard.md) · 스윕 · 아래 → [마운트](../positions/mount.md)

다른 이름: 들어 올려 넘기기

## 세팅 과정 (오른손잡이 기준)

1. 리버스 X에서 양 다리로 상대 왼다리를 들어 올린다
2. 상대가 왼손으로 바닥을 짚으려 하면 안은 상대 오른쪽 발목을 당긴다
3. 상대를 상대 왼쪽으로 넘겨 등이 닿게 한다
4. 따라 올라가 마운트를 잡는다

## 핵심 디테일

- 엉덩이를 상대 무게중심 바로 아래로 넣고 두 다리를 끝까지 펴 들어 올린다
- 내 왼팔로 상대 오른쪽 발목을 꽉 안아 상대가 그 다리로 딛지 못하게 한다
- 상대가 왼손으로 바닥을 짚으려는 때가 신호 — 그 순간 오른발목을 당긴다
- 다 넘어갈 때까지 훅을 유지하다 마운트로 올라탄다

## 흔한 실수

- 상대 아래로 덜 들어간 채 들면 → 상대가 뒤로 버틴다 → 엉덩이를 더 깊이 넣는다
- 다리를 반만 펴면 → 높이가 안 나와 못 넘긴다 → 끝까지 편다
- 다 넘어가기 전에 훅을 풀면 → 상대가 다시 선다 → 등이 닿을 때까지 유지

## 막히면

- 상대가 엉덩이를 낮춰 넓게 버티면 → [리버스 X 가드 스윕](../techniques/reverse-x-guard-sweep.md)
- 상대가 다리를 빼며 돌면 → [리버스 X → 백 테이크](../techniques/reverse-x-to-back-take.md)

## 방어하는 쪽 (상대 입장)

- 상대 엉덩이가 내 몸 아래로 깊이 들어오고 두 다리가 함께 밀어 올리면 엘리베이션 신호
- 들리기 전에 왼다리를 넓게 빼고 엉덩이를 낮춰 받침을 만든다
- 뒤로 버티지 말고 체중을 상대 가슴 쪽으로 보낸다
- 이미 떠오르면 넘어가는 쪽으로 몸을 돌려 상대 다리를 하프가드로 감는다
