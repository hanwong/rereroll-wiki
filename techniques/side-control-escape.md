# 사이드 이스케이프 (프레임 · 쉬림프) (Side Control Escape (Frame & Shrimp))

[사이드 컨트롤](../positions/side-control.md) · 탈출 · 아래 → [하프가드](../positions/half-guard.md) / [클로즈드 가드](../positions/closed-guard.md)

다른 이름: 힙 이스케이프, 쉬림프, 사이드 탈출, 사이드 이스케이프, 엘보 이스케이프 (사이드), 팔꿈치 넣어 가드 회복

## 세팅 과정 (오른손잡이 기준)

1. 상대가 내 오른쪽에서 사이드를 잡았을 때 내 왼팔뚝은 상대 목, 오른팔뚝은 상대 골반에 대어 프레임을 만든다
2. 먼저 브릿지로 상대를 띄우고 프레임으로 공간을 지킨다
3. 엉덩이를 내 왼쪽으로 빼서(쉬림프) 공간을 만든다 — 한 번에 안 되면 두 번
4. 내 오른쪽 무릎을 상대와 나 사이로 넣어 가드를 되찾거나 내 오른팔로 언더훅을 잡고 일어난다

## 핵심 디테일

- 프레임은 팔꿈치를 굽혀 뼈로 받친다 — 상대를 밀어내는 게 아니라 공간을 지키는 것
- 브릿지로 상대를 먼저 띄운 순간 엉덩이를 뺀다
- 한 번에 공간이 안 나면 쉬림프를 두 번 한다
- 공간이 생기면 바로 오른 무릎을 넣어 다시 눌리지 않게 한다

## 흔한 실수

- 팔을 쭉 펴서 밀면 상대가 팔을 잡아 기무라·암바를 건다 → 팔꿈치를 굽혀 붙인다
- 브릿지 없이 쉬림프만 하면 상대 체중 때문에 안 움직인다 → 브릿지 → 쉬림프
- 무릎을 넣기 전에 프레임을 풀면 다시 눌린다 → 무릎이 들어갈 때까지 프레임 유지

## 막히면

- 상대가 크로스페이스로 얼굴을 돌려 누르면 → [터틀로 돌기 (사이드)](../techniques/roll-to-turtle.md)
- 내 오른팔이 끼어 있으면 → [팔 빼내기 (사이드 아래)](../techniques/arm-extraction.md)
- 상대가 니 온 밸리로 바꾸면 → [니 온 밸리 이스케이프](../techniques/knee-on-belly-escape.md)

## 방어하는 쪽 (상대 입장)

- 상대 팔뚝이 내 목과 골반에 프레임을 대고 브릿지하면 탈출 신호
- 내 왼팔 크로스페이스로 얼굴을 돌려 프레임을 무너뜨리고 가슴을 더 무겁게 누른다
- 엉덩이가 빠지면 내 무릎을 상대 엉덩이에 붙이며 따라간다
- 무릎이 들어오면 골반으로 무릎을 눌러 접거나 사이드 → 니 온 밸리로 바꾼다
