# 바디락 빠져나오기 (Escape Body Lock)

[클린치 · 가드 풀링](../positions/clinch.md) · 탈출 · 서서 → [클린치 · 가드 풀링](../positions/clinch.md)

다른 이름: 바디락 이스케이프

## 세팅 과정 (오른손잡이 기준)

1. 상대가 허리를 안으면 엉덩이를 뒤로 빼고 자세를 낮춘다
2. 내 오른팔부터 상대 왼팔 아래로 파고들어 언더훅을 되찾는다(퍼멀, 양팔이면 더 좋다)
3. 머리를 언더훅 쪽인 상대 왼쪽 어깨(턱 옆)에 붙여 들리지 않게 한다
4. 오른팔 언더훅을 잡으면 상대 왼쪽 옆으로 돌아 나간다

## 핵심 디테일

- 엉덩이를 뒤로 빼고 무릎을 굽혀 상대가 나를 들어 올리지 못하게 한다
- 내 오른팔은 상대 가슴에 붙여 좁게 파고들어 언더훅을 넣는다
- 머리를 상대 턱 왼쪽에 붙여 체중을 상대 쪽에 싣는다
- 언더훅이 들어가면 바로 상대 왼쪽 옆으로 돌아 정면에서 벗어난다

## 흔한 실수

- 손으로 상대 팔을 떼려고만 하면 힘이 안 된다 → 엉덩이를 빼고 팔을 파고든다
- 허리를 펴고 서 있으면 들려서 던져진다 → 무릎을 굽혀 낮춘다
- 등을 보이며 돌면 백을 준다 → 언더훅 쪽인 상대 왼쪽으로 마주 보며 돈다

## 막히면

- 상대가 나를 들어 올리면 → 내 다리를 상대 다리 바깥에 감아 버틴다
- 상대가 등 뒤로 돌아가면 → [스탠딩 백에서 돌아서기](../techniques/grip-break-and-face.md)
- 바닥으로 넘어갔으면 → [터틀 → 가드 회복](../techniques/turtle-to-guard.md)

## 방어하는 쪽 (상대 입장)

- 상대 오른팔이 내 왼쪽 겨드랑이로 파고들면 → 빠져나가려는 신호
- 손깍지를 상대 허리 아래쪽에 단단히 잡고 머리를 상대 가슴에 붙여 공간을 안 준다
- 상대 엉덩이가 빠지기 전에 → 바디락 테이크다운
- 이미 언더훅을 내줬으면 → 언더훅 퍼멀링으로 다시 다툰다
