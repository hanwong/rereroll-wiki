# 다스 초크 (터틀) (Darce from Turtle)

[터틀 · 크루시픽스](../positions/turtle.md) · 서브미션 · 위

다른 이름: 터틀 다스, 다스, 다스 초크

## 세팅 과정 (오른손잡이 기준)

1. 터틀 상대 오른쪽 옆에서 내 오른팔을 상대 오른쪽 겨드랑이 아래로 넣어 목 왼쪽까지 깊게 꿴다
2. 꿴 오른손으로 내 왼팔 이두를 잡고 내 왼손은 상대 머리 뒤에 둔다(8자 그립)
3. 상대 머리를 아래로 누르며 내 가슴을 상대 오른쪽 어깨에 싣는다
4. 다리를 상대 머리 쪽으로 걸어 돌며 가슴을 조여 마무리한다
5. 천천히 조이고 탭하면 바로 푼다

## 핵심 디테일

- 오른팔을 상대 오른쪽 겨드랑이 아래로 깊게 넣어 목 왼쪽까지 꿴다
- 오른손으로 내 왼팔 이두를 잡고 왼손은 상대 머리 뒤에 둔다
- 가슴을 상대 오른쪽 어깨에 실어 상대 어깨로 상대 목을 누르게 한다
- 다리를 상대 머리 쪽으로 걸어 돌며 천천히 조인다

## 흔한 실수

- 팔을 얕게 꿰면 팔꿈치만 걸리고 조이지 않는다 → 겨드랑이 깊이 넣는다
- 무게 없이 팔로만 조이면 안 잠긴다 → 가슴으로 어깨를 누른다
- 급하게 쥐어짜면 목이 다칠 수 있다 → 천천히 조이고 탭하면 바로 푼다

## 막히면

- 상대가 머리를 빼며 각도가 바뀌면 → [다스 ↔ 아나콘다 전환](../techniques/darce-to-anaconda-switch.md)
- 상대가 엎드려 버티면 → [터틀에서 백 테이크](../techniques/turtle-back-take.md)

## 방어하는 쪽 (상대 입장)

- 상대 오른팔이 내 오른쪽 겨드랑이 아래로 들어와 목 왼쪽으로 나오면 다스 신호
- 오른팔꿈치를 몸에 붙이고 왼손으로 상대 오른손목을 잡아 그립이 잠기지 않게 한다
- 그립이 잠겼으면 다스 방어로 가고 조여 오면 바로 탭한다
