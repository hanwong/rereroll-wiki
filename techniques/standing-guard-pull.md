# 오픈 가드 풀링 (Standing Guard Pull (to Open Guard))

[클린치 · 가드 풀링](../positions/clinch.md) · 가드 풀링 · 서서 → [데라히바 · 리버스 데라히바](../positions/de-la-riva.md) / [스파이더 · 라쏘 · 소매 가드](../positions/spider-lasso.md) / [오픈 가드](../positions/open-guard.md)

다른 이름: 오픈 가드로 앉기

## 세팅 과정 (오른손잡이 기준)

1. 내 오른손은 상대 왼쪽 깃, 왼손은 상대 오른쪽 소매를 잡고 상대를 당긴다
2. 내 오른발을 상대 왼쪽 골반에, 또는 왼발을 상대 오른쪽 이두에 대며 앉는다
3. 앉으며 바로 내 왼다리로 상대 오른다리 바깥에 데라히바 훅을 걸거나 왼발로 스파이더를 잡는다
4. 상대 균형을 흔들며 스윕을 노린다

## 핵심 디테일

- 앉기 전에 깃 · 소매 그립을 먼저 잡는다
- 앉을 때 발로 상대 골반이나 이두를 막아 거리를 지킨다
- 앉자마자 내 왼다리로 데라히바 훅이나 스파이더를 건다 — 상대에게 시간을 주지 않는다
- 가드를 잡았으면 상대 균형을 계속 흔든다

## 흔한 실수

- 상대에게서 멀리 앉으면 상대가 다리를 옆으로 치우고 패스한다 → 발을 상대 몸에 붙이며 앉는다
- 앉은 뒤 훅을 안 걸면 상대가 바로 패스를 시작한다 → 앉는 동작과 훅을 한 번에
- 그립 없이 앉으면 상대를 붙잡을 수 없다 → 그립 두 개 먼저

## 막히면

- 상대가 훅을 끊고 돌아 패스하면 → [가드 리텐션 (다리 되돌리기)](../techniques/open-guard-retention.md)
- 상대가 뒤로 물러나 거리를 두면 → [테크니컬 스탠드업](../techniques/technical-stand-up.md)
- 상대 체중이 앞으로 오면 → [데라히바 스윕](../techniques/de-la-riva-sweep.md)

## 방어하는 쪽 (상대 입장)

- 상대가 깃 · 소매를 잡은 채 앉으려 하고 상대 오른발이 내 왼쪽 골반이나 상대 왼발이 내 오른팔 이두에 닿으면 오픈 가드 풀링 신호
- 앉는 순간 소매 그립을 끊고 오른다리를 뒤로 빼 훅을 피한다
- 상대 왼다리가 이미 내 오른다리 바깥을 감았으면 무릎을 붙여 자세를 낮추고 바로 패스를 시작한다
- 데라히바가 잡혔으면 토레안도 (데라히바 상대)나 레그 드래그 (데라히바 상대)
