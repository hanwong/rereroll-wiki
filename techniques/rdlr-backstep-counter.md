# 백스텝 (RDLR 상대) (RDLR Backstep Counter)

[데라히바 · 리버스 데라히바](../positions/de-la-riva.md) · 패스 · 위 → [패스](../positions/passing.md)

다른 이름: RDLR 백스텝

## 세팅 과정 (오른손잡이 기준)

1. 상대가 오른다리로 내 오른다리에 리버스 훅을 걸면 내 왼손으로 상대 오른쪽 깃을 눌러 구르지 못하게 한다
2. 내 오른손으로 내 오른쪽 발목을 잡은 상대 왼손을 떼어낸다
3. 체중을 왼다리에 싣고 훅 걸린 오른다리를 뒤로 크게 돌려 뺀다
4. 풀린 상대 오른다리를 내 오른손으로 눌러 두고 헤드쿼터 자세로 자리 잡는다

## 핵심 디테일

- 내 왼손으로 상대 오른쪽 깃을 눌러 상대가 다리 사이로 구르지 못하게 먼저 막는다
- 내 오른손으로 발목 그립을 떼야 다리를 돌려 뺄 수 있다
- 체중을 왼다리에 싣고 오른다리를 뒤로 크게 돌려 훅에서 빼낸다
- 풀린 상대 오른다리를 오른손으로 눌러 두고 헤드쿼터를 잡는다

## 흔한 실수

- 깃을 누르지 않고 돌면 상대가 키스 오브 더 드래곤으로 백을 노린다 → 깃을 눌러 상대 상체를 묶는다
- 다리를 작게 돌리면 훅이 다시 걸린다 → 크게 원을 그려 뺀다
- 헤드쿼터에서 멈추면 상대가 가드를 다시 만든다 → 바로 패스로 잇는다

## 막히면

- 상대가 데라히바 훅을 다시 걸면 → [토레안도 (데라히바 상대)](../techniques/toreando-pass-from-de-la-riva.md)
- 헤드쿼터에서 상대가 무릎을 세우면 → [니컷 (헤드쿼터)](../techniques/knee-cut-from-headquarters.md)
- 상대가 다리를 바깥으로 빼면 → [레그 드래그 (헤드쿼터)](../techniques/leg-drag-from-headquarters.md)

## 방어하는 쪽 (상대 입장)

- 상대 왼손이 내 오른쪽 깃을 누르고 상대 오른손이 내 발목 그립을 떼면 백스텝 신호
- 상대가 다리를 돌리는 순간 오른다리 훅을 더 깊게 감고 발목을 다시 잡는다
- 헤드쿼터가 잡히면 헤드쿼터 상대 신 투 신이나 헤드쿼터 상대 인버트 → 데라히바로 다리를 다시 건다
