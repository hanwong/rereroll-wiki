# 하프가드 → 레그 위브 (Half Guard to Leg Weave)

[하프가드](../positions/half-guard.md) · 전환 · 위 → [패스](../positions/passing.md)

다른 이름: 레그 위브 진입

## 세팅 과정 (오른손잡이 기준)

1. 내 오른다리가 감기면 상대 니 쉴드(왼다리) 위로 내 오른팔을 넘긴다
2. 상대 오른다리 밑으로 오른손을 넣어 바닥을 짚는다
3. 머리를 낮춰 상대 무릎을 모은다
4. 레그 위브 패스로 잇는다

## 핵심 디테일

- 상대가 왼쪽 무릎 니 쉴드를 세웠을 때 쓴다
- 내 오른팔을 상대 왼다리 위로 넘겨 오른손을 상대 오른다리 밑 바닥에 짚는다
- 오른쪽 어깨를 상대 왼쪽 허벅지에 무겁게 기대 무릎을 접는다
- 머리를 낮춰 상대 두 무릎을 한데 모은다

## 흔한 실수

- 팔을 무릎 근처에 얕게 걸면 니 쉴드가 그대로 버틴다 → 오른다리 밑까지 깊게
- 상체를 세운 채 엮으면 상대가 다리를 빼 거리를 만든다 → 머리·어깨를 낮춘다
- 엮은 뒤 가만히 있으면 상대가 다시 다리를 감는다 → 바로 레그 위브 패스로 잇는다

## 막히면

- 상대가 니 쉴드를 빼고 언더훅을 잡으면 → [하프 탑 위저 카운터](../techniques/half-guard-whizzer-counter.md)
- 팔이 깊게 안 들어가면 → [바디락 패스](../techniques/body-lock-pass.md)
- 엮기에 성공하면 → [레그 위브 패스](../techniques/leg-weave-pass.md)

## 방어하는 쪽 (상대 입장)

- 상대 오른팔이 내 왼쪽 무릎 위로 넘어오면 신호
- 내 왼손으로 상대 오른쪽 팔꿈치를 밀어 팔이 깊게 못 들어오게 한다
- 니 쉴드 무릎을 상대 어깨 쪽으로 세워 버티며 엉덩이를 뺀다
- 엮였으면 → 레그 위브 상대 하프 회복
