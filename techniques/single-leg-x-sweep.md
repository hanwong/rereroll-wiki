# 싱글 레그 X 스윕 (Single Leg X Sweep)

[X 가드 · 싱글 레그 X · 앵클락](../positions/x-guard.md) · 스윕 · 아래 → [패스](../positions/passing.md)

다른 이름: SLX 스윕, 싱글렉스 스윕

## 세팅 과정 (오른손잡이 기준)

1. 상대 왼쪽 발목을 안고 내 오른발로 상대 왼쪽 골반을 밀며 엉덩이를 든다
2. 상대 왼쪽 무릎을 상대 왼쪽 바깥으로 틀어 넘어뜨린다
3. 상대가 앉으면 상대 왼다리를 든 채 일어난다
4. 상대 왼다리를 놓지 않고 패스 자세로 간다

## 핵심 디테일

- 팔로 당기기보다 내 오른발로 상대 왼쪽 골반을 밀어 다리를 펴는 힘으로 넘긴다
- 상대 왼쪽 발목을 겨드랑이에 꽉 붙여 상대가 그 다리로 딛지 못하게 한다
- 상대 왼쪽 무릎을 상대 왼쪽 바깥으로 틀면 버틸 다리가 없어진다
- 상대가 앉는 순간 왼다리를 든 채 바로 일어난다 — 늦으면 상대가 다리를 빼 가드를 잡는다

## 흔한 실수

- 팔로만 당기면 → 상대가 버틴다 → 오른발로 골반을 밀어 다리를 편다
- 넘긴 뒤 다리를 놓고 일어나면 → 상대가 바로 가드를 잡는다 → 왼다리를 든 채 일어난다
- 내 왼다리 감기를 일찍 풀면 → 상대가 다리를 빼고 균형을 되찾는다 → 넘어질 때까지 유지

## 막히면

- 상대가 오른발을 가까이 두고 버티면 → [힐 그랩 스윕](../techniques/heel-grab-sweep.md)
- 상대가 앞으로 무겁게 눌러 오면 → [싱글 레그 X → X 가드](../techniques/slx-to-x-guard.md)
- 상대가 다리를 뒤로 빼면 → 엉덩이로 따라가 다시 발목을 안는다

## 방어하는 쪽 (상대 입장)

- 상대 오른발이 내 왼쪽 골반을 밀고 상대 엉덩이가 들리면 넘기려는 신호
- 무릎을 굽혀 엉덩이를 낮추고 오른발을 넓게 디뎌 받침을 만든다
- 잡힌 왼쪽 무릎이 바깥으로 돌아가지 않게 안쪽으로 붙인다
- 이미 넘어가면 엉덩이부터 낮게 앉고 발을 상대 골반에 대 가드를 다시 세운다
