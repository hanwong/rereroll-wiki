# 트라이앵글 초크 (Triangle Choke)

[클로즈드 가드](../positions/closed-guard.md) · 서브미션 · 아래

다른 이름: 트라이앵글, 삼각 조르기, 산카쿠, 클로즈드 가드 → 트라이앵글 세팅, 트라이앵글 셋업

## 세팅 과정 (오른손잡이 기준)

1. 내 오른손으로 상대 왼쪽 손목을 잡아 밀어 상대 왼팔은 바깥, 오른팔은 내 다리 안쪽에 남게 만든다
2. 가드를 열고 내 왼발로 상대 오른쪽 골반을 밀어 엉덩이를 띄운 뒤, 오른다리를 상대 목 뒤로 올린다
3. 오른발목을 내 왼쪽 무릎 뒤에 걸어 삼각형을 만들고, 두 손으로 머리를 당겨 자세를 낮춘다
4. 엉덩이를 내 왼쪽으로 빼 직각을 만들고 상대 오른팔을 상대 목 앞 너머(내 오른쪽)로 넘긴 뒤 다리를 조인다

## 핵심 디테일

- 상대 오른팔은 내 다리 안쪽, 왼팔은 바깥에 둔다
- 오른다리를 상대 목 뒤 깊게 걸고 오른발목을 내 왼쪽 오금에 잠근다
- 두 손으로 머리를 당겨 상대 자세를 계속 무너뜨린다
- 엉덩이를 내 왼쪽으로 빼 직각을 만들고 상대 오른팔을 목 앞 너머로 넘겨 조인다

## 흔한 실수

- 상대 두 팔이 다 안에 있거나 다 밖에 있으면 안 조여진다 → 오른팔만 안에 둔다
- 정면에서 다리만 조이면 안 잠긴다 → 엉덩이를 빼 각도를 만든다
- 머리를 놓으면 상대가 자세를 세워 빠진다 → 두 손으로 계속 당긴다

## 막히면

- 상대가 자세를 세워 버티면 → [트라이앵글 → 암바](../techniques/triangle-to-armbar.md)
- 상대가 쌓아 누르면 → [트라이앵글 → 오모플라타](../techniques/triangle-to-omoplata.md)
- 상대 오른팔이 빠지면 → 다리를 다시 잠가 [클로즈드 가드 (자세 · 포스처 깨기)](../techniques/closed-guard-basics.md)

## 방어하는 쪽 (상대 입장)

- 상대가 내 왼쪽 손목을 밀어내고 오른팔만 다리 안에 남기면 → 트라이앵글 신호
- 두 손을 같이 안쪽에 두거나 같이 바깥에 두고 자세를 세운다
- 상대 오른다리가 목 뒤로 오면 → 트라이앵글 탈출 (자세 세우기)
- 이미 잠겼으면 → 트라이앵글 스택 탈출, 늦으면 탭
