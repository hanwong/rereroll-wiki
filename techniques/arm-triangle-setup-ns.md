# 암 트라이앵글 세팅 (남북) (Arm Triangle Setup from North-South)

[남북 (노스사우스)](../positions/north-south.md) · 서브미션 · 위

다른 이름: 남북 헤드앤암, 노스사우스

## 세팅 과정 (오른손잡이 기준)

1. 남북에서 상대 오른팔을 상대 머리 너머 왼쪽으로 밀어 올린다
2. 내 오른팔을 상대 목 아래로 넣고 내 왼손과 맞잡는다
3. 상대 왼쪽 사이드로 돌아가며 상대 오른팔을 목과 함께 가둔다
4. 가슴을 낮춰 내 오른쪽 어깨로 조인다

## 핵심 디테일

- 상대 오른팔을 상대 머리 너머까지 밀어 올려 팔이 목 앞을 가로지르게 한다
- 내 오른팔을 상대 목 아래로 깊게 넣고 내 왼손과 맞잡아 팔과 목을 함께 감는다
- 상대 왼쪽 사이드로 걸어 돌며 가슴 압박을 놓지 않는다
- 팔로 짜지 말고 가슴을 낮춰 오른 어깨로 상대 팔을 목에 밀어 조인다

## 흔한 실수

- 상대 팔이 목 앞을 다 넘지 않으면 틈이 남아 안 조여진다 → 어깨로 팔을 끝까지 밀어 넣는다
- 상대 오른쪽에 머문 채 조이면 각도가 안 나온다 → 상대 왼쪽 사이드까지 돌아가 마무리한다
- 갑자기 힘을 주면 목이 다친다 → 천천히 조이고 탭하면 바로 푼다

## 막히면

- 상대가 오른 팔꿈치를 옆구리에 붙여 버티면 → [남북 기무라](../techniques/north-south-to-kimura.md) · [아메리카나 (남북)](../techniques/americana-from-north-south.md)
- 상대가 내 다리를 하프가드로 감으면 → 엉덩이를 낮추고 무릎을 빼 [사이드 컨트롤 유지](../techniques/side-control-maintain.md)
- 상대 목 앞이 비면 → [남북 초크](../techniques/north-south-choke.md)

## 방어하는 쪽 (상대 입장)

- 상대가 내 오른팔을 내 머리 쪽으로 밀어 올리고 목 아래로 팔을 넣으면 신호다
- 오른 팔꿈치를 옆구리로 당겨 팔이 목 앞을 넘지 않게 한다
- 상대가 내 왼쪽으로 걸어 돌 때 왼 무릎을 사이로 넣어 하프가드로 다리를 감는다
- 이미 조여 오면 버티지 말고 일찍 탭한다
