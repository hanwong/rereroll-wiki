# 버터플라이 → X 가드 (Butterfly Guard to X-Guard)

[버터플라이 가드](../positions/butterfly-guard.md) · 전환 · 아래 → [X 가드 · 싱글 레그 X · 앵클락](../positions/x-guard.md)

다른 이름: X가드 진입, 엑스가드 진입

## 세팅 과정 (오른손잡이 기준)

1. 상대가 서려 할 때 내 오른발 훅으로 상대 왼다리를 들어 올리며 그 다리 밑으로 몸을 밀어 넣는다
2. 들린 상대 왼다리를 내 오른쪽 어깨에 얹고 오른팔로 안는다
3. 내 오른발은 상대 오른쪽 골반 앞, 왼발은 상대 오른쪽 오금 뒤에 걸어 X 모양을 만든다
4. 엉덩이를 상대 가까이 붙여 X 가드를 완성한다

## 핵심 디테일

- 상대가 일어서려 할 때 오른발 훅으로 상대 왼다리를 들며 밑으로 들어간다
- 들린 상대 왼다리를 내 오른 어깨에 얹고 오른팔로 꽉 안는다
- 오른발은 상대 오른쪽 골반 앞, 왼발은 상대 오른 오금 뒤에 걸어 X를 만든다
- 엉덩이를 상대 발밑 가까이 붙여야 상대가 다리를 못 뺀다

## 흔한 실수

- 훅을 너무 일찍 빼면 상대가 다리를 빼고 눌러 온다 → X가 걸릴 때까지 훅을 유지한다
- 엉덩이가 멀면 X가 얕다 → 엉덩이를 상대 오른발 쪽으로 밀어 넣는다
- 상대 왼다리를 안지 않으면 상대가 다리를 빼 패스한다 → 어깨에 얹고 팔로 감싼다

## 막히면

- 상대가 다리를 빼고 물러나면 → [시팅 가드 기본 자세](../techniques/seated-guard-basics.md)로 거리를 다시 잡는다
- 상대가 무릎을 바닥으로 눌러 내려오면 → [오픈 가드 → 딥 하프](../techniques/open-guard-to-deep-half.md)
- X 가드가 잡히면 → [X 가드 스윕](../techniques/x-guard-sweep.md)
- 상대가 일어서며 다리를 빼면 → [애시 가라미 (스트레이트 애시)](../techniques/ashi-garami.md)

## 방어하는 쪽 (상대 입장)

- 상대가 훅으로 내 왼다리를 들며 엉덩이를 내 다리 밑으로 넣으면 X 가드 신호
- 들린 왼다리를 빼서 뒤로 디디고 엉덩이를 낮춘다
- 이미 걸렸으면 X 가드 빠져나오기 (서서)나 무릎 눌러 X 가드 패스
