# 레그 위브 상대 하프 회복 (Leg Weave Escape to Half Guard)

[패스](../positions/passing.md) · 탈출 · 아래 → [하프가드](../positions/half-guard.md)

다른 이름: 레그 위브 디펜스

## 세팅 과정 (오른손잡이 기준)

1. 상대가 내 오른다리를 엮어 레그 위브를 잡았을 때
2. 엮인 내 오른쪽 무릎을 당기며 내 오른손 프레임으로 상대 왼쪽 어깨를 민다
3. 자유로운 내 왼다리로 상대 오른다리를 감는다
4. 내 오른쪽 옆구리를 바닥에 대고 상대 쪽으로 돌아 눕는다
5. 내 왼팔 언더훅이나 왼쪽 무릎 니 쉴드를 잡아 하프가드를 만든다

## 핵심 디테일

- 내 오른손 프레임은 팔꿈치를 굽혀 상대 왼쪽 어깨를 받친다
- 엮인 무릎을 당기는 동작과 엉덩이를 빼는 동작을 함께 한다
- 내 왼다리가 상대 오른다리를 감을 때까지 다리 연결을 놓지 않는다
- 하프가드가 되면 바로 내 왼팔 언더훅이나 왼쪽 무릎 쉴드로 거리를 지킨다

## 흔한 실수

- 팔을 쭉 펴서 밀면 상대 체중에 무너진다 → 팔꿈치를 굽혀 뼈로 받친다
- 조금씩 여러 번 시도하면 힘만 빠진다 → 상대가 움직일 때 한 번에 크게
- 돌면서 등을 보이면 백스텝으로 백을 내준다 → 가슴이 상대를 향한 채로 돈다

## 막히면

- 상대가 크로스페이스로 얼굴을 돌려 누르면 → 브릿지로 잠깐 띄운 순간 엉덩이를 뺀다
- 상대가 니슬라이스로 바꿔 넘어오면 → 넘어오는 다리를 감아 [하프가드](../positions/half-guard.md)로 잡는다
- 언더훅이 들어가면 → [레그 위브 상대 도그파이트](../techniques/leg-weave-to-dogfight.md)로 일어난다

## 방어하는 쪽 (상대 입장)

- 상대 오른손이 내 왼쪽 어깨를 밀며 엮인 무릎을 당기면 탈출 신호
- 내 왼팔 크로스페이스로 얼굴을 돌리고 엉덩이를 낮춰 프레임을 접는다
- 상대 엉덩이가 빠지면 같은 방향으로 따라가며 엮은 무릎을 더 깊게 넣는다
- 하프가드가 잡혔으면 하프가드 → 레그 위브로 다시 엮는다
