# X 가드 빠져나오기 (서서) (Standing Escape from X-Guard)

[X 가드 · 싱글 레그 X · 앵클락](../positions/x-guard.md) · 탈출 · 위 → [패스](../positions/passing.md)

다른 이름: X가드 이스케이프

## 세팅 과정 (오른손잡이 기준)

1. 상대가 내 왼다리를 안고 내 오른다리에 X 훅을 걸었을 때, 엉덩이를 낮추고 발을 넓게 서서 균형을 잡는다
2. 내 왼쪽 발목(또는 바지)을 잡은 상대 손을 먼저 떼어낸다
3. 내 오른다리에 걸린 상대 훅을 손으로 눌러 떼며 안긴 왼다리를 빼낸다
4. 뒤로 물러나 거리를 두고 다시 패스 자세를 잡는다

## 핵심 디테일

- 무릎을 굽혀 엉덩이부터 낮춘다 — 높이 서 있을수록 상대가 들어 올리기 쉽다
- 순서는 발목 그립 떼기 → 훅 떼기 → 안긴 왼다리 빼기
- 내 왼손으로 왼쪽 발목을 잡은 상대 손을 떼고, 내 오른손은 상대 무릎·골반을 눌러 버틴다
- 빠져나오면 바로 뒤로 물러나 거리를 두고 다시 패스 자세

## 흔한 실수

- 꼿꼿이 선 채 다리를 빼면 → 들려서 뒤로 넘어간다 → 무릎을 굽혀 낮게 버틴다
- 안긴 왼다리를 뒤로 세게 잡아당기면 → 훅이 더 깊어진다 → 그립과 훅부터 풀고 뺀다
- 두 손을 다 다리 싸움에 쓰면 → 균형이 무너져 스윕 당한다 → 내 오른손은 상대 골반에 두고 버틴다

## 막히면

- 상대가 발목을 다시 잡으면 → [무릎 눌러 X 가드 패스](../techniques/knee-pin-from-x-guard.md)
- 상대가 훅을 바꿔 싱글 레그 X로 가면 → [싱글 레그 X 빠져나오기 (서서)](../techniques/standing-escape-from-slx.md)
- 상대가 들어 올리기 시작하면 → 체중을 떨어뜨려 [스매시 패스 (X 가드 상대)](../techniques/smash-pass-from-x-guard.md)

## 방어하는 쪽 (상대 입장)

- 상대가 무릎을 굽혀 낮아지고 손이 내 오른손 그립(상대 왼쪽 발목)으로 내려오면 빠지려는 신호
- 상대가 낮아지기 전에 바로 X 가드 스윕으로 들어 올린다
- 그립이 떼어지면 다시 잡고, 훅이 얕아지면 X 가드 → 싱글 레그 X 로 바꾼다
- 다리가 이미 빠졌으면 발을 상대 골반에 대 가드를 다시 세운다
