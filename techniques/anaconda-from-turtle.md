# 아나콘다 초크 (터틀) (Anaconda from Turtle)

[터틀 · 크루시픽스](../positions/turtle.md) · 서브미션 · 위

다른 이름: 터틀 아나콘다, 아나콘다, 아나콘다 초크

## 세팅 과정 (오른손잡이 기준)

1. 터틀 상대 앞에서 내 오른팔을 상대 목 아래로 넣어 상대 오른쪽 겨드랑이 아래로 뺀다
2. 뺀 오른손으로 내 왼팔 이두를 잡고 내 왼손은 상대 등에 올린다(8자 그립)
3. 갇힌 상대 왼팔 쪽(내 오른쪽)으로 오른쪽 어깨를 대고 구르며 상대를 옆으로 넘긴다
4. 무릎으로 상대 쪽으로 걸어 들어가며 가슴을 조인다
5. 천천히 조이고 탭하면 바로 푼다

## 핵심 디테일

- 오른팔을 상대 턱 아래로 깊게 넣어 겨드랑이까지 꿴다
- 오른손으로 내 왼팔 이두를 잡고 왼손은 상대 등에 올려 8자 그립을 만든다
- 갇힌 팔 쪽인 내 오른쪽으로 오른쪽 어깨를 대고 굴러 상대를 옆으로 넘긴다
- 구른 뒤 무릎으로 상대 쪽으로 걸어 들어가며 조인다

## 흔한 실수

- 그립이 느슨한 채 구르면 상대 머리가 빠진다 → 그립을 잠그고 구른다
- 구른 자리에 누워만 있으면 조이지 않는다 → 무릎을 상대 쪽으로 걸어 붙인다
- 확 쥐어짜면 다친다 → 천천히 조이고 탭하면 바로 푼다

## 막히면

- 상대가 머리를 빼며 각도가 바뀌면 → [다스 ↔ 아나콘다 전환](../techniques/darce-to-anaconda-switch.md)
- 상대가 굴러가지 않고 버티면 → [길로틴 (터틀)](../techniques/guillotine-from-turtle.md)

## 방어하는 쪽 (상대 입장)

- 상대 오른팔이 내 턱 아래로 파고들어 겨드랑이까지 꿰이면 아나콘다 신호
- 턱을 당기고 팔꿈치를 몸에 붙이며 머리를 들어 자세를 세운다(아나콘다 방어)
- 이미 굴러 조여 오면 바로 탭한다
