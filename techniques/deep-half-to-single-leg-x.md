# 딥 하프 → 싱글 레그 X (Deep Half to Single Leg X)

[딥 하프가드](../positions/deep-half.md) · 전환 · 아래 → [X 가드 · 싱글 레그 X · 앵클락](../positions/x-guard.md)

다른 이름: 딥 하프에서 SLX, 딥 하프 → SLX, 딥하프 싱글엑스, deep half to slx

## 세팅 과정 (오른손잡이 기준)

1. 딥 하프에서 내 오른팔로 상대 오른쪽 허벅지를 안고 내 두 다리로 상대 오른다리를 감은 자세에서 시작한다
2. 상대가 다리를 빼려 일어서거나 체중을 왼발로 옮기면, 내 왼손으로 상대 오른쪽 발목을 잡아 내 가슴 쪽으로 당겨 붙인다
3. 감고 있던 다리를 풀어 내 왼발을 상대 오른쪽 골반 앞에 대고, 내 오른다리는 상대 오른쪽 허벅지 바깥을 감아 오금 뒤에 건다
4. 상대 오른쪽 발목을 내 왼쪽 겨드랑이에 안고 등을 바닥에 대 싱글 레그 X 를 잡는다
5. 여기서 싱글 레그 X 스윕으로 넘기거나 애시 가라미로 잇는다

## 핵심 디테일

- 바꾸는 때는 상대가 일어서거나 다리를 빼려 할 때 — 상대가 앞으로 누를 땐 딥 하프에 머문다
- 발목을 먼저 가슴에 붙여야 다리를 풀어도 상대 다리가 도망가지 못한다
- 안쪽 발(왼발)은 상대 골반 앞 — 너무 깊이 넣어 상대 몸 가운데 선을 넘기지 않는다
- 좌우는 딥 하프 기준(상대 오른다리)을 그대로 쓴다

## 흔한 실수

- 발목을 잡지 않고 다리를 풀면 상대가 다리를 뽑아 패스한다 → 발목부터 가슴에 붙인다
- 상대가 앞으로 누를 때 바꾸면 크로스페이스에 눌린다 → 상대가 일어설 때 바꾼다
- 안쪽 발을 상대 배 위로 넘기면 반칙(니 리핑)이 될 수 있다 → 골반 앞까지만

## 막히면

- 상대가 다시 무릎을 꿇고 내려앉으면 → [딥 하프가드](../techniques/deep-half-guard.md)
- 싱글 레그 X가 잡히면 → [싱글 레그 X 스윕](../techniques/single-leg-x-sweep.md)
- 상대가 무릎을 안으로 돌려 버티면 → [애시 가라미 (스트레이트 애시)](../techniques/ashi-garami.md)

## 방어하는 쪽 (상대 입장)

- 딥 하프 아래 상대가 내 오른쪽 발목을 잡아 가슴에 붙이고 다리를 풀면 싱글 레그 X 신호
- 일찍: 발목이 잡히기 전에 무릎을 꿇어 체중을 다시 실어 내린다
- 잡혔으면 상대 쪽으로 무릎을 눌러 내리고 → 싱글 레그 X 빠져나오기 (서서)
