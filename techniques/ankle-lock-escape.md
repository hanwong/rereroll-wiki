# 앵클락 빠져나오기 (Ankle Lock Escape)

[X 가드 · 싱글 레그 X · 앵클락](../positions/x-guard.md) · 방어 · 위 → [패스](../positions/passing.md)

다른 이름: 앵클락 디펜스

## 세팅 과정 (오른손잡이 기준)

1. 상대가 내 왼발에 앵클락을 걸었을 때, 바로 앉아 내 발목을 감은 상대 오른팔을 잡아 못 눕게 한다
2. 왼발 발끝을 위로 세워 발목이 안 펴지게 한다
3. 내 오른발로 상대 엉덩이나 발목을 밀며 왼다리를 뺀다
4. 위로 올라가 패스한다

## 핵심 디테일

- 상대가 눕기 전에 바로 앉아 내 발목을 감은 상대 오른팔을 잡는다 — 상대가 누우면 힘이 실린다
- 왼발 발끝을 세우고 왼쪽 무릎은 굽혀 둔다 — 다리가 펴지면 꺾인다
- 손으로 그립을 떼는 것과 내 오른발로 상대 엉덩이·발목을 미는 것을 같이 한다
- 빠지면 바로 일어나 위에서 패스 자세

## 흔한 실수

- 다리를 쭉 펴서 확 빼면 → 아킬레스가 더 조인다 → 무릎 굽히고 발끝 세운 채 뺀다
- 손 그립만 싸우고 상대 다리 조임을 놔두면 → 다리가 안 빠진다 → 오른발로 밀어 공간을 만든다
- 아픈데 참으면 → 발목 인대가 다친다 → 위험하면 바로 탭

## 막히면

- 상대가 두 다리로 꽉 조여 안 빠지면 → [무릎 빼기 (앵클락 상대)](../techniques/knee-extraction.md)
- 일어나는 중 상대가 다시 발목을 감아 오면 → [싱글 레그 X 빠져나오기 (서서)](../techniques/standing-escape-from-slx.md)
- 압박이 이미 아프면 → 바로 탭하고 다음엔 더 빨리 앉는다

## 방어하는 쪽 (상대 입장)

- 상대가 앉아 내 오른팔을 잡거나 상대 오른발이 내 엉덩이를 밀면 빠지려는 신호
- 미리 두 무릎을 모아 상대 왼쪽 허벅지를 조이고 내 오른쪽으로 빨리 눕는다
- 상대 발이 빠져나오면 겨드랑이 깊이 다시 끼우고 손목을 아킬레스에 붙인다
- 다리가 빠졌으면 발을 상대 골반에 대 싱글 레그 X 가드로 다시 잡는다
