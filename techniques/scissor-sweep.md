# 시저 스윕 (Scissor Sweep)

[클로즈드 가드](../positions/closed-guard.md) · 스윕 · 아래 → [마운트](../positions/mount.md)

다른 이름: 가위 스윕, 시저스 스윕

## 세팅 과정 (오른손잡이 기준)

1. 내 오른손으로 상대 오른쪽 깃, 왼손으로 상대 오른쪽 소매(또는 팔꿈치)를 잡고 상대를 앞으로 당긴다
2. 가드를 열고 엉덩이를 내 오른쪽으로 살짝 빼서 오른쪽 정강이를 상대 배 앞에 가로로 댄다(니 쉴드)
3. 내 왼다리는 바닥 가까이 내려 상대 오른쪽 무릎 바깥에 건다
4. 오른다리는 밀고 왼다리는 당기며(가위) 소매를 당겨 상대 오른쪽(내 왼쪽)으로 넘기고 마운트로 올라간다

## 핵심 디테일

- 깃과 소매를 당겨 상대 체중을 앞으로, 내 오른쪽 정강이 위에 싣게 한다
- 오른쪽 정강이는 상대 배 · 골반 앞에 가로로, 무릎은 상대 왼쪽 겨드랑이 쪽에 둔다
- 왼다리는 바닥에 붙여 상대 오른쪽 무릎 바깥을 쓸어낸다
- 상대 오른팔을 끝까지 당겨 상대가 오른손으로 바닥을 짚지 못하게 한다

## 흔한 실수

- 엉덩이를 안 빼고 정면에서 하면 정강이가 안 들어간다 → 내 오른쪽으로 엉덩이를 뺀다
- 소매를 놓으면 상대가 오른손을 짚고 버틴다 → 끝까지 당긴다
- 상대 체중이 뒤에 있을 때 하면 안 넘어간다 → 먼저 당겨 앞으로 싣는다

## 막히면

- 상대가 체중을 뒤로 빼고 자세를 세우면 → [힙 범프 스윕](../techniques/hip-bump-sweep.md)
- 상대가 오른손을 바닥에 짚으면 → [기무라 (가드)](../techniques/kimura-guard.md)
- 상대가 무릎을 붙여 다리가 안 걸리면 → [플라워 스윕 (펜듈럼)](../techniques/flower-sweep.md)

## 방어하는 쪽 (상대 입장)

- 상대 엉덩이가 빠지고 정강이가 내 배 앞에 가로로 오면 → 시저 스윕 신호
- 내 오른쪽 소매 그립을 떼어 오른손을 바닥에 짚을 수 있게 한다
- 엉덩이를 낮추고 체중을 뒤에 둬 정강이 위에 실리지 않게 한다
- 넘어가는 중이면 상대 다리를 감아 하프가드라도 잡는다
