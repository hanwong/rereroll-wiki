# 스택 패스 (스파이더 상대) (Stack Pass from Spider)

[스파이더 · 라쏘 · 소매 가드](../positions/spider-lasso.md) · 패스 · 위 → [사이드 컨트롤](../positions/side-control.md)

다른 이름: 스파이더 스택

## 세팅 과정 (오른손잡이 기준)

1. 소매를 잡은 상대 양손을 손목을 돌려 하나씩 끊는다
2. 상대 발이 내 이두에서 떨어지는 순간 두 팔을 상대 두 다리 아래로 넣어 깍지 낀다
3. 앞으로 밀어 상대 엉덩이를 들어 스택한다
4. 상대 두 다리를 내 왼쪽으로 넘기며 내 오른쪽으로 돌아 상대 왼쪽 사이드로 간다

## 핵심 디테일

- 상대 발이 내 이두에서 떨어지는 순간(트라이앵글·오모플라타 시도)이 들어갈 신호
- 손이 아니라 엉덩이와 다리로 앞으로 걸어 상대 엉덩이를 띄운다
- 내 가슴을 상대 허벅지에 붙여 공간을 주지 않는다
- 돌 때는 작은 걸음으로 상대 머리 쪽으로 돌며 체중을 계속 싣는다

## 흔한 실수

- 소매 그립이 남은 채 스택하면 상대가 소매를 당겨 트라이앵글을 건다 → 손목을 돌려 그립부터 끊는다
- 엉덩이를 들고 누르면 상대가 다리로 띄운다 → 엉덩이를 낮춘다
- 깍지가 느슨하면 상대가 다리를 빼 가드를 되찾는다 → 두 팔로 허벅지를 꽉 감는다

## 막히면

- 상대가 엉덩이를 옆으로 빼 스택이 풀리면 → [토레안도 패스](../techniques/toreando-pass.md)
- 상대 다리 하나가 내 다리에 감기면 → [하프가드](../positions/half-guard.md) 위에서 [패스](../positions/passing.md)를 이어간다
- 상대 다리가 내 목에 걸리면 → [트라이앵글 스택 탈출](../techniques/stack-escape-from-triangle.md)

## 방어하는 쪽 (상대 입장)

- 상대가 내 두 다리 밑으로 팔을 넣어 깍지를 끼면 스택 신호
- 깍지가 끼기 전에 발을 상대 골반이나 이두에 다시 대 거리를 만든다
- 들리기 시작하면 엉덩이를 옆으로 빼 무릎을 상대 가슴 앞으로 넣는다
- 이미 접혔으면 턱을 당기고 상대가 도는 쪽으로 같이 돌아 하프가드라도 잡는다
